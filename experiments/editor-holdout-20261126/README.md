# 새 문학·우주과학 기사에서 원자료 검색 점검

사전에 고른 주장 6개 가운데 지정한 원자료로 확인할 수 있었던 주장은 4개였다. 편집 도구에 기사 문장을 그대로 넣었을 때, 상위 세 검색 결과에 필요한 근거가 모두 들어간 주장은 그중 2개였다. 기사 두 편의 핵심 주장만 보면 2개 중 1개였다.

## 기사와 기준 자료

- **K-공감, 2024년 10월 17일.** 한강의 노벨 문학상 수상을 다룬 한국어 기사다. 수상일과 수상자, 수상자의 인터뷰 발언, 서점 판매량을 골랐다. 한국어 문장을 영어 원자료에서 검색했다. 수상 발표문 전체에서 시상 주체부터 선정 사유까지 6개 단락, 10월 전화 인터뷰의 제목부터 마지막 인사까지 40개 단락을 순서대로 붙였다. [보도 원문](https://gonggam.korea.kr/newsContentView.es?mid=a12605000000&section_id=NCCD_CULTURE_TOTAL&news_id=f547fd9c-62f7-4f67-9c34-e2d1ccbaf293) · [스웨덴 한림원 발표](https://www.nobelprize.org/prizes/literature/2024/press-release/) · [한강 전화 인터뷰](https://www.nobelprize.org/prizes/literature/2024/han/interview/)
- **KEYT에 실린 CNN 보도, 2024년 6월 18일.** 보이저 1호 과학 관측 복구를 다룬 영어 기사다. 기기 네 대의 복구 상태, 5월 19일 명령, 재교정 필요성을 골랐다. 세 주장은 같은 보도 단락에서 나왔다. NASA의 6월 13일 임무 발표에서 요약문부터 보이저 1호 거리까지 6개 단락을 사용했다. [보도 원문](https://keyt.com/news/national-world/cnn-other/2024/06/18/voyager-1-sends-back-science-data-from-more-than-15-billion-miles-away-after-nasa-fix/) · [NASA 임무 발표](https://science.nasa.gov/missions/voyager-program/voyager-1/voyager-1-returning-science-data-from-all-four-instruments/)

## 무엇을 맞혔나

표의 번호는 원자료별 단락 번호다. 상위 세 후보 안에 필수 단락을 **모두** 직접 제시한 경우를 완전 적중으로 셌다. 양옆 미리보기는 제외했다. 발표문의 날짜와 수상자는 서로 다른 단락에 있으므로 1위 한 단락만으로는 해당 주장의 조건을 채울 수 없다.

| 선정 주장 | 원자료 대조 | 필요한 근거 | 도구가 제시한 상위 후보 | 결과 |
| --- | --- | --- | --- | --- |
| 10월 10일 한강의 문학상 수상 발표 **(핵심)** | 지지 | 발표 2·5 | 발표 2 | 날짜만 회수 |
| 한국문학 독자와 동료 작가들에게 좋은 소식이기를 바란다는 한강의 발언 | 지지 | 인터뷰 26 | 없음 | 미적중 |
| 10월 16일 오전 9시 서점 3사 종이책 판매 103만 2천 부 | 미결 | 서점 집계 필요 | 발표 2 | 판매량 근거 없음 |
| 6월 13일 기준 네 기기 모두 쓸 수 있는 과학 자료 전송 **(핵심)** | 지지 | NASA 3 | NASA 3·4·5 | 1위 적중 |
| 5월 19일 과학 자료 전송 명령 | 지지 | NASA 3 | NASA 3·5·2 | 1위 적중 |
| 나머지 두 기기에 재교정이 필요했음 | 미결 | 작업 종류를 밝힌 자료 필요 | NASA 3·5·6 | NASA 3은 추가 작업만 언급 |

- **원자료 대조 범위**는 선정 주장 6개 중 지지 4개(66.7%), 미결 2개(33.3%), 명시적인 반박 0개다. 판정이 가능한 4개만 분모로 잡으면 지지는 4/4다. 두 핵심 주장 모두 원자료가 지지했다. 미결 두 건은 실제 오류 개수에 포함하지 않았다.
- **도구의 근거 검색**에서 지지 가능한 4건의 완전 적중은 1위 2/4, 상위 3위 2/4로 각각 50%였다. 선정한 6건 전체를 분모로 한 상위 3위 완전 근거 확보율은 2/6(33.3%)이었다. 핵심 주장은 1/2, 영어 보도는 2/2, 한국어 보도는 0/2였다. 영어 성공 두 건의 근거가 같은 NASA 단락이어서 두 개의 독립 자료에서 성공한 것으로 해석할 수 없다.
- **검색과 최종 판정**에서 미결 2/2에도 후보가 표시됐다. 편집 도구는 6개 행을 모두 검토 대기 상태로 두었다. 미결을 발견하거나 참·거짓을 판정하는 기능의 정확도는 측정하지 않았다.
- **분모와 적용 범위.** 도구가 기사 전체를 각각 81행과 33행으로 나눴고, 지정한 6개 행을 모두 찾았다. 나머지 108행에 대해서는 원자료 대조를 하지 않았다. 에이전트 한 명이 구간을 목적 표집하고 검색 출력 확인 전 기준을 작성했다. 기사 전체의 사실 정확도, 정치적 편향 감소율, 편집자의 실제 시간, 편집자 간 판정 일치도는 이 실험으로 추정할 수 없다.

## 고정 순서와 재현

1. 보도와 당시 공식 원문을 읽고, 정규화한 판본 5개와 구간·판정·채점 방식을 [key.json](key.json)에 기록했다. 2026-11-26 14:13:05 UTC에 고정하고 첫 검색 전에 해시를 공유했다. SHA-256은 `d6f28e1b5896376b81d6743b11fbe2d08589aa8b472f216b35c6332c8bac0567`이다. 날짜·시각은 실행 환경의 시계로 기록했다.
2. 같은 날 14:13:40 UTC에 편집 도구 기준 커밋 `9b62cce015ef3fbc988a6e1da75c023ef4971358`의 기사 분할·근거 검색 함수를 호출했다. 지정 행을 쿼리로 쓰고, 번역이나 검색어 수정 없이 편집 화면 기본값과 같은 후보가 나오는지도 검사했다. 브라우저 조작 시간은 측정하지 않았다. 행 번호·검색어 해시·결과 순위는 [result.json](result.json)에 있다. SHA-256은 `149aafc78451184a9fd791e90eb6314426862009c4364ff2f73cc9ef6ab62b43`이다.
3. 14:14 UTC에 공개 URL 다섯 곳에서 다시 내려받아 모든 판본 해시와 여섯 검색 결과가 동일함을 확인했다. 원문 HTML은 각 실행자의 임시 폴더에만 저장한다. 저장소에는 좌표, 짧은 검색용 표시 문구, 재서술한 주장과 결과를 남겼다.

저장소 루트에서 기존 Node 의존성을 설치한 뒤 다음을 실행한다. 공개 사이트의 본문이 바뀌면 판본 검사에서 멈춘다. 최초 판본 HTML을 보관하고 있다면 그 폴더를 두 번째 명령에 넘길 수 있다.

```sh
raw_dir="$(node experiments/editor-holdout-20261126/download.cjs)"
node experiments/editor-holdout-20261126/replay.cjs "$raw_dir" --check
```

## 근거를 직접 읽은 별도 AI의 판정

검색 시험 뒤, 별도 AI 판독자에게 순서를 섞은 영문 주장 6개와 위 원자료의 번호 붙은 52개 단락만 제공했다. 판독자는 사전 정답, 원문 외부 링크, 기사별 검색 순위를 제공받지 않았다. 한국어 보도의 주장도 영문으로 재서술한 상태였다. 이 과정에서 편집 도구가 찾은 후보로 읽을 범위를 제한하지 않았다. 판독자의 답과 인용 좌표를 [blind-answers.json](blind-answers.json)에 원형대로 보존했다.

| 판독 지표 | 결과 |
| --- | --- |
| 6개 전체의 판정 일치 | 5/6 (83.3%) |
| 기준상 지지된 주장 중 판정이 일치하고 필수 단락도 전부 인용 | 3/4 (75%) |
| 기준상 지지된 주장 중 필수 단락을 전부 인용 | 4/4 (100%) |
| 기사별 핵심 주장 판정 일치 | 1/2 (50%) |
| 기준상 미결인 주장 판정 일치 | 2/2 (100%) |

보이저 복구 시점을 묻는 C6에서만 판정이 갈렸다. 판독자가 인용한 NASA 3번 단락은 네 기기가 유효한 자료를 보내고 있다고 확인한다. 제공된 여섯 단락에는 발표일인 **6월 13일**이 없다. 판독자는 기기의 상태는 지지되지만 날짜를 검증할 수 없어 전체 주장을 미결로 남겼다. 사전 기준을 작성할 때 본 공개 페이지에는 6월 13일이 표시되고, 재확인한 게시 메타데이터의 값은 `2024-06-13T19:48:23-04:00`이었다. 사전 기준 작성자와 판독자가 받은 날짜 정보가 달랐으므로 이 한 건으로 판독자의 사실 오류를 단정하기 어렵다. 검색표는 동결한 단락 좌표대로, 판독 점수는 원래 답과 동결한 판정대로 유지했다. [NASA 발표 원문](https://science.nasa.gov/missions/voyager-program/voyager-1/voyager-1-returning-science-data-from-all-four-instruments/)

아래 명령은 저장된 답안의 여섯 ID, 사전 기준·답안 해시, 인용 좌표와 지표별 분모를 검사하고 점수를 다시 계산한다. 마지막 명령은 공식 자료로 판독 입력까지 재구성해 원래 입력 SHA-256 `fcdf65c99252dd9e6257ec1d5a4199a28bee2575250670ad17c0c4dbf6a78861`와 비교한다. 같은 AI가 새로 답변하는 실험은 재실행하지 않는다.

```sh
node experiments/editor-holdout-20261126/score-blind.cjs
node experiments/editor-holdout-20261126/score-blind.cjs "$raw_dir"
```

여섯 답의 일치도는 이 판독자 한 명과 사전에 작성한 기준 사이의 값이다. 사람 편집자 평가와 비교하지 않았으며, 반박 판정이 정답인 사례가 없어 틀린 기사를 가려내는 성능도 측정하지 못했다.

# v18 반복 기록 — 사전 실행 항목

| 단계 | 해결 대상 | 변경 | 반증 조건 | 관측 결과 | 다음 행동 |
|---|---|---|---|---|---|
| 자연 전체 기사 개발 | 유도된 문장 단위 시험에서 드러나지 않은 중요 결함·교차문장 손실 | 방법 변경 없음. 새 자연 원문 2건을 처음부터 끝까지 최소편집; 원생 전체 출력 검사 | 중요 결함 미탐지, 불필요한 편집/보류, 새 의미 손실, exact 전달 실패 | 실행 전, 미관측 | 개발 원기록으로 원인 확인; 실제 실패가 있을 때만 최소 변경 |
| 미사용 전체 기사 평가 | 개발 개선의 전이 또는 고정법의 새 범위 성능 | 개발 후 버전·해시 동결; 새 4건 | 위와 같음; 사전 분모·미확정 유지 | 실행 전, 미관측 | 독립 감사와 기존 회귀 결과로 다음 행동 결정 |

이 표의 예정 단계는 실행·성공·새로운 접근 횟수가 아니다. 관측 결과는 원출력/감사 파일과 함께 후속 행 또는 별도 결과 문서에 기록하며 사전 조건을 덮어쓰지 않는다. 자연 기사 평가로 이동한 것만으로 새로운 해결 메커니즘을 시도했다고 세지 않는다.

v1–v16까지 확인된 실질적 접근 하한은 보존목록 4, 최소편집 부작용 8, AI 판정 불일치 4이며 같은 문제의 서로 다른 접근 10회 실패는 입증되지 않았다. 이는 역사 기록의 하한으로 전체 상한이나 실패 횟수와 동일하지 않다. v17 추가 연결 점검은 기존 메커니즘의 명시성 비교이고 관측 이익 없음이며, 표지 명료화·직렬화 수정은 의미 보존의 새 일반 해법으로 부풀리지 않는다. 이번 회차의 구체 수정이 생기면 기존 접근과 실질적으로 다른지 원인·작동 방식·근거를 확인한 뒤에만 원장에 추가한다.

## 실질적으로 다른 접근 수 갱신

확인된 하한은 계속 P1=4, P2=8, P3=4이며 잔여 실패 가족 하한은 1·4·1이다. v18의 전체 기사 적용은 기존 A02/A04, 입력 인용 지칭 수리는 A04의 계약 수정, 상호 의존 폐쇄는 A09의 구현 수리, 별도 감사·이견 추적은 A11/A12의 적용이다. 문장 추가·새 버전·새 기사·재생을 새 접근으로 세지 않는다. 같은 문제의 서로 다른 10개 실패는 아직 확립되지 않았고 초기 기록 때문에 역사 상한은 unknown이다. 전달 차단과 선택적 과잉 추가를 새로운 의미 손실로 위장해 실패 수를 올리지 않았다.

최종 후속: K183 첫 조립 후보와 측정 조건 복원 후보의 hold를 보존했다. 불확실한 질병 문장 수정 P3를 제외하고 측정 조건·분석물 범위 P1/P2만 함께 적용한 네 번째 조립 후보는 같은 감사자의 실제 전체문 재검토에서 accept_local, overall_readiness=unknown이었다. 새로운 독립 감사자·모델 작성·미사용 표본으로 세지 않는다. 원 호흡기 문장은 참으로 인증하지 않고 대응 근거를 기다린다. 세포 연구 직접 링크 계보와 실제 초록은 확보했으나 확인한 출판사·저장소 전문 경로는 403 또는 파일 없음이었다. [근거 공백](source-gap.md)과 [후속 해시](followup-hashes.json)를 남겼다.

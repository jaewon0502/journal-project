# v18 한국어·영어 전체 기사 최소편집 결과

새 실제 기사 6건을 처음부터 끝까지 읽고 정책·기업/소비자·과학 분야에서 기존 최소편집 절차를 시험했다. **동결 평가 4건에서 사전 AI 참조가 필수로 정한 5항목 중 3항목을 안전하게 전달했다.** 나머지 2항목은 당시 감사에서 의미상 적절한 제안으로 판단했지만 적용기의 순환 의존 거절로 전달하지 못했다. 후속 감사에서는 그중 질병 단정 수정의 필요성에 이견이 나왔으며 아래에 분리해 보고한다. 이후 코드 수리나 노출 사례 재검증으로 이 결과를 소급 변경하지 않았다.

전체 실제 작성은 개발 v1 2개, 개발 v2 2개, 평가 4개, 이전 회귀 2개로 10출력이다. 별도 기준 작성 8개와 원출력 감사 10개는 작성 출력이나 새 사건 수에 합산하지 않았다. 두 사례에서 후속으로 조립한 네 후보도 새 모델 작성으로 세지 않았다.

## 실제로 고친 것과 아직 못 고친 것

모바일 주민등록증 기사에서는 빠진 월만 복원하고 다른 단계별 날짜를 유지했다. 개발 첫 출력은 인용 칸에 수정 후 문장을 넣어 실패했지만 입력 원문을 인용하도록 명시한 재실행은 통과했다. 이는 출력 계약의 국소 수리다.

eVisa 기사에서는 영주권자의 종이 증명 예외만 남기고 필수성이 확인되지 않은 일반 입국 조건 추가를 되돌렸다. 별도 감사는 이 후보를 국소 수용했다. 12월 3일 기사와 12월 4일 공식 확인을 구별하고 기존 정부 책임·피해 호소·비판을 유지했다.

미세플라스틱 기사에서는 최초 감사가 분석물 범위와 인체 질병 유발의 단정 정정을 지지했다. 그러나 선택적 설명을 줄이는 과정에서 **17/22명이 정량한계를 넘었다는 결과를 단순 검출률처럼 남긴 문제**가 드러났다. 80% 반올림이 문제라는 뜻은 아니다. 첫 후보는 보류했다. 정량 조건만 다시 넣은 다음 후보에서 측정 조건·분석물 범위는 복구됐지만, 질병 단정 문장은 별도 호흡기 연구를 가리키므로 현재 원자료만으로 필수 수정임을 확정하기 어렵다는 새 감사 이견이 남았다. 마지막으로 질병 문장 수정은 보류하고 제목·본문의 측정 조건과 분석물 범위만 함께 고친 후보를 만들었다. 같은 감사자의 이어진 검토에서 이 두 패치가 국소 수용됐다. 질병 원문을 그대로 둔 것이 그 진실을 인증하는 것은 아니며, 기사 전체 준비 상태는 미확인이다. 확인된 측정 조건 복구와 남은 근거 공백을 구별한다. 필요한 조건까지 불필요한 세부사항으로 제거하면 안 된다는 재현 가능한 실패는 그대로 보존한다.

## 해석 범위

한국어 3건·영어 3건 중 정부 정책 기사가 1건이고 영어 3건은 같은 매체다. 독립 매체 6곳의 대표 표본이 아니다. 기사 본문은 전체지만 원자료 일부는 제한된 구간이며, K183은 최종 출판본이 아닌 공개 저자 교정 전 원고다. 후속 자료를 보도 당시 지식으로 소급하지 않았다. 정상 대조란 제공 근거에서 필수 수정이 확립되지 않았다는 뜻이다.

인간 평가는 0명이다. 모델은 상속된 설정으로 실행했고 정확한 배포 버전·시드·토큰 비용은 확인할 수 없었다. 실제 파일 문자 수는 작성 입력 469,691자, 출력 131,709자이며 비용으로 환산하지 않았다. 독자 이해나 정치적 편향 감소는 측정하지 않았다.

실질적 접근 수의 확인된 하한은 보존목록 4, 최소편집 부작용 8, 평가 불일치 4다. 잔여 실패 가족 하한은 각각 1·4·1이며 같은 문제의 서로 다른 접근 10회 실패는 아직 입증되지 않았다. 계약·코드 수정과 재실행을 새 원리로 세지 않는다.

상세 수치와 출처는 [RESULTS.md](RESULTS.md), 후속 수리와 실패는 [followup-results.md](followup-results.md), 바로 적용할 절차는 [usable-procedure.md](usable-procedure.md)에 있다.

추가로 실제 세포 연구의 인용 계보와 초록까지 확인했지만 정확한 손상 용어를 확인할 본문은 확보하지 못했다. 별도 호흡기 주장에 대응하는 연구도 현재 자료에는 없다. 접근 범위와 필요한 입력은 [source-gap.md](source-gap.md)에 기록했다. 코드 검사 213개 메서드·16개 모음이 통과했으며 이 검사 중 새 모델 호출은 0회다.

# v18 전체 기사 최소편집 실험 패키지

한국어·영어 새 기사 6건과 이전 노출 회귀 2건에서 실제 최소편집 출력과 별도 AI 감사를 보존했다. 개발·미사용 평가·회귀·노출 후속을 분리한다. 본실험은 작성 10출력이며 추가로 조립한 두 사례의 네 후속 후보는 모델 출력이 아니다.

- [한국어 요약](SUMMARY.md): 세 문제의 현재 상태와 남은 실패.
- [본실험 결과](RESULTS.md): 동결 분모, 사례별 결과, 출처 범위와 비용 측정 한계.
- [후속 진단](followup-results.md): 적용기 수리, 선택적 롤백, K183 보류와 E183 판정 차이.
- [사용 절차](usable-procedure.md): 필요한 부분만 고치고 불확실하면 중단하는 방법.
- [사전 등록](PREREGISTRATION.md), [반복 기록](iteration-ledger.md), [별도 판정](scope-disagreement.md).
- [추가 원자료 공백 확인](source-gap.md): 세포 연구 인용 계보·접근 결과·남은 호흡기 근거.
- [원자료 메타데이터](sources-metadata.json), [원출력 해시](raw-hashes.json), [집계 수치](results-summary.json).

공개 패키지는 기사 전문을 포함하지 않는다. 비공개 원문·원생 전체 출력·적용문·초기 판단·감사와 입력 해시는 별도로 보존했다. 공개 코드 검사는 합성 데이터로 계약을 확인하며, 실제 기사 결과 재생에는 승인된 원자료 사본이 필요하다.

```bash
python experiments/v18/aggregate.py --private-root PRIVATE_ARTIFACT_DIRECTORY --output replay-summary.json
```

이 명령은 저장 출력을 재생하며 새 AI를 실행하지 않는다. 원실험 검증기를 유지하므로 이후 v3 적용기 판정을 소급 적용하지 않는다. 사람 평가·유료 독립 모델을 사용하지 않았고 런타임 설정은 상속했다. 원격 저장소·공유 Page·계정 설정을 변경하지 않았다.

코드 검사는 16개 모음의 213개 테스트 메서드가 통과했다. 이 과정의 새 모델 호출은 0회다. 코드 검사를 실제 기사 정확도 평가로 합산하지 않는다. 원격 PR5 관련 통보는 아직 검증·통합하지 않았으며 이 로컬 결과에 포함됐다고 주장하지 않는다.

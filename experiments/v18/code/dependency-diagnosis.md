# 패치 동시 적용 의존성 진단과 별도 v3 어댑터

동결된 v18 실행에서 상호 의존 패치가 거부된 실패 결과는 그대로 유지한다. 이 진단과 v3 어댑터는 동결 검증기, 원시 출력, 스키마, 원래 실행 결과 및 실행기 설정을 변경하지 않는다.

작성 지침은 `depends_on`을 필요한 동시 적용을 기록하는 필드로 정의하고, 제안된 모든 패치를 모델이 직접 출력한 전체 기사에 반영하도록 요구한다(`writer-v2.md` 11행). 패치 스키마는 의존 대상 ID 배열을 요구하지만 비순환 그래프(DAG) 조건은 명시하지 않는다. 동결된 v17의 `check_output.py` 65–73행은 대상 ID 누락을 검사한 뒤 순환을 거부하며, v18은 이 함수를 가져와 사용한다. 그러나 실제 적용은 의존성 탐색 순서가 아니라 원문 위치의 역순으로 수행한다(v17 81행). 따라서 서로 다른 패치가 모두 존재하고 원문 구간이 겹치지 않는다면, 상호 의존만을 이유로 거부하는 것은 명시된 동시 적용 계약에 비추어 구현상의 잘못된 차단이다. 이것이 패치 내용의 사실적 타당성이나 최소 수정 요건 충족을 뜻하지는 않는다.

선택된 패치 집합 S에 대해, 필요한 동시 적용 조건은 S의 각 패치가 선언한 모든 의존 대상도 S에 포함되어야 한다는 것이다. 상호 의존하는 패치들은 함께 적용되어야 한다. 더 큰 순환이나 그룹 밖으로 향하는 의존성도 같은 조건을 따른다. 이 인터페이스에서는 선언된 모든 패치를 선택하며, 일부만 묵시적으로 선택하지 않는다. 같은 그룹이라도 원문 구간이 겹치면 거부한다. 모든 앵커는 입력 원문에서 유일하게 확인되어야 하므로, 앞선 치환으로 새로 생긴 앵커도 허용하지 않는다. 의존성 순서는 순차적인 텍스트 변환을 허용하는 근거가 아니다.

`check_output_v3.py`는 별도 이름의 어댑터다. 변경하지 않은 출력에 대해 스키마, 패치 ID의 유일성, 의존 대상의 존재 여부, 중복 및 자기 의존을 먼저 검사한다. 이어 깊은 복사본의 의존성 목록만 비우고 동결된 v18 검증기를 호출한다. 따라서 원래 의존성 정보를 확인한 후 기존 DAG 검사만 우회한다. 선언된 모든 패치는 기존의 finding 연결, 수정 필요성, 출처 인용, 의미 보존, 안전성, 앵커 유일성, 구간 중복, 보류, 보호 앵커 및 전체 기사 출력 일치 검사를 그대로 거친다. 입력 데이터는 변경하지 않는다. v3에서 자기 의존과 중복 의존을 잘못된 선언으로 거부하는 것은 별도로 명시한 직렬화 규칙이며, 동시 적용 논리 자체가 비순환성을 요구한다는 주장은 아니다.

운영 실행기는 v3로 전환하지 않았다. 저장된 모델 출력에서 상호 의존을 지우거나 원래 실패를 성공으로 바꾸면 안 된다. 재검증은 기존 출력에 다른 검증기를 적용했을 때의 기계적 수락 여부를 보는 반사실적 재검증으로 표시해야 한다. 새 모델 생성, 독립 반복 실험 또는 정확도 향상으로 집계하지 않는다. 원래 전달된 수정에 대한 결과는 변경하지 않는다.

검증 결과: `python test_atomic_dependencies.py`의 합성 테스트 16개가 통과했다. 완전한 상호 의존 및 세 패치 순환, 의존 대상 누락, 일부 선택 시 의존 조건, 전체 기사 일부만 반영한 출력, 구간 중복, 치환으로 생성된 앵커, 패치 목록 순서 독립성, 안전성의 unsafe/unknown 값, 필요성·근거·의미 보존·문맥 안전성의 각 조건, 잘못된 출처 ID, 중복 패치 ID, 중복 의존, 자기 의존 및 입력 불변성을 검사한다. 동결 검증기의 상호 순환 거부도 명시적으로 확인한다. 기존 v17 테스트 10개와 v18 테스트 3개도 통과했다. 합성 문장을 사용한 테스트이므로 의미적 정확성의 증거는 아니다.

저장된 출력 10개에 대한 비공개 기계적 재검증에서는 K183-v2만 `cyclic patch dependency` 거부에서 수락으로 바뀐다. K181-v1은 여전히 `inexact article quote`로 거부되며, 나머지 8개의 수락 결과는 유지된다. 상세 재검증 기록은 비공개로 별도 보관한다. 공개용 `counterfactual-replay-summary.json`에는 허용 목록에 따라 출력 식별자, 원래 검증과 v3 반사실적 검증의 판정 및 해시만 담았다. 기사 전문이나 비공개 경로는 포함하지 않는다. 이 결과는 기계적 호환성을 확인할 뿐, 가장 작은 적절한 수정이라는 요건이나 사실적 타당성을 입증하지 않는다.

사실적 정확성, 필요한 수정의 누락, 부수적인 의미 손실 및 선택적 설명 추가는 원래 기사와 적용 가능한 출처를 대조하는 독립 감사로 평가해야 한다. 의존성 의미를 판단하기 위한 이 코드 진단 때문에 원문 진실성 감사를 추가로 수행할 필요는 없으며, 별도로 배정된 감사를 중복하거나 대체해서도 안 된다. 완료된 독립 감사 결과를 기계적 검증 보고와 함께 제시하되 각 결과가 뒷받침하는 주장은 구분한다.

# v18 사전등록: 새 전체 기사에서 최소편집의 실제 결함 탐지

이 문서는 새 기사 내용·참조·작성 결과를 보지 않고 작성했다. 원자료의 모든 의미를 완전히 보존한다는 추상적 보장 대신, 전체 기사 작업에서 재현 가능한 중요한 누락·오류·편집 부작용을 확인한다. 실행 동결은 조율자가 검사 코드·지시문·입력·참조 파일의 해시와 시각을 기록한 뒤 성립한다. 이 문서 생성만으로 동결 완료라고 하지 않는다.

## 표본과 노출 경계

새 실제 기사 6건: 개발 K181(한국어 정책), E183(영어 과학); 평가 E181(영어 정책), K182/E182(한국어/영어 기업·소비자), K183(한국어 과학). 수집 과정에서 실제 사건·원자료 계보의 기존 중복, 본문/원자료 접근 차단, 수집 누락은 제외 사유와 함께 기록한다. 수집 범위와 접근 시각·버전·해시를 보존한다. 전문은 비공개 원기록에만 보관하고 공개에는 최소 인용·링크·위치를 사용한다.

원문 전체를 그대로 후보 C=O로 사용한다. 오류를 주입하거나 대상 결함을 질문으로 암시하지 않는다. 기사 제목·부제·본문·공급된 캡션을 처음부터 끝까지 읽는다. 원자료도 실제 공급 범위를 전부 읽되 전체 법령·연구·이미지 등을 확보했다고 확대하지 않는다. 정상 비율은 사전 AI 참조의 no_established_necessary_repair로 관찰하며 임의 정상/오류 수를 맞추지 않는다. 정상 기사가 부족해도 오류 주입이나 사후 선별로 채우지 않는다.

## 고정 방법과 전달물

v17의 단순 BASE 최소필요편집을 유지한다. 추가 연결표나 새 아키텍처 없이, 원문과 근거를 읽고 필요한 정확한 절만 고치며 전체 맥락에서 결합 효과를 확인한다. 임의 길이 상한·요약 목표는 없다. 보호 항목은 짧은 원문 구간과 관계·이유·불확실성을 기록하지만 정답 목록으로 취급하지 않는다.

필요성·근거 지지·다른 의미 보존·맥락 안전이 모두 yes일 때만 유일하고 겹치지 않는 exact patch를 적용한다. 원문의 사실 오류를 근거로 고치는 것은 허용한다. original_proposition_changed는 변경 사실만 나타내고 사실 오류·부작용과 분리한다. 가치 선호만으로 수정하지 않는다. 본문 출력 full_edited_article은 작성 모델이 실제 완전한 텍스트로 내며, 기계적으로 패치를 적용한 결과와 문자 단위로 일치해야 한다. 패치 밖 문장·공백·문장부호를 임의 정규화하지 않는다. 불일치는 전달 무결성 실패로 별도 집계하고 성공으로 보정하지 않는다.

## 평가 순서와 반증 조건

각 기사의 별도 문맥 AI 사전 참조를 작성 출력 전에 동결한다. necessary_repair / no_established_necessary_repair / uncertain을 구별한다. 이는 인간 정답이 아니다. 실제 확인 가능한 중요 결함을 놓침, 불필요한 수정·부당한 국소 보류, 새 의미 손실, 전달 실패 중 하나라도 발견하면 그 항목의 성공 주장을 반증한다. no_change나 전부 보류는 탐지 성공을 자동으로 얻지 못한다.

별도 감사자는 방법 이름을 가린 단일 출력에 대해 (1) 전체 O/S 독립 판단을 저장하고 (2) 실제 수정문 전체를 읽은 판단을 저장한 뒤 (3) 동결 참조를 읽어 대조한다. 앞선 판단을 덮어쓰지 않는다. 보호목록에 없는 정보도 원문·근거에서 다시 찾는다. 문장 간 귀속·강도·시간 순서·조건·책임/비판 대상을 양방향으로 검사한다. 파일 접근 순서는 지시 기반이며 기술적 격리를 보장하지 않는다.

고정 참조의 필요 결함별 탐지/미탐지, 안전하게 전달된 수정/실패/보류/미확정, 필요 수정이 입증되지 않은 기사에서 불필요한 패치·부당한 보류를 보고한다. 새로 찾은 결함은 별도 추가 발견 표에 두고 원분모를 소급 변경하지 않는다. 잘못된 참조의 정정·민감도 분석은 원판정을 보존해 별도 보고한다. 원자료 사실 이견, 의미/기준 해석 이견, 가치 선호 이견을 분리한다. 단일 성공점수·정치편향 감소율로 합치지 않는다. 불확실한 부작용을 0으로 숨기지 않는다.

## 개발 후 검증

개발 2건에서 중요한 재현 실패가 발견되면 원인에 맞는 가장 작은 변경 한 가지를 명시하고, 변경·반증조건·검사 계획을 평가 출력 전에 동결한다. 해당 실패의 노출 재검사는 회귀이며 새 평가가 아니다. 구체 실패가 없으면 지시문을 늘리지 않고 기존 절차로 미사용 평가 4건을 실행한다. 평가 사례를 보고 바꾼 방법은 해당 사례를 더는 미사용 평가라고 부르지 않는다. 개선 시 기존 회귀집합을 별도 검증하며 재생·단위검사와 새로운 모델 출력을 구별한다. 실제 중요 결함이 남으면 그 원인을 근거로 다음 행동을 정하고, 단지 보고서 작성 완료를 중단 이유로 삼지 않는다.

## 실행·한계·집계

신규 작성은 기사당 새 문맥 1회가 기본이며 참조/감사 호출과 개발 재검사를 따로 센다. 동일 inherited runtime/model effort를 유지하고 정확한 배포 버전·모델 시드·토큰·금액은 제공되는 메타데이터까지만 기록한다. 입력/출력 문자·바이트와 실제 벽시계 구간은 측정하되 토큰·금액·모델 연산시간으로 부르지 않는다. 현재 회차 실제 인간 평가 0명. 기관 기사나 같은 원자료 계보의 기사 수를 독립 증거 수로 세지 않는다. 표본 6건과 AI 내부 판정으로 일반적 무결함·완전성·한국 언론 전체 성능을 주장하지 않는다.

# v18 전체 기사 편집: 고정된 본실험 결과

새 실제 기사 6건(한국어 3·영어 3)을 처음부터 끝까지 읽고 최소 편집했다. 개발 2건으로 인용 필드 오류를 수정한 뒤, 미사용 평가 4건에 v2를 고정했다. 평가의 사전 필수 수정 5항목 중 안전하게 전달된 수정은 **3항목**이다. 나머지 2항목은 의미상 적절한 제안을 생성했지만 패치 순환 의존으로 검증기를 통과하지 못했다. 성공으로 바꾸어 계산하지 않았다.

이는 사람이 확정한 정답이나 언론 전체 정확도가 아니다. 별도 문맥의 AI가 출력 전에 만든 기준과, 원문·원자료를 먼저 읽은 별도 AI의 실제 출력 감사를 대조한 결과다. 자료 수집, 의미 판정, 기계적 전달을 하나의 성공 점수로 합치지 않는다. 이후 v3 또는 선택적 롤백은 노출된 사례의 후속 실험이며 아래 본실험 분모를 바꾸지 않는다.

후속 유의사항: K183 질병 단정 정정은 뒤의 원자료 재검토에서 필요성이 미확립으로 판정되어 최종 선택 후보에서 보류했다. 위 수치는 당시 동결 AI 참조·감사에 대한 기록이며 현재까지 모든 필수성을 확정한 정답표가 아니다. [후속 판정과 최종 후보](followup-results.md)를 함께 확인해야 한다.

## 세 문제에서 실제 발견한 내용

### 1. 보호정보 목록 밖의 문제 찾기: 부분 해결

감사자는 작성자의 보호목록을 먼저 보지 않고 원문과 제공 원자료를 읽어 초기 판단을 저장했다. E182에서는 가입과 해지 절차의 잘못된 연결, 소 제기 직전 일부 가입자에게 적용된 해지 절차 개편의 누락을 독립적으로 찾아냈다. 수정문은 이 두 내용을 고치면서 규제기관의 **주장**이라는 귀속, 기업의 부인, 경영진의 책임에 관한 주장과 비판을 유지했다. 공식 발표를 판결로 승격하지 않았다.

K183에서는 인체 질병 유발이 확정됐다는 단정과, 분석 대상인 스티렌계 고분자를 폴리스티렌 하나로 좁힌 서술을 각각 독립적으로 확인했다. 서로 다른 두 문제를 한 오류의 중복 표지로 부풀리지 않았다. 한편 K181의 월 누락은 사실 오류·조건 누락 두 이름이 붙어도 한 항목이다.

보호목록의 완전성이 확인된 것은 아니다. K182의 기업 발언 진위와 빠진 수정 첨부자료, E183의 배경 통계·인터뷰 원문 등은 현재 자료로 검증되지 않았다. 누락된 근거는 거짓의 증명이 아니다. 독립 감사가 발견한 **새 해석 이견**과 확립된 사실 오류를 분리했다.

### 2. 조건·반론·시점 보존: 의미 보존과 전달 실패가 갈렸다

K181은 전국 발급 시점에서 빠진 **3월**만 복원했고, 다른 문장의 2월 28일 단계 전환과 3월 14일 지역 확대는 유지했다. v1의 실제 완성문 의미는 적절했으나 원문 인용 필드에 수정 후 문자열을 넣어 전달 계약에 실패했다. v2는 인용 필드가 반드시 원문 부분문자열이어야 한다는 한 문장을 추가했고 재실행에서 통과했다. 의미 정확도 향상과 출력 계약 수리를 구분한다.

E181은 다음 날 발표된 공식 자료의 영주권자 종이 증명 예외를 **12월 4일 확인**으로 표시했다. 기존 보도의 과거 계획·장관 발언과 이후 확인을 섞지 않았다. 하지만 일반 입국 심사 조건을 추가한 P1은 근거는 있으나 반드시 필요한 수정인지 확립되지 않았다. 필수 복구 성공으로 추가 계산하지 않는다.

K183의 수정 제안은 인체 질병 유발의 불확실성과 분석물 범위를 고쳤지만 P1과 P2가 서로를 의존하게 만들어 전체 전달이 실패했다. 또한 80%를 77%로 세분화하고 정량한계·추가 물질 설명을 넣은 부분은 근거 있는 세부사항이라도 필수성이 입증되지 않았다. 원문의 80%는 반올림으로 양립 가능하므로 새 오류로 세지 않았다. 의미상 적절한 제안과 실제 사용 가능한 전달은 별개다.

감사에서 새로 만들어진 중대한 의미 손실은 확인되지 않았다. 이는 제공 자료와 해당 감사 범위의 관측 결과이며, 미발견 손실이 없다는 보장은 아니다. 불필요한 확장과 실제 전달 실패가 남아 있으므로 완전 해결로 보지 않는다.

### 3. 평가자 불일치: 여전히 해석 이견이 남음

E183의 원문은 연구가 폐경 후 여성을 대상으로 했다는 사실을 밝히고, 다른 집단에도 적용될 것이라는 기대를 연구자에게 귀속한다. 원자료에는 다른 집단에 일반화되지 않을 수 있다는 한계가 있다. 사전 기준과 v1 감사자는 이 한계의 추가를 선택적 설명으로 봤다. v2 감사자는 필수 설명으로 봤다. **두 v1/v2 완성문은 바이트 해시가 같은 원문**이다. 따라서 이 차이를 편집의 퇴행이라고 해석할 수 없다.

핵심은 기대 발언이 거짓이라고 판정한 것이 아니라, 이미 귀속·대상 조건을 밝힌 기사에 원자료의 한계를 더 넣어야 하는지의 필요성 판단이다. v2 감사의 추가 미수정 1항목은 민감도 기록으로 유지하고 사전 분모 0을 소급해 1로 바꾸지 않았다. 사실 이견·해석 이견·가치 선호를 혼합하지 않는다. 이 표본에서 가치 선호 차이가 기록되지 않았다는 사실도 가치 중립성의 증명은 아니다.

## 측정·재실행과 다음 행동

10회 작성에 지정된 입력 파일의 문자 수 합계는 **469,691**, 출력 파일은 **131,709**다. 코드가 실제 파일에서 센 유니코드 문자 수이며 토큰·금전 비용이 아니다. 숨은 시스템 지시문과 도구 포장은 제외됐다. 독립 기준 작성 8회와 감사 10회는 작성 10회와 별도로 기록한다. 런타임은 상속 설정이고 모델/노력 변경을 요청하지 않았다. 정확한 배포 버전·시드·과금·모델 순수 실행 시간은 노출되지 않았으며 설정 파일 부재·허용 환경 메타데이터 공백을 그대로 남겼다.

첫 개발 입력 동결부터 마지막 원출력 파일의 관측 수정시각까지는 **662.404초**다. 동결·대기·개발·수집을 포함한 조정 작업의 경과 구간이며, 모델 실행시간이나 방법별 시간 비교가 아니다. 파일 복사로 수정시각이 바뀔 수 있어 당시 관측을 별도 보존했다.

공개 `aggregate.py`는 승인된 비공개 자료 사본을 지정해 저장 출력만 재생한다. 새 모델 실행이 아니다. 고정 해시·사전 분모·감사 판단 해시를 검사하고, 원래 검증기로 실제 완성문과 패치 적용 결과의 일치를 확인한다. 예상 파일 누락이나 변경이면 실패한다.

```bash
python experiments/v18/aggregate.py --private-root PRIVATE_ARTIFACT_DIRECTORY --output replay-summary.json
```

관측된 다음 수정 대상은 K183의 의존 관계 표현에 따른 전달 실패와, 근거는 있으나 필요성이 확립되지 않은 추가 문장이다. 이 문제에 맞춘 작은 후속 시험 결과는 별도 기록에 둔다. 본실험 수치를 덮어쓰거나 이미 본 기사를 새 평가로 재사용하지 않는다. 같은 문제의 실질적으로 다른 접근 10개 실패는 이 결과로 입증되지 않는다. 인용 필드 수리와 의존 관계 표현 수리를 새 의미 보존 원리 두 개로 부풀리지 않는다.

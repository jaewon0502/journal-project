# 최종 원장 연결 — 한정 후속 통합 검사

이 단계는 최초 9출력/18판정을 본 뒤 수행하는 **노출된 후보 후속검사**이다. 새 holdout이나 새로운 작성 성능으로 세지 않는다. 원자료와 모든 원출력을 보존한다.

발견: 단위는 후보 본문에 반영됐지만 작성 메모는 제안 단계여서 적용 여부가 불확실하다고 말한 합성 한 건. A=거부, B=불확실. 외부 기사에 실제 게시되지 않았다는 문장 자체는 참이며, 후보/발행본 지칭을 혼동한 전달 문제다.

후속 규칙(결과 사후 개선임을 공개): 두 독립 독자 중 한 명이라도 전달문 fail/ambiguous 또는 reader_note 새 오류를 기록하면 해당 자유문장 메모를 최종 첨부하지 않는다. 실제 source/proposal/output와 해시를 바탕으로 생성한 상태/변경 목록만 전달하고, 근거 설명이 보류됐음을 표시한다. 메모 제거를 새 AI 생성으로 세지 않는다. 두 독자가 패치 모두 approved일 때만 provisional에 남기고, 그 외 rejected 또는 unknown으로 보류한다. 의존 판단 차이는 unknown으로 처리한다. 원래 반론/발언/시간은 보존한다.

상태 원장은 기계 생성, 본문/근거 설명의 의미는 세 번째 fresh-context 최종 감사자가 평가한다. 마지막 감사자는 기존 A/B 판정·조건·작성자 보호목록을 보지 않는다. 최종 후보 본문과 설명·동일근거·질문을 모두 본다. exact candidate hash에 대한 승인 전에는 release하지 않는다. 불확실하거나 새 오류면 hold/해당 의존컴포넌트 원복하며, 새 후보는 별도 승인이 없으면 발행하지 않는다. 이번 한 회차에서는 추가 의미 재작성으로 연장하지 않는다. 외부 게시나 운영 반영을 의미하지 않는다.

이 절차가 원문 완전성·독립 세계진실·모델 독립성을 보증하지 않는다. 고정 입력에 대한 최종 의미 감사와 검증기 국소 수정은 회귀 확인으로만 보고한다.

# Journal v10 결과 패키지

읽을 순서: `results/report.md` → `results/initial-candidates-summary.json` / `final-summary.json` → `calibration/results/REPORT.ko.md`.

## 재실행

Python 3 표준 라이브러리만 필요하다. 압축을 풀고 다음을 실행한다.

```sh
python3 run_checks.py
```

15개 구현·회귀 검사와 4개 독립 적대 검사를 수행한다. 원래 독립 시험은 거부 시 False를 기대하고 구현 계약은 ValueError를 발생시키므로, runner는 그 거부 방식만 정규화한다. 원본 독립 시험 코드는 보존되어 있다. 합성 평가자 원응답의 축별 일치를 재집계하고, 공개된 9후보 판정 투영값의 산술 집계를 검증한다. 모델 추론이나 새로운 사실 판정은 실행하지 않는다.

## 들어 있는 것과 제외한 것

- `editing/`: 최초 동결본. 독립 검사에서 자료형 동등 비교 결함을 찾은 버전.
- `editing-v1_1/`: 그 결함만 고친 버전. vendor 엔진 고정 hash 검사를 유지한다.
- `independent-code-audit/`: 실패 재현과 별도 수정 검증.
- `calibration/`: 연구자가 만든12평가후보·기대값·24개 실제 평가 원응답. 기대값은 gold가 아니다. 일부 최소쌍의 구성 결함을 그대로 남겼다.
- `synthetic-native/`: 합성6사례의 실제 native 작성 및 평가/최종 전달 원응답. 합성 자료이므로 전문 포함.
- `protection/`: 실자료3건의 위치·짧은 근거·해시와 접근 범위. 전수 gold가 아니다.
- `protocol/`: 설계·작성·평가 지시·동결 manifest. 최초의 '최대15' 설계 상한 안에서 실제 작성9, 별도 calibration12를 실행했다.
- `integration/`: 관측 뒤의 국소 전달문 수정 규칙과 최종입력 hash. 새 holdout 아님.
- `natural-private-records.json`: 공유에서 제외한 실기사 원문·작성 보호목록·근거 인용이 많은 원판정 파일들의 hash. 비공개 작업환경에서 보존했다.

실기사 전문·전체 수정기사·광범위 원문 인용이 있는 원응답은 재배포하지 않았다. 공유된 자연어 사례의 수치집계는 투영값으로 재계산 가능하지만, 원판정 전체를 같은 패키지만으로 재감사할 수는 없다. 원문 URL에서 직접 확보할 때에는 현재 자료의 범위·수집일·hash 차이를 기록해야 한다.

실제 생성과 판정을 다시 하려면 지원되는 별도 문맥 agent에 동일한 고정 원문·근거·질문·지시를 제공하고 raw 응답을 새 버전으로 저장해야 한다. 정확한 배포모델/seed/비용이 없어 동일 응답 재생성을 보장하지 않는다. 자동 API 실험 실행기나 인간 평가가 아니다. 외부 게시·push·배포를 수행하지 않는다.

검증 파일의 과거 절대경로는 당시 provenance다. `run_checks.py`는 이 패키지 상대경로로 실행한다. 자연어 조사 자체는 패키지에 없는 실기사 원문 접근이 필요하다.

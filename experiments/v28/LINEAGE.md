## Exact missing capacity / evidence

1. **Autonomous relation discovery and trustworthy relation judgment.** Before seeing a failure label, identify which original speaker/source governs which proposition, which quantifier governs which set, and which numerator is bound to which denominator; then determine whether the actual selected text changes that relationship. A fresh same-family model repeating the same assessment or compiling its own “original relation ledger” supplies another fallible judgment, not independent truth. v15 can enforce supplied edges; it cannot establish that those edges are correct or complete. v24 can enforce certificate structure; it cannot establish semantic identity.
2. **Support for the particular unresolved source claim.** For D71, inspect the actual paper/protocol or direct source statement tying the compared systems to physical area and identifying precisely which propositions the speaker endorsed. `v27/SOURCES.md` states that full-paper access was unsuccessful and was not retried; the supplied announcement/expert-comment packet did not resolve the area/similar-size condition. The wording in `v27/RESULTS.md:28` must not be read as evidence that the full paper was inspected. Existing source silence justifies withholding a new attribution or unsupported deletion; it does not certify the original condition. More prompts cannot manufacture that evidence. A broad “need the full paper” request alone is insufficient if the relevant relation is absent there too.
3. **A fixed necessity standard where the dispute is reader interpretation.** D73's 17/22→80% dispute requires a precision/editorial policy before scoring; it is not solved by enumerating denominator fields. For whether already present caveats/attribution prevent a misleading reading, obtain a stated editorial purpose or actual reader/editor judgments with reasons. `v19/CLOSURE.md:26–32,40–42` already specifies such questions and restart conditions. Human votes do not decide source facts.
4. **Evidence for generalization.** A genuinely new operational study would need held-out full original/source/compound-edit packets, prespecified meaningful-versus-optional outcomes, and independently established relation annotations or a validated independent resolver. The inspected records do not establish an available trained relation/coreference resolver, compatible checkpoint, evaluation labels, or cost (`v25/NOVELTY-AUDIT.md`). An external-ID table solves only relations actually encoded by that source; attribution and quantifier scope are not automatically supplied by IDs.

## Stop / resume boundary

Stop new variants with the same source packet, same model judgment channel and another preservation checklist. Keep D71's safe S result and T failure as a local regression; do not convert a prompted repaired candidate into autonomous validation. Do not add an attempted or failed method family.

Resume only after an independently checkable relation signal, a concrete source passage resolving the disputed binding, or a fixed editorial/reader criterion becomes available. At that point the operational intervention and contrast can be specified around the changed input or judgment capacity. This review does not propose a speculative control without those inputs. New code is warranted now only if an actual mechanical closure/recomposition defect is reproduced; none was established by this lineage review.

Absence boundary: this is targeted inspection of relevant v13–v27 policies, results and mechanism documentation, not an exhaustive audit of every private output. It supports “this proposed rule repeats inspected predecessors,” not “every imaginable implementation has already been tested.”

# v28 사전 범위

2026-10-03. v27의15개 최종문을 새 별도문맥에서 재감사한다. 입력은 원문·제공 원자료·정확한 최종문뿐이다. 보류 이유·불확실성 부록·패치·조건이름·이전평가·정답표는 주지 않는다. 원문과 최종문 차이로 처리 방식을 추측할 수 있어 완전한 지각적 눈가림을 보장하지 않는다.

분류: 명시적 근거 충돌 / 근거 부족 / 귀속 또는 수량·분모 관계 변경 / 실제 필요한 수정 / 문맥으로 해소 가능한 모호성 / 독자 명료성 개선 선호. 기존 오류 잔존과 수정으로 발생한 오류를 구분한다. 정밀도 기준 없이 반올림을 오답으로 만들지 않는다. 출처 침묵은 원문 거짓의 증거가 아니다.

별도 세 감사 문맥: 발전량·eVisa6출력 / 미세플라스틱3출력 / 새 기사6출력. 감사자에게 분류 기준은 주지만 v27 판정은 주지 않는다. 독립 실행이지만 동일계열 AI 내부평가이며 인간검증이 아니다. 원평가와 원출력은 보존하고 이번 결과로 소급 대체하지 않는다.

동시에 기존 v13 이후 실제 연구 산출물을 읽어 귀속·수량자·분모 연결 규칙의 선행 여부를 검토한다. 이미 반복한 가설이면 같은 지시 추가로 새 성과를 주장하지 않는다. 추가 시험을 할 경우 한 가지 새로운 조작만 사전 고정하고 정상/오류 대조로 실시한다. 근거 없는 수정 성과나 완전성 보장은 주장하지 않는다.

## 노출 사례 국소 수정 추가 — 감사 결과 뒤 고정

첫 깨끗한 감사는 미세플라스틱 전체 검출/재질 나열을 보편수량 오류로 확정하지 않았으나 본문의 폴리스티렌 특정은 분석법이 뒷받침하지 못한다고 판정했다. 해당 노출 사례만 본문 1곳의 `폴리스티렌(PS)`를 `스티렌계 고분자(PS)`로 바꾸는 결정론적 회귀 패치를 만든다. 숫자·분모·검출 종말점·반론·시간 등 다른 내용은 그대로 둔다. 새로운 미사용 성능 시험이나 새로운 모델 생성 출력으로 세지 않는다. 이후 별도문맥은 패치 이유 없이 원문/원자료/최종문을 다시 감사한다. 타 연구나 인터뷰 등 제공자료 밖 주장은 확정 판정하지 않는다.

# 실행과 한계

v27 원출력15개는 바꾸지 않고 동일 본문을 새 불투명 ID로 배정했다. 각 감사 입력에 허용된 키는 blind_id/article/sources/final_text뿐이다. 원기사와 제공 원자료는 전문 추출 범위를 그대로 유지했고, 사전 이유·불확실성 메모·패치 그룹·조건명·지도표·이전 평가는 제거했다. clean-freeze의 해시로 입력 버전을 고정했다. 최종문 내용으로 어떤 편집이 일어났는지는 볼 수 있어 조건 추정까지 불가능한 것은 아니다.

세 독립 문맥에서15개를 나눠 재감사하고, 논점이 큰 발전량3개와 미세플라스틱3개는 각각 다른 문맥에서 같은 과업 지시로 한 번 더 감사했다. 첫 발전량 문맥은 eVisa3개도 함께 읽었고 반복 문맥은 발전량3개만 읽어, 발전량 반복은 주변 배치량이 완전히 같지 않다. 미세플라스틱 반복은 동일3입력·동일 지시다. 반복 수를 사건 수로 세지 않는다. 같은 계열 AI의 합의를 정답으로 삼지 않는다.

명시적 근거 충돌/제공근거 부족/관계 변경/실제 정정/해석 가능한 모호성/선택적 명료화를 구분했다. 이 구분을 미리 적었으므로 v27의 원기준 점수를 소급 재계산한 것이 아니다. 특히 v27과 현재 감사의 차이가 메모 제거 때문에 생겼다고 인과적으로 주장할 수 없다. 문맥·질문 프레이밍·모델 비결정성도 달라졌다.

미세플라스틱 국소 패치는 v27 결과를 본 연구자의 결정론적 회귀수정이다. 별도 최종문 감사에 원문/자료/결과만 주었다. 모델이 자율 생성한 새 수정이나 신선한 실제사례 전이로 세지 않는다. v27의 새 해수면 기사도 이번에는 이미 노출된 재감사 대상이다.

기존 정책 계보를 별도 문맥에서 실제 파일로 검토했다. 귀속이 지배하는 절 전체, 수량자, 분모 연결 보존은 v23/v24에 이미 명시·시험되어 있었다. 같은 지시를 덧붙인 새로운 정상/오류 통제는 만들지 않았다. 이것은 새 가설의 실패가 아니라 새 독립 기제가 없다는 계보 판단이다.

정확한 배포모델·seed·비용·토큰·시간 비교는 통제/계측하지 못했다. native 별도문맥 AI 내부 검토이며 API 통제실험·인간검증·독자이해 측정이 아니다. 코드가 검사하는 문자 일치/구간 보존은 의미 보증이 아니다. 기존 원출력·오염 가능 평가·보고서는 그대로 보존하며 새 정정 부록만 추가한다.

자료는 v27에서 실제 읽고 동결한 전체 원기사/제공 원자료를 재사용했다. 이번에는 외부 페이지 현재 접근성을 재확인하지 않았다. 기존 article/source manifest에 수집일·수정표시·누락범위가 남아 있다. 논문 그림 픽셀·추가표·다른 독립 연구·인터뷰는 일부 입력에서 빠져 있으며 추출본문이 이들을 대체하지 않는다.

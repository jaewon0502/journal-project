# 특정 용도의 지출과 예비비 연간 합계 대조

한국일보 기사의 2019년 수출 규제 대응 지출 구절을 국회예산정책처의 2019회계연도 결산 총괄분석 I 전체에서 검색했다. PDF 54쪽(인쇄 43쪽)에는 용도별 **지출결정액**과 **지출액**이 각각 적혀 있다. 표의 합계는 지출결정액 27,230억 원, 지출액 26,901억 원이다. 재해대책비 지출액 6,654억 원, 영유아보육료지원 712억 원도 이 표에 나온다. ‘일본 수출 규제’라는 항목은 표시돼 있지 않다. 통상 대응에 실제로 쓴 규모를 결정하려면 세부 사업을 확인해야 한다. 실제 기사 문장은 한 개다. 아래 두 문장은 용도가 원표에 명시된 경우를 대조하기 위해 만들었다. 같은 자료에서 고친 뒤 다시 검사한 결과여서 새로운 기사의 검색 성능과 실제 편집 시간은 미측정이다. 브라우저에서는 원표 위치를 열고 표 제목·단위·용도·합계를 한 번에 발췌할 수 있다. 금액이 다르면 편집자가 원본과 대조해 판정한다.

## 한국일보 원문 전체에서 검토 구간을 선택한 결과

원문 제목·부제, 사진 설명 2개와 본문 7문단을 페이지 순서대로 입력하자 검토 구간 28개가 나왔다. 20번째 구간은 본문 4번째 문단 끝의 65자 문장이다. 과거 지출 사례와 정부의 산업·통상 대응 입장이 한 문장에 함께 있다. 이 구간을 그대로 선택해 검색한 기준판의 상위 세 문단은 **4070, 4112, 1491**이었다. 개선판에서는 **1483문단**, 용도별 지출표의 합계 행이 첫 후보가 됐다. 화면은 과거 지출 구절을 표시하고 뒤에 이어지는 정책 입장을 발표 원문에서 따로 확인하도록 안내한다. 같은 문장에 또 다른 금액이나 반박이 나오면 편집자가 지출 구절을 선택해 다시 검색할 수 있다.

오프라인 Chrome에서 390px와 1280px로 기사를 각각 입력하고 20번째 구간을 눌렀다. 검색 문구를 편집하지 않고 PDF 54쪽의 지출액 열과 용도별 행을 열어 저장했다. 새 탭에서 작업 파일을 복원한 결과 두 경우 모두 원자료 1건의 발췌와 위치가 보존됐고 편집자 판정은 0건이었다. 앞 표 첫 행과 같은 기사에서 문장을 자르는 방식만 바꾼 재시험이다.

원문 HTML을 직접 내려받아 두고 아래 명령으로 원문과 PDF의 판본 및 검색 결과를 확인할 수 있다. 스크립트는 기사 원문을 출력하지 않는다. 제목부터 본문까지 검증한 텍스트의 SHA-256은 `ae9a15f20236133475a817459cc81906efca361082f1625bcbef97a85c9ec351`이다.

```sh
node experiments/cross-party-review/replay-reserve-whole-article.cjs newspaper.html report.txt
```

## 재현

위 국회예산정책처 PDF의 SHA-256은 `0678b8f7b94c897e304590084e5e6fbb3d54aeb67bf7eedd57d80f1742289267`이다. 프로젝트 루트에서 PDF를 레이아웃 보존 텍스트로 추출한다. 재현 스크립트는 전체 텍스트의 SHA-256을 확인한 뒤 [원래 편집자 작업 파일](blind-workspace.json)에서 기사 문장을 가져와 검색한다. 쪽수는 문서에 인쇄한 숫자와 별도로 PDF 첫 쪽부터 센다.

```sh
pdftotext -layout report.pdf report.txt
node experiments/cross-party-review/replay-reserve-uses.cjs report.txt
baseline_dir=$(mktemp -d)
git archive 725fc79 docs/reader | tar -x -C "$baseline_dir"
node experiments/cross-party-review/replay-reserve-uses.cjs report.txt "$baseline_dir/docs/reader/evidence-search.js"
```

[표 부분의 레이아웃 텍스트](reserve-uses-layout.txt)는 행과 숫자 간격을 보존했다. 연도, 열, 단위, 페이지 경계나 자료 범위가 맞지 않는 경우의 동작을 `node --test tools/test_reserve_uses.cjs`로 확인할 수 있다.

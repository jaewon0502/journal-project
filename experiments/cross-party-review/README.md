# 실제 기사 검토 · 2025년도 예비비 감액 공방

한국일보 이유지 기자의 2024년 12월 2일 오후 6시 보도(지면 3면)를 사용합니다. 당시 정부가 제출한 예비비와 국회 예산결산특별위원회에서 심사한 예비비를 두고, 정부와 야당이 다른 판단을 내린 날의 기사입니다. [한국일보 원문](https://www.hankookilbo.com/news/article/A2024120214070004656)

## 근거를 찾는 데 걸리는 시간

[현장 측정 화면](../../docs/reader/field-review.html)에서 [참여자용 과제 파일](blind-tasks.json)을 불러오세요. 검토할 문장은 연구진이 만든 문장입니다. 각 문장을 원자료로 판단하고, 같은 위치를 다시 찾아갈 수 있도록 문서 주소와 표·행·열 또는 문단을 기록하세요. 과제를 마칠 때까지 아래의 편집자용 작업 파일과 조정자 자료는 열지 마세요.

## 두 편집자의 독립 검토

1. 각자 [편집자용 작업 파일](blind-workspace.json)을 받아 [팩트체크](../../docs/reader/factcheck.html)의 **작업 파일 저장 · 이어 열기 → 파일 이어 열기**로 여세요. 들어 있는 것은 기사 발췌와 두 사람에게 공통으로 주는 근거 자료입니다. 먼저 링크에서 기사 전체를 읽고 발췌의 앞뒤 문맥을 확인하세요.
2. 작업 파일의 네 줄은 원문에서 그대로 가져온 제목, 정부·민주당 부제 각 한 줄, 2019년을 언급한 본문 문장의 일부입니다. 줄을 이어서 읽으면 원문의 문단 순서·간격이 사라집니다. 화면이 제목을 여러 구간으로 나누면 같은 제목이라는 점을 고려하세요. 파일에서 평가한 건수와 비율의 적용 범위는 이 발췌입니다.
3. 핵심 구간을 각자 지정하고 확인한 사실, 발언 주체, 발언 내용, 남은 의문을 기록하세요. 이어서 표현과 귀속, 제목·도입부와 본문, 근거 선택과 맥락 누락, 양측에 적용한 검증 기준을 각각 평가하세요. 판단에는 기사 구절, 원자료 구절, 달라지는 독자 해석이 필요합니다. 발췌에 대조할 구절이 없으면 미평가 사유를 별도로 남기세요. [평가 기준](../../docs/article-rubric.md)
4. 두 사람이 서로의 판단을 보기 전에 각자 작업 JSON을 저장합니다. [편집자 간 비교](../../docs/reader/article-compare.html)에서 같은 판본·같은 근거로 만든 두 파일을 엽니다. 추가 자료가 필요하면 발견 내역을 따로 보관하고 첫 비교를 끝낸 다음 양쪽에 동일한 추가 자료를 주어 다시 검토하세요.

여기서 가리는 것은 다른 편집자와 AI의 판단입니다. 기사에 나온 정당·기자 이름은 보입니다. 시간 측정과 독립 검토를 모두 진행한다면 시간 측정을 먼저 끝내세요. 같은 사람이 이 기사를 다시 만나면 이전 열람을 기록하세요. 현재 배포물에는 사람이 제출한 결과가 없습니다.

2019년 수출 규제 대응 지출을 다룬 기사 구절에서 연간 총액과 용도별 지출을 대조하는 과정은 [예비비 지출 원표 검색 기록](reserve-uses.md)에 있다.

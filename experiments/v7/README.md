# v7: 원문 관계 보존과 최소편집

2026-10-01에 완료한 연구의 공개용 파생 자료다. 공식 자료 6사건(개발 2, 평가 4)에 기반한 **AI 작성 합성 대조문**을 사용했다. 자연 발생 기자 오류나 자연 발생 슬롯 오류의 표본이 아니다. 공개 작업에서 새 모델 실험·의미 재판정은 수행하지 않았다. 과거 전체 실험 이력과의 사건 중복 여부는 확인되지 않았으므로 완전히 새로운 사건 집합이라고 단정하지 않는다.

고정 평가에서 오류 복구는 자유 최소편집 4/4, 유형 렌더러 3/4, 원문 구간 삽입 3/4였다. 정상·동등 대조문은 각 8/8 보존됐다. J 근거 개입은 4사건 모두 세 가지 예상 패턴과 일치했다. 작은 합성 대조와 내부 AI 평가이며 통계적 우월성·전체 문서 감사·편향 감소를 입증하지 않는다.

## 실행

이 디렉터리에서 Python 3.9 이상, 표준 라이브러리만으로 실행한다. API 키·네트워크·유료 호출은 필요 없다.

```sh
python -m unittest discover -s tools -p 'test_*.py' -v
python tools/reaggregate.py
python tools/typed_renderer.py --schema
python tools/typed_renderer_v2_dev.py --schema
python tools/patch_guard.py --help
```

`reaggregate.py`는 공개된 실제 판정 필드와 해시의 동일 여부에서 T 결과를 재계산하고 동결 결과와 대조한다. J 판정과 정답 패턴도 다시 집계한다. 해시 비교는 비공개 원바이트나 원문 의미를 재검증하지 않는다. `patch_guard.py`는 UTF-8 바이트 경계·승인 범위·변경 밖 보존·롤백을 검사하며 사실성을 보장하지 않는다. 테스트의 짧은 입력은 합성 단위 테스트이며 연구 성과에 더하지 않는다.

`realize_T.py`, `realize_T_v2.py`, `score_T.py`, `score_J.py`는 원래 알고리즘을 유지한 도구다. 고정된 로컬 경로 기본값은 필수 CLI 인수로 바꿨다. 사용자가 합법적으로 확보한 입력으로 실행할 수 있지만, 원연구의 전체 입력·blind mapping·원문 전문은 배포하지 않아 원실험 전체를 동일 입력으로 재실행할 수 없다. 공개 재집계에는 이 입력들이 필요 없다.

`typed_renderer.py`와 `typed_renderer_v1.py`는 초기 6유형이다. `typed_renderer_v2_dev.py`는 개발 1회 개선 뒤 **같은 해시로 평가에 동결된** 파일이다. 파일명과 첫 주석의 DEV-only 문구는 개발 당시의 표기를 그대로 보존한다. 실제 평가 승인 상태는 동결 계보를 따른다.

## 공개 범위

명시적으로 선정한 코드·테스트·파생 판정·최소 수정절만 포함했다. 원문 HTML/PDF/전문, 원래 입력 묶음, 비공개 대응표, 내부 대화·작업 지시·저장소 식별자, 자격증명은 제외했다. 판정의 인용과 근거 발췌를 제거하고 출처 경로를 공개 source ID로 치환했다. 따라서 JSON export는 원출력과 바이트 동일하지 않으며 보존된 원본 SHA-256은 원본 식별용이다. 점수와 실패 여부를 바꾸지 않았다.

원출처 파일은 수집 당시 스냅샷이다. 현재 URL의 내용이 같은 해시라는 보장은 없다. BEA는 이후 개정으로 대체된 최초 추정 빈티지, NASA는 2024-12-27 발표·2025-01-02 수정 표지의 현재 수집본이다. 정확한 모델 배포 버전·seed·토큰 비용은 미확인이다.

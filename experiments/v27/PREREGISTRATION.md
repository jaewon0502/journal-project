# v27 실행 전 설계: 혼합 패치의 자동 분해와 부분 적용

노출 개발 회귀 D71=농업태양광 P19(추정 상태+크기 조건 삭제), D72=eVisa의 과거계획/의무 강도 두 패치, D73=미세플라스틱 제목/본문 반올림과 PS 범위 혼합을 사용한다. 원기사·자료·제안 최종문을 고정한다. v26의 원평가와 승인 철회는 변경하지 않는다.

세 조건: W는 원래 whole patch, T는 결정론적 단어/공백/문장부호 토큰 diff의 각 변경 구간, S는 AI가 같은 제안 전체를 의미 변화별로 자동 분해한 그룹이다. S는 인접한 변경을 분리하거나 떨어진 실현 구간을 한 의미로 묶을 수 있다. 전체 그룹을 적용하면 원래 제안과 바이트 동일해야 한다. 분해 단계는 정오답 선택이나 후보 수리를 하지 않는다. 같은 원자료를 읽지만 판정 이유는 후속 선택자에게 주지 않는다.

선택자는 세 조건 모두 동일 원문·전체 원자료·제안문·선택 규칙을 받으며, 차이는 편집 그룹 경계뿐이다. 각 그룹의 원문 구간·근거·의미 효과·동시 성립 가능성을 판단하고 apply/reject/hold를 결정한다. 그룹 내부를 다시 편집할 수 없으며 무효/의존 미확인 그룹은 보류한다. S의 추가 모델 작업량이 있으므로 순수 동일 비용 효과가 아니다. 의미 설명·분해자의 정답 판정은 전달하지 않는다. 그룹 ID는 중립적으로 표시한다.

선택 결과는 원문에 위치 기반으로 동시 적용하고 전체문을 별도 감사한다. 필수정정 효과, 불필요 수정, 조건/귀속/시간/반론 손실, 문법·참조 연결 손상, 보류, 실행 오류를 분리한다. 단순 diff는 문자열 위치만 설명하며 의미 단위의 정답이 아니다. 의미 그룹도 모델 가설이지 gold가 아니다. 전체 후보 승인/부분 승인/보류를 단일 성공 점수로 합치지 않는다.

개발 후 정책을 동결하고, 별도 수집자가 확보한 미사용 실제 기사 1건에서 정상 원문 및 하나의 인공 오류 변형을 숨겨 평가한다. 제안 혼합 패치는 통제 자극이며 자연 언론 오류나 자연 작성 실패 빈도로 세지 않는다. 기존 세 회귀와 신규 기사 결과를 구분한다. 새 실제 기사 전문·원자료 확보 실패 시 정확한 범위를 기록하고 대체 표본을 무한 수집하지 않는다.

v13 선택적 rollback과 v15 의존 검사와 같은 가족의 후속이다. 구체적 차이는 이미 주어진 패치 간 선택이 아니라, 실제 실패한 하나의 복합 패치 안을 자동으로 분해해 필요한 효과를 회수할 수 있는지, 토큰 분할과 의미 분할을 같은 제안에서 직접 대조하는 것이다. 신규 독립 가족 증분은 0을 기본으로 한다.

모델/노력 override 없이 별도 문맥을 사용한다. 정확한 배포버전·seed·비용 미통제. AI 내부 검증이며 사람/다른 모델 신뢰도 측정 아님. 이번 묶음은 개발 3입력×3조건과 신규 정상/오류 2입력×3조건, 의미 분해·독립 감사로 한정한다. 구조적 실행 버그는 원기록을 보존하며 수리하되 평가 기준을 사후 완화하지 않는다.

## 개발 이후 평가 동결

개발 선택 출력 9개를 받은 뒤 선택/분해 정책을 변경하지 않고 평가 정책 해시를 동결했다. 이 시점까지 통합 담당자는 신규 기사 전문을 열지 않았다. 자료 수집자는 별도 문맥에서 한 사례만 확보했다. 신규 통제 자극은 방법 동결 뒤 작성하며 정상/오류 대응과 기대 판정은 별도 oracle에 두고 분해자·선택자·평가자에게 전달하지 않는다.

분해자 입력에는 원래 전체 패치와 토큰 인코딩도 들어 있었지만 정오답 표지는 없었고 의미 분해 시 이를 정답으로 쓰지 않도록 했다. 따라서 S는 원자료로부터 독립적으로 의미 단위를 발견하는 순수 측정이 아니라 기존 인코딩을 볼 수 있는 추가 모델 처리다. 실제 선택자에게는 분해자의 의미 설명·의존 판단·이유를 전달하지 않고 id/원문 위치/치환 문자열만 동일 스키마로 전달했다.

정확한 전체 재합성에 더해 모든 원문 구간의 비중첩·삽입 경계 유일성·원문 앵커를 강제한다. 서로 겹치는 상쇄 편집으로 후보 밖 문구를 만드는 것을 막는다. 이 조건도 부분 적용의 의미/문법 안전성을 입증하지는 않으므로 독립 전체문 감사가 필요하다.

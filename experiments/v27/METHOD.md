# 조건·검사·한계

W는 원래 복합 패치, T는 결정적 토큰 diff, S는 자동 의미분해다. 세 조건은 같은 전체 원문·전체 제공자료·제안 결과문·선택 정책을 받았다. 선택자는 동결된 그룹의 적용/보류만 결정하고 새 문장을 만들지 못했다. S분해기는 좋은 수정과 나쁜 수정을 모두 분해해야 하며 판단을 대신하지 않는다. 분해 설명·기대 정답은 선택자에게 전달하지 않았다. 분해기는 원문/제안 외에 기존 whole/token 인코딩도 볼 수 있었다. 독립적인 의미 발견만의 효과를 분리한 설계가 아니다.

모든 조각은 Unicode 원문 좌표로 고정했다. 겹침 금지, 원문구간 일치, 전체 선택 시 원래 제안문 정확 재구성, 선택결정과 결과문 일치를 검사했다. 의미상 의존성 자기보고와 전체문 POST를 사용했으며 v15의 모든 쌍 이중평가 계약을 그대로 재실행한 것은 아니다.

15출력 모두 구조 재실행에서 불일치0. 코드 단위검사8개는 좌표/겹침/재구성 등을 검사하며 의미 정확도 검사가 아니다. 특히 구조적으로 통과해도 의미 오류가 가능함을 명시한 시험을 포함한다. 옛288검사는 이번 성과로 재계상하지 않는다.

PRE를 출력 평가 전에 보존하고 POST의 기준 정정은 별도 기록했다. 개발9출력 뒤 정책을 동결한 후 새 기사 내용/변형을 검토했다. 새 자료 정상/오류 표지는 숨겼다. POST에는 익명 전체문과 원문/자료 및 remaining_uncertainty를 주었다. 이 불확실성 부록에 보류 이유·일부 그룹ID가 남아 조건을 추측하거나 판정에 영향을 받을 가능성이 있다. 감사자는 근거로 사용하지 않았다고 기록했지만 완전한 눈가림은 아니었다. 기존 노출3개는 회귀 전용이다.

v13은 패치 선택/롤백, v15는 의존성, v16은 문자 diff 표시를 이미 다뤘다. 이번 차이는 한 복합 패치 내부를 자동 의미 단위로 나누고 토큰/전체 단위와 비교한 것이다. 새 독립 방법 계열 수 +0(A09/A10 내 검증). v13 전체 제안 묶음 G0와 여기의 단일 원래 복합 패치 W는 동일하지 않다.

독립 문맥이지만 같은 런타임 계열의 AI 내부 검토다. 정확 배포모델 버전·seed·토큰비용·실행시간의 균등 통제는 불가했다. S는 추가 모델 분해를 거쳐 계산량과 입력 그룹 수도 다르다. 비용을 맞춘 인과효과나 일반 성능 우위를 주장하지 않는다. 실제 API 자동실험/인간검증/독자신뢰 측정이 아니다.

공개 패키지는 자체 분석·코드·해시·선택 기록만 포함한다. 기사 전문과 전체 결과문은 비공개 작업 폴더에 보존하며 전재하지 않는다. 따라서 공개 패키지만으로 전체 의미 판정까지 재현할 수 없고, 동일 원자료 버전과 private 입력이 필요하다. 해시는 진실 인증이 아니다.

# 원자료 확보와 AI 평가 후속 검증

**2026-10-03에 실행한 연구 기록의 공개 파생본**이다. 기존 연구에서 남은 6번 ‘미확보 원자료 검증’과 7번 ‘인간 중요도 판단과의 일치’를 후속 점검했다. 이번 공개 과정에서 새 모델을 실행하거나 과거 v6 점수를 재채점하지 않았다.

3사건의 **로컬 검토에 필요한 자료 6개 확보**와 한국어 발표문 1건의 **AI 검토·수정·재검사**까지 실행했다. 인간 중요도 일치는 입증하지 않았다. 서로 대화 이력을 공유하지 않은 동일 계열 AI의 결과이며, 다른 모델 계열이나 기술적 격리의 증거는 아니다.

75개 선정 단위는 세 검토자의 분할 방식이 다른 기록이며, 서로 다른 중요 사실 75개가 아니다. 18문장은 **재사용한 한국은행 원문 하나의 짧은 합성 주장**이고, 실제 기사 18개나 미사용 사건 18개가 아니다. 같은 입력에 대한 판정 반복을 독립 사건 수로 세지 않는다. 이전 방식과 통제 비교하지 않았으므로 성능 향상이나 일반 오류율을 추정하지 않는다.

## 6번: 확보 범위와 내용 검증의 구분

원자료는 ICJ의 2024-05-24 잠정조치 명령·보도자료, 2024-07-19 권고적 의견·요약, ECHR의 2024-04-09 KlimaSeniorinnen 판결 HTML·보도자료다. 6개 문서의 공식 URL, 취득한 바이트와 추출본 해시는 출처 등록부에 있다. 최초 다운로드 파일과의 바이트 동일성이나 원사이트의 현재 접근 가능성까지 확인한 것은 아니다.

보관된 로컬 검사는 최신 후속 답안 12개와 55개 locator를 대상으로 한다. HUDOC HTML의 2,256개 본문 블록은 별도 추출에서도 공백 정규화 후 일치했다. PDF 5개는 해당 검사에서 재추출하거나 시각 재검사하지 않았다. 해시·위치가 맞는 것은 법률 해석이나 주장 지지의 증명이 아니다.

답안은 후속 AI 작업답안이다. 원래 v6의 O1~O4 의무 기준·매핑은 복원하지 못했고 과거 66/78·65/78을 바꾸지 않았다. 원답안 파일의 `pending` 상태와 `finalized_at_utc=null`은 저장 당시 값으로 보존했다. 이후 별도 확인 기록과의 차이는 `workflow_answer_status_conflict` 경고 1건으로 남아 있다.

## 7번: 인간 평가를 대체했다고 주장하지 않는 AI 검토

[프로토콜](data/protocol.json)에 따라 원문만 읽는 첫 단계와 후보를 보는 단계를 분리했다. 첫 보고서를 저장한 뒤 후보를 제공했고, 검토자에게 동료 판정·운영자 구성 의도·인간 응답을 주지 않았다. 공개된 동결 시각·해시는 보관 기록이며 외부 공증이나 실제 입력 격리 증거가 아니다.

중요도는 검토 순서를 정하는 보조 정보다. **낮은 중요도를 사실·조건·책임·정당한 비판의 삭제 권한으로 쓰지 않는다.** 수정은 원문과의 확인된 충돌, 근거를 넘는 단정, 관계·조건의 의미 변화에 근거한다. 선택적인 배경 설명이 빠졌다는 이유만으로 짧은 문장을 오류 처리하지 않는다.

기존 인간 참여자 1명의 중요도 응답 3개는 유용이었고, 이번 AI들은 같은 후보를 필수로 판단했다. 이 [사후 참고 대조](data/human-reference.json)는 어느 쪽이 틀렸다는 판정이 아니다. 인간의 이유는 미입력이고 원문 독해·지침 이해 상태가 같다고 보장할 수 없다. 최초 자유 선정도 범주 수준의 부분 응답이므로 자유 선정 대비 회수율을 만들지 않았다. 인간 응답 원문·식별자·채팅은 공개하지 않으며, 공개된 세 라벨만으로 인간 응답의 출처를 독립 검증할 수 없다.

## 자료 부족으로 보류한 문장을 처리한 방법

`S08`은 1.6%의 비교 기준을 전년 같은 달로 적은 문장이다. 첫 입력의 한국은행 본문에는 그 기준이 명시되지 않았다. 이 구성상 애매함은 판정 전에 기록했고, 구성 레이블을 정답으로 고정하지 않았다. 세 검토자와 추가 검토자 모두 원문 범위 안에서는 보류했다. 실제로 틀린 문장이라고 판정하거나 정상 문장의 오거절로 바로 집계하지 않았다.

이후 [통계청 2024년 9월 소비자물가 발표](https://www.kostat.go.kr/boardDownload.es?bid=11751&list_no=433062&seq=1)의 실제 페이지 2에서 전월 대비 0.1%, 전년 같은 달 대비 1.6%를 확인했다. 문구는 그대로 두고 이 자료를 추가한 후 새 문맥에서 승인받았다. 최초 한국은행 본문만 사용한 판정은 덮어쓰지 않았다. 자료 확대는 적응적 후속 처리이며 미사용 평가군의 성공으로 세지 않는다.

원래 법원 자료 6개와 이 단계의 한국은행 스냅샷·통계청 보충 자료는 구분한다. 한국은행 스냅샷의 해시는 문단 라벨·메타데이터가 포함된 입력 파일의 해시로서 원사이트 HTTP 응답 해시가 아니다.

## 공개본에서 재실행하는 검사

저장소 루트에서 Python 3 표준 라이브러리로 실행한다.

```sh
python experiments/source-evidence-ai-review/tools/replay.py
python -m unittest discover -s experiments/source-evidence-ai-review/tools -p 'test_*.py' -v
```

이 검사는 **공개된 저장 판정의 재집계**, ID·판정·매핑의 일관성, 수정 전후와 실제 후속 검토 입력 문구의 정확한 연결을 확인한다. 원자료 의미를 다시 판단하거나 AI·인간을 새로 실행하지 않는다.

공개 준비 중 확인한 로컬 검사기의 두 누락을 새 공개 검사기에서 보완했다.

- 변경된 ID가 같은지만 보지 않고 `초기 문장 → 수정 기록 → 후속 V/S 매핑 → 실제 검토 입력 → 최종 문구`가 정확히 연결되는지 검사한다. 검토받지 않은 문구로 바뀌면 실패한다.
- 오류를 JSON에 적고 정상 종료하지 않도록 검사 실패는 비정상 종료 코드로 전달한다.

현재 저장된 문구 연결은 일치했다. 이 보완을 과거의 모델 성능 개선이나 원점수 정정으로 주장하지 않는다. 변이 회귀 테스트는 미래의 손상·오연결을 검사기가 거부하는지 확인한다.

[로컬 검사 기록](data/archived-local-validation.json)의 해시 35건·인용 위치 172건은 **당시 비공개 원입력에서 실행한 보관값**이다. 공개 CI는 원문을 갖고 있지 않아 이를 다시 수행하지 않는다. 앞의 해시 26건과도 중복될 수 있어 독립 표본으로 합산하지 않는다.

## 원보관 번들이 있을 때만 가능한 추가 검사

```sh
python experiments/source-evidence-ai-review/tools/audit_private_bundle.py --bundle "$JOURNAL_SOURCE_BUNDLE" --output source-audit-result.json
```

`JOURNAL_SOURCE_BUNDLE`은 사용자가 가진 원보관 디렉터리를 가리킨다. 이 도구는 자동 다운로드하지 않는다. URL의 문서만으로는 충분하지 않고, 원보관본의 `source-manifest.json`, `freeze-manifest.json`, `sources/`, `evidence/`, `source-first-review-2026-10-03/` 아래 보고서·해시·최신 답안·검사 기록도 필요하다. 원자료 전문과 이 전체 번들은 Git에 배포하지 않는다.

이번 공개 준비에서 보관 번들로 이식한 검사기를 실제 실행해 6자료·12답안·55위치·26해시, 오류 0·기존 상태 경고 1을 확인했다. 공개 CI에서 같은 검사를 했다는 뜻은 아니다. 원문을 가진 경우에도 이 도구는 법률적 의미 정확도를 채점하지 않는다.

## 공개 변환과 남은 범위

[PUBLIC-DERIVATION.json](PUBLIC-DERIVATION.json)은 원자료·실행 산출물의 논리 이름과 원본 해시, 공개 변환 범위를 기록한다. 원본 해시와 현재 공개 파일의 해시는 다르다. [SHA256SUMS](SHA256SUMS)는 현재 공개본의 무결성 목록이다. 해시는 보관 바이트를 식별하며 내용의 진실성이나 실험 독립성을 공증하지 않는다.

원자료 전문·PDF·전체 추출, 원문 우선 보고서의 전체 주장·인용, 판정의 직접 인용 구절, 인간 원응답, 내부 대화·작업 지시·실행환경 경로는 제외했다. 공개 위치와 링크로 원자료를 별도 확인할 수 있지만, 이 패키지만으로 전체 의미 감사를 재현할 수는 없다.

동일 계열 AI의 공통 오류, 검증된 교차 모델 실행, 인간 중요도와의 일치, 새로운 사건·전체 기사로의 일반화는 미입증이다. 추가 독자를 기다리지 않고 AI 검토를 진행할 수 있다는 것과 원래 7번의 인간 일치를 해결했다는 것은 다르다.

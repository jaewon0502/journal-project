# v22: 명제·근거·수정 필요성을 분리한 검증

부분 해결입니다. 새 한국어·영어 실제 기사 각 1건에서 국소 수정을 실행했고, 불필요한 설명 추가 1건은 되돌려 재검사했습니다. 그러나 보호목록의 완전성이나 수정 필요성 판단의 일관성은 보장되지 않습니다. 새 지시문의 일반적 우위도 확인하지 못했습니다.

## 실제 실행과 구분

- 합성 통제 18출력: 3경계 × 3문장형태 × 2정책. 정상문 6개 모두 무수정, 수치 오류 6개와 자료 귀속 과장 6개 모두 국소 수정. 두 정책 전달 결과 차이 없음.
- 노출 실제 사례 3출력: 편집 2개와 기존 지시문의 발견 전용 1개. 셋 모두 핵심 문제를 발견했으므로 새 정책 때문이라고 단정 불가.
- 명제 판정 대상 명확화 회귀 2출력: 표지와 실제 판정 대상 일치 확인. 새로운 실제 사건 아님.
- 미사용 실제 기사 KO/EN 2건 × 2정책 = 4출력. 제공한 전체 기사·전체 확보 원자료를 읽고, 별도 평가자가 출력 전에 기준을 고정한 다음 익명 출력과 실제 편집문을 대조.

합계 사례별 원출력 27개(편집문 26개·발견 전용 1개), 생성 문맥 14개입니다. 합성 3개 조작 반례, 결정론적 롤백 1개, 별도 AI 감사는 이 수에 포함하지 않습니다. 사람 평가·자동 API 실험이 아니며 동일 계열 모델의 별도 문맥 AI 내부 검증입니다. 정확한 배포 버전·seed·토큰 비용은 통제/측정하지 못했습니다. 문맥 배치, 지시문 길이와 작업량 차이도 분리하지 못했습니다.

## 세 문제의 현재 상태

| 문제 | 이번에 확인한 결과 | 남은 한계 |
|---|---|---|
| 보호할 의미 누락 | 원문을 다시 읽는 별도 평가가 수수료 예외와 지역 선정 조건을 사전 추출했고 두 편집 모두 복원 | 보호목록 자체가 정답은 아님. 표현 필요성에 사전/사후 판단 이견이 남음 |
| 재작성·압축 손실 | 필요한 구간만 패치하고 정확한 전달문 검사. 정상 합성문은 유지. 불필요한 실험 절차 추가를 롤백 | 정확한 문자열 패치도 잘못된 판단을 실행할 수 있음. 길이 제한에 대한 일반 해법 검증 아님 |
| AI 판정 불일치 | 세계 사실과 자료 귀속, 근거 지지와 수정 필요성을 분리. 대상 불명확 표지는 회귀에서 명확해짐 | 같은 약한 근거를 두 정책이 모두 과대평가. 선택적 설명의 필요성 판정도 완전히 일치하지 않음 |

## 확인된 국소 개선과 반례

한국어 기사에서는 ‘재발급 비용 1만원’에 2006년 11월 1일 이전 발급 주민등록증의 5천원 예외를 추가했습니다. ‘시범지역이 포함된 지역’이라는 일률적 설명은 ‘그런 지역을 중심으로’로 범위를 고쳤습니다. 두 정책 모두 이 두 실질 문제를 수정했습니다. 사전에 별도로 기록한 인용문의 작은 동사 차이는 남았으므로 3개 전부 해결했다고 세지 않았습니다.

영어 기사에서 두 정책은 최초 발견 범위와 반강자성 설명 문제를 고쳤습니다. 기준선은 ‘2주간 가열’에 앞선 준비 단계까지 추가했지만 원문이 총 소요시간이라고 단정하지 않아 필수 수정으로 보기 어려웠습니다. 새 정책은 이 추가를 하지 않았습니다. 기준선의 해당 패치만 제거한 파생본도 독립 검사에서 필수 오류 재도입이나 새 의미 손실이 확인되지 않았습니다. 해석 여지가 있어 확신은 중간입니다.

두 정책 모두 ‘고유한 양자 특성’이라는 구간을 더 긴 스핀 정의의 완전한 근거처럼 연결했습니다. 전체 자료를 다시 읽은 별도 감사도 나머지 설명을 뒷받침할 구간을 찾지 못했습니다. 따라서 원문이 거짓이라는 결론 대신 근거 연결을 ‘일부만 지지’로 정정하는 별도 주석을 남깁니다. 원출력과 원평가는 보존합니다.

형식 검사만으로 해결되지 않는 반례도 재현했습니다. 원자료가 12마리라고 하는데 이유에는 이를 올바르게 쓰고 표지만 ‘지지됨·유지’로 조작한 출력은 형식 검사를 통과했습니다. 반대 방향의 잘못된 12→18 수정도 통과했습니다. 별도 의미 감사는 두 반례를 잡았습니다. 연구자가 만든 조작 반례이며 실제 작성 모델의 실패율로 세지 않습니다.

## 바로 적용할 짧은 절차와 중단 기준

1. 전체 원문과 원자료에서 주장·대상·조건·반론·행위자·사건/발표 시점을 근거 위치와 함께 적습니다. 추출 목록 밖의 원문을 다시 읽는 별도 검토를 둡니다.
2. 한 판정이 무엇을 평가하는지 명시합니다. ‘자료가 X를 입증했다’와 ‘X가 사실이다’, ‘지지됨’과 ‘고칠 필요가 있음’을 별개로 판단합니다.
3. 근거가 직접 요구하는 최소 구간만 바꿉니다. 선택적 설명은 기본적으로 추가하지 않습니다. 길이가 부족하면 압축 불가 또는 길이 증가 필요를 표시합니다.
4. 원문→수정문 보존 검사와 수정문→근거 검사를 별도로 수행합니다. 패치 밖 변화와 반론 대상·발언 강도·시간 조건을 검사합니다.
5. 근거 대상이 다르거나 일부만 지지되거나 평가가 갈리면 출판 승인을 보류합니다. 새 손실이 생긴 패치는 되돌립니다. 보류 주석을 떼어낸 본문을 검증 완료본으로 배포하지 않습니다.

확인된 해결은 국소 패치와 롤백입니다. 명제별 계약과 독립 감사는 유망한 절차이나 보호 의미의 완전성이나 사실성 보증은 아닙니다. 실패마다 보호항목을 추가한 것은 해당 사례 회귀 수정이며 일반 해법 검증이 아닙니다. 기존 접근 계열 집계 4/8/4, 확인된 잔존 실패 1/4/1을 새 버전 수로 늘리지 않았으며 같은 문제의 독립 접근 10개 실패 기준도 충족했다고 주장하지 않습니다.

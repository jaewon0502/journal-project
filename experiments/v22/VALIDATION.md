# v22 검사와 보존

전체 코드 검사 260개 메서드·20개 unittest 실행 묶음이 통과했고 실행된 skip은 없었습니다. 이는 조사 방법의 의미 정확도 260건 검증이라는 뜻이 아닙니다. 저장된 편집 출력 26개는 동결 입력·정책 해시와 정확한 패치 전달·형식 계약을 확인했습니다. 별도 발견 전용 출력 1개에는 편집문 검사를 적용하지 않았습니다.

공개 합성 출력 18개와 의도적 반례 3개를 재생할 수 있습니다. 반례 2개는 의미상 틀렸어도 형식 계약을 통과하는 설계 한계를 보여 줍니다. 별도 AI 감사 원기록을 보존하며 재생 스크립트가 AI 감사를 다시 실행하는 것은 아닙니다.

실제 기사 전문·원자료·실제 원출력은 비공개로 보존했습니다. 공개 source-metadata.json에는 원문 링크, 게시/수정/수집 날짜와 접근 범위가 있습니다. private-artifact-hashes.json은 내용 동일성 대조용이며 전문 열람 권한이나 의미 정답을 제공하지 않습니다.

자료 수집과 명제 추출, 편집·롤백, 독립 감사는 별도 문맥과 파일로 분리했습니다. 평가자에게 조건명은 숨겼지만 산출물 형태로 추론할 수 있으며 같은 모델 계열의 공통 오류를 제거하지 못합니다. 원기준 미충족 항목과 사후 이견을 별도 기록했고 소급 점수 변경은 하지 않았습니다.

외부 물리학 설명을 찾는 탐색은 시작했으나 동결 자료의 약한 지지 연결을 대체할 검증 완료 증거로 채택하지 않았습니다. 해당 후속 검색을 실험 입력이나 성공으로 세지 않습니다. 추가 자료 검증은 다음 회차 후보로 남깁니다.

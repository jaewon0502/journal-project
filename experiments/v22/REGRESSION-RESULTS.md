# 기존 실패 기사 회귀

같은 기사 본문과 원자료에서 A, B-v1, 정확한 v21 발견 지시문 C를 각각 새 문맥으로 실행했다. A/B는 이번 공통 형식과 최소 편집, C는 원래대로 발견만 수행했다. C에 수정문이 없다고 실패로 세지 않았다.

세 출력 모두 제목의 독성 범위 과잉과 피부/점막 구분을 찾아 수정 필요성을 표시했다. A/B는 실제 두 패치를 전달했고 별도 AI 감사에서 필수 오류 잔류·새 의미 손실 없이 선언한 패치와 전체 전달문이 일치했다. B의 제목 분석 두 행은 같은 문제이므로 오류2건으로 세지 않는다.

중요한 반증: 기존 지시문 C도 이번에는 두 문제를 수정 필요로 분류했다. 따라서 v21의 필요성 유보가 새 계약 덕분에만 해결됐다고 말할 수 없다. 지시문은 같지만 이번은 한 기사 문맥이고 v21은 다른 기사와 함께 처리했으며 입력 ID/메타데이터도 다르다. 문맥 구성·확률적 변동·정확한 모델 배포버전의 영향을 분리하지 못했다. 과거 판정을 소급 변경하거나 안정적으로 해결됐다고 선언하지 않는다.

C의 conflict 표지는 세계에서 모든 금속이 독성인지의 반대 사실을 증명했다는 뜻으로 읽으면 안 된다. 문제는 해당 논문이 지지하는 귀속 범위다. 이 표적 구분과 실제 전달문의 안전성을 별도로 감사했다.

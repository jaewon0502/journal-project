# v22 재실행과 접근 범위

공개 자료는 SUMMARY, PREREGISTRATION, CONTROL-RESULTS, REGRESSION-RESULTS, FRESH-RESULTS, FOLLOWUP-RESULTS, 정책 원문, 출처·날짜·해시, 합성 입력/원출력/감사, 형식 검사 코드입니다. 기존 회차 원출력/원평가는 보존했습니다. 실제 기사와 논문 전문 및 이를 많이 인용하는 원출력은 저작권상 비공개 실행 폴더에 보존하며 공개 패키지에 넣지 않습니다. 해시만으로 제3자가 원문 의미 검증을 재현할 수 있다는 주장은 하지 않습니다.

새 디렉터리에 패키지를 풀고 저장 출력 검사를 실행합니다.

```
python tools/run_checks.py
python experiments/v22/code/replay_control.py
python experiments/v22/code/replay_challenge.py
```

전체 검사의 구형 JSON Schema 의존성은 requirements-research.txt를 따릅니다. 이번 v22 자체 코드는 Python 표준 라이브러리만 사용합니다. 테스트 재생은 저장 출력과 패치/형식 불변식 검사이며 새 모델 생성이나 사람 검증이 아닙니다.

기사 전문을 가진 비공개 실행에서 편집문 26개 모두 정확한 패치 전달과 형식 계약을 재생했습니다. 의미 감사는 별도 AI가 전체 제공 원문을 읽어 수행했고, 공개 요약에 실패·이견을 포함했습니다. 모든 형식 통과를 의미 정확도로 해석하면 안 됩니다. 서로 상충하는 이유/표지를 갖춘 인위적 반례 두 개도 형식 검사를 통과했습니다.

동일 모델 계열을 상속한 별도 문맥으로 실행했고 별도 유료 API·키·계정은 사용하지 않았습니다. 배포 버전·seed·토큰 비용·순수 C/D 소요시간은 측정하지 못했습니다. 이전 회차 API 인증 실패를 이번 실행에서 다시 시험하지 않았으므로 현재 인증 상태를 새로 단정하지 않습니다. 원격 저장소·공유 Page·다른 세션은 변경하지 않았습니다.

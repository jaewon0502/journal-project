# v16 사전등록: 원문–후보 대응표의 단독 효과

사전등록 대상은 새 실제 기사에 기반한 원문 보존·최소수정 업무다. 원기사의 모든 주장이 참이라는 전제는 아니다. 동일 기사에서 만든 통제 후보는 실제 언론이 작성한 오류가 아니며 자연 발생 오류와 분리한다.

선행 접근과 판단규칙은 `prior-and-rules.md`에 고정한다. 유일한 방법 조작은 원문/후보/근거/질문이 같은 상태에서 결정론적 대응표를 추가하는지(M1) 여부(M0)다. 두 조건은 동일 지시·출력 스키마·한 문항 한 별도 문맥·기본 runtime 설정을 사용한다. 표는 문자 위치만 표시하고 의미/중요도/오류유형을 알려주지 않는다. 동일 범위는 offset으로 표시하며 전체 본문은 양쪽 모두 읽는다. 문서 정규화 없음; SequenceMatcher autojunk=False, Unicode code-point offset, 문맥 80자. 구현 hash와 24개 입력 파일을 평가 호출 전에 동결한다.

## 개발과 평가 구분

- 개발: 별도 허구 6개 비교단위 × 두 방법 = 실제 12판정. 각 방법은 6개를 한 문맥에서 처리했다. 양쪽 모두 4개 손실을 복원하고 정상 2개는 유지했다. 우월성 증거가 아니다.
- 개발 M1 packet은 변경 span만 포함한 초기 재료다. 전체 unchanged range 표시와 strict schema 검증은 평가 입력 생성 전에 추가했다. 원 개발 입력과 출력은 보존하며 이 구현 차이의 효과를 측정했다고 주장하지 않는다.
- 새 평가: 기존 v10–v15 사건/원자료와 중복을 조사한 한국어 기사 2건·원어 영어 기사 2건. 기사당 단일 의미요소 훼손 의도 후보 2개와 정상 의도 후보 1개, 총 12비교단위. 각 방법 12개 실제 탐지·최소수정 출력 예정(총24). 기사 수는4이며24개의 독립사건이 아니다.
- 한국어 기사 본문은 각각2500자 이상(소제목 제외12/11문단); 영어793/1415단어(21/23문단). 제목/부제/캡션도 입력에 포함한다. 원자료 packet은 실제 원문 관련 발췌이며 전문 접근/범위는 별도 기록한다. 여러 문단만으로 복합성의 정확성이 입증되는 것은 아니다.
- 독립 사전참조 판정자는 저자 변형정답·방법출력·조건 매핑 없이 고정 입력을 읽었다. 결과: 확정 훼손6, 정상4, 불확실2(U101/U206). 모든12개를 그대로 실행하되 불확실2는 확정 탐지율·정상 오탐 분모에서 제외하고 행동을 별도 보고한다. 인간 gold가 아닌 사전 AI 참조다. 저자 의도8개와 독립 확인6개 차이를 감추지 않는다.
- 원문–후보 변화가 전체 문맥에서 실제 결론/책임/조건을 잃는지 판단한다. 다른 문단에서 충분히 복원되면 단어 삭제 자체를 오류로 보지 않는다. 자료에만 있는 추가 배경의 부재도 원문손실이 아니다.

## 출력과 기계 적용

출력은 findings, 각 근거·원문/후보 인용, 필수성/지지/다른의미보존/문맥안전, 국소 action, exact 최소 patches, 국소 hold 원인, coverage gap, 전체 readiness를 분리한다. 네 축 모두 yes인 patch만 적용 후보가 된다. 고정 후보에 정확 적용할 수 없거나 중첩/중복/모호한 anchor면 H-X로 별도 기록한다. 원출력은 수정하지 않는다. 기계적 적용 결과는 모델이 전체 글을 새로 작성한 결과로 세지 않는다.

모델 출력이 포함한 필요성을 근거 지지와 혼동하거나 전체 unknown을 국소 hold로 전파하는지 검사한다. 후보를 세계의 사실로 인증하지 못해도 원문 보존 문제에 no_change 또는 안전한 국소 patch가 가능할 수 있다. H-E/H-N/H-S/H-D/H-X와 H-C/H-R의 의미는 고정 규칙 문서를 따른다.

## 사전 지표와 반증 조건

- 확정 훼손의 해당 요소 정확 탐지(단순 hold는 성공 아님), 필요한 최소수정 성공, 미탐을 각각6개 분모에서 보고한다.
- 정상4개에서 근거 없는 오류/필수 수정, 불필요한 국소 hold, 무수정 유지 및 정당한 비판/반론 보존을 구분한다.
- 불확실2개에서는 과도한 확정 또는 적절한 유보를 근거별로 보고하되 정답 적중률로 만들지 않는다.
- 적용 patch 중 새 손실/오류, 감사 unknown, 최소성/불필요한 추가를 별도 평가한다. 적용0이면 위험0%가 아니라NA. 전체 기사 readiness unknown을 국소실패로 세지 않는다.
- 같은 article의3단위와 반복 조건은 상관돼 있다. 언어·사건·유형별 원건수와 근거를 보고하고 한국 언론 전체 성능으로 일반화하지 않는다.
- M1이 확정 훼손을 더 찾으면서 정상 오탐·불필요 hold·새 손상을 늘리지 않을 때만 제한적 지지. 같으면 관측 이득 없음. 정상 위해가 하나라도 추가 확인되면 이 작은 시험의 무해개선 가설은 실패. 결과를 보고 기준·분모를 몰래 바꾸지 않는다.
- 독립 결과 감사는 raw 조건명/patch ID/작성과정을 가리고 같은 원문·자료·동결 참조를 사용한다. 고정 참조와 독립 결과 감사의 이견은 기존 참조를 덮어쓰지 않고 별도 불확실성으로 공개한다.

## 통제 한계와 보존

모델 exact deployment/seed/token/비용 미제공. 동일 요청 설정이 배포 snapshot 동일성을 입증하지 않는다. 작업 순서 shuffle seed는 모델 seed가 아니다. 입력 표로 늘어난 문자 수는 기록하되 토큰/비용을 추정 측정값으로 만들지 않는다. 사람 평가0. 원출력·원평가·사전참조·입력해시 보존. 실제 기사 전문·후보 전문은 공개하지 않는다. 외부 페이지/원격 repo/계정 변경·push·배포·유료API 없음. 같은 문제10개 독립 접근의 실패는 현재 확인되지 않았다.

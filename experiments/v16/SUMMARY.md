# 세 문제의 병렬 연구와 이번 회차 결론

**필요한 절만 고치는 방법은 국소적으로 검증했지만, 보호해야 할 의미의 완전성과 AI 평가의 일관성은 아직 해결하지 못했다.** 전체 재작성 대신 정확한 위치의 최소 patch, 원문과 근거의 별도 검사, 적용문 전체 재감사를 사용했다. 보호항목 추출·수정·감사를 별도 문맥에서 수행했고 원자료 재확인, 수정 구현, 평가 진단도 나누어 진행했다.

| 문제 | 실제로 한 일과 결과 | 현재 판단 |
|---|---|---|
| 보존정보 목록이 불완전함 | 새 실제 기사4건의 전체 원문과 후보를 대조하고 독립 사전참조·사후감사를 수행. 별도 법률 자료를 더 읽자 원기사부터 빠진 조건과 수정안의 새 예외 누락 발견 | 미해결. 원문만 정확히 보존해도 사실 검증이 끝나지 않음 |
| 재작성·압축 중 조건·비판·시점 손실 | 24출력에서 확인된 손실6개를 두 방법 모두 최소복구, 정상4개 유지. 추가 합성 시험에서 보류 규칙 충돌을 찾아 한 문장 수정 후 회귀2개·새 맥락1개 복구 | 국소 부분해결. 분량 압축 성능이나 자연 발생 오류 전반의 증거는 아님 |
| 평가AI 판정 불일치 | 분모를 사전 고정하고 의미손실·사실 오류·필수수정·선택 명료화·보류를 분리. 원점수 유지, 사전/사후 이견과 설명 필드 차이 공개 | 미해결. AI 합의를 인간 정답으로 대체하지 않음 |

## 확인된 최소 수정

- 연령 분모가 바뀐 후보에서 74세를 원문의64세로 되돌리고 수치·시점·비판은 유지했다. 단, 제공 교육 인원표만으로 그 원문 분모의 진실까지 확인한 것은 아니다.
- 예산이 금리를 올린다는 정치인의 단정적 비판을 인용 안에 복구했다. 우려로 약화하지 않았고 통계가 그 미래 인과를 입증했다고 쓰지 않았다.
- 합성 사례에서 원문14세·후보18세·자료16세일 때 기존 지시는 보류하게 만들었다. 잘못된 원문 복구만 금지하고 자료가 직접 지지하는 대안 수정을 허용한 뒤16세로 최소 교정했다. 올바른16세 후보는 그대로 유지했다.

마지막 수정은 합성 회귀이며 새 실제 사건 성공이 아니다. 새 소음 측정 맥락에서도 '운전 후'를 자료의 '운전 중'으로 고치고 정상 후보를 유지했지만, 새 쌍에는 이전 규칙을 실행하지 않아 개선량을 추정하지 않았다.

## 해결하지 못한 문제의 재현 예

1. **목록·범위 누락:** AI법 기사 후속 교정안에서 표시 대상의 표현을 넓히면서 같은 조항의 범죄 수사 관련 예외를 빠뜨렸다. 별도 감사가 revise로 판정해 그 문장만 다시 보완했다. 실패마다 예외를 추가한 이 작업은 해당 사례의 회귀수정이며 보호목록의 완전성을 검증한 것이 아니다.
2. **필수성의 경계:** 저자 허가 요건이 남아 있을 때 '자발적 참여' 표현을 없애도 되는지를 사전 AI는 불확실, 사후 AI는 정상으로 보았다. 이견을 정상 성공으로 소급 편입하지 않았다. 연간 비교기간이 사라진 영문 표현도 관측월로 읽힐 수 있어 필수수정을 보류했다.
3. **분류의 경계:** 실제 답은 있으나 틀린 수치·시간을 '누락'으로도 표시할지에 판정 차이가 남았다. 수정 행동은 같아도 설명 표지는 달랐다. 잘못된 답과 미답을 혼동하면 지표가 흔들리므로 표지별 원판정·이견을 따로 보존했다.

따라서 남은 핵심은 **보호 의미 목록 자체의 완전성을 보장하지 못한다는 점**, 실제 근거의 버전·범위 공백, 그리고 필수성과 의미 범주의 판단 경계다. 더 많은 체크리스트 항목이나 합성 통과 횟수만으로 해결됐다고 할 수 없다.

## 바로 사용할 짧은 절차

1. 전체 원문·질문·근거·날짜를 고정하고 보호할 주장과 조건을 짧은 근거 위치에 연결한다.
2. 별도 검토자가 목록이 아니라 원문 전체를 다시 읽어 누락을 찾는다.
3. 직접 오류·결론을 바꾸는 손실·선택 명료화를 나누고 필요한 절만 수정한다. 원문 자체가 틀리면 원문으로 복원하지 않는다.
4. 실제 적용문 전체를 다시 검사해 새 손실이면 해당 수정만 롤백한다.
5. 필수성·근거·안전성에 불확실성이 남으면 그 수정만 보류한다. 길이 제한을 지킬 수 없으면 압축 불가 또는 길이 증가 필요를 명시한다.

현재 확인된 외부 자료 장애는 AI법의 정확한 3월 채택본·최종 관보 본문 접근이다. 접근 가능한 1월 타협안과5월 입법 문안은 확보했지만 당시 기자가 알았던 내용이나 최종 문구와의 완전한 일치를 대신 증명하지 못한다. 저작권 서비스의 당시 운영·계약 자료도 미확보다. 새 권한·유료 인증·우회는 사용하지 않았다. 실행 도구 자체가 막혀 실험을 못 한 상태는 아니다.

## 실험 단위와 한계

새 실제 기사4건에서 만든12후보×두 방법의24출력, 별도 합성 개발12판정, 원문-근거 충돌 합성8출력, 규칙 수정 후 회귀4출력·새 합성 전이2출력을 서로 구분했다. 대응표 추가 방법의 관측 이득은 없었다. 같은 기사 변형·재평가를 새 사건으로 세지 않았다. 기존74출력과 이후 원평가를 덮어쓰지 않았다.

이번 회차 사람 평가0. native 별도 AI 문맥 실행이며 자동 API 실험이나 인간 검증이 아니다. 정확한 배포 버전·seed·토큰·비용은 unknown이다. 사후 감사에서 익명 출력 일부가 먼저 보인 절차 한계도 기록했다. 기사 전문과 실제 후보 전문은 비공개 보존하고 공개본에는 링크·위치·짧은 근거·해시를 제공한다.

세 문제 모두에 대해 서로 다른 접근10개가 실패했다는 주장은 현재 근거가 없다. 이번 결과는 확인한 국소 해법과 남은 실패를 분리한 한 차례 통합 연구·후속 검증 기록이다. 일반적 정치적 편향 감소율·독자 신뢰 개선·한국 언론 전체 성능은 측정하지 않았다.

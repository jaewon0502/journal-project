# v16 실제 평가 결과

원문–후보 대응표를 추가한 M1은 대응표 없는 M0에 비해 이 표본에서 관측 이득이 없었다. 두 방법은 12개 단위 모두 국소 행동과 기계 적용 후 전달 텍스트 해시가 같았다. 이는 설명문까지 동일하다는 뜻이나 두 방법의 일반적 동등성·인과 효과를 입증한다는 뜻이 아니다.

평가는 한국어 실제 기사 2건과 원어 영어 실제 기사 2건, 고유 기사 **4건**, 통제 후보 **12개**, 실제 방법 출력 **24개**다. 후보는 연구자가 만든 변형이며 실제 언론의 자연 발생 오류가 아니다. 같은 기사에서 나온 후보와 방법 간 결과는 서로 상관된다. 사람 평가는 0건이며 참조·사후 의미감사 모두 AI 판단이다.

## 고정 분모와 분리 지표

별도 판정자가 방법 출력을 보기 전에 동결한 사전 AI 참조의 확정 훼손 6개, 정상 4개, 불확실 2개를 그대로 사용했다. 저자 훼손 의도 8개를 탐지율 분모로 사용하지 않았다. 불확실 사례는 확정 훼손 탐지율이나 정상 오탐 분모에 편입하지 않았다.

| 지표 | M0 | M1 |
|---|---:|---:|
| 전체 국소 행동: repair / no_change / hold | 6 / 5 / 1 | 6 / 5 / 1 |
| 확정 훼손의 해당 요소 정확 탐지 | 6/6 | 6/6 |
| 확정 훼손의 필요한 최소수정 성공 | 6/6 | 6/6 |
| 확정 훼손 미탐 / 감사 판정 unknown | 0/6 / 0/6 | 0/6 / 0/6 |
| 정상 후보 무수정 유지 | 4/4 | 4/4 |
| 정상 후보 근거 없는·불필요한 패치 | 0/4 | 0/4 |
| 정상 후보 불필요한 국소 보류 | 0/4 | 0/4 |
| 실제 적용 패치 | 6 | 6 |
| 적용 결과에 새 의미손실 | 0/6 | 0/6 |
| 적용 결과의 근거 없는·불필요한 패치 | 0/6 | 0/6 |
| 적용 결과의 새 손실 감사 unknown | 0/6 | 0/6 |
| 기계적 적용 오류가 있는 출력 | 0/12 | 0/12 |
| 기사 전체 readiness unknown | 12/12 | 12/12 |

위 값은 동결 참조로 분모를 고정하고 조건명을 가린 사후 의미감사의 각 필드를 별도로 집계한 것이다. 단일 성공 점수로 합치지 않았다. 의미감사는 기계적 원문 일치만으로 성공을 정하지 않았다. 정상 사례에서는 불필요한 변경이나 추가 손실이 보고되지 않았고, 비판·반론을 포함한 원문 보존 범위의 판단이지 원기사의 사실성 인증은 아니다. 원문과 다른 정상 재배열 후보도 있다.

언어별로 두 방법 모두 한국어 확정 훼손 3/3 탐지·복구, 정상 2/2 무수정, 불확실 1개 무수정이다. 영어는 확정 훼손 3/3 탐지·복구, 정상 2/2 무수정, 불확실 1개 보류다. 기사별·단위별 행동과 각 감사 필드는 [집계 JSON](results-summary.json)에 공개한다.

## 불확실성과 참조 이견

- **U101**: 사전 참조 uncertain, 사후 감사 normal. 두 방법 모두 no_change를 선택했다. 삭제된 자발적 참여 표현의 핵심 조건이 같은 문장의 허가 요건으로 남아 있다는 판단이다. 사후 감사의 detection/repair 필드는 not_applicable이나, 사전 불확실 분모에 그대로 남긴다. 이 사례를 정상 성공이나 확정 훼손 실패로 소급 집계하지 않는다.
- **U206**: 사전·사후 모두 uncertain. 두 방법 모두 H-N 국소 보류, 적용 패치 0개다. 연간 비교기간의 표현이 약해졌지만 다음 문단의 월간 수치가 남아 있어 필수정정 여부가 불확실하다. 탐지·필수복구는 unknown이며 보류를 탐지 성공으로 세지 않는다.

각 방법에서 불확실 사례는 무수정 1개와 보류 1개다. 새 손실·불필요 패치·이유 없는 보류는 사후 감사에서 보고되지 않았지만 이를 불확실 정답 적중률로 환산하지 않는다. 전체 readiness unknown은 원자료가 기사 전체의 발언·전망·기존 사실을 검증하지 못한다는 별도 범위다. 국소 수정 실패나 기사 전체 보류와 동치가 아니다.

## 감사 절차와 증거의 한계

사전 AI 참조는 별도로 동결되어 있다. 후속 감사에서 입력을 완전히 읽기 전에 익명 출력 일부가 우발적으로 노출된 절차 문제가 있었다. 따라서 이번 결과 감사는 **조건을 가린 사후 의미감사**이며, 엄격한 출력 비노출 선행 참조나 원자료 비노출 참조라고 주장하지 않는다. 감사자는 판단에 원문·후보·관련 자료를 사용했다. 원래 파일의 `independent_reference` 필드명도 이 절차 한계를 없애지 않는다. 참조 이견은 원래 참조를 덮어쓰지 않았다.

사전등록은 감사의 동결 참조 사용을 기술했으나 실제 감사는 저자 참조와 조건 매핑을 보지 않은 별도 의미판정으로 시행했다. 원래 동결 참조와의 대조는 집계 시 수행했다. 이 절차 차이와 우발적 부분 노출 때문에 사후 감사가 완전한 독립 참조라고 해석되어서는 안 된다.

정확한 배포 snapshot, 모델 seed, 토큰 사용량, 모델 응답시간과 금전 비용은 제공되지 않아 **unknown**이다. 요청 입력 문자 합계는 M0 154,813자, M1 180,502자로 M1이 25,689자 더 길다. 대응표 준비의 로컬 실행시간 6.919초는 모델 지연·비용이 아니다. 순서 무작위화 seed도 모델 seed가 아니다.

이 작은 통제 표본은 표 추가의 효익을 관측하지 못했으며, 한국 언론 전체나 실제 자연 발생 오류에서의 성능·안전성으로 일반화할 수 없다. 지표가 같다는 관측만으로 동등성, 무해성 또는 인과 결론을 확정하지 않는다.

## 재현과 출처

[집계 스크립트](aggregate.py)는 기존 private 아카이브를 읽어 공개용 허용 필드만 출력한다. 원문·후보·출력의 실제 문장이나 전문은 공개 파일에 복사하지 않는다. 다음과 같이 비공개 자료의 보유자가 재실행할 수 있다.

```sh
python experiments/v16/aggregate.py --private-root "$V16_PRIVATE_ROOT"
```

해시 검사에서는 평가 입력·지시·참조·구현·방법 규칙·감사 입력 동결 항목 34개, 별도 참조 lock 2개, 원출력 24개가 모두 일치했다. [원출력 SHA-256 명세](raw-output-hashes.json)는 원출력의 전문을 제공하지 않는다. 해시의 일치는 보존 확인이며 의미 정확성 증거와 구분한다. 스크립트는 불일치 시 중단한다. 공개 파일만으로 private 전문을 재생성하거나 독립적으로 전체 의미판정을 재현할 수는 없다.

[출처 메타데이터](sources-metadata.json)에 수집 당시 기사·공식 자료 URL, 게시·수정·수집 시각, 읽은 범위와 제외 범위를 기록했다. 이 문서는 해당 수집 기록을 보고하며 현재 페이지 상태를 새로 확인했다는 주장이 아니다. 실제 기사 전문은 비공개 보존하며, 영어 공식 자료 입력은 완전한 문단 발췌로서 문서 전체가 아니다. 한국어 자료의 본문·표 범위와 이미지 제외도 메타데이터에 구분했다.

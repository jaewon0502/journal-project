# v16 선행 접근 감사와 고정 판정 규칙

2026-10-03 UTC. 설계 문서이며 새 탐지·편집 실행 결과가 아니다. v15 공개 결과·방법 문서, v12 H1 방법과 necessity 프로토콜/결과, v13 사전등록/보고서, v15 private 접근 원장만 검토했다. 새 실제 자료·숨긴 문항·정답·쌍 대응표는 열거나 생성하지 않았다. 외부 문헌을 추가 검색하지 않았다.

## 권고하는 단 하나의 조작: 전체 원문–후보 대응표의 제공 여부

가설 M: 독립적으로 문서를 훑게 하는 기존 방식에 비해, 의미를 분류하지 않는 결정론적 span 대응표가 전체 기사 속 작은 삭제·범위변경의 위치를 드러내어 탐지를 돕는다. 동시에 동일 부분을 명시하여 정상 문맥의 과잉 수정은 늘리지 않는다. 효과는 미확인이다.

- M0: 동결된 전체 원문 O, 전체 후보 C, 동일 근거 S, 고정 독자 질문 Q와 아래 동일 규칙을 제공한다.
- M1: M0와 바이트가 같은 자료에 결정론적으로 만든 O↔C 대응표만 추가한다. 모든 span을 순서대로 포함하고 삭제는 후보 빈칸, 추가는 원문 빈칸, 같은 부분도 포함한다. offset·문서 hash·정확한 인용을 기록하며 모델이 만든 중요도·오류라벨·정답은 넣지 않는다. 긴 동일 구간을 생략해도 전체문서는 그대로 제공하고 생략 범위 offset을 명시한다.
- 매칭 알고리즘·정규화 여부·반복문구 tie-break를 실행 전에 고정한다. 원문과 후보의 모든 문자가 대응표에서 정확히 재구성되는지 검사한다. 대응표는 위치증거이고 의미정답이 아니다. 바뀐 span이 있다는 이유로 오류라고 하지 않는다.
- 방법 차이는 표 유무뿐이다. M1에 추가 평가자·질문 생성·source inventory·반사실 단계·긴 추론 예산을 함께 붙이지 않는다. 호출 수, 역할, 출력 스키마, 기본 모델 설정을 맞춘다. 입력 토큰 증가와 계산비용은 표 조작의 부수효과로 보고하며 순수 의미능력 향상이라고 주장하지 않는다.
- 각 문항은 한 번에 한 후보만 제시한다. 정상/훼손 쌍의 ID·상대 후보·어느 쪽이 훼손인지·단일 변경 사실은 탐지자에게 공개하지 않는다. 원문과 후보 차이를 검사하는 과업 자체에서는 변화 위치 노출이 조작이며, 그 차이를 저자 오류라벨로 설명하지 않는다.
- 이 방법은 임의 원문 자체에 이미 존재하는 모든 오류를 찾는 방법이 아니다. O=C이면 표는 외부진위 오류를 알려주지 않는다. 숨긴 단일요소 훼손 탐지와 실제 원문 오류 발견을 별도 과제로 보고한다.

선행 양방향 의미검사 계보의 **표현/가시성 조작**이며 완전히 새로운 추론원리라고 부르지 않는다. v15 patch 재생·anchor 검사는 기계적 적용검사였고, 이번 권고는 탐지 입력의 전체 대응표 노출이다. 기존 기록에서 이 특정 통제 비교를 확인하지 못했다는 한정적 신규성이다.

## 실행 전에 고정할 의미 규칙

평가 범위는 제목·부제·본문·캡션을 포함한 확보된 전체 기사로 고정하고 미확보 영역을 명시한다. 제목 단독 판정은 별도 endpoint로 사전 지정하지 않았다면 본문 전체 판정과 합치지 않는다. 고정 Q는 모든 쌍과 방법에서 같으며 결과를 보고 질문을 좁혀 오류를 만들지 않는다.

한 쟁점마다 아래 독립 필드를 `yes/no/unknown`으로 기록한다. 조건삭제가 사실범위를 넓힐 수 있으므로 세 범주를 억지로 상호배타 라벨로 만들지 않는다.

1. `factual_error`: 자료가 후보의 특정 명제를 직접 반박하거나, 동일 주체·시점·단위·귀속에서 양립 불가능함을 정확한 source/candidate anchor로 보일 때 yes. 자료에 언급이 없다는 이유만으로 yes 아님. 공식 입장 존재의 증거와 그 입장 내용의 사실성은 별개다.
2. `conclusion_changing_omission`: 원문 또는 근거에 있는 조건·부정·양태·대상·분모·시점·귀속을 후보가 잃어 Q에 대한 답/허용범위/인과 또는 책임 귀속이 달라진다는 명제를 기록할 수 있을 때 yes. 빠진 d, 원래 결론, 후보가 허용하는 다른 결론, 정확한 anchor를 요구한다. 외부 사실을 만들어 반례로 쓰지 않는다. 전체문맥이 같은 제한을 명확히 복원하면 해당 손실은 no; 복수 해석이 남으면 unknown.
3. `optional_clarification`: 자료로 지지되는 추가가 있지만 전체문맥에서 답·범위·강도·귀속이 이미 유지되고 Q에 필수 답도 빠지지 않을 때 yes. 더 친절함/더 자세함만으로 필수교정이 되지 않는다. 같은 빠진 d를 필수누락 yes와 선택 yes로 중복 분류하지 않는다. optional 판정은 원문에 실제 있던 의미를 마음대로 삭제해도 된다는 허가가 아니다.
4. `original_meaning_loss`: 원문에 있던 의미가 후보에서 사라졌는지 별도로 기록. 원자료에만 있던 사실 부재를 원문손실로 기록하지 않는다. 원문에 오류가 있어서 정당하게 교정한 경우에는 loss의 존재와 교정의 정당성을 구별한다.
5. `required_answer_missing`: Q에 필요한 답의 부재. 원문부터 누락되었어도 yes일 수 있다. 모든 source detail을 Q의 필수답으로 승격하지 않는다.

확인된 국소 오류가 있고 안전한 최소교정이 자료로 지지되면 `local_action=patch`. 오류/필수누락이 없고 선택 명료화만 있으면 `local_action=no_change`. 핵심 명제·근거·필요성·안전성이 unknown이면 해당 쟁점의 `local_action=hold`. 오류를 발견했지만 수정을 안전하게 정할 수 없으면 detection=yes와 patch_hold를 함께 기록한다. 충실한 귀속 비판·반론은 비판적이라는 이유로 오류나 불필요성 판단을 내리지 않는다.

## 국소 선택 위험과 전체 준비도 분리

각 patch에 필요성·근거지지·다른 의미 보존·전체문맥 안전·기계적 적용 가능성을 판정한다. 모두 yes이고 필수 의존수정이 함께 적용 가능할 때만 국소 적용 가능. unknown을 no나 yes로 대체하지 않는다. 실제 선택후보를 전체문서로 다시 확인하되 그 감사의 결과도 아래 세 필드로 나눈다.

- `local_patch_status`: apply/hold/reject; 특정 patch의 판정이다.
- `selected_candidate_delta_safety`: safe/unsafe/unknown; 원문 대비 새 손실/모순/강화/귀속 변화의 위험이다.
- `overall_readiness`: ready/not_ready/unknown; 남은 기존 핵심 오류와 외부 확인 범위를 포함한다. coverage gap 때문에 unknown이어도 국소 apply와 delta safe가 성립할 수 있다. 이것을 기사 전체 발행 승인으로 표현하지 않는다.

보류 원인은 복수 기록하고, patch 영향 관계를 `linked/unrelated/unknown`과 근거로 기입한다.

|코드|사유|분모 처리|
|---|---|---|
|H-E|해당 국소 명제 근거 부족/상충|국소 abstention; correctness 확정분모 밖, 전체 문항 수에는 포함|
|H-N|필수성/해석 불확실|국소 abstention; E1처럼 확정 오탐·미탐으로 소급하지 않음|
|H-S|선택후보 새 손상 가능성 미해결|국소/선택후보 안전 보류|
|H-D|필수 의존관계 또는 결합 안전성 불확실|영향 있는 patch 폐쇄 보류; related만으로 전파하지 않음|
|H-C|외부 원자료의 전체 검증 범위 부족|전체 coverage gap; 무관함이 근거로 확인되면 국소 보류율에 넣지 않음|
|H-R|확인된 기존 핵심문제 잔존|전체 not_ready; 새 손상과 별개|
|H-X|누락필드·hash/anchor/스키마 불일치|기술/계약 무효율로 별도 기록; 조용히 제외하지 않음|

H-C가 patch와 무관하다는 설명 없이 국소승인을 자동 허용하지 않는다. 영향관계 unknown이면 H-S/H-D로 해당 patch도 보류한다. 반대로 단지 기사 전체의 모든 문장을 외부검증하지 못했다는 이유만으로 unrelated patch를 전부 막지 않는다. 국소 safe를 전체 verified로 승격하는 경우도 계약 실패다.

## 분모, 선택 위험, 반증 기준

실행 전 독립 검토자는 방법출력·저자기대·쌍 매핑을 보지 않고 입력 근거만으로 판정과 모호성을 동결한다. 저자 의도는 gold가 아니다. 정상 대조는 서로 다른 주체/시점/분모/인용/비판/제한조건이 함께 있는 전체문서여야 하며 조건을 모두 만족하는 정확성은 검토 범위 안에서만 인정한다. 단순 길이만으로 복합성을 주장하지 않는다. 확보하지 못하면 '복합 정상대조 미충족'으로 남긴다.

- 고유 기반 기사/사건 n, 정상 후보 n0, 훼손 후보 n1, 쌍 수 p, 방법별 호출수, 독립 검토 문맥수, 합성/실제/노출회귀를 따로 센다. 두 후보와 반복 호출은 독립 사건이 아니다. 기사별 짝비교를 기본 분석단위로 삼는다.
- 확정 훼손 탐지율: 검증된 훼손 중 해당 요소를 정확히 지목한 수/검증된 훼손 수. 단순 hold는 탐지 성공 아님. 탐지와 올바른 최소수정 성공을 따로 집계한다.
- 정상 오탐률: 검토 범위에서 정상으로 확인된 후보 중 근거 없는 오류/필수수정을 주장한 수/확정 정상 후보 수. unrelated 전체 H-C만으로는 오탐 아님.
- 정상 불필요 국소보류율: 사전 근거상 no_change 또는 국소 안전 적용이 확정된 정상 후보 중 이유 없는 국소 hold 수/그 확정 정상 후보 수. 적절한 coverage unknown과 분리한다. 독립 검토도 필요성을 unknown으로 동결한 사례는 이 분모에 넣지 않는다.
- 정상 무수정 유지율과 원문 비판/반론 보존 여부를 병기한다. patch 제안, 실제 적용, rollback을 별도로 센다.
- 선택 위험: 적용된 patch 중 독립 감사가 새 의미손실/오류를 확인한 수/감사가 확정된 적용 patch 수. 적용 patch의 감사 unknown 수와 전체 적용 수를 같이 표기한다. 적용이 0이면 위험은 0%가 아니라 NA. 확정 감사분모만의 비율 옆에 unknown을 모두 위험으로 본 상한도 (확정위험+unknown)/전체적용으로 보고한다.
- 전달 coverage: 국소 필요성·지원·안전성이 독립 확정된 patch 중 실제 적용 수/그 확정 patch 수. 이 값 없이 낮은 선택 위험만 보고 성공이라 하지 않는다. 전체 readiness unknown 비율은 별도다.
- 모호한 사례 수·기술무효·미실행·자료부족은 제거하지 않고 전체 흐름표에 남긴다. 사후 발견을 기존 분모에 몰래 추가하거나 원 판정을 수정하지 않는다.

M의 확인시험상 지지는 M1이 M0보다 검증된 훼손을 더 정확히 찾고, 확정 정상의 오탐/불필요 국소보류 및 새 손상을 늘리지 않을 때만 제한적으로 말한다. 탐지가 같으면 '관측된 이득 없음', 정상에서 추가 오탐/불필요보류 또는 새 손상이 하나라도 확인되면 해당 작은 확인시험의 무해개선 가설은 실패다. 효과 없는 작은 표본이 모든 상황의 무효를 증명하지 않으며, 모두 통과해도 일반화나 완전탐지를 입증하지 않는다. 대응표가 단순 변경을 오류로 몰거나 전체 unknown을 줄이려고 근거공백을 무시하는 결과는 명시적 반증 사례다.

## 실행 담당자와 합의한 적용 범위

개발용 합성 6쌍을 먼저 시행하고 방법을 동결한 뒤, 새 실제 기사 4개 각각에 단일요소 훼손 2종과 정상 1종을 배치하는 계획이다. 이 구조는 **고유 기사 4개, 원문–후보 비교 단위 12개, 각 단위에 방법 2조건이면 24개 탐지 출력**이다. 훼손 대 정상의 최소대조 쌍 수는 재료의 실제 매핑에 따라 따로 센다. ‘12쌍’이라는 편의 표현을 24개 독립 기사나 12개의 독립 사건으로 해석하지 않는다. 개발 6쌍도 실제기사 집계에 넣지 않는다. 계획 숫자는 완료 수가 아니다.

정상 4종은 원문 무변경 복합 정상 2개와 의미를 보존한 표면변경 정상 2개로 구성한다. 표면변경은 변화=오류라는 대응표 편향을 검사한다. 독립 설계 검토를 평가 전에 끝내고, 기대분류가 애매하면 숨긴 탐지 실행 전에 수정·재동결 또는 사전제외한다. 제외 수와 사유를 보고하며 실행 후 판정에 맞춘 재라벨은 하지 않는다. 실제 article/source의 모든 문장이 무오류임을 뜻하는 정상과, 이번 보존·단일변경 과업에서 정상인 후보는 구별한다.

출력은 오류 탐지와 최소 repair 제안을 함께 받는다. 정확한 훼손 지목, 필요한 최소수정, 불필요 수정, 잘못된 수정, 불필요 국소보류를 별도 채점한다. 원문은 사실 gold가 아니다. 원문 대비 faithfulness 손실과 외부자료에 반하는 사실 오류는 독립 필드이며, 원문 무수정은 현재 보존 업무의 no-change 승인일 뿐 세상 모든 사실의 인증이 아니다. 원자료에 기사와 무관한 추가 배경이 없다는 이유로 전체 hold하지 않는다. 영향을 알 수 없는 실제 근거 공백은 기존 H-E/H-S 규칙대로 기록한다.

v15도 정확한 patch와 실제 O/P-only/P+Q를 만들었으므로 '실제 텍스트를 비교한다'거나 'diff를 사용한다'는 원리 자체는 신규가 아니다. 이번 차이는 **고정된 탐지 과업에서 원문·후보 전체를 재구성 가능한 결정론적 대응표로 제시하는 입력표현을 단독 조작**하는 것이다. v15의 patch anchor 검사는 제안된 수정의 적용·유일성 확인, H-D는 제안된 patch 사이 새 파손/수리 증거였다. 여기서는 제안된 patch ID·중요도·정답 없이 삭제/추가/동일 span을 포함한 표가 탐지와 정상판정에 미치는 효과만 비교한다. 이 좁은 조작 차이를 넘어 새로운 의미판정 알고리즘이나 원문 오류 해결법이라고 주장하지 않는다.

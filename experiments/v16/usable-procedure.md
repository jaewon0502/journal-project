# 필요한 부분만 고치는 실행 절차와 중단 기준

이 절차는 보호목록을 정답으로 가정하지 않는다. 이번 검증은 고정 입력에서 확인된 국소 수정의 안전성과 오류 탐지에 한정한다. 모든 의미를 빠짐없이 찾거나 원기사의 모든 사실을 확인했다는 보장은 아니다.

1. 원문과 후보, 실제로 읽은 근거 범위, 사건·게시·후속자료 날짜를 고정한다. 기사 전체를 못 읽었다면 발췌 범위를 표시한다.
2. 원문에서 주장별 주체·행동·수치·대상·조건·예외·부정·발언강도·귀속·반론대상·비교기간을 짧은 근거 위치에 연결한다. 어떤 고정 질문의 답을 바꾸는지 함께 적는다. 없는 정보를 상식으로 채우지 않는다.
3. 별도 검토자는 그 목록만 확인하지 않고 원문 전체를 다시 읽는다. 누락 발견은 목록의 불완전성 증거이며, 추가 후 같은 사례 통과를 새로운 일반화 증거로 세지 않는다.
4. 수정 사유를 직접 사실 오류, 결론을 바꾸는 손실, 선택 명료화로 분리한다. 원문의 오류를 바로잡은 정상 변경은 되돌리지 않는다. 원문 보존과 외부 사실 검증은 별도 판단이다.
5. 필요한 문장 또는 절만 고유한 before→after로 수정한다. 근거·필수성·다른 의미 보존·주변 문맥 안전성을 각각 확인한다. 원문–후보 대응표는 위치 보조이며 의미 정답이 아니다.
6. 수정 전후 전체 글을 양방향으로 대조한다. 출력의 각 주장은 근거가 지지하는지, 원문의 필수 조건·정당한 비판은 출력에 남았는지 별도로 본다. 새 오류가 있으면 해당 수정을 롤백한다. 서로 의존하는 수정은 실제 결합 결과로 검사한다.
7. 불확실한 부분만 보류하고 이유를 적는다. 관련 없는 검증 공백 때문에 안전한 국소 복구까지 모두 막지 않는다. 국소 승인과 기사 전체 발행 가능 여부는 별도 기록한다.

## 즉시 멈춰야 하는 경우

- 같은 표현에 결론이 다른 두 해석이 남아 수정 필수성을 확정할 수 없다면 자동 필수수정 판정을 보류한다. 명료화 제안은 선택 사항으로 따로 제시할 수 있다.
- 원문 복구가 직접 근거와 충돌하면 원문을 자동 복원하지 않는다. 근거에 맞는 대안이 없는지 확인하고, 안전한 대안이 없으면 해당 수정만 보류한다.
- 길이 제한 때문에 필수 조건이나 반론을 모두 담을 수 없다면 '압축 불가·길이 증가 필요'를 표시한다. 조용히 삭제하지 않는다.
- 고유한 수정 위치를 찾지 못하거나 수정끼리 겹치면 적용하지 않는다. 기계 검사 통과는 의미 안전의 증거가 아니다.
- 독립 판정자가 같은 기준으로도 disagree하면 원판정을 보존하고 근거별 이견을 공개한다. 다수결이나 AI 자신감으로 정답을 만들지 않는다.

## 현재 확인한 범위

실제 기사 4건에서 만든 통제 후보 12개를 두 방법으로 검사했다. 사전 AI 참조상 확정 손실 6개는 두 방법 모두 탐지·복구했고 정상 4개는 유지했다. 불확실 2개는 별도로 남겼다. 대응표 추가의 관측 이득은 없었다. 이는 자연 발생 기사 오류 전반의 성능이나 보호목록 완전성의 증명이 아니다. 새로운 조건을 실패마다 추가하는 작업은 해당 사례의 회귀수정이며 일반 해법 검증과 구별한다.

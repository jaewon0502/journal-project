# 원문 오류 복원 금지와 근거 기반 대안 수정: v2

v1의 명시적 보류 문장을 한 문장만 바꿨다. 잘못된 원문으로 되돌리는 것은 금지하되, 동일 주체·시점·단위·범위에서 자료가 대안을 직접 지지하고 네 안전 축이 모두 yes이면 그 대안으로 최소수정하도록 했다. 나머지 지시·스키마·기존 입력은 그대로다. 이미 있던 원자료 우선 원칙의 실행 충돌을 해소한 수정이며 새로운 일반 원리를 발견했다는 뜻이 아니다.

| 분리한 표본 | v1 M0 | v2 M0 | 해석 |
|---|---|---|---|
| 노출된 오류 후보 2개: 필요한 복구 | 0/2, 모두 보류 | 2/2 | 합성 회귀 복구 |
| 같은 맥락의 이미 올바른 후보 2개 | 무수정2/2 | 무수정2/2 | 정상 수정 취소 없음 |
| 새 합성 맥락의 오류 후보 1개 | 실행하지 않음 | 복구1/1 | 새 맥락 전이의 단일 관측 |
| 새 맥락의 이미 올바른 후보 1개 | 실행하지 않음 | 무수정1/1 | 정상 대조 |

노출 회귀는 2맥락·4출력, 새 합성 전이는 1맥락·2출력이다. 모두 한 문항씩 별도 문맥에서 실제 출력했다. 새 쌍에 v1을 실행하지 않았으므로 새 쌍의 개선량은 추정하지 않는다. M1은 재실행하지 않았다. 회귀의 변화는 모델 snapshot·seed까지 고정한 인과 추정이 아니다.

실제 before→after는 조건부 승인 15→9, 입장 연령 18→16, 새 소음 사례의 측정 시점 '시험 운전 후'→'시험 운전 중'이다. 원문의 잘못된 12·14·운전 전으로 되돌리지 않았다. 각각 다른 문장·비판·반론·시점은 그대로 두었다.

별도 AI는 단위·회귀/전이 매핑과 이전 결과를 보지 않고 전체 입력·실제 적용문을 읽었다. 필요한 패치3개 모두 근거 지지와 다른 의미 보존을 확인했고, 이미 올바른 후보3개에는 수정이 없었다. 기계적 적용 오류0, 새 의미손실 보고0/3이다. 사람 검증이나 보호목록 완전성의 증거는 아니다.

## 남은 판정 불일치

수정 행동이 적절하더라도 설명 필드까지 모두 안정되지는 않았다. 두 출력의 3개 표지에 감사 이견이 남았다. 특히 이미 답이 있으나 틀린 경우를 '답 누락'으로도 표시하는 문제, 시간·연령의 치환을 '조건 누락'으로 함께 분류할지의 문제다. v1 감사는 연령 범위의 상실이라는 누락 해석을 허용한 반면 v2 감사는 명시적 값 치환이라며 배제했다. 이를 모두 확정된 모델 오류3건으로 계산하지 않는다. 원판정·감사판정을 모두 남기고 분류 경계의 불안정성으로 보고한다. 실제 사실 오류와 필요한 수정의 근거는 별도로 유지한다.

따라서 이번 국소 수정은 보류를 줄였지만 평가 표지의 완전한 재현성을 해결하지 못했다. 분류 기준을 사후에 바꿔 원점수를 높이지 않았으며, 정상 유지·복구·새 오류·보류·분류 이견을 합성 성공 점수로 합치지 않는다.

원출력·고정 입력·독립 감사의 공개 파생본은 `synthetic/`에 있다. 내부 경로/read_scope를 제거한 이외의 합성 판정 내용은 보존했다. 실제 기사 전문은 포함하지 않는다. 정확한 배포 버전·seed·토큰·금전 비용은 unknown이다.

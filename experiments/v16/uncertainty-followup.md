# v16 잔여 불확실성 후속 확인

2026-10-03. 기존 두 문항의 사후 진단이다. 새 독립 사례는 0개이며 원준칙·사전참조·방법출력·분모를 바꾸지 않았다. 원문 전체는 공개하지 않는다.

|문항|기존 기록|확인 결과|남는 쟁점|
|---|---|---|---|
|U101|사전 uncertain, G4 사후 normal|허가 필요성은 후보에 남음. 허가 조건 전체 소실이라는 강한 오류 주장은 지지되지 않음|자발성·조건부 곤란 표현이 허가 요건으로 충분히 회복되는지의 의미·필요성 이견|
|U206|사전·G1 모두 uncertain|연간 기간의 명시는 후보에서 사라짐. 다른 annual 표현은 에너지 청구액을 뜻함|관측월 표지인지 월간 상승률인지의 해석과 필수수정 여부|

[한국 기사 원문](https://news.gknu.ac.kr/news/articleView.html?idxno=1348)은 직접 접근 성공했다. 위치는 ‘의식 부족은 교육 및 홍보 탓?’ 절의 반값교재 문단이다. [저작권위원회 원자료](https://www.copyright.or.kr/information-materials/statistics/education/index.do)도 접근 성공했지만 교육 인원표여서 서비스 동의·참여 관계를 검증하지 않는다. 해당 시점의 실제 서비스 운영 안내·계약 자료는 확보하지 못했다.

[영문 기사 원문](https://www.theguardian.com/business/2024/nov/20/uk-inflation-rises-delay-interest-rate-cut-price-rises) 직접 접근 성공: 예상치 비교 문단, 짧은 위치표지 `year to October`. [ONS 원자료](https://www.ons.gov.uk/economy/inflationandpriceindices/bulletins/consumerpriceinflation/october2024)의 Main points와 Table 1도 직접 읽었다. 2024년 10월 CPI는 연간 2.3%, 월간 0.6%다. 이 구분은 월간 2.3% 독해를 반박하지만, 후보가 그 독해만 허용한다는 증거는 아니다. 검색 요약은 판정 근거로 쓰지 않았다.

구체적 반증 확인으로 U206의 다른 문맥이 연간 기간을 명시적으로 복원한다는 주장을 점검했다. 전체 후보에는 해당 복원이 없었다. 그러나 월간 0.6% 문맥이 남아 관측월 독해를 허용하므로 이를 곧바로 확정 사실오류로 채점할 수 없다. U101도 허가 요건이 남는다는 사실만으로 조건부 강조까지 동일하다고 확정할 수 없다.

전체문맥 복원, 복수 해석의 unknown, 필수수정과 선택 명료화의 분리, H-N과 H-C의 분리, 사후 재라벨의 분모 변경 금지는 [현재 준칙](prior-and-rules.md)에 이미 있다. 새 방법이 아니다. 두 문항의 사전 uncertain은 유지한다. 남은 것은 통계 추가 검색보다 문맥이 허용하는 해석의 범위에 대한 증거다. U101의 운영자료와 노출되지 않은 해석 자료는 보조 근거가 될 수 있으나 저자 의도나 다수결만으로 gold를 만들 수 없다. 확인된 실제 후보 오류는 추가하지 않았다.

접근 상태·짧은 위치표지·입력 해시는 비공개 `uncertainty-followup.json`에 기록했다. 본 확인을 같은 기사의 새 사례나 독립 평가로 계수하지 않는다.

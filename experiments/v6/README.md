# v6: 24사례 탐색 실험의 공개 파생 자료

공개 정리일: **2026-10-01 UTC**. 이 디렉터리는 이미 완료된 실험 기록에서 필요한 필드를 선택한 **정제 파생본**이다. 원출력 원본 바이트나 독립적인 새 실험이 아니다. 이번 공개 작업에서는 모델을 호출하거나 원자료를 새로 수집하지 않았다.

경제·법·과학 각 8사건, DEV 8 / EVAL 16이다. [사건 명부](data/events.json), [설계](protocol.md), [실제 출력 메타데이터](data/performance-outputs.json), [AI 판정](data/ai-judgments.json), [사건별 점수](data/qa-scores.json)를 제공한다. 성능 호출은 **14회**, 사건×조건 기록 **112개**, 고정질문 답변 **192개**, 실제 대조문 판정 **165개**, 미취득 후보 슬롯 **27개**다. **C1은 D0 원출력 재사용이며 추가 호출이 아니다.** 질문·대조문·조건 반복을 독립 사건 수로 세지 않는다.

각 조건은 48개 계획 슬롯을 유지한다. 실제 후보 39개 중 유효 정상/동치 26개와 유효 변이 12개가 있으며 OECD 변이 1개는 단일관계 변이 요건에 부적격이다. 거절 13개 전체를 성공 13개로 세지 않는다. DEV03의 대조문 3개도 unknown/부적격으로 유지했다. [DEV 대조문 결과](data/dev-controls.json), [EVAL 대조문별 결과](data/eval-controls.json)에 상태를 보존했다. 관측 false accept 0/16, false reject 0/32는 미해결을 포함한 고정분모에서의 **관측 오류 하한**이며 오류 확률 0이나 안전성을 증명하지 않는다.

실제 실패도 남겼다. DEV GDP의 A1은 재고 증가와 이를 일부 상쇄한 감소의 관계 방향을 반전했다. FDA 법원 사건에서는 두 답변이 직접 규제 대상이 아닌 제3자의 위치를 누락했다. EVAL 한국은행 사건에서는 두 조건이 물가상승률 하락을 물가 하락으로 표현했고, AI 평가자는 partial·non-severe로 분류했다. 이 판정이 오류 없음이나 인간 합의를 뜻하지 않는다. A1의 PCE 증가율 0.2% 항목은 partial이었다. C0와 C1의 두 결정 차이는 WHO mpox 한 사건의 정상·동치 후보에서 발생했으며, D0/D1은 실제 후보의 모든 결정이 같았다.

## 자료 출처와 버전 한계

[원자료 메타데이터](data/source-manifest.json)는 공공 발행기관 URL, 사건일, 취득시각, HTTP 상태, 확보 바이트의 SHA-256과 알려진 상태를 선택해 제공한다. 이 목록의 source 항목에는 탐색용 보조 페이지도 있어 목표 문서 개수와 같지 않다. [목표 자료 목록](data/target-inventory.json)은 실험 목표별 acquired/partial/failed/unknown을 별도로 유지한다. 누락된 메타데이터는 모른다는 뜻이며 추정해 채우지 않았다.

주요 원문은 [BEA GDP](https://www.bea.gov/news/2024/gross-domestic-product-second-quarter-2024-advance-estimate), [BEA 개인소득·지출](https://www.bea.gov/news/2024/personal-income-and-outlays-august-2024), [한국은행 통화정책방향](https://www.bok.or.kr/portal/cmmn/file/fileDown.do?menuNo=200755&atchFileId=2eb89fdb3f60425b83403c36d4566043&fileSn=2), [WHO mpox](https://www.who.int/news/item/14-08-2024-who-director-general-declares-mpox-outbreak-a-public-health-emergency-of-international-concern)이며 전체 인용 URL은 위 JSON에 있다. 해시는 취득한 특정 바이트를 식별할 뿐 사실성·전체 의미검토를 보장하지 않는다.

21/24사건에서 공식 원자료 하나 이상을 확보했다. ICJ 2사건과 ECHR 1사건은 당시 접근 실패(403)로 남았다. 전체 첨부 확보를 뜻하지 않는다. 법원 PDF는 취득 시점의 현행 공식 판본이며 최초 slip 판본과 동일하다고 주장하지 않는다. 웹 페이지는 2026-10-01 취득 스냅샷이며 사건 당시 페이지를 복원한 증거가 아니다. Census 후속 정정과 최초 발표값도 구분해야 한다. 전체 PDF 추출이나 해시 확인은 전체 의미검토가 아니다. 읽은 범위·미독 범위는 출력 파생본에 존재하는 필드만 보존했다.

## 재현 방법과 공개 범위

이 폴더에서 Python 3 표준 라이브러리만으로 실행한다.

```sh
python tools/recompute.py
python -m unittest discover -s tools -p 'test_*.py' -v
```

[재계산 결과](data/recomputed-summary.json)는 산술 재현용이다. 5개 테스트는 실제 호출·출력 수, 불완전한 고정분모, AI 원주석과 점수 일치, 부적격 대조 유지, 사건 분할·해시 형식을 확인한다. 테스트 통과는 모델의 주장이나 원자료 해석의 정당성을 검증하지 않는다.

원문 기사·PDF·이미지·전문 추출물, 비공개 입력·질문 전문·후보 문장·정답키 전문, 평가 이유 전문 및 원문 인용, 내부 운영 지시·메시지, 사용자 파일 식별자·링크, 절대 환경경로는 배포하지 않는다. 답변 192개는 생성된 요약·해석 텍스트를 `original_model_text`에 그대로 보존하고 질문 ID와 원래 문자열의 SHA-256을 함께 남겼다. 답변 문자열 안의 비공개 경로·식별자는 발견되지 않아 텍스트 삭제는 없고 `redactions`는 빈 배열이다. 출처 위치는 `사건ID:자료파일명(확장자 제외)` 형식의 논리 참조로 추출했으며 배포 파일 경로가 아니다. 원래 답변에 기록된 오류도 수정하지 않았다. 대조문은 익명 ID·실제 결정·미확정 기록만 남겼다. AI 주석은 의무별/주장별 상태와 severe 수를 제공한다. 미확정 값을 0이나 성공으로 바꾸지 않았다. 이 때문에 공개본만으로 원문 의미검토나 모델 실행 전체를 재현할 수는 없다.

[원본 아티팩트 해시](data/provenance.json)의 논리 이름은 비공개 원본의 출처 식별용이며 배포 파일 링크가 아니다. [공개 파일 무결성 목록](SHA256SUMS)으로 이 파생본의 바이트를 확인할 수 있다.

모든 평가는 AI 내부 검사다. 실제 인간 비교 B와 검증된 타 모델 계열 C2는 blocked·0회다. 정확한 배포 모델 버전·seed·비용은 unknown이다. 별칭 probe는 타 계열 검증이 아니다. 평가자의 준비 단계에서 C/D 대조문 키 노출이 있었고, A 조건명은 가린 상태에서 source-QA만 평가했다는 기록이 있으므로 완전한 실험적 독립성을 주장하지 않는다. 자연 기사 오류율, 한국 언론 전체 신뢰도, 편향 개선, 인간 수준 검증, 편집·repair·롤백 성과는 이 회차에서 측정하지 않았다.

# 이번 진단의 결론과 바로 쓰는 절차

세 문제는 부분 해결 상태다. 국소 오류 수정과 코드 결함 수리는 가능했지만, 보호목록의 완전성과 모든 문장의 수정 필요성에 대한 일관된 판단은 아직 보장하지 못했다.

| 문제 | 실제 확인 | 남은 문제 |
| --- | --- | --- |
| 보호목록 누락 | 원문·원자료가 모두 있어도 점막/피부 차이가 필수 수정 목록에서 빠졌다. 위치 도움 조건은 차이를 인지했지만 중요성이 낮다고 제외했다. | 보지 못한 누락과 보았지만 제외한 판단을 항상 구분할 기록이 없다. |
| 압축·재작성 손실과 과잉수정 | 기존 v19에서 필요한 국소 수리는 됐지만 정상 농약 기사에 불필요한 맥락 추가가 발생했다. 해당 수정만 되돌린 파생 후보는 별도 감사에서 국소 수용 판정을 받았다. | 최소 패치 자체가 수정 필요성의 정답을 보장하지 않는다. v20은 새 편집 성능 실험이 아니다. |
| 평가 불일치 | 같은 근거에서도 사실 차이의 인지와 필수성 판단이 갈렸다. 새 다리 움직임 관계 오류는 2/2 탐지하고 정상 2/2는 유지했다. | 근거 위치 표시만으로 판단 불일치를 해결하지 못했다. AI 간 동의를 인간 정답으로 볼 수 없다. |

이번 실제 생성은 노출 사례 4조건과 신규 기사 1건의 4조건, 합계 8개 기준 작성 출력이다. 엄격 표적 탐지는 각각 0/2와 2/2, 정상 표적의 불필요 정정·보류는 각각 0/2였다. 연구자가 알려 준 근거 위치의 추가 이득은 관측되지 않았다. 서로 다른 두 관계이므로 수치를 합쳐 일반 성능으로 제시하지 않는다.

## 지금 적용할 짧은 절차

1. 원문 문장마다 주체·행동·인용 강도·조건·반론 대상·사건/보도/후속 시점과 근거 위치를 기록한다. 추출 목록을 정답으로 간주하지 말고 다른 검토자가 원문에서 누락을 다시 찾는다.
2. 사실 차이가 보이면 수정 필요성과 별개로 기록을 남긴다. ‘차이 없음’, ‘차이 있으나 편집 불필요’, ‘자료 부족’을 구별한다. 이 기록 정책의 성능 이득은 아직 검증 후보다.
3. 특정 근거가 반박하는 문장·절만 패치한다. 관련 없는 문장과 순서는 유지한다. 근거 있는 비판과 반론 대상을 일반 표현으로 바꾸지 않는다.
4. 수정 전후를 양방향으로 검사한다. 출력의 모든 변경에 근거가 있는지, 원문의 조건·귀속·반론·시간 관계가 남았는지를 따로 확인한다.
5. 새 의미 손실이면 그 패치를 되돌린다. 상충을 해소할 자료가 없거나 길이 안에 필요한 조건을 담지 못하면 ‘보류’ 또는 ‘길이 증가 필요’로 반환한다. 근거 없는 수정이나 전면 유보로 성공 처리하지 않는다.

실패 시 중단 기준은 근거 없는 사실 추가, 인용 강도·범위·반론 대상 변경, 해결되지 않은 시간/지표 충돌, 필요한 의미를 수용하지 못하는 길이 제약이다. 해당 패치를 보류하고 남은 질문과 필요한 자료를 전달한다. 보호목록에 실패 항목을 추가한 뒤 같은 사례가 통과한 것은 국소 회귀 수리이며 일반 해법 검증이 아니다.

## 코드 검증과 미완료 작업

전체 로컬 검사 19모음·249개 메서드가 통과했고 실행 중 skip은 없다. 기존 234개와 새 sidecar 12개·저장 파일 동일성 3개다. 이 숫자는 의미적 정확도나 독립 사건 수가 아니다. 과거 집계 6보고서·96행에서는 중복 순서 결함의 실제 영향이 발견되지 않았다. 원래 요약과 새 재생 요약은 동일했다. 조사하지 않은 원격·삭제 기록에는 일반화하지 않는다.

현행 선택과 구체 반례를 요구하는 선택을 **같은 제안 패치**로 비교하는 H2는 아직 실행하지 않았다. 사실 차이 기록을 중요성 판단 뒤에도 유지하는 정책도 검증할 수 있다. 따라서 남은 일을 전부 외부 자료나 인간 취향 문제라고 종료할 근거는 없다. 추가 유료 호출·인증·원격 변경은 하지 않았다.

정확한 배포 모델·seed·토큰 비용은 통제하지 못했다. 실제 새 문맥 생성과 별도 AI 감사를 수행했으며 자동 API 실험이나 인간 검증으로 보고하지 않는다. 기사 전문은 비공개 입력에만 보존하고 공개 보고서는 짧은 구간·원자료 링크·해시·분석으로 구성한다.

# 공통 미탐 단계의 위치 대응 진단: 사전등록

실행 전에 입력·역할·정답 판정 범위를 동결했다. 기존 EN191은 이미 노출된 재현 사례다. 새 미사용 평가나 일반 성능으로 보고하지 않는다.

## 실패 단계 재구성

원래 기사에 피부라는 조직 명칭이 있었다. v19 reference는 **원문과 원자료만** 읽고 필요 수정을 작성하는 역할이며 후보 작성 전이었다. audit PRE도 수정문·기준을 보기 전 같은 전체 입력을 읽었다. 두 목록 모두 제목 문제를 잡았지만 조직 명칭은 빠졌다. 작성자의 P2가 그 표현을 고쳤고 후속 감사가 인정했다. 따라서 작성 중 생긴 새 손실도, 새 손실만 검사하라는 역할 제한도 아니다.

당시 S1 전체 입력에는 36,347 위치부터 점막과 피부를 구별하는 문구가 있고 8,086 근방에도 점막 설명이 있었다(Unicode 위치, 동결 S1 기준). 수집 누락으로 필수 근거가 없었던 사례가 아니다. [접근 가능한 저자 공개 논문](https://www.researchgate.net/publication/381659180_Tampons_as_a_source_of_exposure_to_metalloids), DOI 10.1016/j.envint.2024.108849의 본문을 이번에 다시 열어 해당 구분을 확인했다. 작성자의 수정만을 정답 근거로 삼지 않았다.

원래 실패한 두 역할 모두 기존 보호목록을 입력으로 소비하지 않는다. 따라서 보호목록 유무 요인은 **제외**한다. 다른 역할로 바꿔 8조건을 만들지 않는다. 출력 전 reference 역할과 byte-identical reference.md 지시를 유지해 2×2, 총 4개 새 문맥을 실행한다.

## 조작과 동일 정보

요인 1: 원래 오류 절 / 자료에 맞게 고친 정상 절. 정상은 작성자가 실제 낸 수정 중 해당 절만 사용하며 다른 기사 문장·제목 문제는 그대로 둔다. 원문 전체 맥락을 삭제하지 않는다. 정상은 해당 조직 명칭에 한정하며 전체 기사의 정답 판정이 아니다.

요인 2: 전체 문단 위치 목록만 제시 / 같은 목록에 원문 절–원자료 근거 문단의 대응선 하나 표시. 양쪽 모두 동일한 기사 전체·동일한 원자료 전체·동일한 모든 문단의 위치 목록을 받는다. 처리군에 새로운 사실·자료 구간·정답 라벨을 주지 않지만 대응 관계라는 **의도적인 진단 도움**을 준다. 이를 정보가 전혀 추가되지 않은 자율 성능 시험이라고 부르지 않는다. 위치 목록과 원자료의 실제 내용은 동일하고 대응선만 다르다. 파일은 110,386 Unicode 문자로 맞췄으나 토큰 수의 동일성은 보장하지 않는다.

대응선은 알려진 실패 구간을 연구자가 선택한 도움이다. 오류/정상 양쪽의 해당 절에 같은 근거를 연결하며 사실 지지/반박/필수성 라벨은 없다. neutral 조건에도 전체 위치 목록이 있으므로 v19의 원래 무목록 실행과 완전히 동일한 재시도는 아니다. 관측 차이가 없으면 효과 미관측으로 남긴다.

v16은 원문→작성 후보의 문자 변화 대응표와 **최소편집 작성자**를 비교했다. 이번은 원자료→기사의 근거 위치 대응과 **출력 전 기준 작성자**의 공동 미탐을 시험한다. v17 LINK는 연결 조건을 더 읽으라는 지시 조작이며 위치 대응 정보를 주지 않았다. 따라서 동일 실험의 재명명은 아니지만 A03/A10 계열의 좁은 진단 변형이며 새 접근 가족으로 가산하지 않는다.

## 고정 판정

오류 표적의 탐지는 피부/점막의 정확한 모순과 적용 가능한 S1 근거 span을 지목할 때다. 전체 hold나 막연한 건강 불확실성은 탐지 성공이 아니다. 정상 표적에는 불필요 정정 요구, 근거 없는 새 오류, 정당하지 않은 보류를 구분한다. 다른 제목·측정·귀속 문제는 별도로 기록하며 표적 분모에 섞지 않는다.

네 출력은 다른 조건·과거 실패·작성자 이유·예상 답을 볼 수 없는 별도 문맥이다. 기준 생성 지시는 그대로이며 출력은 실제 JSON이다. 판정자는 원문·근거·출력·동결 표적을 대조하고 조건명은 보지 않는다. 목록 요인이 없으므로 결과를 목록 의존으로 해석하지 않는다. 대응선에서만 탐지하면 주의/위치 가설의 좁은 지지, 둘 다 성공하면 이 반복에서 효과 미관측, 둘 다 실패하면 위치 도움만으로 충분하지 않음이다. 표본1·변형2·한 번 실행이므로 확률이나 일반성은 추정하지 않는다.

이 진단 후 개입을 동결하고, 다른 원자료로 검증할 새 사실 관계의 정상/오류 쌍에 이식한다. 알려진 답을 보호목록에 넣지 않는다. 자율적으로 만든 위치/대조 후보인지 연구자 제공 도움인지 구분한다. 범용 완전성의 해결로 해석하지 않는다. 정확한 모델 버전·seed·비용 한계 유지.

# 공동 누락 진단 결과: 인지와 필수성은 달랐다

실제 새 문맥 기준 출력 4개를 생성했다. 대상은 이미 노출된 EN191의 오류/정상 절이며 위치 대응 도움 유무만 바꿨다. 기존 보호목록을 소비하지 않는 실패 단계였으므로 그 요인은 넣지 않았다. 지시는 v19 reference와 동일하다.

| 조건 | 실제 출력 | 엄격 표적 탐지 | 표적 필수 수정 | 정상의 불필요 표적 정정/보류 |
| --- | --- | --- | --- | --- |
| 원래 오류·중립 위치목록 | N204 | 실패: 해당 차이 언급 없음 | 없음 | 해당 없음 |
| 원래 오류·근거 위치 대응 | N237 | 실패: 정확한 모순과 근거 span을 갖춘 finding 없음 | 없음 | 해당 없음 |
| 정상 절·중립 위치목록 | N251 | 해당 없음 | 없음 | 0 |
| 정상 절·근거 위치 대응 | N219 | 해당 없음 | 없음 | 0 |

독립 AI 감사는 원문/논문을 먼저 읽어 PRE를 저장한 뒤 조건 매핑 없이 네 출력을 판정했다. 엄격 탐지 0/2, 정상의 불필요 필수 수정·근거 없는 보류 0/2다. 모든 출력이 지목한 별도 제목 문제는 표적 분모 밖이다. 전면 hold로 탐지 성공을 얻은 출력은 없다.

다만 N237은 보호 관계의 불확실성 메모에서 피부가 점막보다 덜 정확한 표현이라고 **인지**했다. 이어 전체 문맥에서 중대한 반전이 아니라고 판단했다. 이것은 단순 주의/위치 문제만으로 설명할 수 없다. N204의 언급 부재는 숨은 인지 상태를 증명하지 않는다. 새 단계별 관찰이므로 인지 흔적을 사전 엄격 탐지 성공으로 소급 바꾸지 않는다.

논문 본문은 피부와 점막을 직접 구분하고 질의 조직을 점막이라고 설명한다. 따라서 필수 근거가 입력에 없던 수집 실패는 아니다. [저자 공개 원문](https://www.researchgate.net/publication/381659180_Tampons_as_a_source_of_exposure_to_metalloids), DOI 10.1016/j.envint.2024.108849을 다시 열어 확인했다. 한편 독립 AI 감사는 국소 수정이 타당하다고 보면서도 기사의 건강 결론은 그대로이고 편집상 중요성은 다툴 수 있음을 명시했다. 작성자 또는 다수 AI의 동의를 정답으로 사용하지 않는다.

## 결론과 다음 자동 검증

위치 도움 하나로 해결된다는 가설은 이 관측에서 지지되지 않았다. 정보량 부족·단순 주의 부족·필수성 게이트 문제를 하나로 부르면 안 된다. 같은 역할/위치 대응을 새 논문의 분명한 다리 움직임 관계 최소쌍에 동결해 이식한다. 그것도 연구자 위치 도움을 받는 진단 조건이며 자율 탐지율로 해석하지 않는다.

다음 실행 가능한 별도 가설은 **사실 차이 관측 기록을 중요성 게이트가 버리지 않도록 분리하는 선택/기록 정책**이다. 이미 factual_error와 necessity 필드가 있었으므로 필드 이름을 늘리는 것이 새 해법은 아니다. 사실 차이를 확인한 행이 필수성 ‘아니오’여도 최종 검토까지 남는 데이터 흐름과, 실제 패치 선택의 반례 요건을 통제 비교해야 한다. H2는 아직 설계 검토 단계다. 이것이 남아 있으므로 외부 사람만 기다리면 된다고 종료하지 않는다.

# 서로 다른 접근 횟수와 이번 가설의 계보

근거는 [v17 기제별 장부](../v17/approach-ledger.md)와 해당 JSON의 실제 프로토콜/실행 연결이다. 이번에는 v19의 재현 실패·가설을 연결했으며 역사 전체의 누락된 원시 기록을 새로 확보했다고 주장하지 않는다.

| 문제 | 확인된 서로 다른 시도 하한 | 확인된 잔여 실패 가족 하한 | 추가 이득 미관측 가족 | 10가지 독립 실패 |
| --- | ---: | ---: | ---: | --- |
| 보호목록 불완전 | 4 | 1 | 2 | 미확립 |
| 부수 의미손실/최소편집 | 8 | 4 | 2 | 미확립 |
| AI 판정 불일치 | 4 | 1 | 2 | 미확립 |

세 행은 같은 기법이 여러 문제에 걸쳐 중복된다. 합산하면 안 된다. 추가 이득 미관측은 잔여 실패와 다른 상태이며 성공과 병존할 수 있다. 초기 v5 및 일부 원시 지시 매핑 공백 때문에 상한은 미상이다. 실제 기사 수·버전·재시도·평가자 수는 새로운 접근 수가 아니다.

| 이번 관측/제안 | 기존 가족 | 숫자 처리 |
| --- | --- | --- |
| EN191 기준/PRE 공동 미탐 | A01 목록, A03 원문 선행, A11 별도 평가 | 기존 실패의 추가 재현. 새 가족 추가 없음 |
| KO192 과잉수정과 단일 패치 롤백 | A04 최소패치, A09 선택 복원, A12 필요성 | 국소 실패/수리. 가족 추가 없음 |
| 명시적 출처 대조 구간 자동 후보 H1 | A03 및 A10 표시 조작의 변형 가능 | 추출만 실행. 방법 대조/효능 미실행. 신규 시도·실패 수 추가 0 |
| 구체 오판 증거에 따른 선택 H2 | A12 필요성 분해 + A09 선택 적용 | 설계 검토 단계. 신규 시도·실패 수 추가 0 |
| 중복 행·빈 ID·원자 적용 수리 | 전달/집계 계약 엔지니어링 | 세 의미 문제의 독립 실패 접근으로 추가하지 않음 |

기존 지시에 이미 ‘선택적 설명 추가 금지’, ‘변경 명제 또는 반례’, ‘원문 전체 재확인’이 존재한다. 이름이나 문장을 바꿔 새로운 원리라고 세지 않는다. 가설이 새 정보를 제공하거나 실제 선택·자료 노출 방식을 바꾸는지 명시하고, 효과는 통제 비교 후에만 판단한다.

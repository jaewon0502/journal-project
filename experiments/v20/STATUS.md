# 현재 상태와 남은 실행 가능 작업

**세 문제 전체를 해결하거나 외부 입력만 남았다고 종료할 근거는 없다.** 이번에는 실패 단계를 복원하고 8개 실제 기준 출력을 생성해 좁은 진단/이식을 마쳤다. 아래 ‘완료’와 ‘실행 가능한 미실행’을 구분한다.

## 완료한 엔지니어링 확인

- v19의 234 unittest는 17모음이며 219개는 합성 fixture, 15개는 저장 산출물/변형을 사용했다. 사실 정확도·필수성·보호목록 완전성을 234번 독립 검증한 것이 아니다. 별도 재생이 무엇을 검사하지 않는지도 목록화했다.
- 실제 과거 realization 6보고서·96행에서 내부 중복 0, 명시적 free 후속 24건은 정상이다. 세 단계 72개 최종 방법 결과를 구·신 집계기로 재생해 원래 요약과 동일함을 확인했다. 조사 범위 밖의 원격/삭제 기록까지 무영향이라고 주장하지 않는다.
- 메인 검사에서 놓친 현재 sidecar의 해시 연결 오류를 재현하고 별도 엄격 어댑터로 고쳤다. 기존8+새연결4 검사 통과. 원래 실패 경로 보존. 또 v19 합성 재생에 없던 출력 파일의 정확한 해시 결합을 별도 래퍼로 보완해 17개 저장파일을 검증했다. 이는 의미 정답 판정이 아니다.

## 진단으로 바뀐 이해

점막/피부 차이는 원래 기사에 있었고 필요한 논문 구간도 입력에 있었다. 기존 보호목록을 소비하지 않는 출력 전 역할에서 빠졌으므로 목록 유무 실험은 하지 않았다. 위치 대응 도움을 줘도 엄격 표적 탐지는 0/2였지만 도움을 받은 한 출력은 차이를 인지하고 중요성이 부족하다고 했다. 따라서 순수 주의 부족이라고 단정했던 해석을 좁힌다.

다른 논문의 대각선/같은 쪽 다리 관계는 도움 유무 모두 탐지했고 정상 표적도 유지했다. 모든 관계에서 사실 추론이 불가능한 것은 아니다. 위치 가시화만으로 공통 누락을 해결했다는 주장도 지지되지 않았다. 인지 관측과 필수성 선택이 함께 작동한다는 더 구체적인 미해결 문제다.

## 실제로 남아 있는 자동 실행 가설

1. **사실 차이 기록이 필요성 게이트에서 사라지지 않도록 하는 기록/선택 정책.** 기존 필드 이름을 늘리는 것이 아니라, 차이가 확인된 항목을 필수성 ‘아니오’여도 유지하는 흐름과 패치 선택을 비교한다. 원문과 근거가 같아도 ‘보지 못함’과 ‘보았지만 편집하지 않음’을 사후에 구분할 수 있어야 한다. 현재 원기록에서는 일부만 구분 가능하다.
2. **동일 제안 패치에 대한 구체 오판 증거 선택 비교(H2).** KO192처럼 오해 가능성만 든 추가와 KO191/EN192의 명시 오류 수정을 같은 자료·같은 패치로 고정한다. 현행 선택과 엄격한 반례 요건만 바꿔 과잉수정 감소뿐 아니라 필수 수정 누락/과잉보류를 함께 본다. 아직 실제 대조를 실행하지 않았다. 이 자동 작업을 사람 취향 부족으로 막혔다고 부르지 않는다.

둘 다 A09/A12 및 기존 기록·감사 계열의 검증 후보다. 새 이름·새 버전이라는 이유로 다른 접근 횟수를 늘리지 않는다. 이번 명시적 대조 추출도 후보 생성까지 실제 확인했지만 자율 검출 이득은 미검증이다. 새로운 평가 표본·기준을 먼저 고정하고 이미 본 사례는 개발/회귀로만 써야 한다.

## 외부 의존성은 좁게 지정

문헌 전문/보충 파일의 접근, 실제 독자별 중요도·수용성, 다른 모델로의 일반화는 실제 외부 의존성이다. 반복 AI 이견 자체는 외부 사람 없이는 아무 일도 못 한다는 근거가 아니다. 정확한 문헌·DOI·기사·필요 구간은 EXTERNAL-INPUTS.md에 있다. 새로운 다리 연구의 15% 계산 근거에는 DOI 10.7717/peerj.17675의 보충 stride 자료/영상이 관련되며 파일별 항목을 이번에 확보·검증하지 않았다.

보존해야 할 모든 의미 목록의 완전성은 여전히 보장되지 않는다. 이것을 포괄적 ‘불가능’으로 결론내린 것도 아니다. 같은 문제의 독립 실패 10회는 확인되지 않았고 현재 가족 하한은 변경하지 않았다.

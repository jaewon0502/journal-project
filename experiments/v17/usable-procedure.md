# 바로 사용하는 국소 수정 절차

기본은 전체 재작성 대신 근거로 필요성이 확인된 절만 고치는 것이다. 이번 작은 평가에서 추가 연결 추적 지시의 성과 이익은 관찰되지 않았으므로 절차를 더 늘리지는 않는다. 다음은 완전성을 보장하는 알고리즘이 아니라 실제 실행에서 사용한 점검·보류 절차다.

1. **읽은 범위를 고정한다.** 원문 전체, 현재 후보, 질문, 접근한 원자료의 버전·위치·날짜를 저장한다. 사건일·게시일·수집일·후속 자료를 구분한다. 원자료는 실제로 읽은 절과 읽지 못한 표·이미지·부록을 적는다.
2. **보호할 의미를 원문에 연결한다.** 주장, 주체, 단정·예측 강도, 수치·부정, 조건·예외, 반론의 대상, 사건·비교 시점을 짧은 근거 구간과 함께 기록한다. 발언 존재와 발언 내용의 진실, 반론 존재와 그 증거 강도를 분리한다. 목록을 정답지로 취급하지 않는다.
3. **수정 필요성을 먼저 판단한다.** 사실 오류인지, 필수 질문의 미답인지, 선택적 설명인지 구분한다. 관련된 원자료의 정의·예외·범위·시점이 결론을 바꾸는지 확인한다. 가치 선호 차이를 사실 오류로 고치지 않는다. 원문이 틀렸다면 틀린 원문으로 복원하지 않고 자료가 지지하는 대안을 찾는다.
4. **정확한 최소 패치를 만든다.** 바꿀 구간과 대체 구간, 이유·출처 ID·위치를 남긴다. 출처 ID에는 설명을 붙이지 않는다. 필요성, 자료 지지, 다른 의미 보존, 문맥 안전성이 확인된 변경만 적용한다. 겹침·중복 앵커·의존성 실패는 적용하지 않는다.
5. **적용된 전체 글을 별도로 읽는다.** 패치 문구만 보지 않고 실제 전달문을 원문·후보·원자료와 양방향 비교한다. 별도 검토자는 기존 보호목록을 보기 전 원문에서 빠진 항목을 찾는다. 범위 밖 바이트 보존은 의미 보존의 충분조건이 아니다. 인접 문장의 지시 대상·조건·시간 관계가 변했는지 확인한다.
6. **불확실한 변경은 보류한다.** 새 오류·정당한 비판 약화·반론 대상 삭제가 생기면 그 변경을 롤백한다. 안전한 대안이 없으면 문제 구간과 부족한 증거를 텍스트로 반환한다. 전체 검증 준비 상태와 특정 국소 수정의 안전성은 따로 보고한다.

## 멈추어야 할 때

핵심 출처의 버전이나 적용 시점이 충돌하고 결론을 정할 근거가 없을 때, 사실과 가치 판단을 분리하지 못할 때, 정확한 수정 구간이 유일하지 않을 때, 수정 뒤 새로운 의미 손실을 해소하지 못할 때 해당 변경을 멈춘다. 감사자 불일치는 다수결로 지우지 않고 어떤 명제·기준에서 갈렸는지 남긴다. 관련 없는 미확인 부분 때문에 안전한 국소 수정을 자동으로 막지는 않지만, 전체 기사 검증 완료로 표시하지 않는다.

사용자가 별도 길이 제한을 주지 않았다면 보호 내용을 줄이기 위한 임의 제한을 두지 않는다. 명시된 길이에 필요한 조건·반론·시간 맥락이 함께 들어가지 않으면 **압축 불가 또는 길이 증가 필요**라고 표시한다. 몰래 생략하지 않는다.

기록은 원문→근거 구간→보호 이유→필요 변경→실제 적용문→별도 감사→남은 공백 순서로 남긴다. 기사·원자료 전문은 공개 보고서에 싣지 않고 짧은 인용·위치·링크와 해시를 공개한다. 실제 문서에 대한 인간 확인이 없으면 AI 내부 평가라고 표시한다.

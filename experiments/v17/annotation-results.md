# v17 주석 필드 명확화 결과

사전에 고정한 6개 레코드의 명확성 확인 기준을 통과했다. 독립적으로 응답한 두 판정자는 모든 레코드의 세 범주형 필드에서 사전 작성 참조와 일치했다. 두 판정자의 관계 설명 12개를 검토한 결과, 명제의 문자 그대로의 변화를 해로운 손실과 혼동하거나 발언 귀속의 증거를 가치판단의 진실로 취급한 설명은 없었다. 이는 제한된 범위의 프로토콜 명확화 결과이며, 사실 정확도 향상이나 일반적인 신뢰성을 입증하지 않는다.

제안은 `original_meaning_loss`를 `original_proposition_changed`(`yes/no/unknown/not_applicable`)로 **한 필드만 교체**하는 것이다. 편집 점검 목록을 추가하는 것이 아니며, 이번 묶음에서 본 실험의 스키마를 변경하지 않았다. `candidate_factual_error`는 기존 사실 오류 구분을 보고하는 이름이다. `normative_value_resolution`은 확인 가능한 발언 귀속과 별개로 가치판단 자체가 해결되는지를 표시한다. 기존의 수정 필요성 및 귀속된 가치판단 구분은 별도로 유지한다. 기사 수정, 기존 출력의 재라벨링, 기존 점수 재계산은 없었다.

## 레코드별 실제 출력

두 판정자와 사전 작성 참조는 아래와 같은 라벨을 반환했다. 각 판정자가 작성한 서로 다른 관계 설명 원문과 짧은 정확 인용 근거는 [judge01.json](annotation/judge01.json), [judge02.json](annotation/judge02.json), [reference-withheld.json](annotation/reference-withheld.json)에 보존되어 있다.

| 레코드 | 구분 및 국소 판정 대상 | 원문 명제 변화 | 후보문 사실 오류 | 가치판단 해결 상태 |
|---|---|---|---|---|
| A01 | 기존 노출 R004 F2: 지름 오류 정정 | yes | no | not_applicable |
| A02 | 기존 노출 R006 F1: 학생 본인만이라는 제한 | yes | yes | not_applicable |
| A03 | 합성: 개방 시각 오류 정정 | yes | no | not_applicable |
| A04 | 합성: 연령 제한 추가 | yes | yes | not_applicable |
| A05 | 합성: 의미를 보존한 표현 변경 | no | no | not_applicable |
| A06 | 합성: 귀속된 의견을 반대로 변경 | yes | yes | unresolved |

## 사전에 고정한 범주형 필드 비교

아래 각 수치는 **세 범주형 필드 각각**에 적용된다. 서로 다른 필드를 합쳐 하나의 성능 점수로 산출한 것이 아니다.

| 비교 | 기존 노출 회귀 확인 레코드 | 새 합성 레코드 | 전체 레코드 |
|---|---:|---:|---:|
| 판정자 01 대 판정자 02 | 2/2 | 4/4 | 6/6 |
| 판정자 01 대 사전 작성 참조 | 2/2 | 4/4 | 6/6 |
| 판정자 02 대 사전 작성 참조 | 2/2 | 4/4 | 6/6 |

참조는 판정자 호출 전에 AI가 작성한 프로토콜 기반 예상값이며, **사람이 확정한 정답이 아니다**. 기존에 노출된 두 사례는 관찰된 모호성의 회귀 확인용이며, 미노출 검증 사례가 아니다. 새로 작성한 합성 사례 네 개는 최소한의 설명용 레코드이며 대표성 있는 표본이 아니다. 교체 필드의 `unknown`과 `not_applicable`은 정의했지만 이번 사례에서는 시험하지 않았다. 응답 봉인 기록에는 정확한 배포 버전, 시드, 비용이 제공되지 않았다.

## 인용 근거 및 관계 설명 검토

오프라인 재현으로 모든 인용이 지정된 국소 O/C/S 텍스트에 실제로 존재함을 확인했다. **각 판정자의 근거 19/19개**, **참조의 근거 19/19개**가 일치했다. 출처 위치 표기도 제공된 출처 발췌와 일치한다. 판정자의 관계 설명 12개는 의미적 일관성을 별도로 검토했다.

- A01: 두 판정자 모두 약 반 마일에서 150미터로 바뀐 명제를 식별했다. 근거가 있는 정정을 해로운 변화로 부르거나 원문 복원을 요구하지 않았다.
- A02: 두 판정자 모두 새로 추가된 학생 본인만의 제한과 O에 없었던 가구원 정보를 명시적으로 구분했다. 원문에 있던 내용이 누락되었다고 만들어내지 않았다.
- A03: 두 판정자 모두 개방 시각의 정정을 식별했다. 명제의 문자 그대로의 변화 자체를 후보문의 사실 오류로 취급하지 않았다.
- A04: 두 판정자 모두 추가된 연령 제한을 식별했으며, 사실 오류 판정과 일관된다.
- A05: 두 판정자 모두 표현은 바뀌었지만 정확한 참석자 수는 보존되었다고 설명했다.
- A06: 두 판정자 모두 Mira에게 귀속된 의견이 반대로 바뀌었다고 식별했다. 공정성 자체는 둘 다 **미해결(`unresolved`)**로 남겼다. 기록된 발언은 발언 귀속의 오류를 확인하지만, 요금이 실제로 공정한지는 확정하지 않는다.

충족하지 못한 기준이나 출력 이후의 기준 변경은 발견되지 않았다. 관계 설명 검토도 AI의 검토이며 독립적인 사람의 판정이 아니다. 재현 스크립트는 해시, 범주형 일치 수, 정확 인용을 확인한다. 의미적 판정을 자동화했다고 주장하지 않는다.

## 원본 보존 및 독립 실행 가능한 재현

[자료 묶음](annotation/)에는 바이트 단위로 보존한 [지침](annotation/instruction.md), [O/C/S/Q 레코드 6개](annotation/items.json), 판정 시 비공개였던 참조, 실제 출력 두 개, [사전등록 문서](annotation/prereg.md), [판정 전 동결 기록](annotation/prejudge-freeze.json), [응답 봉인 기록](annotation/response-seal.json), [해시 목록](annotation/hashes.json), [재현 스크립트](annotation/replay.py)가 포함되어 있다. 사전등록 문서와 동결 기록의 호출 0회 표기는 설계 동결 시점을 설명한다. 그 뒤의 응답 봉인 기록에는 완료된 독립 호출 두 번이 기록되어 있다. 상위 에이전트가 비공개 참조를 열기 전에 두 출력의 해시를 봉인했다.

기존 공통 지침 및 R004/R006의 입력·관찰·결과 파일은 실행 전 SHA-256 지문 7개와 다시 비교했으며 모두 변경되지 않았다. 원본 해시는 보존하되, 비공개 원본 전문과 중첩된 감사 데이터는 배포 묶음에 포함하지 않았다. 공개 묶음은 범위를 명시적으로 제한한 국소 레코드 6개이며, 뉴스 기사 전문과 비공개 파일시스템의 절대 경로를 포함하지 않는다.

네트워크나 비공개 파일 없이 다음과 같이 실행할 수 있다.

```sh
python experiments/v17/annotation/replay.py
```

재현은 통과했다. 이 후속 작업은 해당 사례들의 주석 정의 모호성을 다룬다. 앞서 사실 판단과 수정 조치에 관해 일치했던 결과를 뒤집거나, 모델이 해를 초래했다고 입증하거나, 게시 또는 오류가 있는 원문의 복원을 승인하는 것은 아니다.

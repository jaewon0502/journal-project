# v17 절차 차이와 변경 기록

- 개발 최초8출력은 공통 지시 v1을 사용했다. 출처 ID에 위치 설명을 합친7출력이 엄격한 전달 계약에서 거부됐다. 원출력·v1 지시를 보존하고 별도 v2 지시에 exact ID 직렬화 문장만 추가했다. 노출2단위×두 방법4출력만 재실행했으므로 개발 전체8개를 v2로 통과시켰다고 주장하지 않는다.
- 실제 평가의 동결 명세와 실행은 `v17-common-v2.md`를 사용한다. 사전등록의 Shared semantics 절에 남은 `v17-common.md`는 초안 파일명 잔재다. 의미 기준은 동일하고 추가된 것은 ID/위치 분리 문장이다. 동결된 사전등록 파일을 사후 수정하지 않았다.
- 개발 독립 감사자의 실질 결과 메시지는 평가 동결 전에 받았지만 최종 감사 파일은 평가 실행 개시 후 저장됐다. 평가에는 이미 동결한 지시를 썼으며 이후 감사 파일을 반영해 입력이나 기준을 바꾸지 않았다. 완성된 최종 감사 파일이 사전에 있었던 것처럼 서술하지 않는다.
- 정상 대조의 실제 구성은 원문 그대로3개·근거 있는 원문 오류 정정1개다. 계획의 정상 어순 변형은 실행하지 않았다. 기관 기사4건으로 확정된 표본 성격도 평가 전에 기록했다.
- 출처 ID 직렬화, 기계적 적용 검사 및 저장 형식 수리는 의미 해법의 새 독립 접근으로 세지 않는다. 의미가 맞는 제안과 실제 전달 계약을 통과한 수정은 분리한다.

# 실행된 지시의 보존본

본문의 proposed/pre-development 표지는 당시 파일 그대로 보존했다. 개발 최초 실행은 v17-common.md, 제한된 개발 재실행 및 실제 평가·자연 오류 후속은 v17-common-v2.md를 사용했다. 차이는 출처 ID와 절 위치의 직렬화 안내 한 문장이다. 두 방법은 같은 공통 지시·스키마·입력을 사용하고 basemethod.md/linkmethod.md만 달랐다. reference 및 audit 지시는 별도 AI 판정에 사용했으며 원출력을 수정하지 않는다. 이 파일과 코드만으로 비공개 전체 기사 입력이나 정확한 모델 배포·시드까지 재현할 수는 없다.

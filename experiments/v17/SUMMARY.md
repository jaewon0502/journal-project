# v17 통합 판단

이번 회차에서는 실제 원문에 있던 NASA 소행성 크기 오류를 필요한 절 하나만 고쳐 별도 AI 감사에서 다른 조건의 보존을 확인했다. 출처 식별자 형식 때문에 올바른 수정이 전달되지 않던 개발 단계 문제도 일부 노출 입력에서 고쳤다. 다만 보호목록의 완전성과 AI 의미 분류의 일관성을 일반적으로 해결한 것은 아니다.

| 문제 | 이번에 확인한 결과 | 남은 문제 |
|---|---|---|
| 보호해야 할 정보 목록 불완전 | 새 기사 맥락 4건의 지정 결함 4개를 두 방법 모두 탐지·수정했다. 원자료의 정의·범위·시점 연결을 검토했다. | 고정 질문이 관심 조건을 알려주므로 스스로 모든 누락을 찾아내는 성능이 아니다. 보호목록 밖의 의미가 없다는 보장은 없다. |
| 수정·압축에서 조건·반론·시간 손실 | 각 방법의 필요 수정 4/4와 정상 유지 4/4, 관찰된 새 손상 0건. 별도 자연 오류 후속에서도 절 하나의 수정 뒤 질량 의존성과 경고 시간 등을 보존했다. | 기관 기사와 제공 원자료 범위의 작은 표본이다. 원문 전체의 사실 정확성이나 일반 안전성을 인증하지 않는다. |
| AI 평가 불일치 | 사실 정정과 유해 손실을 분리해 두 개의 의미 표지 해석 차이를 확인했다. 원판정·분모를 보존했다. | 사실 오류 정정도 ‘원문 의미 변경’인지를 해석하는 차이가 남는다. 별도 표지 명료화의 6개 국소 기록에서는 두 평가자가 세 분류 모두 사전 작성 참조와 일치했으나, 가치 판단 항목은 미해결로 남겼다. [후속 기록](annotation-results.md). |

## 더 복잡한 방법을 기본값으로 채택하지 않는다

새 실제 기사 4건에서 후보 8개를 만들고 BASE/LINK를 각각 실행한 16개 실제 출력을 평가했다. 각 방법은 지정 결함 4/4를 안전하게 수정하고 정상 4/4를 그대로 유지했다. 8개 대응 전달문은 모두 동일한 해시였다. 정상 중 하나는 출처에 근거해 원문 오류를 이미 고친 후보이므로, 이를 잘못된 원문으로 되돌리지 않는 대조도 포함한다.

BASE도 이미 근거 관계를 기록한다. LINK는 같은 자료·질문·스키마에서 직접 연결된 정의·예외·범위·시점 절을 명시적으로 추적하라는 지시를 더한 것이다. LINK의 추가 안전 수정 이익은 이 표본에서 없었다. 입력 문자는 369,168→373,360, 출력 문자는 36,016→41,476으로 늘었다. 문자 수는 토큰·금액이 아니다. 따라서 현재 기본값은 더 단순한 BASE 절차로 두되 필요한 원자료 관계 검토는 유지한다. 임의의 글자 수 제한을 새로 부과하지 않는다.

이 비교는 절차 효과의 일반적 부재나 두 방법의 동등성을 입증하지 않는다. BASE가 지정 결함을 모두 고친 천장 효과, 유도된 질문, 기관 기사 계보, AI 평가라는 제한이 있다. 자세한 분모·감사·실행 시간은 [실제 평가 결과](RESULTS.md)에 있다.

## 확인된 국소 해결과 그 경계

- **실제 원문 오류:** NASA 원문을 그대로 후보로 사용한 후속에서 잘못된 크기만 원자료의 측정값에 맞게 고쳤다. 두 별도 작성 문맥과 두 별도 감사 문맥에서 수정 성공과 부수 손상 없음으로 판정했다. 이미 본 출처의 노출 후속이므로 새로운 holdout으로 세지 않는다. [수정 전후와 근거](natural-followup.md).
- **실제 전달 실패:** 최초 개발 8출력 중 7개가 출처 ID에 설명을 붙여 계약 검사에서 거부됐다. 스키마를 완화하지 않고 ID와 위치 설명을 분리하도록 명시했다. 노출된 2단위의 4회 재실행은 모두 계약을 통과했다. 재실행하지 않은 개발 입력까지 해결했다고 주장하지 않는다. [개발 감사](development-results.md).
- **표지 해석:** 안전한 원문 오류 정정과 새로운 사실 오류를 하나의 손실 표지로 합치면 혼동할 수 있다. 별도 명료화 시험의 6개 국소 기록에서 두 평가자는 세 분류 모두 사전 작성 참조와 일치했다. 참조는 인간 정답지가 아니고 전체 기사 정확성 시험도 아니다. 가치 판단 항목은 미해결로 유지했으며 원실험의 점수나 정의를 소급 변경하지 않았다.

## 실패 접근 수와 중단 판단

v1–v16 기록으로 확인한 서로 다른 접근의 하한은 보호목록 4, 부수 손실 8, 평가 불일치 4다. 그중 같은 문제의 확인된 잔여 실패 가족 하한은 각각 1·4·1이다. 문구 수정, 새 버전, 재시도, 추가 기사나 평가자는 새 접근으로 세지 않았다. 일부 초기 기록의 전수 대응이 없어 역사 전체의 상한은 알 수 없으며, **같은 문제의 서로 다른 10개 접근 실패는 확립되지 않았다**. 추가 이익이 없었다는 결과를 실패 수에 더하지 않았다. [접근 장부](approach-ledger.md).

이번 회차의 실질 성과는 확인된 원문 오류와 전달 계약 문제의 국소 수정이다. 남은 핵심은 보존해야 할 의미 목록 자체의 완전성을 보장하지 못한다는 점이다. 별도 감사와 전체 적용문 재독은 이를 점검하는 수단이지 완전성 증명은 아니다. 인과·정치 편향 감소, 독자의 신뢰·이해 향상, 인간 가치 합의를 측정하지 않았다. 정확한 모델 배포 버전·시드·토큰·금액도 제공되지 않았으며 별도 AI 문맥 실행을 자동 API 실험이나 인간 검증으로 부르지 않는다.

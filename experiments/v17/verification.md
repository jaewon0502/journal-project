# 이번 공개 패키지 검사

`python tools/run_checks.py` 실행에서 독립 unittest 15개 묶음의 **194개 테스트 메서드**가 통과했다. 저장된 합성 출력·주석 출력의 해시, 출처 구간, 실제 적용문과 집계도 재생했다. 이 중 v17의 적용 계약 검사는 10개 메서드다. 의미적 정답 194개나 새 모델 출력 194개가 아니다. 검사 중 새 모델 호출은 0회다.

v17 실제 평가의 별도 재집계는 동결 파일 74개, 사전 참조 8개, 실제 작성 출력 16개와 별도 사후 감사 16개를 확인했으며 대응하는 실제 전달문 8쌍의 해시가 같았다. 비공개 원문이 필요한 재집계와 원문 없이 가능한 공개 코드·합성 출력 재생을 구분한다.

원문 전문과 긴 실제 출력은 공개하지 않았다. 공개 해시는 원본이 바뀌지 않았는지 비교하는 식별자이며 원본 미소지자가 그 내용을 검증하게 하지는 않는다. 코드 검사는 정확 앵커·출처 ID·적용 순서·필드 계약을 확인할 뿐 의미 목록의 완전성을 증명하지 않는다.

이 작업은 v16 로컬 커밋을 잇는 독립 작업 트리다. 다른 계정이 반영한 원격 PR4 변경은 읽기만 했고 통합하지 않았다. 공개 ZIP은 새 디렉터리에서 검토할 스냅숏이며 원격 main 덮어쓰기용이 아니다. 외부 Page 수정, 원격 push·병합·배포, 계정 변경은 하지 않았다.

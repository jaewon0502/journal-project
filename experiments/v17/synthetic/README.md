# v17 합성 개발 출력 공개 재생 패키지

이 폴더는 실제로 생성·보존한 가상 개발 출력 12개를 재생한다. 새 모델 호출이나 새 실험 조건을 만들지 않는다. 두 가상 문맥의 후보 4개(D171–D174)에 BASE/LINK를 적용한 최초 출력 8개와, 출처 ID 직렬화 안내를 명확히 한 뒤 이미 노출된 D172·D174만 다시 실행한 출력 4개다. 실제 기사 성능이나 미사용 평가 사례로 세지 않는다.

## 재생

저장소 또는 공개 패키지의 어느 작업 디렉터리에서든 다음 파일을 Python 3으로 실행한다. 표준 라이브러리만 필요하다.

```sh
python experiments/v17/synthetic/replay.py
```

스크립트는 인접 `../code/check_output.py`와 `../code/schema.json`을 사용한다. 입력·공개 출력·검사기 해시, 정확한 인용과 출처 ID, patch 적용 조건, 실제 적용 후 전체 후보의 해시를 확인하고 관측치를 JSON으로 출력한다. 불일치는 비정상 종료한다. 모델 재생성 및 의미의 참·거짓을 독립 평가하는 코드는 아니다.

| 실행 | 실제 출력 | 형식 통과 | 거절 | 전달된 수정 | 전달된 유지 |
|---|---:|---:|---:|---:|---:|
| 최초 v1 | 8 | 1 | 7 | 0 | 1 |
| 노출 사례 재실행 v2 | 4 | 4 | 0 | 2 | 2 |

v1 거절 7개는 `source_refs`에 ID와 설명을 함께 써 `unknown source reference`가 된 실제 실패다. 의도한 수정 문구가 적절해도 전달된 성공으로 세지 않는다. 유일한 v1 통과는 D172-BASE 유지다. v2에서는 출처 ID만 쓰고 설명은 위치 필드에 쓰도록 안내를 명확히 했다. D172 정상 후보를 두 방법 모두 유지하고 D174 시행일 오류를 두 방법 모두 수정했다. D171·D173은 다시 실행하지 않았으므로 최초 8개가 모두 해결됐다고 말할 수 없다.

## 원본과 공개 파생본

- `units/`는 저자가 만든 가상 입력 원본과 바이트 단위로 같다. 인물·기관·날짜·출처는 모두 허구이며 실제 기사 전문이 없다.
- `outputs/`는 실제 저장된 출력을 공개용으로 파생한 것이다. `read_scope` 실행 메타데이터만 고지 문구로 교체하고 JSON을 다시 직렬화했다. 판단·근거·patch·실패한 출처 ID를 포함한 나머지 필드는 그대로 보존했다.
- `manifest.json`에 비공개 원본 해시와 공개 파생본 해시, 변경 필드, 원래 검사 결과와 전달 후보 해시가 있다. 원본은 별도로 보존되며 공개 파생본을 원본과 동일한 바이트라고 주장하지 않는다. 원본 해시만으로 비공개 원본 내용까지 공개 독자가 검증할 수 있는 것은 아니다.
- 검사 통과는 형식·앵커·적용 결과 재현이다. 보존목록의 완전성, 모든 판단의 의미적 정답, 사람 평가 또는 한국 언론 전체 개선을 입증하지 않는다. 동일 출력의 재생을 추가 모델 실행이나 추가 사건으로 세지 않는다.

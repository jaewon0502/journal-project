# 고용 기사 전체 문장으로 원자료 찾기

2025년 1월 15일 SBS 기사에서 짧은 발췌가 속한 세 문장을 통째로 검색했다. 저장한 보도 페이지에서 제목과 본문 14문단을 읽고, 팩트체크 화면의 기사 분할기가 만든 2·11·5번 구간을 사용했다. 세 문장과 두 입력 파일은 SHA-256으로 고정했다. [SBS 보도](https://news.sbs.co.kr/news/endPage.do?news_id=N1007948583) · [통계청 원자료](https://mods.go.kr/boardDownload.es?bid=210&list_no=434801&seq=1)

## 검색 결과

문장만 입력했을 때 기준판은 3건 중 1건, 개선판은 3건 중 2건에서 사전에 지정한 근거 행을 첫 후보로 제시했다. 개선판에서 기사 제목을 한 번 더 눌러 검색하면 나머지 1건에서도 최근 3년을 대조할 행이 첫 후보에 나왔다. 이 행으로는 2000년 이후 최고 기록인지 판정할 수 없어 부분 근거로 셌다.

| 기사 구간 | 기준판에 제목까지 입력 | 개선판에 문장만 입력 | 개선판에 제목까지 입력 |
|---|---|---|---|
| 2번 · 취업자 증가 폭 | 상위 3개에 근거 행 없음 | PDF 28쪽 822행 1위 | 같은 행 1위 |
| 11번 · 15세 이상 고용률 | PDF 32쪽 940행 1위 | 같은 행 1위 | 같은 행 1위 |
| 5번 · 2000년 이후 기록과 최근 둔화 | 상위 3개에 근거 행 없음 | 첫 후보 814행에 당년 수치만 있음 | PDF 28쪽 822행 부분 근거 1위 |

822행에는 2022·2023·2024년 취업자 전년 대비 증가분이 각각 81.6만·32.7만·15.9만 명으로 적혀 있다. 기사 발행일은 2025년 1월 15일이고, 마지막 수치는 2024년 값이다. 편집자는 기사 속 ‘올해’가 어느 해인지 따로 대조해야 한다. 고용률은 940행의 62.7%와 0.1%포인트 상승을 바로 앞 939행의 ‘2024년 15세 이상’과 함께 읽어야 한다. ‘연도와 대상이 적힌 앞 문단 보기’에서 두 문단을 함께 발췌해 등록하면 원본의 두 줄이 그대로 남는다. 분모의 정의는 별도로 원표 주석과 대조한다.

인터넷을 끈 Chrome에서 폭 320px와 1280px로 팩트체크 화면을 열고 세 문장을 각각 검토했다. 원본 PDF와 검색 파일을 연결한 뒤 각 첫 후보에서 PDF 28·32·28쪽 링크를 확인했다. 5번에서 ‘기사 첫 줄로 다시 찾기’와 ‘표에 실린 기간만 발췌’를 누르면 발췌문에 2020~2024년 열 머리글과 증감 행이 들어갔다. 확인 위치에는 2000년부터 2019년까지의 기록을 추가로 확인하라는 안내가 남았고, 문장 판정란은 비어 있었다. 이 세 문장에서는 편집자의 작업시간과 정치적 편향 변화율을 측정하지 않았다.

## 재현

저장소 루트에서 `npm ci`로 잠금 파일의 jsdom을 설치하고 다음 명령을 실행한다. 첫 인자는 SBS 기사의 HTML 파일이고, 둘째 인자는 통합 PDF의 페이지 경계를 유지한 `pdftotext -layout` 결과다. 페이지 광고나 외부 스크립트가 바뀌어도 정규 기사 주소·발행일·제목·14개 본문 문단이 같은 판본이면 재시험할 수 있다. 해당 내용이나 PDF 추출문의 해시가 다르면 중단한다. 2026년 11월 25일 같은 주소에서 새로 내려받은 HTML은 파일 전체 해시가 달랐지만 기사 해시는 일치했고 같은 결과가 나왔다.

```sh
node experiments/labour-field-review/replay-whole-article.cjs ./sbs.html ./report.txt
```

| 입력 | 고정한 SHA-256 |
|---|---|
| 이 실험에서 사용한 SBS HTML 전체 | `61ced30e4b71af42445a519f8fa1858d3bb7283baf084211808f9b8f6ccd8ac1` |
| SBS 정규 주소·발행일·제목·본문 | `1391873f8c2aa7ff850085af6cd5a0fb298063c9cda7534e5c3b72b00715ed16` |
| 통계청 PDF 추출문 | `c49ed71c04e00adc0f3ecff89fe9a5fd646f403870b5e6eb0b18e0d2673ad53b` |
| 추출에 사용한 통계청 PDF | `69325b4d227fc0cbe62e1ff6e26d59eccbeb35cbd0d40a1b15f7b5bbe0ed1a93` |

실행기는 Git에서 기준 커밋 `90ce80c`의 검색기를 읽고, 같은 입력으로 현재 작업 트리의 검색기를 실행한다. 기본 출력은 문장 단독 검색과 기사 제목을 추가한 검색의 비교표다. 명령 끝에 `--json`을 붙이면 각 판본의 상위 세 후보, 기사 구간의 해시, 표에 수록된 연도를 확인할 수 있다. 원표 위치는 PDF 첫 페이지부터 센 쪽과 추출문에서 비어 있지 않은 줄을 센 행 번호다. [재현 코드](replay-whole-article.cjs) · [기존 근거 행](transfer-gold.json)

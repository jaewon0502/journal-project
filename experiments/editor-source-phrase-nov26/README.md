# 원자료 언어로 같은 근거 다시 찾기

한국어 기사와 외국어 원자료를 대조할 때, 편집자는 **원자료 언어로 찾을 표현**에 기관명이나 검색어를 직접 입력할 수 있다. 이번 시험에서는 자동 번역을 쓰지 않았다. 검색어와 함께 입력한 비교 기간·대상은 해당 문장에 연결돼 같은 창에서 다시 사용할 수 있다. 작업 파일을 다시 열면 새로 입력한다. 기사·자료·점수 저장 파일에는 보조 검색어가 들어가지 않는다.

편집자가 입력한 표현의 상위 세 문단을 먼저 보여 주고, 기사 주장으로 찾은 다른 문단을 이어서 보여 준다. 같은 문단에는 어느 검색어로 찾았는지 표시한다. 다른 날짜나 반대 진술도 낱말이 겹치면 후보가 될 수 있다. 번역이 약하면 기사 주장으로 찾은 직접 근거가 4위 이하로 밀릴 수 있다. 원자료 표현을 비우면 원래 순위를 다시 볼 수 있다. 표의 수치·기간·단위, 회의록 화자를 따로 대조해야 하는 검색에서는 기존 확인 절차를 유지한다.

## 같은 근거까지 필요한 조작

가상 한국어 기사 두 문장과 영어 원자료 네 문단을 오프라인 Chrome에서 열었다. 첫 문장의 검색 표현은 `withheld charter`였다. 세 방식 모두 원자료 2번 문단을 1위에 표시했고 판정과 발췌는 비어 있었다. 화면 너비 390px와 1280px에서 같은 결과가 나왔다.

| 검색 방식 | 첫 검색 클릭 · 영어 입력 | 다른 행에 갔다가 처음 문장을 다시 검색한 클릭 · 영어 재입력 |
|---|---:|---:|
| 이전 화면에서 기사 검색어를 영어로 교체 | 2회 · 1회 | 5회 · 1회 |
| 이전 화면에서 기사 검색어 뒤에 영어를 덧붙임 | 2회 · 1회 | 5회 · 1회 |
| 새 화면의 원자료 언어 입력란 사용 | 2회 · 1회 | 3회 · 0회 |

처음에는 각 방식에서 해당 입력란을 누르고 영어 표현을 넣은 다음 검색 버튼을 눌렀다. 재방문 구간은 다른 문장 선택, 원래 문장 선택, 근거 찾기를 누르는 데서 시작한다. 이전 버전에서는 영어 표현을 다시 입력하고 검색해야 같은 문단이 첫 후보로 돌아왔다. **재방문 클릭은 5회에서 3회로 40%**, 두 구간 전체는 7회에서 5회로 줄었다. 원자료나 번역을 찾는 시간, 결과를 읽는 시간과 실제 편집자의 시간 절감률은 측정하지 않았다. [측정 기록](clicks.json)

## 발행처 표지가 후보를 바꿨던 예

가상 도서관 운영비는 자체 결산에 1,200만, 보수 신문과 진보 신문의 주장에 각각 1,100만과 1,300만으로 적었다. 기존 검색란에 `[conservative newspaper]` 또는 `[liberal newspaper]`와 같은 운영비 검색어를 넣으면 각각 해당 신문의 주장이 첫 후보였다. 새 입력란에서는 한국어 기사에 붙은 발행처 표지를 바꾸고 영어 표현 앞의 표지도 같은 쪽으로 바꾼 두 경우 모두 결산 문단이 1위였다.

원문이 독립된 사실 주장을 담고 있고 보조 표현의 첫 대괄호가 분리된 발행처·독자층으로 식별될 때 적용한다. 화면에서 제외한 표지를 확인하고 한 번 눌러 그 표지까지 다시 찾을 수 있다. 해당 신문의 명시적 발언이나 특정 정당의 주장을 찾는 대조 문항은 각 당사자의 문단을 첫 후보로 유지했다. 이 시험은 가상 조건에서 검색 순위가 달라지는지만 확인했다. [입력과 반례 검산](../../tools/test_cross_language_search.cjs)

## 재현

저장소 루트에서 아래 명령으로 합성 검색과 편집 화면을 점검한다.

```sh
npm ci --ignore-scripts
node --test tools/test_cross_language_search.cjs
```

Chrome과 Playwright가 설치된 환경에서는 다음 명령으로 이전 판본과 현재 화면을 비교한다. 스크립트는 Git 이력의 `2e0e028`에서 이전 화면을 임시 폴더에 추출한다. `--check`를 빼면 실행 결과 JSON을 표준 출력으로 내보낸다. Playwright가 다른 폴더에 설치돼 있다면 그 `node_modules` 경로를 `NODE_PATH`로 지정한다.

```sh
node experiments/editor-source-phrase-nov26/measure-clicks.cjs --check
```

## 영문 회의록에서 화자 표지 대조

영문 회의록에서 검색한 문단 앞에 `THE CHAIR:`나 `Speaker: Jane Rivers`처럼 명시된 화자 표지가 있으면 후보 카드에서 두 위치를 함께 펼쳐 볼 수 있다. 예시에서는 인용할 문단이 5번에, 표지는 2번에 있다. 편집자가 구간을 읽고 **화자 표지부터 이 문단까지 발췌**를 눌러야 발췌 초안에 옮겨진다. 후보 순위와 사실 판정은 그대로다.

원문에 두 종류 이상의 명시적 발언·질답 표지가 있어야 한다. 같은 구간 안에서 앞선 여섯 줄까지만 살핀다. 화자 교대, 의장 인계, 빈 줄, 페이지 경계, 회의 중단이나 다른 사람의 발언을 서술하는 대목에서는 연결을 멈춘다. 발언자 이름만 적은 표지 등 형식을 확정하기 어려우면 일반 문단 후보를 보여 준다. 이 기능이 제안하는 범위는 해당 원문의 표지와 인용 위치다. 인용한 주장의 진위와 정치적 편향은 편집자가 별도로 판정한다. [영문 회의록 합성 대조와 UI 검산](../../tools/test_english_transcript_context.cjs)

### 21개 구간 떨어진 실제 발언

MBC 유엔 안보리 보도의 팔레스타인 대표 발언은 회의록 142번 구간에 있고, 화자 표지는 121번에 있다. 구판과 개선판에서 같은 한국어 기사를 열고 같은 영어 회의록을 붙여 넣은 뒤, 오프라인 Chrome 1280px에서 다음 두 검색을 수행했다. 기사·원자료 입력은 클릭 수에서 제외했다. [MBC 기사와 회의록 판본](../editor-transfer-nov26/README.md) · [미리 고정한 영어 표현](../editor-transfer-nov26/diplomacy/queries.json)

1. 전체 영어 표현을 입력하고 검색했다. 양쪽 모두 첫 세 후보는 **142, 137, 166번**이었다. 첫 후보의 **이 문단을 발췌문으로 사용**을 눌러 인용을 초안에 유지했다.
2. 같은 표현에 이미 있던 화자 단서 `Palestinian ambassador Mansour`로 바꿔 검색했다. 양쪽 모두 첫 세 후보는 **121, 22, 23번**이었다. 142번 초안을 유지한 상태에서 121번 표지를 읽을 수 있었고 판정은 비어 있었다.

두 판본 모두 검색 2회, 입력란·검색·발췌 버튼 클릭 5회, 영어 입력 2회였다. 이 경우 여섯 줄보다 멀리 떨어진 화자를 자동으로 연결하지 않았다. 두 검색을 나누는 방법은 첫 시험 결과를 확인한 뒤 대조했으며, 화자 전환 여부는 진행자가 원문 10~12쪽에서 읽어야 한다. [유엔 회의록 원본](https://digitallibrary.un.org/record/4045076/files/S_PV.9609-EN.pdf)

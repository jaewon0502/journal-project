# 한국어 기사에서 영어 원자료의 근거를 찾는 시험

서로 다른 한국어 보도 4편에서 주장 20개를 골랐다. 지정한 원자료가 지지한 주장 10개 중 한국어 기사 문장만으로 필요한 근거를 모두 상위 세 후보 안에서 찾은 것은 **2/10**이었다. 기사를 읽고 미리 작성한 영문 검색어를 사용하면 기존 화면에서 검색어를 바꿔 입력해도 **8/10**, 보완한 화면에서 별도 입력란에 넣어도 **8/10**이었다. 영어를 사람이 입력해야 하는 조건이다. 이 시험의 영문구는 AI가 직접 작성했다.

## 기사별 검색 결과

각 칸은 원자료가 지지한 주장 중 검색 결과 상위 3개가 필요한 단락을 **모두** 직접 제시한 건수다. 한국어 원문에 영문을 이어 쓴 비교군까지 같은 영문 표현을 사용했다. 새 화면의 영문 입력란을 비웠을 때의 후보는 네 기사 모두 기존 한국어 검색과 같았다.

| 기사와 시험 순서 | 기존 한국어만 | 기존 영문만 | 기존 한영 이어 쓰기 | 새 입력란 최초판 | 새 입력란 보완판 |
|---|---:|---:|---:|---:|---:|
| 지디넷코리아·뉴시스, 최초 시험 | 2/2 | 2/2 | 2/2 | **1/2** | **2/2** |
| SBS에 실린 연합뉴스 국제 자연보전 기사, 추가 시험 | 0/4 | 4/4 | 4/4 | 4/4 | 4/4 |
| MBC뉴스데스크 유엔 안보리 기사, 보완판의 새 표본 | 0/4 | 2/4 | 2/4 | 2/4 | 2/4 |

첫 두 줄의 보완판 결과는 최초판의 오류를 공개한 뒤 같은 문항으로 재시험한 값이다. 마지막 줄은 보완판 코드를 고정한 뒤 처음 실행한 별도 기사다. 네 기사는 무작위 표본이 아니며, 행이나 주장마다 서로 다른 원자료를 사용한 것도 아니다. 1위 하나만으로 충분한 지지 근거가 나온 건수는 한국어 1/10, 기존 영문만 4/10, 보완판 4/10이었다.

**기존 검색어 입력란과 비교.** 원래 화면에서도 찾을 표현을 영문으로 바꿔 검색할 수 있었다. 한영 이어 쓰기는 기존 칸의 기사 문장 맨 뒤에 공백 한 칸과 같은 영문구를 덧붙인 비교다. 새 입력란은 원래 기사를 유지한 채 추가 표현을 받을 수 있다. 이 표본에서 보완판과 두 수동 방식의 상위 3개 완전 적중 **건수**는 같았고, 일부 후보의 순위와 구성은 달랐다.

## 어디서 판단이 갈리는가

- **한 주장을 여러 단락에서 확인하는 경우.** 맥 미니 포트 배치를 확인하려면 본문의 22번과 기기 뒷면을 설명한 24번이 필요했다. 최초판 후보는 22·23·19번으로 24번을 놓쳤다. 이를 개발자에게 알린 뒤 보완판으로 같은 질문을 재시험하자 22·23·24번이 나왔다. 두 판본 모두 단독 1위만으로 전체 배치를 확인할 수 없었다. [애플 발표](https://www.apple.com/newsroom/2024/10/apples-new-mac-mini-is-more-mighty-more-mini-and-built-for-apple-intelligence/)
- **출시일과 행복 점수.** 애플 발표는 미국을 포함한 첫 출시 시장에서 11월 8일로 적었다. 보도의 11월 9일은 시장을 명시하지 않았다. 영문 입력에서 시장이 적힌 38번 단락이 나왔다. 세계행복보고서 보도자료는 핀란드의 연속 1위와 미국의 23위를 확인하지만 보도에 적힌 정확한 점수까지 싣지 않았다. 핀란드에 관한 부분 근거는 영문 표현으로도 놓쳤다. 이 세 건에서 부분 판정에 필요한 단락을 찾은 수는 한국어 1/3, 보완판 2/3이었다. [세계행복보고서 발표](https://www.worldhappiness.report/news/world-happiness-report-2024-most-comprehensive-picture-yet-of-happiness-across-generations/)
- **실제로 반박되는 주장.** SBS에 실린 보도는 동부고릴라의 두 집단을 ‘종’으로 표현했다. 당시 IUCN은 같은 집단을 두 아종으로 분류했다. 네 검색 방식 모두 해당 단락을 찾았다. 반면 르완다 내전의 서식지 파괴가 감소 원인이었다는 보도에 대해 이 원자료가 뒷받침한 것은 사냥의 위협까지였다. 해당 단락은 영문구로 찾을 수 있었다. IUCN의 판다 관련 두 지지 주장은 같은 17번 단락이다. [IUCN 2016년 발표](https://www.iucn.org/news/species/201609/four-out-six-great-apes-one-step-away-extinction-%E2%80%93-iucn-red-list)
- **발언과 발언자.** 새 정치 기사에서 영문을 넣어 미국이 설명한 직접 협상의 취지와 이스라엘 대표의 감사 발언은 재확인할 수 있었다. 팔레스타인 대표의 질문을 담은 12쪽 본문은 찾았으나 발언자가 표시된 10쪽은 상위 세 후보에 없었다. 표결의 찬성국, 반대국, 기권국, 집계·부결 사유는 3쪽의 네 블록에 나뉘어 있었다. 상위 3개라는 기준에 구조적인 한계가 있고 실제로 네 블록 중 하나도 검색되지 않았다. 이 기사에서 지지 4건의 필수 블록 9개 중 보완판이 직접 제시한 것은 4개였다. [유엔 안보리 회의록 S/PV.9609](https://digitallibrary.un.org/record/4045076/files/S_PV.9609-EN.pdf)
- **2011년 신청과 2024년 표결.** MBC 보도에는 미국이 2011년에도 가입안에 거부권을 실제 행사했다는 대목이 있다. 2011년 안보리 보고서에 따르면 9월에 신청이 상정됐고 위원회는 만장일치 권고를 내리지 못했다. 유엔 도서관의 그해 전체 거부권 기록은 두 표결이다. 미국의 거부권은 신청 전인 2월, 10월 시리아 표결의 거부권은 중국·러시아였다. 보완판은 신청 경위는 찾았지만 이 두 표결을 찾지 못해 2011년 서술을 단독 검증할 근거가 부족했다. [2011년 안보리 위원회 보고서](https://documents.un.org/doc/undoc/gen/n11/585/55/pdf/n1158555.pdf) · [유엔 도서관 거부권 전체 기록](https://research.un.org/en/docs/sc/quick/veto)
- **자료가 부족해도 후보는 나온다.** 처음 고른 M4 칩 연산 횟수, 한국의 행복 순위와 점수, 북한 포함 여부, 나중에 고른 미국 여론 추세의 네 주장은 지정한 원자료로 판정할 수 없었다. 이 네 건 중 한국어 검색은 2건, 보완판 영문 입력은 4건에서 후보를 보여 줬다. 모든 과제의 기사 행은 검토 대기 상태로 유지됐다. 검색 결과를 오류 판정·정치적 편향 점수로 환산하지 않았다.

### 재현

저장소의 Node 의존성, Git, curl, Poppler의 `pdftotext`를 사용한다. 정치 기사에는 당시 회의 발언을 수록한 정식 PDF를 썼다. 파일의 생성일은 2024-04-23이며, 방송 시각에 동일한 PDF를 열 수 있었다는 뜻은 아니다. 당시 발언을 후향적으로 대조했다. 해당 PDF에서 2~13쪽의 본문 텍스트 블록을 왼쪽 열부터 정규화했고, 2011년 자료는 위원회 보고서 23개 번호 문단과 유엔 도서관의 해당 연도 전체 거부권 표 2행을 이어 붙였다. 다른 자료는 기사 본문, 공식 발표의 본문·목록·사진 설명에서 [최초 자료](editions.cjs), [자연보전](prose/editions.cjs), [안보리 자료](diplomacy/editions.cjs)의 고정 규칙으로 단락을 추출했다. 추출한 본문을 검토 화면에 붙여 넣는 조건이다.

다음 명령을 저장소 루트에서 실행한다. 다운로드한 전문과 Git 스냅숏은 임시 폴더에만 저장된다. 공개 사이트의 본문이나 PDF 판본, 추출 결과가 달라지면 중지한다. 검산에 사용한 Poppler는 26.11.0이다.

```sh
raw_dir="$(node experiments/editor-transfer-nov26/download.cjs)"
snapshot_dir="$(mktemp -d)"
mkdir "$snapshot_dir/base" "$snapshot_dir/first" "$snapshot_dir/revised"
git archive 2e0e028e7552aa2f3f3e209783d5d436738aba5c docs/reader | tar -x -C "$snapshot_dir/base"
git archive 61f62daa1ffeabdd95fbef4e257070f30d8a0ae0 docs/reader | tar -x -C "$snapshot_dir/first"
git archive e7184d15e3bef7d2a53b5baaa3338c8730daa450 docs/reader | tar -x -C "$snapshot_dir/revised"
for sample in initial prose diplomacy; do
  node experiments/editor-transfer-nov26/replay.cjs "$raw_dir" "$snapshot_dir/base/docs/reader" "$sample" check "$snapshot_dir/first/docs/reader" result.json
  node experiments/editor-transfer-nov26/replay.cjs "$raw_dir" "$snapshot_dir/base/docs/reader" "$sample" check "$snapshot_dir/revised/docs/reader" result-retest.json
done
```

회귀 검산은 각 판본의 실제 기사 분할·검색 함수를 사용한다. 결과 파일에는 원문 전체 대신 검색한 행의 해시, 필수 단락 좌표와 후보 순위를 보관한다. 기사 전체의 정확성, 반영된 정치 성향, 실제 편집 시간의 증감은 이 기록에서 추정할 수 없다.

### 정치 기사에서 검색을 나눠 봤을 때

단일 검색 결과와 원자료를 본 뒤, 같은 정치 기사 여섯 문항에서 검색어를 쪼개는 방법을 시험했다. 처음에 고정한 영문구에 있던 단어만 사용했다. 조각을 입력하기 전에 [분할 규칙·검색어](diplomacy/fragments.json)를 고정했다. 한 문항의 검색들에서 1위씩, 다음에는 2위씩 번갈아 읽고, 같은 문단은 한 번만 셌다. 예산이 남으면 검색 결과가 제공한 주변 단락을 가까운 순서로 읽는 것으로 계산했다. '주변 원문 확인'을 눌러 더 넓게 펼칠 수 있는 모든 행이나 외부 PDF를 수동 탐색하는 행동은 포함하지 않았다. 여기서 블록 수는 문항별 중복을 제거한 합계다.

| 입력과 전체 검색 횟수 | 최대 3블록에서 지지 4건 완전 적중 | 최대 6블록에서 지지 4건 완전 적중 | 최대 6블록에서 찾은 지지 필수 블록 |
|---|---:|---:|---:|
| 원래 한국어 6회 | 0/4 | 0/4 | 0/9 |
| 영문구 하나씩 6회 | 2/4 | 2/4 | 4/9 |
| 영문구 분할 16회 | 1/4 | 3/4 | 6/9 |

영문 조건은 3블록 한도에서 총 18블록, 6블록 한도에서 36블록을 골랐다. 한국어는 후보가 부족해 각각 3·6블록이었다. 단일 영문은 기존 칸의 영문 단독·한영 이어 쓰기와 보완판이 같았고, 분할 영문은 기존 칸과 보완판이 같았다. 분할 검색은 팔레스타인 대표의 이름과 인용문을 함께 찾았지만, 3블록 제한에서 미국·이스라엘 대표 관련 두 주장의 완전 적중을 잃었다. 6블록을 읽어도 어느 방식도 2011년 반박 자료를 모두 찾지 못했다. 검색어 작성자의 사전 지식과 추가 검색 열 번의 비용이 포함된 후향 시험이다. 실제 편집자의 클릭이나 소요 시간은 측정하지 않았다. [문항별 순위와 집계](diplomacy/split-result.json) · [검산 코드](diplomacy/split-search.cjs)

원래의 단일 검색으로 팔레스타인 대표 발언을 찾은 뒤, 별도로 영어 화자 미리보기를 검사했다. 직접 후보 142·137·166번에는 인용문(142번)이 있었고 발언자가 명시된 121번은 없었다. 원래 검색에 붙은 문맥에도 121번은 없었다. 선택적 화자 기능을 호출할 수 있는 일반 검색이었지만 열 수 있는 화자 미리보기는 0개였다. 공식 회의록에서 화자 표지와 발언이 21블록, 두 쪽 떨어져 있다. 이번 입력으로 이 기능을 눌러 발언자를 확인할 수 있는 경로는 생기지 않았다. 이 검사는 분할 검색과 별개다. [화자 기능 검사 결과](diplomacy/speaker-result.json) · [검산 코드](diplomacy/speaker-check.cjs)

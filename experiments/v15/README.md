# v15: 원문 보호·부분 편집·판정 불확실성

기존 원실험, 원평가, v14 결과는 수정하지 않는다. 이 디렉터리는 별도 회차의 코드 수정, 합성 최소단위 실제 AI 출력, 공개 가능한 분석이다. 실제 기사 전문·전체 후보·긴 근거 인용은 공개 패키지에서 제외했다.

- `code-audit/receipt`: 실제 CLI 경로 충돌 재현과 수정, 기존 결과 영향 검사.
- `code-audit/aggregation`: 예상 ID 집합과 다른 판정을 거부하는 수정과 기존 원평가 영향 검사.
- `dependency`: 실제 원문/O+P/O+P+Q 해시와 두 독립 관계판정의 완전성을 검사. 이는 의미 안전성 인증이 아니다. 모든 후보에는 최종 전체 감사가 필요하다.
- `micro/`, `micro-results.md`: 12개 합성 unit × 두 절차 = 실제 24개 최종 판단. 최종 판정 우월성은 확인되지 않았다.
- `method-research.md`: 기존 접근과 문헌 근거, 새 조작과 단순 반복의 구분.
- `RESULTS.md`: 실제 전체 기사·노출 회귀·남은 실패에 대한 최종 보고.

재현: 저장된 공개 코드와 합성 회귀는 저장소 루트에서 `python tools/run_checks.py`. 네트워크/API/모델 호출이 없다. 이 검사는 실제 AI 출력을 새로 생성하지 않는다. 별도 문맥의 실행 metadata/원문 원본/수집시각/해시/원평가는 비공개 실험 기록에 보존했다. 배포 모델 snapshot/seed/token/비용 통제 미확인, 인간 검토 0. 공개 로그는 환경 경로만 삭제한 파생본이며 원로그는 보존한다.

실제 기사에서는 수정 전후 문자·anchor·후보 해시를 확인하고, 별도 검토자가 writer 목록을 보지 않은 채 원문에서 독립 목록을 만든 뒤 익명 후보를 감사한다. 이 독립 목록도 gold가 아니며 중요성·필수성의 완전성을 보장하지 않는다. 동의는 진실의 증거가 아니라 원자료 대조의 추가 관찰이다.

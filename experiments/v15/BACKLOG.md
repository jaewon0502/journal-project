# v15 재개 감사와 미해결 목록

범위: 기존 원실험·동결코드는 보존하고 독립 브랜치에서 검증 도구와 편집 절차를 보완한다. 시간 경과나 보고서 작성 자체를 종료 조건으로 삼지 않는다. 새 주요 실패가 생기면 원인별 접근 기록에 추가한다. 서로 다른 접근 10개가 같은 문제를 해결하지 못하면 이를 명시하고 재실행 횟수를 새 접근으로 부풀리지 않는다.

## 선행 접근과 이번 구분

v10에 이미 관계 유형 구분, v12에 필요성 최소쌍 및 source-generated 질문/양방향 검사, v13에 선택수정과 의존폐쇄가 있었다. 단순 지시문 반복은 신규 해법이 아니다. 이번 개발의 새 조작은 실제 부분적용 결과와 반사실 파손 근거를 연결하는 간선 계약, 원문 목록을 기존 보호표 노출 전에 동결하는 순서 통제다. 필요성 실험은 기존 절차의 재현·확장으로 표시한다.

## 공개 경계와 재현성

원문 전문·실제 기사 전체 후보·긴 원평가는 비공개 작업영역에 둔다. 공개 코드/단위시험에는 합성 자료만 사용한다. 원문/수정/근거 대조 보고서는 짧은 인용·위치·링크와 자체분석으로 작성한다. 외부 Page, 원격 repo, 계정, 유료 API를 변경하지 않는다. 코드 커밋은 허용된 독립 로컬 브랜치에만 한다.

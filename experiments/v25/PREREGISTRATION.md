# v25 사전 계획 — 원출판 표 배치의 대상 연결 효과

## 가설과 계보

v24의 same 장부를 믿는 게이트는 의미 동일성을 입증하지 못했다. 게이트를 추가하지 않는다. FEVEROUS의 표 머리말·맥락 처리와 FinQA의 행 검색에서 연도 맥락이 빠지는 오류를 참고하여, **같은 전체 원자료 텍스트에 출판자가 배치한 표 페이지 이미지를 더하면 서로 다른 대상/지표의 수치를 오연결하는 일이 줄어드는가**를 시험한다.

텍스트에 수치·행·열 명칭이 모두 있는지 먼저 확인한다. 이미지에서만 새로운 값/문구가 보인다면 순수 배치 효과가 아니라 정보 복구가 섞인 것으로 보고한다. 모델이 작성한 보호표/동일성 라벨은 어느 조건에도 주지 않는다. 출판자의 행·열·조건은 AI와 독립적으로 존재하는 근거지만 같은 연구/통계에 속하며 독립된 재현 실험은 아니다. 별도 AI 평가자도 독립 모델/인간 검증은 아니다.

기존에 ClinicalTrials.gov ID, XML표좌표, layout텍스트, 공식래스터자료를 사용한 전례가 있다. 첫 시각자료 사용이나 새 독립 원리라고 주장하지 않는다. 조사 범위에서 같은 전체텍스트의 이미지 유무를 직접 대조한 실험은 찾지 못했다. 새 비교 기제1회, 독립 접근 가족 증분+0을 사전에 유지한다. 역사 하한4/1·8/4·4/1을 버전수로 늘리지 않는다.

## 실제 자료와 범위

- KO: 경향신문2026-04-23 전체 기사 본문8문단과 기사 도표. 한국은행 2026Q1 GDP 속보 전체20쪽(공보2026-04-24호; 번호는 발표일이 아님). 개입은 원PDF물리쪽2·3의 표 배치.
- EN: ABC News/ABC7 2024-02-05 전체 본문11문단·본문캡션. 발견논문 arXiv:2305.06206v1 전체19쪽과 NASA2024-01-31 발표. 개입은 원논문 물리쪽11 Table3. 실제 기사시점과 수집시점/원논문버전을 구별한다.

원문 기사2개는 실제 새 입력이다. 각 기사에서 한 숫자만 바꾼 인공 오류본1개씩을 별도 작성한다. 원문과 인공본은 같은 전체 근거·질문을 사용한다. 다른 대상의 값을 옮기되 인공본이라고 메타데이터에 표시하고 실제 언론 오류로 보고하지 않는다. 기사 전체가 입력이지만 평가는 사전 지정한 언어별2개 수치 주장과 각 주장에 대한2개 후보 근거셀에 집중한다. 기사 전체의 모든 사실을 검증했다고 하지 않는다. 기사 다른 구간 보존은 문자 대조로 확인한다.

## 조건과 독립성

- T: 전체 기사와 모든 원자료 전문 텍스트, 동일한 질문·후보셀 위치, 공통편집 지시.
- V: T와 동일 + 원PDF의 지정 페이지를 그대로 렌더링한 이미지. AI 주석/열 색칠/정답 라벨 없음.

한국어 기사 자체의 도표는 양쪽에 동일하게 제공하므로 차이는 원자료 표 이미지뿐이다. 입력 토큰/시각처리 비용은 같지 않고 측정 가능한 비용도 없으므로 순수 계산량 통제를 주장하지 않는다. 언어별·조건별 새 문맥에 원문/변형2개를 함께 주므로 해당2개는 독립 반복이 아니다. 양쪽의 모델/노력 override 없음; 정확한 배포버전/seed는 통제 못함.

별도 평가자가 원문·자료·원출판 이미지에서 후보대상과 선택주장 기대판정을 먼저 저장한다. 작성자의 oracle을 보지 않는다. 편집자는 PRE/다른조건을 못 본다. 평가에는 조건명과 실행파일 열람기록만 가리고 실제 이유·근거·최종문을 제공한다. 이유 자체가 조건을 드러내면 보고한다. 새로운 숫자 종합점수/사후 합격선을 만들지 않는다.

## 지표와 완료기준

조건별 후보셀16판정(언어2×변형2×질문2×후보2)에서 같은대상 오판, 다른대상 오판, 미확인을 구분한다. 이를 독립 사건16개로 세지 않는다. 선택 주장8판정/조건, 자연기사2개와 인공오류본2개 최종편집/조건을 분리한다. 올바른 수치정정·정상 선택주장 보존·잘못된 정정·불필요 보류·관련없는 본문 변경을 각각 보고한다.

핵심 모형산출물8개(2언어×2변형×2조건)를 실제 생성한다. 오류를 유도한 인공 링크 후보/변형의 결과는 실제 기사 자연오류 빈도가 아니다. 전체기사2개 외에 실제 기사 수를 늘려 세지 않는다. 더 나은 결과가 없으면 원자료 이미지 단계를 일반 기본절차에 추가하지 않고 실험만 보존한다. 중요한 실패가 남으면 구체 관계·문장·필요외부자료를 명시한다. 이번 회차는 한 차례 비교와 독립검증으로 끝내며 새 게이트/무한 체크리스트를 만들지 않는다.

## 편집 실행 전 최종 분리

짝을 같은 작성 문맥에 주면 원문 숫자를 기억해 인공 오류를 되돌릴 수 있어, 최종 실행은 **언어×변형×조건 각각 새 문맥8개**로 분리한다. 앞 문단의 ‘2개를 함께 주기’ 계획을 실행 전에 대체하며 원계획은 지우지 않는다. 작성 입력에서 original/artificial 라벨도 제외한다. 한국어 후보의 AI가 옮긴 행 이름은 입력투영에서 제외하고 표·분기열·셀값으로 실제 셀을 찾게 한다. 원자료 전문의 실제 행 이름은 그대로다. 후보참조를 출처 그 자체로 믿지 말고 원출판에서 확인하도록 한다. 설계 원본과 투영본을 모두 해시로 보존한다.

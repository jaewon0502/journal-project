# v25 결과: 원출판 표 이미지를 더해도 이번에는 개선되지 않았다

2026-10-03 UTC. 기존 원실험과 구분한 소규모 AI 내부 비교다. 한국어 경제 기사와 영어 천문 기사 전문을 새로 확보하고, 동일한 전체 원자료 텍스트에 원출판 표 이미지를 추가하는 효과를 시험했다. **두 조건의 대상 연결과 최종 본문이 모두 같았다. 기본 절차에 새 필수 단계를 추가하지 않는다.**

실제 기사 2개와 각각 숫자 하나만 바꾼 인공 오류본 2개를 사용했다. 8개 별도 작성 문맥에서 실제 출력을 생성했다. 원기사의 실제 오류를 2건 발견한 실험이 아니다. 양쪽 모두 정상 원문을 보존하고 인공 오류만 최소수정했다.

반복 출력과 후보셀을 독립 사건으로 세지 않는다. 언어별 선택 주장은 2개다. 전체 기사를 입력하고 나머지 문자의 보존을 검사했지만 기사 전체의 모든 사실을 인증하지 않았다. 양 조건 모두 성공한 쉬운 표본일 수 있어 개선 여지가 없었던 결과이며, 두 방법의 일반적 동등성을 입증하지 않는다.

## 세 문제의 현재 상태

1. **보존정보 목록의 완전성: 미해결.** 작성 전 원출판의 행·열·측정대상·시점·단위를 고정하는 방법은 유용하지만, 이 시험의 질문도 연구자가 선택했다. 질문 밖의 중요한 의미가 없다는 증명은 없다.
2. **불필요한 재작성 손실: 국소 해결, 일반화 미확인.** 아래 두 인공 오류에서는 필요한 숫자만 바꾸고 나머지 전부를 보존했다. 모호한 대상관계나 문장 사이 인과·반론까지 자동으로 안전하게 고친다는 결과는 아니다.
3. **평가 AI 불일치: 이번에는 관측되지 않음, 해결 아님.** 언어별 별도 AI가 출력을 보기 전에 근거 판정을 저장하고 조건명을 가린 결과를 후검사했다. 평가자 반복 재현성이나 독립 모델·인간 정답 정확도는 측정하지 않았다.

## 바로 쓸 절차와 중단 기준

1. 고칠 주장과 원자료의 대상·지표·기간·단위·귀속을 정확한 위치에 연결한다. 값이 비슷하다는 이유로 같은 대상이라 하지 않는다.
2. 불일치가 확인된 절·숫자만 패치한다. 정상문장과 발언 강도·반론 대상·시간 조건은 그대로 둔다.
3. 원문→수정문 문자 차이를 검사하고, 별도 검토자가 원자료에서 관계와 수정 필요성을 다시 판단한다. 문자 동일성은 의미 진실의 대체물이 아니다.
4. 대상 관계가 미확인, 근거가 상충, 필수 의미를 길이 안에 보존 불가, 또는 새 의미 손실이 발견되면 해당 수정을 보류/롤백한다. 부족한 연결자료 또는 길이 증가 필요를 명시한다.

보호항목을 실패마다 추가하는 것은 사례별 회귀수정이다. 목록을 늘리는 것만으로 일반해법이 검증되지는 않는다. 이번 회차는 한 번의 비교와 독립 후검사로 종료했다.

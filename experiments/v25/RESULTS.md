# 실제 근거, 보호 관계와 최소편집

## 한국어: 서로 다른 지출 항목과 GDP/GDI

[경향신문 원기사](https://www.khan.co.kr/article/202604232039005)는 2026-04-23 보도다. 전문 8문단과 기사 도표를 확보했다. 직접 HTTP 요청은 403이었으나 공개 웹 읽기 도구로 본문에 접근했다. 기사 도표는 공개 HTTP 200으로 받아 실제 보았다. [한국은행 원발표](https://www.bok.or.kr/portal/bbs/B0000501/view.do?nttId=10097644&menuNo=201264)의 [20쪽 PDF](https://www.bok.or.kr/fileSrc/portal/c7597db684a44fef969442faf012bd20/1/de5d5987539244efa4497079fa5f8182.pdf) 전체 텍스트를 입력했다. 수집은 2026-10-03 13:53 UTC. 공보 ‘2026-04-24호’는 발행 번호이며 발표일 4월23일과 구별한다. 2026년 1분기 속보 당시 수치로, 후속 개정치를 소급 적용하지 않았다.

| 보호할 관계 | 원자료 위치 | 짧은 표지·값 | 보존 이유·판정 |
|---|---|---|---|
| 건설투자와 설비투자 구별 | 물리 2쪽/인쇄 1쪽, 지출 표의 서로 다른 행 | 건설투자 2.8 / 설비투자 4.8 | 같은 분기라도 다른 항목. 원표 직접 확인, 선택 관계 상충 없음 |
| 실질 GDI와 GDP 구별 | 물리 3쪽/인쇄 2쪽, 경제활동 표 | GDI 7.5 / GDP 1.7 | 소득과 생산은 같은 지표가 아님. 직접 근거 있음 |
| 계절조정·전기비와 원계열·전년비 구별 | 위 표 제목·주석·2026년 1분기 열 | 괄호 밖/괄호 안 | 이번 값은 계절조정 실질 전기비. 수치만 떼면 비교 대상이 달라짐 |

자연 기사 2.8%는 양 조건 모두 그대로 유지했다. 인공본의 **건설투자 4.8% → 2.8%**만 두 조건 모두 수정했다. 실제 설비투자의 4.8%, GDI의 7.5%, GDP의 1.7%와 다른 모든 문자는 유지됐다. 이 인공 오류를 경향신문의 실제 보도 오류로 해석하면 안 된다. ECOS 분류번호는 표 계열 분류이며 고유 행/대상 식별자로 취급하지 않았다.

## 영어: 두 천체의 같은 측정 행 구별

[ABC News/ABC7 기사](https://abc7ny.com/post/nasa-super-earth-exoplanet-toi-715-b/14388381/)는 2024-02-05 게시, 2월6일 수정으로 기록했다. 전문 11문단·제목·부제·캡션을 확보했다. [원논문 arXiv:2305.06206v1](https://arxiv.org/pdf/2305.06206) 전체 19쪽과 [NASA 2024-01-31 발표](https://science.nasa.gov/universe/exoplanets/discovery-alert-a-super-earth-in-the-habitable-zone/) 전체 본문을 제공했다. 세 자료는 공개 HTTP 200으로 접근했다. 수집은 2026-10-03 13:53 UTC이며, 논문 v1과 당시 천체 확인 상태를 고정했다.

| 보호할 관계 | 원자료 위치 | 짧은 표지·값 | 보존 이유·판정 |
|---|---|---|---|
| 두 천체 구별 | 논문 물리 11쪽, Table 3 열 머리말 | TOI-715 b / TIC 271971130.02 | 같은 항성계라도 다른 대상. 직접 표 근거 있음 |
| 공전주기와 대상 연결 | 같은 표 Fitted Parameters, P(d) 행 | 19.288004 / 25.60712 | 첫 값은 b, 둘째 값은 다른 후보. 정수일 반올림과 오차 범위 확인 |
| 크기와 대상 연결 | 같은 표 Derived Parameters, 반지름 행 | 1.550±0.064 / 1.066±0.092 | 지구 대비 반지름 비율과 지름 비율은 같음. 별 대비 반지름 비율과 혼동 금지 |
| 적합 조건·당시 확인 단계 | Table 3 및 논문 8·9쪽 | 2-planet linear fit | 사전분포와 적합 결과를 구별. 두 번째 후보를 당시 확정 행성으로 승격하지 않음 |

정상 기사의 19일은 그대로 유지했다. 인공본의 **26 Earth days → 19 Earth days**만 양 조건 모두 수정했다. 26은 다른 천체의 25.60712일을 정수로 반올림해 주입한 값이다. 최종 본문의 다른 문자는 전부 보존했다. 선택한 크기 주장도 그대로 유지했다.

## 왜 추가 이득이 없었는가

두 PDF 모두 `pdftotext -layout`으로 추출해 행·열 배치가 상당 부분 남아 있었다. 사전 평가자가 이미지의 선택 수치·머리말·조건이 텍스트에도 있음을 확인했다. 따라서 이번 결과는 **양질의 전체 텍스트에 원표 이미지를 더한 추가 이득이 없었다**는 뜻이다. 텍스트에서 머리말이 없어진 경우나 관계 자체가 공개되지 않은 경우를 시험한 결과는 아니다.

T와 V의 기사·전체 원자료·질문·편집 정책은 동일하고, 한국어 기사 도표도 공통 제공했다. V만 원자료 물리 2·3쪽(KO) 또는 11쪽(EN) 전체 이미지를 더 봤다. 출판자의 공간 관계는 AI 밖에 존재하는 근거지만 같은 통계/연구를 다시 보여주는 것이며 독립 연구의 재현 증거가 아니다. 시각 입력의 토큰·처리량 차이는 통제하지 못했다.

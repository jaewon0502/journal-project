# 연구 방법과 남은 문제

## 읽은 원방법과 이번 가설

[FEVEROUS §3·4](https://arxiv.org/pdf/2106.05707)는 표 셀의 행·열 머리말과 문서 맥락을 보존한다. [FinQA §3·5.1 및 부록 C](https://arxiv.org/pdf/2109.00122)는 행 중심 검색이 연도 구별을 놓치는 사례를 제시한다. 이로부터 원출판 표의 공간 맥락을 추가하는 가설을 택했다. 두 논문이 래스터 이미지 추가의 성능 이득을 입증했다고 주장하지 않는다.

[DWIE §3·4.2·4.3](https://arxiv.org/pdf/2009.12626)는 개체 공지시와 개체 간 관계를 구별한다. 해당 구현의 entity linking은 후속 과제이며 명사형·대명사형 공지시가 주석에서 빠지는 한계가 있다. 논문을 읽은 것을 학습된 연결 모델의 실제 배포·검증으로 세지 않았다. 관련 본문은 원PDF로 읽었고 접근 기록과 해시를 보존했다.

AI가 같은 대상이라고 적은 장부를 코드가 받아들이는 문제를 새 게이트로 감싸지 않았다. 출판자의 실제 표를 추가한 이번 비교에서도 모델의 시각 해석은 틀릴 수 있다. 정답으로 가정한 AI 보호표는 작성자에게 주지 않았다.

## 새 이름과 독립 접근을 구별

과거 v17에는 ClinicalTrials.gov NCT01867671의 실제 등록자료가 이미 쓰였다. 다만 결과 비율의 출처로 registry Results를 쓴 것은 아니다. XML 표 좌표, `pdftotext -layout`, 공식 래스터 페이지 열람도 선행했다. 이번에 조사한 이력에서는 같은 전체 텍스트의 원표 이미지 유무를 통제한 비교는 찾지 못했다. 따라서 새 비교는 맞지만 최초의 외부 식별자/시각자료 사용이나 새 독립 접근 가족은 아니다.

| 문제 | 과거 시도 가족 하한 | 잔여 실패 확인 가족 하한 | 이번 증분 |
|---|---:|---:|---:|
| 보존정보 목록 불완전 | 4 | 1 | 0 |
| 최소편집·부수 손실 | 8 | 4 | 0 |
| AI 의미·필요성 판정 불일치 | 4 | 1 | 0 |

계보는 NOVELTY-AUDIT.md에 근거 위치와 함께 남겼다. 가족은 행 사이에 중복되므로 합하지 않는다. 같은 좁은 문제에 독립 해법 열 가지가 모두 실패했다는 근거는 아직 없다. 버전 수·출력 수·코드 버그 수로 접근 수를 늘리지 않는다.

## 평가와 실행 한계

8개 작성 출력은 각각 새로운 문맥에서 생성했다. 원문/인공본 표시를 입력에서 가렸고 각 작성자는 한 변형만 받았다. 모델·노력 override를 주지 않았다. 정확한 배포 모델 버전, seed, 토큰 비용은 확보하지 못했고 비용이나 C/D 시간 차이를 추정 측정값으로 쓰지 않는다. 자동 API 실험이 아닌 지원되는 하위 에이전트 실행이다.

언어별 별도 평가자는 출력 전에 전체 원자료와 원표를 보고 PRE를 저장했다. POST에서는 조건명과 실행 영수증을 가렸으며 작성 이유·근거는 남겼다. 문체와 표 전사 방식이 약한 단서를 줄 수 있어 완전한 조건가림은 주장하지 않는다. 평가자와 작성자가 같은 모델 계열일 수 있고, 독립 인간·독립 모델 검증이 아니다. 동일 평가자 반복이나 인간 신뢰·편향 인상은 측정하지 않았다.

기사 전문과 원자료 전문은 사적 재현 파일에 보존했다. 공개 패키지에는 해시·위치·짧은 패치·결과 투영만 제공한다. 전문 입력은 사용했지만 질문 선택은 제한됐고, 전체 기사 모든 주장/반론 누락 감사는 아니다. 사후 결과에 맞춰 기준을 바꾸지 않았다. 사전계획의 ‘변형 두 개를 한 문맥에 제공’은 작성 실행 전에 ‘각각 별도 문맥’으로 수정했으며 원계획과 수정 기록을 함께 보존했다.

## 여전히 필요한 외부 자료

이전 농업태양광 사례의 [원논문 DOI](https://doi.org/10.1016/j.xcrp.2026.103555)는 논문을 식별하지만, 20㎡ 작물 시험구와 20×20m 시설이 같은 면적인지는 식별하지 않는다. 해당 공간의 포함 관계·실험 배치도·측정대상과 처치별 수치를 연결하는 방법/보충자료가 필요하다. 이번 신규 기사 시험은 그 관계를 해결하지 않았다. 기존 접근 실패와 메타데이터 확인을 유지했으며 v25에서 원논문 재접근을 시도했다고 보고하지 않는다.

학습된 별도 공지시/관계 연결 모델은 미실행 후보다. 적용 가능한 체크포인트·언어/영역 적합성·독립 주석과 비용을 검증하지 않았으므로 불가능하거나 검증된 해법이라고 말하지 않는다. 이번 비교 자체의 실행 blocker는 없었다. 남은 핵심은 **보존 목록의 완전성과 기사 주장↔원자료 대상 관계를 AI의 자기판정 밖에서 보증하지 못한다는 점**이다. 필요한 관계가 공개되지 않았다면 정확한 중단은 국소 보류이며, 새 체크리스트의 자동 통과가 아니다.

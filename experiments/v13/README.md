8묶음은 합성6묶음의 연구자 작성 수정안10개와 노출 실제2묶음의 기존 모델 수정안17개입니다. 새 AI 위험검토16개와 고유 최종감사15개를 기록했고, 같은 입력·두 검토를 사용하는 결정적 처리 비교에서 G0는0개, G1은13개를 채택했습니다. 신규 실제1사례의 작성1개는 별도입니다. 사후 발언강도 수정은 원집계에 합치지 않았습니다.

이 Git 판본은 내부 경로·서비스 식별자를 제거한 공개 파생본입니다. `PUBLIC-DERIVATION.json`은 원 패키지 해시와 최초 공개변환 해시를 연결하고 `SHA256SUMS` 및 `PACKAGE-MANIFEST.json`은 현재 파일을 검사합니다. 역사적 동결·감사 해시는 원본 기준이며 현재 파생본 검증과 구분합니다. v12는 중복 ZIP 대신 형제 디렉터리에 게시했습니다. 기사 전문·실자료 raw 판정·긴 인용 산출물은 제외했습니다.

저장소 루트에서 `python tools/run_checks.py`를 실행합니다. 이 폴더에서는 `python v13/code/verify_public_package.py . --full-gate`로 저장된 합성12행을 재생합니다(jsonschema 필요). 모델을 호출하거나 의미 판단을 새로 검증하는 명령이 아닙니다. 실자료 전체 재감사에는 원자료 재확보·버전 확인이 필요합니다.

# 필요한 부분만 고치는 사용 절차

이번 소규모 검사에서 가능성을 확인한 운용법이다. 완전한 의미 보존을 보장하지 않는다.

1. **자료와 질문을 고정한다.** 원문·원자료·수집일·포함 범위를 적고, 원문 의미 보존과 질문에 필요한 추가 답, 선택적 맥락을 구분한다. 실제 분량 제한이 없다면 임의 제한이나 승인 절차를 추가하지 않는다.
2. **수정마다 근거와 보존 대상을 연결한다.** 변경 전후 구간, 필요한 이유, 행위자·발언 강도·조건·반론·시점·비교 관계를 기록한다. 자료에 없다는 이유만으로 원문을 삭제하지 않는다.
3. **위험을 해당 수정과 연결한다.** 수정 자체의 미지원·조건 미확인과, 수정과 무관한 원문의 확인 공백을 구별한다. 관계를 확인하지 못하면 ‘무관’으로 처리하지 않는다. 다른 수정이 있어야 안전하면 의존관계를 표시한다.
4. **독립적인 안전 부분만 적용한다.** 필요한 근거와 의미 보존이 확인된 수정만 적용한다. 위험한 수정과 이에 의존하는 수정은 함께 보류한다. 위치가 특정되지 않은 중요한 위험이 있으면 전체 적용을 멈춘다.
5. **완성된 본문을 다시 검사한다.** 변경한 문장뿐 아니라 인접·전체 문맥을 원문과 양방향으로 대조한다. 비판·조건·유보·책임이 사라지거나 새 단정이 생기면 해당 변경을 보류하고 문제를 기록한다. 출처보다 단정적이지만 ‘중대하지 않다’는 판정도 완전 보존의 증거로 쓰지 않는다.

새 오류나 안전성 미확인이 남으면 자동 전달을 중단한다. 원문 복구는 원래 오류 해결을 뜻하지 않으므로 남은 문제도 함께 전달한다. 핵심 질문에 필요한 오류가 남은 본문은 부분 수정본으로 표시하고 완성된 검증본으로 취급하지 않는다. 보호표를 실패마다 늘리는 작업은 해당 사례의 회귀 수정이며 일반해법 검증이 아니다.

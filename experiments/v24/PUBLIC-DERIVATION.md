# 공개본 처리

합성 입력·모델 산출물·원평가의 내용은 보존했다. 공개 감사/접근/동결 메타데이터의 실행환경 절대경로만 상대경로로 바꿨고, 재생 스크립트도 이 패키지 기준 경로를 사용한다. 비공개 원본과 원래 해시는 별도 보관했다. 재생 스크립트는 원평가 파일을 덮어쓰지 않는다. 실제 기사/방법논문 전문은 공개 패키지에 포함하지 않았다.

전체 공개 검사에서 상속된 v23/DELIVERY.md의 Library 식별자가 검출되어 이 체크아웃의 공개본에서 식별자만 제외했다. 비공개 원문·과거 커밋·다른 worktree·실험 출력/평가·Library 항목은 그대로다.

# v24 후속 1회 보완 — 원실험 결과 공개 후 구분

원실험 두 조건 최종문10쌍이 같았고 두 PRE/POST 감사에서 각각 오류5/5 정정·정상5/5 보존이었다. 이 결과를 바꾸지 않는다. 추가 이득 미관측이며 코드 감사는 이와 별개로 전달 권한의 구조적 결함을 재현했다.

## 제한된 수정

별도 code_v2에서 (1) 비교ID를 같은 입력/원문 해시/정확 주장구간에 묶기, (2) 숫자값 이외의 문자를 보존하고 허용된 기대값으로만 바꾸기, (3) 피연산자의 단위와 계산 차원 확인, (4) 잘못된 스키마를 명시적 차단으로 반환하기를 구현한다. 기존 code/ 및 원평가/출력은 유지한다. 관련 없어도 참조ID만 붙이면 편집을 허용하던 구멍을 고치는 것이며 AI의 잘못된 동일성 판정을 해결했다고 하지 않는다.

피연산자 단위 필드가 없던 기존 비교장부2개는 원자료를 보는 별도 AI가 unit만 추가한다. 원래 값·관계·인용을 바꾸지 않는다. 기존 장부 그대로일 때와 이 새 메타데이터를 보완했을 때를 나눠 재생해 호환성/과잉차단을 보고한다. 저장20제품 재생은 노출된 회귀이며 새 미사용 평가가 아니다.

## 별도 전이 보완

원실험의 ‘같은 대상/다른 단위’ 쌍은 상자 수와 질량처럼 서로 다른 속성을 다룬다. SI 단위의 진짜 동등 변환을 포함하지 않았다는 범위 공백을 공개한다. 정책/기존자료를 안 본 새 작성자가 SI 동등변환 정상/오류 최소쌍1개(2입력)를 만든다. 생성자의 답을 보지 않는 별도 사전 판정과 비교장부를 작성하고, 같은 자료·장부를 기존 재량 절차/보완 게이트 절차에 각각 제공한다. v2 코드·표본은 이 편집 생성 전에 동결한다. 본문 보존·실제 수치정정·불필요 보류를 각각 보고하며 원실험10건과 분모를 합쳐 개선율을 만들지 않는다.

완료: 원 코드 반례 재현 → v2 동일 반례 및 정상 수리 검사 → 저장출력 회귀 → SI2입력×2조건 추가검증 → 한 번의 통합 보고. 새로운 의미 오류가 남으면 구체 예시와 함께 보류하고 이번 회차를 끝낸다. 전체 의미 완전성을 위해 무한히 조건을 늘리지 않는다.

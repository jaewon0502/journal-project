# 실행·검사 범위

원실험: 실제 네이티브 AI 비교장부10파일 + 편집20파일. SI 보완: 장부2파일 + 편집4파일. 핵심 의미 파이프라인 총36파일/최종 편집24개이며 모델 호출36회라는 뜻은 아니다. 별도 피연산자 단위 보완2파일, 사례 작성/감사/문서/기계 파생본은 이 분모 밖이다. 작성자는 같은 runtime 기본 모델·노력을 사용했고 정확한 배포버전/seed/추론량/토큰비용은 얻지 못했다.

`python tools/run_checks.py` 전체 종료코드0. unittest 288개/22회 실행, 기존 저장자료 재생, v24 실제 저장 편집24개의 문자패치와 v1/v2 파생 결과 재생 통과. 그중 새 코드 시험은 v1 8개/v2 20개다. 테스트 수는 기사 정확도나 독립 접근 수가 아니다. 의미 평가는 독립 AI PRE/POST이며 인간 평가가 아니다.

원실험 두 평가자는 모두 오류출력10개 정정/정상출력10개 보존을 확인했다. SI 감사자는 오류출력2개/정상출력2개를 확인했다. 조건을 합친 출력 수를 독립 사건 수로 세지 않는다. 설명의 게이트 단어로 조건을 추측할 수 있어 완전한 가림은 실패했다.

공개 검사에서 환경경로와 상속된 Library 식별자가 검출되어 공개본의 경로/식별자만 정리했다. 원자료·모델 출력·원평가는 바꾸지 않았고 비공개 원본을 보존했다. 기존 실제 논문 접근 실패를 이 검사의 통과로 해결됐다고 하지 않는다.

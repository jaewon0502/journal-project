# v24 사전 실행계획 — 비교 자격의 실행 게이트

2026-10-03 UTC. 기존 v23 원문가림은 추가 이득이 없어 채택하지 않는다. 기존 기록/원점수는 보존한다. 이번 목표는 같은 대상인지 확인하지 않은 수치 충돌 판정을 줄이되, 같은 대상의 실제 수치 오류를 놓치지 않는지 확인하는 것이다.

## 바뀌는 요소

동일한 원문·근거·질문과 한 번 추출해 동결한 AI 비교장부를 두 조건에 제공한다. 기존 조건은 장부를 참고하고 스스로 판정한다. 개입 조건은 같은 장부에서 코드가 산출한 비교 자격을 지켜야 한다. 대상/속성/집단범위/조건/시점 각각 same과 실제 원문/근거 문자열 앵커가 있고, 단위 차원과 합리수 계산이 성립하는 비교만 수치 불일치 정정을 허용한다. 표현이 같은지를 검사하는 것이며 의미 동일성을 코드가 증명하는 것은 아니다. 미확인/다른 대상을 막고, 동등 단위는 정규화하여 불일치로 세지 않는다.

두 조건의 총 입력량은 게이트 결과만큼 다르므로 순수 토큰량 통제가 아니다. 공통장부로 추출 변동을 통제하며, 정정권한의 제약 효과를 시험한다. 코드가 단지 지시를 보여주는 데 그치지 않도록 최종 출력의 contradicted행과 수치 패치가 허용ID를 참조하는지 재검사한다. 미준수 출력은 자동 통과시키지 않고 원출력 그대로 실패로 기록하며, 조용히 정답으로 고치지 않는다.

## 표본·사전 평가

이전 사례/정책/코드를 읽지 않은 별도 문맥이 합성 정상/오류 최소쌍5개(총10입력)를 작성한다. 범주: 다른 대상과 같은 숫자, 같은 대상과 다른 단위, 시간 변화, 집단 부분/전체, 겹치는 지표. 원자료는 각 쌍에서 동일하다. 각각 오류는 실제 근거로 확인 가능한 한 요소만 바꾼다. 생성자의 oracle을 쓰지 않은 별도 감사자가 원문·근거만 보고 독립 사전 판정을 저장한다. 생성자가 새로 만든 정상문은 자연 기사 표본이 아니며 한국 언론으로 일반화하지 않는다.

평가 판정이 다르면 실행 전에 의미 모호성을 기록하고 해당 항목의 판단 범위를 좁힌다. 단순히 유리하게 만들기 위해 사례를 바꾸지 않는다. 공개 후 사례는 다시 미사용이라고 부르지 않는다. 검사자와 편집자 별도 문맥, 조건 이름을 가린 동일 원문·근거로 POST 평가. 게이트가 수정의 실제 정당성을 보장하지 않으므로 원문과 최종문을 직접 대조한다.

## 결과 지표(합산 점수 없음)

- 정상5건: 잘못된 충돌 판정/편집 수, 정확한 본문 보존 수, 불필요 국소보류/전체보류 수.
- 오류5건: 올바른 대상의 오류 검출·최소정정 수, 누락/게이트 과잉차단 수, 조건/반론/시간의 부수 손실 수.
- 추출장부: 잘못된 동일성/수치/단위/계산, 빠진 비교, 의미적으로 잘못되었으나 게이트를 통과한 항목.
- 게이트: 차단 이유와 실행 미준수. 코드 통과와 의미 정확도를 분리.

정상/오류 명칭은 생성 기대이고 독립 PRE에서 확인한다. 표본별 근거와 분모를 공개한다. 원문가림 우월성은 다시 주장하지 않는다. 결과 개선이 없으면 그대로 보고한다. 게이트가 미확인을 막는 대신 정당한 수치 오류도 놓치면 실패로 남긴다. 별도 기계 시험의 오염된 동일성 증명서가 통과할 수 있는 반례를 공개해 구조검사 한계를 숨기지 않는다.

## 완료기준·중단 범위

정책/코드/표본/사전 기준 동결 → 비교장부10개 → 기존/개입 편집 각10개 → 별도 의미 감사 → 실제 오류와 과잉차단 분석. 필요한 수정은 발견한 결함에 한한 1회와 노출사례 회귀로 구분한다. 새 실제 기사 성능 검증은 이번 합성 전이의 분모에 포함하지 않는다. 접근불가 논문은 DOI/제목/필요부분/경로 별도 기록하고 당해 사실 미확인을 유지한다.

네이티브 AI 실행이며 정확한 모델 배포버전/seed/비용 미통제. 동일 runtime 기본 모델·노력 사용, override 없음. 각 단계 한 문맥에 복수 사례가 포함될 수 있어 독립 반복 표본이 아니다. 사람 평가/독자 이해/정치편향 감소 미측정. 추가 결제·계정·푸시·Page 변경 없음.

## 편집 생성 전 실행 보완

비교 자격표를 지시문으로만 제공하는 한계를 피하려고 실제 적용기 `delivery.py`를 별도로 고정한다. 허용 비교ID가 없는 수치 패치는 최종 본문에 적용하지 않고 해당 구간 검토필요를 남긴다. 원래 AI 출력/실패 판정은 보존하며 삭제하지 않는다. 비고유 원문 앵커나 겹치는 패치도 차단한다. 허용된 패치만 원문에 적용한 결과는 모델 새 출력이 아닌 기계적 파생본이다. 개입의 최종 평가는 이 전달본을 포함한다. 같은 적용기를 기존 조건의 저장된 제안에도 돌리는 보조 재생을 분리해 보고한다. 같은 제안에서 실제 차단한 효과와, 두 새 문맥 편집자의 생성 차이를 혼합하지 않는다. 적용기 도입은 편집 출력 공개 전이며 아래 추가 해시에 기록한다.

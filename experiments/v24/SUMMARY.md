# Journal v24 — 잘못된 수치 충돌 판정의 제한적 보완

**새 표본에서는 기존 절차와 강제 비교 게이트의 성능이 같았다. 게이트의 추가 의미 정확도 이득은 확인하지 못했다.** 다만 실행기가 다른 절/다른 값에 정정 권한을 잘못 적용하는 결함을 재현해 고쳤다. 의미 판정과 코드 적용의 개선을 구분한다. v23의 원문가림은 채택하지 않았다.

## 접근 횟수부터

v23까지 확인된 독립 가족 하한은 보호 누락4시도/1잔여실패, 부수손실8/4, 평가불일치4/1이다. 구조화목록, 양방향감사, 근거선행질문, 최소패치, 슬롯렌더링, 원문삽입/정정주석, 절별판정, 선택복원, 결정론적대응, 가린AI감사, 필요성반례, 합의게이트의 계보를 APPROACH-COUNTS.md에 적었다. 행 사이 중복을 합산하지 않는다. 이번 수치비교의 실행게이트 대비는 구체 기제시험1회이며 기존 구조계약과 별개인 새 독립 가족 증분은0으로 둔다. 버전24를 접근24개라고 세지 않는다. 동일 문제의 독립10접근 실패는 확인되지 않았다.

## 바로 사용할 절차

1. 원문 주장과 근거에서 대상·속성·집단/분모·조건·시점을 각각 짧은 위치/인용으로 적는다. 숫자가 같거나 단위가 같다는 이유로 같은 대상이라고 하지 않는다.
2. 두 설명이 동시에 참일 수 있는 다른 대상/시점/부분집합을 찾는다. 동일성 미확인이면 수치충돌 판정을 보류한다. 이는 원문 수치가 참이라는 뜻도 아니다.
3. 같은 대상임을 근거로 확인한 뒤 단위·계산·부정 조건을 대조한다. 한정된 정확 수치 수정은 지정 숫자만 허용값으로 바꾸고 다른 글자는 그대로 둔다.
4. 독립 검토자가 원문·근거·최종문을 직접 다시 본다. 단위 누락, 정당한 비판/조건 손실, 대상 결합 이견, 근사치/범위 등 지원하지 않는 계산이면 해당 수정만 중단/복원한다.

이 방식의 실용적 이점은 오류를 좁은 구간으로 묶고 재현/복원할 수 있다는 것이다. 이번 새 표본에서 기존보다 실제 의미 오류를 더 줄였다는 결과는 없다. 정상문까지 보류해서 성능을 꾸미지 않았다.

## 자료와 실행 범위

모든 새 시험 사례는 **명시적인 합성 자료**다. 실제 언론 기사12건이나 기존 A–D48출력 재실행이 아니다. 원실험10입력·20편집, 별도 SI2입력·4편집, 각 입력의 독립 근거 장부를 저장했다. 코드로 만든 파생본과 저장결과 재생은 새 모델 출력으로 세지 않는다. 정확한 배포모델/seed/비용/시간 비교는 통제·측정하지 못했다. 기본 runtime 모델/노력 override 없이 별도 문맥을 썼다. 사람 검증/독자 신뢰/정치적 편향 감소를 측정하지 않았다.

v23 실제 기사의 면적 관계는 아직 미확인이다. DOI10.1016/j.xcrp.2026.103555의 정확한 제목, 필요한 배치도/처리별 결과/측정정의, 실제 접근경로와 실패를 BLOCKED-PAPER.md에 별도로 기록했다. 검색요약이나 메타데이터로 논문 전문을 대체하지 않았다. 이 자료 부족을 합성 성공으로 해결됐다고 하지 않는다.

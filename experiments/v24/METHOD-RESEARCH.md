# v24 focused method research: executable numerical comparison gate

Prepared 2026-10-03 UTC. This is a method proposal and retrospective denominator audit, not an executed intervention or new factual verification. Read v23 APPROACH-LEDGER.md, binding-controls/policy.txt, SUMMARY.md, REPAIR-RESULTS.md, TRANSFER-RESULTS.md and saved access records. No prior experimental outputs or scores were modified.

## Concrete difference and hypothesis

The existing v23 binding policy already asks for referent, measured property, scope, time, unit, source authority, exact anchors, and an explicit test of whether the two statements could both be true about different referents. Merely making a more detailed binding table, adding a condition column, or saying “verify same object” is a refinement of that advisory policy. It is not a new independent conceptual approach.

A concrete, testable implementation difference is to freeze one AI-extracted binding record per item and feed the identical record to both arms. In the advisory arm, the editor considers the record but retains discretion. In the intervention arm, executable code refuses to label or apply a numeric contradiction repair unless the required evidence fields, typed comparison, and arithmetic satisfy a predeclared contract. Both arms should see the same original, sources, record, and proposed patch. Separate extraction calls per arm would confound extraction variability with enforcement.

The narrow hypothesis is: **enforcement reduces unsupported numerical contradiction edits caused by missing or explicitly unresolved comparison bindings, without losing correction of wrong numbers for a demonstrably identical object and measurement.** This is a proposal to test, not an observed gain. A gate that simply blocks all numerical corrections fails the second half.

A minimally useful record contains each side's literal value and unit; referent; measured property; scope/population or denominator; condition/treatment; time interval; polarity/comparator/approximation; source ID and exact source spans; and a separate, source-anchored identity/comparability assertion for every alignment dimension. Missing identity cannot be filled by numeric proximity or by an identical unit. Explicit not-applicable treatment/time fields require a reason rather than silently using null as agreement. If a dimension is unresolved, the numeric contradiction edit is ineligible; retain the clause with a local uncertainty annotation as appropriate, not a whole-article hold or an assertion that it is true.

The gate should verify exact source-span membership/offsets, record completeness, allowed relation labels, consistency of linked IDs, allowed unit conversions, dimensional compatibility, and arithmetic/comparator semantics. Require an explicit derivation for 20 m × 20 m → 400 m²; do not confuse this with a direct length-to-area unit conversion. Multiplication of stated dimensions requires that those dimensions describe the relevant footprint/shape. A 20 m² crop plot and a 400 m² system can coexist. Conversely, if the same system's footprint is explicitly 400 m², a claim of 20 m² should be eligible for local correction. Equivalent conversions, compatible intervals, approximations and bounds must not be treated as exact unequal point values. Tolerances should be specified by evidence/task rules, not invented by the model or borrowed wholesale from a benchmark.

**The code verifies structural evidence obligations, not semantic truth.** A real quote may be irrelevant; an AI can incorrectly assign identical referent IDs or claim a quotation proves identity. Such records can pass structural checks. Therefore call the output “contract-satisfied numeric comparison,” not a proof of source truth. Independent semantic review of source-to-field alignment remains necessary and fallible. Record semantic false accepts separately from structurally invalid accepts.

## Test design and counting

Use paired normal/wrong-number cases with the same object, plus different-object cases whose values legitimately differ; add treatment, denominator, time, and unit-normalization contrasts. Include missing identity and falsely asserted identity with real but irrelevant anchors. Freeze cases and expectations before examining outcomes; the known v23 article is a regression case, not held-out transfer. Report false contradiction edits, missed same-object contradictions, exact normal-text preservation, unnecessary holds, and structural rejection reasons with case denominators. Replaying the gate on identical saved records isolates enforcement; end-to-end extraction accuracy is a separate measurement. Calls and parser fixtures are not independent intervention families.

Historical family counts remain exactly P1 tried 4 / residual-failure 1; P2 tried 8 / residual-failure 4; P3 tried 4 / residual-failure 1. Source-first is A03, novelty +0. Do not sum rows because families overlap. A future executable-enforcement trial can be recorded as one mechanism-level experiment against advisory bindings, but this research note executes zero such trials and cannot retroactively increase old family counts. A new family label would need explicit scope and evidence that the old ledger lacks equivalent enforcement; no claim of global methodological novelty is warranted.

For the narrow v23 wrong-referent numerical defect, the observed denominator is **one real article/event (F923), one disputed crop-area/system-footprint relation, and two affected editor condition outputs**. The visible and masked/source-first variants are two policy conditions of the same experimental lineage, not two independently novel families. Two PRE auditors also overcommitted to the comparison; those are evaluator judgments about the same instance, not additional intervention failures. POST guidance included checking object identity, so it is not an entirely unprompted discovery.

The v23 binding-controls run adds four synthetic products, of which **two concern numerical referent binding**: K731 preserves different objects and K842 corrects a same-object wrong area. The other two concern source attribution. This is one follow-up advisory-binding control implementation with two numerical cases and no direct old-policy comparison. It supplies no observed residual numeric failure for that intervention, and no superiority estimate. The overlay restores the exposed article's P3 in both conditions; it is regression repair, not a new failed approach or held-out success. Thus the saved records establish a failing v23 source-first/visible pipeline instance and a separately executed small binding-control follow-up, **not ten independently executed, failed interventions for this narrow defect**. No-gain results (identical final texts in the main comparison) are not automatically failures; restored/derived files do not enlarge the failure denominator.

## Primary method sources actually read

1. Ravichander, Naik, Rose and Hovy, *EQUATE: A Benchmark Evaluation Framework for Quantitative Reasoning in Natural Language Inference* (2019), author paper [arXiv:1901.03735v2](https://arxiv.org/pdf/1901.03735). Full PDF retrieved; complete §4.2, including §4.2.1–4.2.5, Tables 3–5 and Algorithm 1, read from PDF text; §5.2 error discussion additionally inspected. Q-REAS extracts structured quantities, prunes incompatible pairs, and constrains symbolic operations. Its error discussion explicitly distinguishes quantity compatibility from legitimate comparison: equal counts of people injured and perpetrators need not refer to the same people/role. This is close prior art for typed comparison and a direct warning against treating shared units as identity. It supports separating alignment from calculation; it does not establish that v24's anchored identity fields are semantically correct. Its unit heuristics and approximate ranges should not be adopted as a guarantee. The paper's natural-language limitations also prevent extrapolating synthetic arithmetic performance to full articles.

2. Chungkham, V, Setty and Anand, *Think Right, Not More: Test-Time Scaling for Numerical Claim Verification* (2025), DOI [10.18653/v1/2025.findings-emnlp.1322](https://aclanthology.org/2025.findings-emnlp.1322/), [publisher PDF](https://aclanthology.org/2025.findings-emnlp.1322.pdf). Full PDF retrieved; complete §3, §3.1 and §3.2 read (printed pp. 24347–24349); introduction's numerical/currency example also read. The method samples candidate verification paths, trains a verifier from verdict-correctness labels, and selects paths, with adaptive compute based on estimated complexity. This is relevant to multi-aspect numerical mistakes but is a learned selection method rather than an executable identity-and-unit contract. It motivates attention to alignment and warns that more reasoning alone does not settle comparison. It does not validate the proposed gate. No paper-reported performance number is transferred to this task.

The papers are method references, not evidence about the agrivoltaic article. Local PDFs/text are private research artifacts under method-sources/. Search snippets were discovery aids only.

# 별도 SI 변환 전이 — 2입력/4출력

이전 원실험의 상자 수/질량 대조가 동등 단위변환 시험은 아니라는 공백을 공개하고, 후속 계획을 고정한 뒤 독립 작성자가 새 합성 최소쌍1개를 만들었다. 작성자는 이전 사례/정책/코드/결과를 읽지 않았다. 별도 비교장부 작성자와 사전 평가자가 생성자 답을 보지 않고 자료를 판정했다. code_v2와 입력은 편집 생성 전에 해시로 고정했다.

같은 막대의 오전10시/20℃ 길이1.25m가 근거다. 정상문125cm는 보존해야 하고, 오류문126cm는125로만 고쳐야 한다. 오후2시/80℃의1.26m는 다른 조건이라 오전 주장을 지지하지 않는다.

| 지표 | 기존 재량 | 보완 게이트 |
|---|---:|---:|
| 오류문 최소 정정 | 1/1 | 1/1 |
| 정상문 정확 보존 | 1/1 | 1/1 |
| 잘못된 충돌·조건 손실·불필요 보류 | 0/2 | 0/2 |

별도 PRE/POST 감사자가 네 최종문을 직접 확인했다. 두 조건 최종문은 각 입력에서 같다. 개입의 설명에 게이트 표현이 드러나 완전한 조건가림은 아니다. **여기에서도 추가 이득은 관측되지 않았다.** 새 SI 한 쌍은 미사용 보완 표본이지만 원실험10건과 합쳐 일반 성능 개선율을 만들지 않는다. 실제 기사 검증이나 다른 단위/근사치/범위의 성공을 뜻하지 않는다.

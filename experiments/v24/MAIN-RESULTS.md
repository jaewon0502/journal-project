# v24 원실험 결과 — 추가 이득 미관측

사전 고정된 새 합성5쌍/10입력, 공통 AI 비교장부10개, 기존 재량 조건/실행게이트 조건 각10개 실제 편집 산출물. 단일원문요약 A–D 실험의 재실행이나 신규 실제 기사 성능 측정이 아니다. 독립 PRE 두 명은 생성자 oracle 없이 정상5/실제충돌5를 각각 판정했고, 같은 기준의 POST에서20최종문을 직접 검토했다.

| 지표 | 기존 재량 비교 | 게이트 조건 |
|---|---:|---:|
| 실제 오류의 올바른 최소정정 | 5/5 | 5/5 |
| 정상 본문 정확 보존 | 5/5 | 5/5 |
| 잘못된 수치충돌/수정 | 0/10 | 0/10 |
| 빠진 실제 수치 오류 | 0/5 | 0/5 |
| 조건·시간·대상 부수 손실 | 0/10 | 0/10 |
| 불필요 국소/전체보류 | 0/10 | 0/10 |

두 평가자가 같은 결과를 냈지만 AI 합의를 정답 인증이라고 부르지 않는다. 문장·근거를 함께 검토한 제한된 합성 결과다. 두 조건 최종문10쌍이 모두 같았다. 실제 적용기는 차단 패치0개였고, 기존 조건 제안에 동일 적용기를 돌린 보조 재생도 차이0이었다. **게이트의 추가 이득이 없었다.** 더 많은 제약을 근거 없이 채택하지 않는다.

## 구체적으로 확인한 수정

- 다른 대상·같은 숫자: 서부 보관소 실제 발송은45→30개. 동부 발송45와 서부 예약45를 혼동하지 않았다.
- 다른 속성/단위: 8상자와 내용물 질량을 구별해8→192kg. 이것은 동등 SI 변환 시험이 아니어서 별도 보완 쌍을 추가했다.
- 시간 변화: 9월5일 정원24→18명. 9월12일의24명을 과거에 적용하지 않았다.
- 부분/전체: 전체 수료96→240명. 주말반96명과 전체를 구별했다.
- 겹치는 집합: 야간이용50명 중 주말이용이 없는 회원20→30명. 교집합20명을 여집합으로 오인하지 않았다.

이는 실제 AI 편집 결과이고 코드에 정답 문장을 넣어 대신 생성한 것이 아니다. 정상 쌍은 모두 그대로 남았다. 사전 평가에서 날짜·대상·범위를 바꿔도 참인 문장이 될 수 있다는 대안은 기록했지만, 실제 편집은 모두 원래 질문 대상을 유지한 숫자 정정이었다.

## 비교장부와 차단의 분모

독립 장부 감사는59비교를 확인했다. 허용 수치불일치5개는 모두 실제 오류, 정규화동등7개는 모두 해당 자료와 일치했다. 차단47개는 달력/시각 단위 미지원28, 다른대상·같은단위의 불일치10, 다른대상·같은숫자6, 다른측정·호환안되는단위3개였다. 47을 예방한 기사 오류 수로 쓰지 않는다. 기존 편집자도 그 비교를 잘못 사용하지 않았다.

## 한계와 원결과 보존

각 조건10개가 같은 작성 문맥에 있어 쌍끼리 독립이 아니다. 조건 이름은 가렸지만10개 출력의 설명에 게이트 표현이 있어 완전한 조건가림에 실패했다. 원문·근거 전체를 본 별도 PRE가 있었고 평가 지표는 바꾸지 않았다. 의미 보호 목록 완전성, 자연 기사 성능, 한국언론 신뢰/정치편향은 측정하지 않았다.

별도 코드 감사는 적용기가 허용ID를 다른 절에 재사용하거나 임의 after문을 넣는 것을 막지 못하고, 피연산자 차원도 계산하지 않는 결함을 재현했다. 원실험 산출물에서 이 결함을 악용한 편집은 발견하지 못했다. ‘타입이 있는 계산’이라는 최초 설명은 끝값 단위 정규화에만 해당했으며, 중간계산까지 보장한다는 뜻으로는 부정확했다. v1 원코드/결과를 보존하고 code_v2 후속을 별도 보고한다.

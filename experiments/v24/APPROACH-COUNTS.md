# 독립 접근 횟수 — 버전 수와 분리

v23까지 추적 가능한 역사 기록의 서로 다른 가족 하한이다. 실패는 해당 문제의 실제 잔여 실패가 확인된 가족만 센다. 추가이득 미관측, 실행 파일 수, 반복 버전, 합성 사례 수는 새 실패 가족이 아니다.

| 문제 | 시도/잔여실패 가족 | 접근명과 결과 |
|---|---:|---|
| 보호 의미 목록 누락 | 4/1 | A01구조화 목록(누락 확인), A02양방향 감사, A03근거 선행 질문·반례, A10결정론적 대응표 |
| 부수 의미손실 | 8/4 | A02양방향 감사·A04자유 최소패치·A08절별 지원/반박 경계·A09선택복원에서 잔여 실패. A05슬롯렌더러·A06연속원문삽입·A07원문+정정주석·A10대응표도 시도 |
| AI 평가 불일치 | 4/1 | A11가린 독립문맥 감사에서 불일치. A03근거 선행 질문·A12필요성 반례·A13합의게이트도 시도 |

이 표의 근거와 정확한 역사 범위는 ../v23/APPROACH-LEDGER.md. 가족이 행 사이에 중복되어 합산하지 않는다. 상한과 초기 일부 기록은 미상이다.

## 이번 구체 결함의 실행 기록

- v23 근거 선행/원문노출 비교: 한 실제 기사, 한 재배구역/시스템 관계, 영향받은 편집출력2개. 정책 조건2개를 독립 실패 접근2개로 세지 않는다.
- v23 명시적 대상결합표·양립반례 후속: 수치 관련 새 합성2건은 정상 보존/실제 오류 정정, 이미 본 실제 기사의 패치 복원. 종전 정책과 직접 비교하지 않아 우월성 미검증.
- v24 실행 계약: 새 기제의 통제 대비1회(동일 AI 장부의 재량/강제 적용). 원실험10입력에서 추가이득 미관측. 코드의 구조적 결함4유형은 별도 재현·수정 대상이며 자연기사의 잔여 실패4개가 아니다.

이번 개입은 기존 명시적 의미비교에 실행 계약을 결합한 구체 구현 차이다. 이를 기존 A10/구조계약 계열과 독립인 새 원리로 확정할 근거는 없으므로 **독립 가족 증분 +0**으로 기록한다. code_v2도 같은 기제의 수리이며 추가 가족 아님. 같은 좁은 문제에서 독립 접근10개 실패는 확립되지 않았다. 측정한 것은 실행기제 대비1회와 별도 회귀/범위 보완이며, 버전24회를 시도24개로 바꾸지 않는다.

# 바로 적용할 수 있는 예: 상태 기록과 잔존 의미 설명

이것은 이미 평가한 합성 사례의 사후 설명이며 새 실험이 아니다. 실제 기사 또는 일반적 해법 검증으로 세지 않는다.

**원문:** 도서관 방문 비율은 21%에서 24%로 올라 3% 증가했다. 회의는 금요일에 열린다.

**실제 최종 본문:** 도서관 방문 비율은 21%에서 24%로 올라 3%포인트 증가했다. 회의는 금요일에 열린다.

|원문 구간|UTF-8 위치, 끝 제외|무엇을 보호/추적하는가|
|---|---|---|
|도서관 방문 비율|0–23|지표 대상·주체|
|21%에서 24%|27–40|비교 전후 값|
|회의|68–74|다른 사건/질문|
|금요일|78–87|원문 주장 위치를 유지해 실제 변경 여부와 미해결 비교를 추적|

원문 51–53바이트의 `3%`만 `3%포인트`로 바뀌었다. 지표 대상,21%와24%,두 사건의 분리,그 밖 본문은 유지했다. 요일 수정 p2는 별도로 거부돼 금요일이 남았다. 이 거부는 가상 일정의 진실과 무관하게 설정된 실행 조건이다.

**기계 상태:** 부분 적용, p1 적용, p2 원복, 외부 게시 없음. 이 상태와 최종 본문 해시는 재생 검사로 일치했다.

**실제 native 의미 설명 원문:**

표시된 최종 로컬 결과에는 p1만 적용되어 “3%”가 “3%포인트”로 바뀌었습니다. 이는 시나리오에 주어진 21%와 24%의 차이와 맞습니다. 제안된 p2의 “금요일→토요일” 변경은 거부·롤백되어 회의 요일은 금요일로 남았습니다. 보류된 패치는 없습니다. 다만 제공된 가상 일정은 토요일이므로, 최종 결과의 금요일 표기와 일정 사이의 불일치는 남아 있습니다. p2의 거부는 금요일이 옳다는 증거가 아니며, 패치 적용 기록도 이 의미 문제의 해결을 판정하지 않습니다.

본문 수정으로 해결된 단위와 해결되지 않은 요일을 분리한다. 원복/거부를 의미 문제 해결이나 원문 진실로 바꾸지 않는다. 상태는 영수증에서, 의미 설명은 근거를 보는 별도 검사에서 관리하는 방향이다.

이 두 채널을 결합한 화면은 새로 독립 평가하지 않았다. native 설명 자체는 기존 조건에서 평가됐고, 이후 설명용 연결 메타데이터만 추가했다. 보호표도 사후 예시라 완전한 정답 목록이 아니다.

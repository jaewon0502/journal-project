# Journal v11 공유 실험 패키지

이 패키지는 기존 A–D/74출력 실험과 별개인 v10 후속이다. 첫 문서는 `results/report.md`이며 `analysis/reader-report.ko.md`, `precision/report.ko.md`가 상세 집계를 설명한다. v10 checkpoint Library는 `[private-library-reference-omitted]`이다.

## 재실행

Python 표준 라이브러리만 필요하다. 네트워크·모델 호출·인증·결제는 없다.

```sh
PYTHONDONTWRITEBYTECODE=1 python3 /path/to/package/run_checks.py
PYTHONDONTWRITEBYTECODE=1 python3 /path/to/package/portable/replay.py --version v1_3
```

첫 명령은 패키지 해시, 잠근 합성10사례의 실제 본문/영수증 재생, 손상6변형 거부, AI 원판정60개의 답/누락 분포, 정밀도8판정 투영값의 산술을 확인한다. 두 번째는 독립 합성 스모크10변형을 확인한다. 반복 실행을 새로운 사건으로 세지 않는다.

`portable`은 동결 소스 파일을 보존하고 실행 메모리에서 고정 의존 경로 한 줄만 바꾼다. pinned v10 wrapper/vendor는 바이트 그대로 포함한다. 원래와 실행 코드의 해시 및 치환은 loader provenance에 남는다. 이 명시적 이식성 조정 없이 원 코드가 어디서나 실행된다고 주장하지 않는다. 자세한 범위는 `portable/README.md`를 참고한다.

## 포함한 자료

- `synthetic`: 하나의 가상 도서관 소재10상태/언어 변형, 원키, 실제 native 메모10개, 결정적 코드 메모10개, 조건 가린 packet30개와 원판정60개. 설계자가 쓴 제안 메모는 native 출력이 아니다.
- `protocol`: 원 설계·동결시각·입력 해시·질문 기준. 원키는 gold가 아니며 no/unknown 지칭 결함을 그대로 보존했다.
- `confirmation`: 실제 재생 결과, 파괴 주입 결과, 버전 변경 후 동일성 회귀 검사. 확인 자료를 본 뒤 수정한 버전은 새 holdout이라 부르지 않는다.
- `precision`: 노출 실제기사 한 건의4출력·8판정에 대한 공개 투영값과 해시, 짧은 추가 구절, 결과 설명. 원기사·긴 감사 인용을 포함한 raw는 여기서 제외했다.
- `v10-context/protection`: 앞선 짧은 보호표·원문 위치·접근 기록. 표는 선별 자료이며 정답 목록이 아니다. EN023의 `conflict` 표지는 당시 후보 표지이며 입증된 모순으로 읽지 않는다. v11 본문에 별도 해석 정정이 있다.
- `frozen-versions`, `code-audit`: 첫 버전과 크기·중첩·인코딩 후속 수정, 각각 실패/독립검사 기록. 일부 역사적 실행 경로는 원 환경을 가리킨다. 일반 재생은 `portable`을 사용한다. 원 동결 manifest는 전체 작업환경을 가리키며 공유본은 전문 자료를 제외한 일부 파일이다. 공유본 전체의 무결성은 패키지 `SHA256SUMS`로 확인한다.

## 제공하지 않는 보증

실기사 전문과 후보 전체를 재배포하지 않는다. `natural-private-records.json`은 비공개 raw의 해시·경로 목록이지 그 내용을 재현하는 자료가 아니다. 자연어 전체 재감사에는 원문을 다시 확보하고 범위/버전 차이를 기록해야 한다. `precision/public-projection.json`만으로 원판정을 다시 심사할 수는 없다.

독립 문맥은 인간 검증이나 다른 모델 계열 검증이 아니다. 정확한 모델 배포 버전·seed·비용은 제공되지 않아 native 출력을 똑같이 재생성할 수 없다. 코드시험 통과는 의미목록 완전성·사실 진실·질문 해결·기사 전체 정확성의 증거가 아니다.

## 마지막 미해결 보조표 회귀

`sidecar/summary.json`은 노출4사례·2조건·2독자의16판정을 보존한다. `synthetic/sidecar-*`에 원입력·코드 산출물·원판정이 있다. 미해결 항목4개는 사전에 알려진 문제이며 새 누락탐지 성과가 아니다. `sidecar`는 `portable`과 나란히 놓아야 한다.

보조표 입력에는 원래 영수증 파일의 절대 경로도 결박돼 있어 다른 환경에서 그대로 실행되지 않는다. 아래 기본 검사는 원판정16개와 원파일 해시를 재계산한다. 코드 자체의 이식성은 독립 감사의 임시 파일 시험으로 확인했으며, 원 위치를 새로 만들거나 다른 세션 경로에 쓰지 않는다. 새 위치에서 보조표를 실행하려면 새 파일 경로로 입력 버전을 만들고 변경된 입력 해시를 기록해야 한다. 이를 원래 입력 바이트의 재실행이라고 부르지 않는다.

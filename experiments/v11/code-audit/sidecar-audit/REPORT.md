# 미해결 보조표 독립 코드검사 기록 요약

이 문서는 독립 감사자가 남긴 `checks.py`, `results.json`, `independent-tests.txt`, `native-tests.txt`를 최종 편집자가 읽어 정리한 것이다. 환경 재연결 당시 감사자 본인의 설명 보고서는 없었다. 따라서 이 문서 작성이 새로운 독립 검토 또는 추가 시험을 뜻하지 않는다. 원 로그·원 코드·원 결과는 변경하지 않았다.

독립 검사6개는 모두 통과했고 개발 시험8개도 별도 로그에서 통과했다. 반복·하위 변형을 고유 시험 또는 사건으로 합산하지 않는다.

1. 실제 본문 변경, 후보를 최종 본문으로 대체, 해시까지 다시 만든 위조 상위 영수증을 거부했다.
2. 변경된 근거·UTF-8 구간·자료형 등10변형을 거부했다.
3. 빈 목록이 모두 해결을 뜻하지 않는다고 표시했고, 인용된 주장을 독립 검증된 사실로 바꾸지 않았다. 원문·본문·영수증·포함 파일이 바뀌지 않았고 렌더링 문구 변조는 거부했다.
4. EN400단어와KO1600문자는 허용,401단어와1601문자는 거부했다. 일부 항목 삭제로 한도를 맞추지 않았다.
5. 구간·항목·근거 수 제한, 변경된 유효 입력과 예전 보조표의 불일치, 포함 파일 변경을 거부했다.
6. `sidecar`와`portable`을 나란히 옮기고 기존 경로 접근을 막은 상태에서 실행됐다.

독립6시험 실행 로그는0.141초, 개발8시험 로그는0.049초를 기록했다. 이는 해당 로컬 시험 로그의 경과값일 뿐 전체 연구시간·모델 호출시간·비용 측정이 아니다. 이 코드검사는 입력·출력 무결성을 다루며, 공급된 문제 목록의 완전성·문제의 진실·독자 이해를 검증하지 않는다. 별도 독자16판정과 합쳐 단일 성공률을 만들지 않는다.

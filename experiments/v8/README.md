# v8: 한국어·영어 실제기사의 전체교체와 국소수정

한국어 30·영어 30기사에서 개발 12 / 평가 48 실험을 실제 실행한 기록의 공개 파생본입니다. **국소수정의 일반 우월성이나 정치적 편향 감소를 입증하지 못했습니다.** 의미 판정은 AI만 수행했으며 사람의 정답 평가가 아닙니다. 정확한 배포 모델·seed·추론 노력·토큰·비용은 확인되지 않았습니다.

평가 언어별 기사 수는 각 24입니다. 필요 여부 자체가 불확실한 항목은 KO 26·EN 36으로 위 필요수정 분모와 분리했습니다. 불필요수정 항목의 변경이 모두 유해한 변경이라는 뜻은 아닙니다. EN 전체교체의 누락 1건은 중대, 왜곡 1건은 경미 판정입니다. 국소수정의 불확실을 무오류로 바꾸지 않습니다.

원문과 바이트가 다른 출력은 전체교체 18/48·국소수정 15/48이며, 국소수정 1건은 제안 전체가 원문으로 복원됐습니다. 무변경이나 복원은 오류수정 성공이 아닙니다. 전체교체도 수정 근거가 없으면 원문 그대로 반환할 수 있는 조건이었습니다.

## 개발과 실행 차이

각 언어의 개발 6기사에는 편집 전 검토 후 필요수정으로 합의된 항목이 없었습니다. 고정 기준의 불필요수정 항목은 KO 9·EN 9, 필요 여부 불확실은 KO 9·EN 6입니다. 추가 수정의 우월성을 식별할 수 없어 기본 국소수정 `whole_base`를 유지했으며, 개발에서 입증된 승자를 선택한 것이 아닙니다.

개발 앞 8기사는 조직 방식(`organization`)·관계 확인(`relations`), 뒤 4기사는 확인(`confirmation`) 단계입니다. 앞 8기사의 24 후보 감사에는 별도 게시일·저자 메타데이터가 빠졌습니다. 원문 텍스트는 제공됐지만 사건/보도 시점 해석을 방해할 수 있는 구현 오류였습니다. 뒤 4기사와 평가에는 양 편집군 공통으로 보완한 v2 봉투를 적용했습니다. 기존 판정은 보존했습니다. 공개 집계는 언어·단계·조건별로 분리하며 개발의 서로 다른 조건을 같은 분모로 합치지 않습니다.

전체교체와 국소수정 모두 별도 후보 감사를 받지만, 전체교체는 진단용이고 국소수정은 승인/보류에 따른 원문 복원을 적용합니다. 따라서 파이프라인 비교이며 편집 범위만의 효과나 동일 실제 비용을 분리한 시험이 아닙니다. 초기 일부 결과평가 문맥에는 서로 다른 기사·조건이 함께 배치됐고 이후에는 같은 조건별 배치를 썼습니다. 같은 기사의 대안 출력을 같은 평가 문맥에 제공하지 않았지만 배치 차이의 효과는 측정하지 않았습니다.

생성 응답은 DEV 32·EVAL 96, 고유 결과평가는 DEV 20·EVAL 81, 조건별 관측은 DEV 44·EVAL 144입니다. 같은 기사 안에서 동일 출력은 한 번 평가한 뒤 조건에 재사용했습니다. 관측 수를 독립 표본 수로 해석하지 않습니다. 평가 누락과 미배정 판정은 0이며 구조 검사 통과가 의미적 정확성을 보장하지는 않습니다. 전체 정확한 문맥 호출 수는 복원하지 못했습니다.

## 실패와 정정 사례

- **KO010:** 비교기간의 분모 복원은 성공 사례입니다. 일반화 근거는 아닙니다.
- **KO009:** 고정 필요수정 항목은 연도 표기의 문자 결함이며 두 편집군 모두 실패했습니다. 역사적 날짜나 정치적 편향의 오류와 구분합니다.
- **KO011:** 국소수정의 단위 정정은 감사에서 승인됐으나 원문에 남은 다른 산술 모순 때문에 전체가 복원됐습니다. 최종 원문/국소수정은 필요수정 2건 모두 실패, 전체교체는 1성공·1실패였습니다. 기존 오류와 새 오류를 복원 규칙이 분리하지 못한 비용입니다. 평가 후 규칙을 소급 변경하지 않았습니다.
- **EN023:** 전체교체는 공식 숫자로 고치면서 귀속된 인물의 기존 발언을 없애 중대 누락 1·경미 왜곡 1·필요수정 실패 판정을 받았습니다. 국소수정도 바꾼 숫자의 발언 근거가 불확실했습니다. 작은 숫자 수정도 발언 관계를 바꿀 수 있으며 두 방식 모두 이 문제의 성공으로 세지 않습니다.
- **KO015·KO021 (DEV):** 비판 문구 소실이나 의향·추세 표현의 범위 축소가 누락/불확실로 남았습니다. 근거보정과 비판 삭제를 충분히 구분하지 못했습니다.

보호목록에도 연도/날짜 절단, 발언 대상 혼동, 시도를 성공으로 기록한 오류가 있었습니다. 편집 전 필드 정정과 누락은 [기준 회계](data/reference-accounting.json)에 남겼습니다. 개발 결과평가 후에는 KO031의 위치 5개·KO016의 위치 7개를 정정하고, EN007·EN001의 새 발견 주장 각 1개를 고정 분모 밖 보충 비고로 옮겼습니다. [정정 기록](data/dev-errata.json)은 원판정 해시와 건수를 보존하며 의미 판정은 바꾸지 않았습니다.

합성 4최소쌍(8입력)은 별도 실행입니다. 네 결함의 필요수정은 두 방식 모두 성공했지만, 정상으로 지정한 KO 2입력은 모두 바뀌고 EN 2입력은 유지됐습니다. KO 대조의 원래 적절성이 독립적으로 확립되지 않아 변경률을 그대로 유해한 과잉수정률로 부르지 않습니다. [합성 집계](data/synthetic-summary.json)는 실제기사 결과와 합산하지 않습니다.

## 표본·근거·계보의 한계

한국어 매체는 프레시안 7·동아일보 8·동아사이언스 7·뉴시스 8, 영어는 Guardian 19·AP 10·Al Jazeera 1입니다. 접근 시도는 KO 73·EN 33회이며 무작위 표본이 아닙니다. AI 이용 금지 고지가 확인된 초기 KO 8후보는 편집 실험에서 제외했지만 초기 접근 자체가 없었던 것은 아닙니다. [접근 기록](data/acquisition-attempts.json)은 실패·제외 사유를 함께 남깁니다.

사건에 맞춘 외부 근거가 확보된 기사는 12/60이고 나머지 48기사는 독립 사실검증 근거가 부족합니다. 출력의 `supported`는 제공한 원문·근거 범위의 지지(발언 귀속 포함)이며 독립적인 외부 사실검증과 다릅니다. 언어별 매체·길이·장르가 다르므로 언어 자체의 효과를 주장하지 않습니다. 알려진 사건 묶음은 58개이나 독립성은 보장되지 않습니다. v5 전체 이력이 없어 과거 전체 실험에서 미사용이었는지도 미확인입니다. v7의 영문 합성 시험에서 실제기사 양언어 시험으로 확장했으나 보호목록의 완전성과 판단 재현성은 미해결입니다.

## 공개 자료와 검사

[기사별 DEV](data/dev-per-case.json)·[기사별 EVAL](data/eval-per-case.json)은 실제 결과에서 식별용 불투명 값과 판단 본문을 빼고 수치만 선별했습니다. 원문 URL·수집일(기록된 경우)·해시는 [출처 목록](data/source-manifest.json)에 있습니다. 수집일은 게시일이 아닙니다. 원본 집계 해시는 [계보](data/provenance.json)에 있습니다. 원본 전체는 이 공개 저장소에 없습니다.

Python 3.11 이상 표준 라이브러리만 사용합니다. v8 디렉터리에서:

```sh
python tools/reaggregate.py
python -m unittest discover -s tools -p 'test_*.py' -v
```

코드는 `patch_guard`, `pilot_harness`, `run_artifacts`, `run_artifacts_v2`, `freeze_reference`의 기계적 무결성·집계·복원 검사를 제공합니다. 원본 모듈은 그대로 보존했으며 입력/출력 경로는 호출자가 명시합니다. 익명화 도우미는 임의 ID와 순서를 생성하지만 patch·hash·집계 검사는 고정 입력에 결정적입니다. 합성 테스트 입력은 기사 성능의 증거가 아닙니다. v2 감사 봉투도 공개하므로 버전 차이를 확인할 수 있습니다.

원문 전문·전체 수정문·전체 근거·판정 전문·내부 지시문·모델 실행 자동화·비공개 입력에 의존하는 준비/집계 도우미는 제외했습니다. 공개 수치의 산술을 재검산할 수 있지만 최초 모델 실행이나 의미적 판정을 완전 재현할 수는 없습니다. 기존 `patch_engine`·`score_T`는 이 실행 경로에 없고 수정하지 않았습니다. 과거 버그 영향이 없다는 증명도 아닙니다. 라이선스는 선택하지 않았으며 저장소 [권리 고지](../../NOTICE.md)를 따릅니다.

# v19 실제 실행 결과

이번 회차는 실제 새 기사 4건(개발 2·평가 2), 기존 노출 기사에 근거를 늘린 회귀 1건이다. 각 원문 전체를 새 문맥에 주어 실제 수정문 5개를 생성했다. 각각 출력 전 기준 작성과 단계별 독립 AI 감사를 분리했다. 임의 길이 상한이나 심은 오류는 없다. 합성 최소쌍 2출력과 선택 롤백 후보는 아래 별도 실험이며 기사 수에 합치지 않는다. 정확한 배포 버전·시드·비용은 통제하지 못했다.

평가 2기사의 동결 필수 항목은 1개뿐이다. 1/1 전달을 기사 전체 정확도나 과잉수정 없음으로 해석하면 안 된다. 필수 수정이 확립되지 않은 평가 기사 1건에서는 원문 유지 0/1, 불필요 패치 1건이었다. 원래 의미 손실은 이번 5출력 감사에서 확립되지 않았으나, 인간 검증이나 완전성 증명이 아니다. 기계 전달은 5/5이며 별도 strict 식별자 검사에서도 같은 결과다. 과거 v18 원평가 3/5는 그대로 보존했다.

원문 링크·자료 버전·실제 확보 범위는 [자료 접근 기록](source-access.md), 전체 입력·출력·독립 단계의 해시는 [기록 해시](raw-hashes.json)에 있다. 기사 전문과 실제 전체 수정문은 공개 패키지에 싣지 않는다. 비공개 원출력은 수정 없이 보존한다. 위 표는 원자료 위치와 수정 관계의 자체 분석이며 보호목록 전수 인증이 아니다.

## 확인된 개선과 여전히 남는 판정 차이

인용 계보를 실제로 따라간 결과, 별도 호흡기 인체 연구가 있다고 전제할 근거가 없었다. 연결된 초록과 중간 기사 전체를 추가하자 질병 단정의 국소 수정을 검증할 수 있었다. 이는 자료 범위 확장의 결과이며 같은 입력으로 편집법만 비교한 실험이 아니다. v18 보류를 오답으로 소급하지 않는다. 어디에도 호흡기 연구가 없다는 주장도 아니다.

반면 영어 빨대 기사에서 “두 회차 시험”이 모든 브랜드에 같은 두 분석을 했다는 뜻인지, 이미 ‘가능성·일부·연구자 귀속’이 있는 코팅 추론에 대안 기원을 반드시 붙여야 하는지는 같은 근거를 읽은 기준 작성과 독립 감사가 갈렸다. K183의 고분자 범주와 장벽 표현도 사실 자료에는 대체로 동의하면서 필수성에서 갈렸다. 추가 4항목을 확정 성공으로 합산하지 않는다. 모두 원분모 밖이며, 엄격한 원기준의 관점에서는 정확하지만 선택적인 설명일 수 있다.

정량한계 조건도 해결됐다고 일반화하지 않는다. v18 후속 감사는 17/22에 정량한계 표기를 필요하다고 보류했지만 이번 EXK183 기준과 감사는 이를 필수 수정으로 잡지 않았다. 원기준·판단을 모두 보존하고 어느 한 판정을 새 정답으로 승격하지 않는다. 명시적으로 틀린 한계 명제는 별도 합성 최소쌍으로 검사한다.

## 비용·시간·통제

주 기사 작성 5회에 실제 전달한 파일 텍스트는 합계 255,209 Unicode 문자, 실제 JSON 출력은 64,071문자다. 이는 토큰이나 요금이 아니며 숨은 시스템 지시·수집·기준 작성·감사 입력은 제외한다. 생성 간 벽시계 관측은 별도 측정 파일에 기록한다. 대기·조정 시간과 모델 실행시간을 분리하지 못하므로 모델 속도로 보고하지 않는다. 추가 API·유료 인증·인간 참가자는 없다. 새 문맥 분리는 지원 도구와 지시 기반이며 파일 수준 차단은 아니다. 동일 상속 runtime을 사용했지만 정확한 배포 모델·seed·비용을 통제했다고 주장하지 않는다.

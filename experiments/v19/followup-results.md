# 별도 후속 검증: 국소 롤백과 합성 최소쌍

## KO192의 불필요 추가 철회

원출력은 필수 수정이 확립되지 않은 기사에 검사 대상의 상세 범위를 덧붙였다. 원기준과 단계별 감사는 이를 정확하지만 불필요한 설명으로 판단했다. P1만 제거해 원문과 같은 608자 후보를 결정적으로 구성했다. **새 모델 작성 출력이 아니다.** 원출력·원판정은 그대로 보존한다.

다른 새 문맥의 검토자는 원문·원자료를 먼저 읽고 PRE를 저장한 뒤 실제 전체 후보를 확인했다. 확립된 필수 수정·중대 누락·새 손실 없이 국소 수용했다. 당시 판본과 같은지 모르는 후일 수정 원자료의 한계도 유지했다. 이는 해당 사례의 과잉수정을 고친 국소 회귀 결과이며 일반적인 불필요 수정 자동 제거법의 완성 증거가 아니다.

## 명시적 검출/정량 구분 한 요소 시험

자연 기사와 분리한 가상 기록을 만들었다. 22명 중 17명은 정량한계 초과, 나머지 중 4명은 검출한계 이상·정량한계 미만, 1명은 검출한계 미만이다. 원문 두 개의 차이는 마지막 5명을 ‘정량한계 미만’ 또는 ‘검출한계 미만’이라고 부르는 부분뿐이다. 사건·근거·나머지 문장·작성 지시는 같다. 기대 판정과 해시는 작성 전에 동결하고 작성자에게 주지 않았다.

| 입력 | 실제 새 문맥 출력 | 별도 원문 우선 감사 |
| --- | --- | --- |
| SY191 정상: 5명 정량한계 미만 | 177자 그대로, 0패치 | 필수 수정·과잉수정·손실 없음 |
| SY192 오류: 5명 모두 검출한계 미만 | 해당 문장 1패치. 4명과 1명의 상태를 정확히 구분한 209자 전체문 | 필수 오류 1/1 복원. 패치 밖 보존, 과잉수정·손실 없음 |

합성 자료의 ‘정답’은 구성한 명제의 논리적 일치에 한정된다. 실제 기사의 모든 함축·중요성 기준을 대신하지 않는다. 짧은 명시 오류를 구별한 결과가 EXK183의 모호한 검출 표현에 관한 필수성 이견을 해결한 것도 아니다. 길이 증가를 숨기거나 강제 압축하지 않았다. 두 입력은 한 최소쌍이며 독립된 실제 사건 2건이 아니다.

입력·실제 출력·독립 PRE와 감사·사전 기준은 [synthetic](synthetic/README.md)에 공개했다. `python experiments/v19/synthetic/replay.py`는 저장 출력을 재생하며 새 모델을 호출하지 않는다. 실제 원문 기사 후속 후보는 전문 공개 대신 해시와 위 자체 분석을 제공한다.

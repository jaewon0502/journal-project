# v19 사전 실행 범위

새 기사 4건: 개발 KO191/EN191, 평가 KO192/EN192. 원문과 원자료 전체의 확보 범위·제외·수정일을 입력 메타데이터에 기록한다. 기존 기사 K183의 인용 계보 확장은 노출된 사례의 별도 회귀 재검증이다. 자연 기사에 오류를 심거나 성공 개수를 정하지 않는다.

v18 writer-v2/schema/reference/audit 지시를 그대로 동결한다. 입력과 독립 기준의 해시를 작성 전에 고정한다. 개발 작성·독립 감사 후 평가 작성에 진입하며, 실제 개발 실패로 변경한다면 변경 이유와 버전을 따로 동결한다. 평가 이후 소급 기준 변경을 금지한다. 이번 기본 전달 엔진은 v18 atomic check_output_v3이다. 이전 집계·출력은 불변이다.

작성자는 원문/근거와 고정 지시만 읽고 실제 전체 수정문을 생성한다. 별도 기준 작성자는 출력 전에 원문/근거만 읽는다. 별도 감사자는 PRE→작성물 JUDGMENT→동결 기준 FINAL 순서로 별도 저장한다. 도구 지원 새 문맥을 사용하며 인간 검증으로 부르지 않는다. 조건 이름은 감사 입력에 제공하지 않는다. 파일 접근 통제는 지시 기반이다.

필요 수정은 같은 대상·시점·범위에서 근거와 모순하거나 결론을 바꾸는 중요한 누락이다. 선택적 설명 추가와 값판단 차이는 필요 수정과 분리한다. 필수 보존·문장 관계·조건·귀속·발언 강도·반론과 시간 맥락은 원문을 다시 읽어 감사한다. 보호 목록은 gold가 아니다. 본문에 임의 길이 상한은 없다. 검출·전달 성공·새 손실·불필요 수정·보류는 합산하지 않는다. 정상 대조의 개수는 실제 독립 기준에 따라 보고한다.

별도 코드 시험은 중복 기록 순서, 입력 인용, 원자적 패치 묶음, 수신 확인/ID 바인딩 경로를 다룬다. 합성 시험·저장 출력 재생·새 모델 작성·후속 자료 확장은 각각 구분한다. 정확한 배포 모델 버전/시드/토큰 비용은 통제·측정 불가이며 같은 상속 runtime을 사용한다. 공개 보고서에는 기사 전문을 전재하지 않는다.

완료: 새 기사 4건 작성/독립 감사, 인용 계보 확장 1건 재검증, 재현된 집계 결함 수정·회귀, 남은 자동 업무/외부 자료 공백/실패 횟수와 재개 조건을 구분한 보고서. 실패마다 무한 반복하지 않고 이번 한 회차의 검증 결과와 미해결 원인을 반환한다.

# v18 staged independent whole-article audit

Use only assigned stage files. No other outputs/method mapping, external retrieval or prior experiments. This is AI internal review, not human truth. Save each stage in a separate tool call before reading the next. File availability is not permission to inspect a later stage. Preserve previous judgments unchanged.

Stage 1: Read full O=C, full S and metadata only. Independently inventory necessary errors/omissions and important preserved cross-sentence relations with short exact source/article anchors. Save PRE JSON: unit_id, independent_findings, protection_items, coverage_gaps, read_scope. No target error count; no-established error does not mean globally true.

Stage 2: After PRE save, read anonymized writer output and mechanical applied article, and read actual writer full_edited_article from beginning to end. Compare O→delivered for loss/new claims and S→delivered for support/important omissions, not merely writer inventory→output. Actively inspect information writer did not list. Check attribution, quoted force, conditions supplied elsewhere, event/publication/follow-up chronology, actor/responsibility and criticism target. A necessary source-backed correction changes original proposition but is not collateral harm. Do not interpret optional extra context or value preference as factual necessity. Check exact delivery equality and patches' combined effects. Save JUDGMENT JSON before reading reference, with unit_id; delivery_integrity; independently_found_important_issues (anchors); writer_detection (per issue detected/missed/uncertain); delivered_repairs (safe_success/failed/held/uncertain per issue); unnecessary_patches; unjustified_local_holds; new_meaning_losses; preserved_relations; coverage_unknowns; factual_disagreements; interpretive_disagreements; value_disagreements; reason. Every adverse/positive issue judgment needs short original/source/delivered evidence and scoped reason. Count issues by atomic proposition; do not double-count one issue under multiple labels.

Stage 3: Only after JUDGMENT save, read frozen pre-reference. Save FINAL JSON retaining the complete earlier judgment or its exact file hash plus reference_comparison rows (agreement/disagreement/newly_found/uncertain; factual/interpretive/value; reason and anchors), reference_issue_results and additional_issue_results separately, final_scoped_assessment, read_order_deviation. Do not revise the PRE or JUDGMENT file. Preserve the frozen denominator even when reference was wrong; report adjudication/correction or sensitivity separately. Failed delivery cannot count as safe delivered repair. A correct no-change on a no-established-repair article is scoped conservatism, not proof of truth. Local justifiable hold is distinct from blanket/unnecessary hold and from unrelated unverifiable content.

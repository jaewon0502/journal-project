# v19 결론: 국소 수리는 검증됐고, 필요성 경계와 목록 완전성은 미해결

세 문제를 나눠 병렬 조사한 뒤 이번 회차에는 새 기사 4건, 자료를 확장한 기존 기사 1건, 한 요소 합성 최소쌍 2출력을 실행했다. 실제 새 문맥 작성은 총 7출력이다. 이전 74출력이나 후속 회차를 새로 생성했다고 세지 않는다. 별도 기준과 작성·감사를 분리했으며 인간 참가자는 없다.

| 문제 | 이번에 확인한 해결/부분해결 | 아직 못 푼 부분 |
| --- | --- | --- |
| 보존정보 목록 불완전 | 원문 전체와 근거를 별도로 읽고, 문장 간 수치·대상·시점·귀속을 정확한 구간으로 연결. 새 영어 사례에서 기준·PRE가 놓친 조직 명칭 오류를 작성 후 검사로 잡음 | 독립 기준과 보호목록도 실제로 누락했다. 전체 의미 목록의 완전성을 보장할 방법은 검증되지 않음 |
| 필요한 문장만 수정 | 새 기사 3건의 동결 필수 항목 각 1개를 국소 수정. 원문 밖 변경 방지와 제목·본문 동시 적용, 불필요 패치 1건의 철회 후 재감사 확인 | 정상 기사에 정확하지만 필요 없는 문구를 추가한 실패 1건. 추가 설명의 필요성 이견도 남음. 소표본에서 새 손실을 못 찾은 것이 일반 무손실 증명은 아님 |
| 평가 AI 판정 불일치 | 원점수와 추가 발견·해석 이견을 분리. 중복 ID 순서만으로 성공값이 뒤집히는 집계 결함을 고치고 회귀검사 통과 | 같은 근거를 읽어도 필수 수정/선택 설명 경계가 달랐다. 다수결이나 점수 완화로 해결하지 않음 |

새 평가 2기사에서 필수 기준 항목은 총 1개였고 안전하게 수정했다. 그러나 다른 정상 대조 기사에는 불필요 수정 1개가 있었다. 이 실패를 지우지 않은 채 해당 패치만 철회한 후보를 새 독립 감사로 확인했다. 합성 최소쌍은 정상 보존 1/1, 명시 오류 수정 1/1이었지만 실제 기사의 모호한 의미·중요성 문제와는 다르다.

지금 적용할 짧은 절차는 다음과 같다.

1. 원문에서 **주장과 조건·반론·주체·시점을 함께** 짧은 구간으로 표시한다.
2. 같은 대상·시점의 근거가 왜 수정을 요구하는지 설명할 수 있는 절만 고친다.
3. 모든 패치와 실제 전체 완성문이 일치하고, 패치 밖 문자가 그대로인지 검사한다.
4. 다른 검토자가 원문 전체를 다시 읽어 목록 밖 누락과 새 손실을 찾는다.
5. 필요성이 불명확한 추가는 보류하고, 새 손실이 생긴 패치만 철회해 전체 후보를 다시 본다.

근거가 없거나 필요성에 이견이 남으면 그 수정에서 멈춘다. 필수 상대 패치·전체 입력·완성문·올바른 수신 확인이 없으면 전달을 완료로 처리하지 않는다. 보호해야 할 정보를 길이 제한에 맞춰 몰래 삭제하지 않는다. 목록을 계속 늘린 뒤 같은 사례를 다시 통과시키는 것을 일반 해법 검증으로 부르지 않는다.

문헌 원문 공백은 일부 세포 구조의 구체 용어·실험 구간에 한정된다. 인용 계보를 더 따라가 해결한 질병 단정과 구분한다. 전체 작업이 외부 자료 때문에 막혔다고 결론내리지 않는다. 이 회차의 자동 실행은 마쳤으며, 남은 필요성 이견과 완전성은 결과와 함께 돌려준다. 다음 회차는 새로운 입력이나 사전 고정한 편집 목적이 있을 때 시작하는 것이 타당하다.

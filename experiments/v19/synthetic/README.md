# v19 합성 최소쌍

실제 기사 결과와 별개다. 자연 기사 작성 후 발견된 정량/검출 필요성 판정의 모호함을, 명시적 문장 하나만 바꾼 두 가상 입력으로 좁혀 검사한다. 오류 입력은 나머지 5명 모두 검출한계 미만이라고 단정하지만 기록은 4명이 검출한계 이상이라고 명시한다. 정상 입력은 정량한계 미만이라고만 말한다. 나머지 원문과 원자료는 동일하다.

실행 전에 위 기대·분모와 입력 해시를 동결했다. 작성자는 조건·기대 없이 동일 writer-v2/schema와 자기 입력만 읽는다. 실제 새 문맥 출력과 별도 감사로 정상 보존/필수 수정/부수 손실/과잉수정을 나눈다. 일반화나 두 독립 사건 성능으로 보고하지 않는다.

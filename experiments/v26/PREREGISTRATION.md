# v26 통합 회귀 감사 — 실행 전 고정

v15–v25 기록에서 구체 실패와 기준/실행 문제를 구분한다. 일반적 완전성 불보증 자체를 재현 실패로 세지 않는다. 과거 원출력/점수는 보존한다. 모든 역사 사례는 개발 노출이며 새 holdout이 아니다.

현행 최소 절차는 v22–v25에서 공통으로 유지한 전체 원문·근거 읽기, 절별 지지/필요성 분리, 대상 일치, 최소패치, 국소 미확인 주석이다. 이번 공통 policy.txt는 그 지시를 같은 스키마로 통합한 적용판이다. 기존의 특정 버전과 바이트 동일하지 않으며 새 접근 가족으로 세지 않는다. 사례별 질문·보호표·수리문은 작성자에게 주지 않는다. 기사 전체에 적용하기 위해 기존 소규모 문항 분량 상한은 제거한다. 따라서 과거 점수와의 변화는 정책 단일요소 인과효과가 아니다.

재사용: 기존 코드 회귀·자율 출력·수작업 파생본을 구별해 저장 결과로 확인 가능한 범위는 재검사만 한다. 질문/사전장부/편집범위가 다른 과거 결과를 이 공통 절차의 자율 성공으로 치환하지 않는다. 새로 필요한 8개 원기사 입력에 동일 정책을 각각 독립 문맥으로 한 번 적용한다. U202는 확보된 기존 S2 발췌만 제공하며 후속 법문 전체 확인을 주장하지 않는다. 다른 자료도 저장 판본 그대로 사용하며 이번에 새 웹 접근을 했다고 하지 않는다.

판정축: 필수정정 누락, 불필요 수정, 새로운 의미 손실, 근거 부족을 해결하지 않은 단정, 실행 오류를 분리한다. 사실성·정정 필요성·출판승인 범위를 구분한다. 원자료 부족은 거짓이나 실패 없음이 아니다. 정당한 귀속/논쟁/반론을 없애면 실패다. 공개 근거 없이 판단이 갈리는 필요성은 이견/보류로 남긴다. 종합 성공점수나 사후 임계값을 만들지 않는다.

별도 감사자는 원문과 같은 자료로 사전 기준을 저장한 뒤 출력과 최소 차이를 감사한다. 작성자에게 과거 실패/평가/정답은 주지 않는다. 원출력과 검사 파일을 보존한다. 새 구체 실패가 남으면 최우선 1개만 기존 방법 계보/문헌에서 유효한 가설을 골라 작은 대조를 실행한다. 미사용 자료를 무한 증식하지 않는다. 기계검사 288개는 의미 정확도 분모에 넣지 않는다.

모델 설정 override 없음. 정확한 모델 배포버전·seed·금액 미통제. 별도 문맥 AI 내부 실행이며 독립 모델·인간 평가가 아니다.

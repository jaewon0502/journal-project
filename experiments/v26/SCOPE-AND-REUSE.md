# 통합 범위와 재사용 판단

v15–v25의 저장 기록에서 30개 증상/계약 행을 수집했다. 이는 독립 실패 30건이 아니다. EN191의 피부/점막 문제는 v19–v21에서 되풀이된 같은 사건이며 중복 표지를 남겼다. 한 패치가 불필요 수정·새 손실·근거 오판에 동시에 해당할 수 있다. 실패 행 수·기사 수·패치 수·AI 호출 수는 합산하지 않는다.

공통 실행에 쓸 수 있는 과거 출력을 먼저 확인했다. v25는 사전 선택한 수치 주장만 수정했고, v21 선택 실험은 이미 주어진 패치를 골랐으며, v23 최종 복원은 사례를 본 뒤 만든 파생문이었다. 모두 해당 범위의 증거로 보존하지만 **이번 원기사 전체의 자율 생성 결과로 재사용할 수는 없다.** 따라서 접근 가능한 여덟 원기사만 새로 한 번씩 생성했다. 수작업 수리문·기존 질문·보호목록·평가 결과는 작성 입력에서 제외했다.

이번 통합 policy.txt는 기존 공통 원칙을 한 스키마로 옮긴 적용판이다. 원문과 자료를 모두 읽되 질문에 국한하지 않았고, 작은 실험의 분석 분량 상한을 없앴다. 특정 과거 버전과 바이트 동일한 실행이 아니다. 그러므로 과거 결과 대비 악화를 한 요소의 인과효과로 해석할 수 없다. 이 통합판에서 재현된 구체 실패는 실제 결과로 남긴다.

| 재사용 항목 | 실제로 확인할 수 있는 범위 | 확인하지 못하는 것 |
|---|---|---|
| v15·v19·v24 코드 반례/수리와 v25에서 실행한 288 테스트 | 같은 코드 스냅샷의 알려진 계약·적용·집계 반례 처리 | 의미 정확도, 보존목록 완전성 |
| v16 충돌 대조의 수정 후 저장 출력 | 명시적 보류 정책으로 막힌 합성 복구가 후속 정책에서 성공 | 새 공통 절차의 전체 기사 성능 |
| v17 출처 ID·v18 인용 필드/상호의존 수리 | 해당 구조적 거절의 원인과 저장된 국소 복구 | 모든 새 출력의 올바른 근거 연결 |
| v21·v22·v23·v25 자율 원출력 | 각 원조건에서 생성한 국소 성공/실패 | 다른 질문·자료·스키마의 통합 실행 성공 |
| 선택적 롤백·수작업 파생문 | 해당 최종문에서 지목한 손실 제거 여부 | 현재 절차가 스스로 그 결과를 생성하는지 |

v24의 잘못된 동일성 장부를 통과시키는 반례는 코드 구조상 현재도 의미 인증이 아니다. 그 실행 게이트는 이번 편집기에 사용하지 않았으므로 폐기한 경로의 실패와 현재 출력 실패를 구분한다. 이를 해결됐다고 지우지 않는다.

v15 E1·K15Q, v18 E183, v19 EN192의 일부 항목은 평가 단위/필수성 이견이며 확정된 사실 오류로 재분류하지 않았다. 이번에는 별도 자율 전수 재실행하지 않았으므로 ‘해소’로 세지 않는다. 구체적 독자 오해나 편집 목적이 필요한 항목은 외부 평가 요구로 남긴다. v16 U202는 원기사에서 다시 시작했다. 과거 잘못된 파생문 자체를 입력으로 재수리한 시험은 아니며, 기존 S2 발췌만으로 후속 법문 전체를 검증하지 않는다.

저장된 기사·원자료 판본을 재사용했다. 이번에 원문 URL 모두를 새로 재접근한 것은 아니다. 확보 범위가 전문인지 발췌인지, 게시/수정/수집일과 계보는 source-metadata.json에 보존했다. 현재 웹 접근 가능성을 과거 HTTP 기록으로 대신 주장하지 않는다. 새로 접근한 문헌은 RARR 원PDF이며 별도 수집 기록을 남겼다.

# 검사와 재현 한계

- 자율 생성 원출력 8개: 고유 before 앵커와 패치→전체 최종문 재생 8개 통과. 원자료 ID 미확인 사용 0개. 이는 실제 출처 문구가 주장을 지지한다는 의미 검사가 아니다.
- 고정 패치 선택 출력 2개와 결정론적 최종문 2개: 선택 ID·19개 후보 전수 대응·정확한 적용 결과 재생 통과.
- 입력·정책·원출력·PRE/POST·후속 정정의 SHA-256을 보존했다. 해시가 사실 진실을 보증하지는 않는다.
- v15–v25의 기존 Python 파일은 직전 v25 checkout과 동일함을 바이트 대조했다. 직전 실행에서 22개 unittest 묶음 총288개와 저장 결과 검사가 통과한 기록을 재사용했다. 변경하지 않은 검사를 성능 건수를 늘리기 위해 다시 실행하지 않았다.
- 공개 콘텐츠 검사에서 전문 기사·내부 Library 식별자·환경 절대경로 유출 발견 없음. 공개 투영은 패치 전체 문구를 합쳐 기사가 재현되는 것을 피하기 위해 위치·길이·해시 중심이다.
- 독립 문맥 AI 감사는 원자료 지지·필수성·보존을 별도로 검토했다. PRE가 틀린 사례와 후속 유도된 검사에서 철회한 승인도 보존했다. 조건가림 감사와 사후 지목 재검사를 혼동하지 않는다.

원문 재접근은 이번에 전수 실행하지 않았다. 기사 자료는 저장 판본과 그 접근 범위를 사용했다. 새로 확인한 RARR 원PDF만 새 수집 기록에 있다. 새 API 인증·계정·유료 실행·푸시·배포·외부 연락은 하지 않았다.
- 최종 별도 문맥 보고서 검토: 실질 blocker 없음. 공개 투영의 ‘인용 제거’ 표기는 짧은 근거 인용이 남아 있음을 정확하게 수정했다. 수치·PRE 정정·P19 승인 철회가 실제 기록과 일치함을 확인했다.
- HTML 표시 검사: 320·390·768·1440px에서 문서 가로 넘침·깨진 내부 앵커·페이지 실행 오류 모두 0.

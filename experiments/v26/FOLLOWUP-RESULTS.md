# 최우선 잔여 실패의 작은 대조: 부분 개선, 전체 승인 불가

같은 원문·원자료·자율 생성 패치 19개를 고정했다. C는 기존 별도 선택, X는 각 패치에 대해 원문과 자료가 동시에 참일 수 있는지 명시적으로 검사했다. 실제 선택 출력은 2개다. 선택된 패치를 적용한 최종문 2개는 결정론적 파생문이며 추가 모델 작성으로 세지 않는다.

| 사전 지목한 쟁점 | C: 기존 선택 | X: 공존 반례 검사 | 근거 기반 판단 |
|---|---|---|---|
| P4 재배구역 면적을 시스템 치수로 대체 | apply | hold | X가 근거 없는 대상 동일시를 막음. 20㎡ 원문이 참이라는 인증은 아님 |
| P19 실측처럼 쓴 전력량을 추정치로 한정 | apply | apply | 이 부분의 정정은 필요하며 양쪽 유지 |
| 같은 P19의 ‘비슷한 크기’ 조건 삭제 | 삭제 | 삭제 | 자료는 이 조건이 거짓이거나 불필요하다고 입증하지 않음. 두 최종문 모두 남은 손실 |
| P16 온실효과를 인과 분리 불가로 재작성 | reject | reject | 관측했다는 것이 인과적으로 통제했다는 뜻은 아님. 원문의 account for 해석에 이견이 있어 필수 실패로 세지 않음 |
| P17 소규모 적용 가능성 문장 변경 | reject | reject | 바로 뒤 직접 인용이 조건을 보존한다는 선택 판단. 독립 PRE의 필요성 판정과 이견을 유지 |

총 선택: C apply 2/reject 3/hold 14, X apply 1/reject 17/hold 1. 이 분포를 성공률로 쓰지 않는다. reject에는 원문이 참이어서가 아니라 제안된 미확인 주석 삽입의 필요성이 입증되지 않았다는 결정도 있다. 모든 미확인 사유는 전체 선택 기록과 함께 봐야 한다. 파생문의 `source_gaps`는 hold만 요약하므로 전체 검증 공백 목록이 아니다. 본문만 따로 배포하면 검증 상태를 잃는다.

## 독립 검사와 정정 순서

별도 검토자의 PRE는 P4·P16·P19를 승인했다. 익명 최종문 POST에서 P4의 대상 혼동, P16의 관측/인과 통제 혼동을 인정하고 원 PRE를 남긴 채 정정했다. X가 원문 관계를 더 보존한다고 평가했지만 P19는 승인했다.

이후 P19를 ‘추정 상태 복원’과 ‘크기 조건 삭제’로 나누어 재대조하도록 명시적으로 질문했다. 이것은 **결과를 본 뒤의 유도된 후속 검사**이며 독립 조건가림 PRE가 아니다. 검토자는 면적당 정규화가 실제 시설 크기의 동일성을 입증하지 않는다고 확인하고 P19 전체의 무조건 승인을 철회했다. 원 PRE·POST·후속 정정을 덮어쓰지 않았다.

결과를 좋게 만들기 위해 P19를 연구자가 수작업으로 분해해 최종 성공문을 만들지 않았다. 두 실제 최종문은 그 상태로 보존하고 승인 불가로 남겼다. 확인된 이득은 **한 노출 사례에서 잘못된 면적 수정 억제**다. 올바른 수정과 정당화되지 않은 삭제가 묶인 패치의 부분 승인 문제는 해결하지 못했다. 추가 작업량·같은 모델 계열·반복 없는 1사건 대조이므로 일반 개선율이나 독립 접근 성공으로 해석하지 않는다.

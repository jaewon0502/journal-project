# 가상 예시로 확인하는 편집자 검증 시간

브라우저에서 [기본 예시 결과표](slow-pass.html)를 연다. 평소 도구로 100초씩 걸리던 네 사람이 저널을 쓰면 둘은 20초, 둘은 120초가 걸린다고 가정했다. 네 사람의 평균은 30초 줄어든다. 두 방식 모두 검증에 성공한 편집자의 시간은 누가 판단 이유까지 맞혔느냐에 따라 달라진다. [대조 예시 결과표](fast-pass.html)에서 같은 시간을 기록하고 이유 채점만 뒤바뀐 경우를 볼 수 있다.

| 가상 채점 기록 | 전체 4명의 평균 | 두 과제 모두 근거 위치·판정·이유가 맞은 2명의 평균 |
|---|---|---|
| 기본 예시. 저널에서 120초 쓴 두 사람이 이유까지 맞힘 | 100초 → 70초 | 100초 → 120초. 20초 증가 |
| 대조 예시. 저널에서 20초 쓴 두 사람이 이유까지 맞힘 | 100초 → 70초 | 100초 → 20초. 80초 단축 |

과제 A는 가상 도서관의 대출 증가율, B는 가상 자전거 대여소의 대여 감소율을 검증한다. 한 사람이 서로 다른 두 과제에 각각 평소 도구와 저널을 쓴다. A에 저널을 쓴 사람과 B에 저널을 쓴 사람이 각 2명이다. 기본·대조 예시 모두 과제마다 저널을 쓴 2명 중 1명이 이유까지 맞힌다. 모든 사람의 근거 위치와 판정은 맞고, 오답자는 비율 계산에 쓰는 분모를 잘못 골랐다. 가상 주소와 코드, 응답, 시간은 이 예시만을 위해 만들었다.

두 결과표는 미리 만든 HTML 파일이다. 열면 가상 기록으로 계산한 인원과 시간만 표시한다. 기본 예시에서 두 과제 모두 맞힌 사람은 `SYNTHETIC-02`, `SYNTHETIC-04`이고, 대조 예시에서는 `SYNTHETIC-01`, `SYNTHETIC-03`이다.

## 시간과 정답 수 검산

| 가상 응답 | 원자료 찾기 | 표 위치 찾기 | 판정 기록 | 합계 |
|---|---:|---:|---:|---:|
| 평소 도구 4명 | 50초 | 30초 | 20초 | 100초 |
| 저널에서 빨라진 2명 | 8초 | 7초 | 5초 | 20초 |
| 저널에서 느려진 2명 | 40초 | 35초 | 45초 | 120초 |

[기대값 파일](expected.json)에서 시간 차이는 **저널 평균 − 평소 도구 평균**이다. 양수면 저널에서 오래 걸렸다. 저장소 루트에서 첫 명령을 실행하면 합성 입력의 형식과 수치를 검산한다. 두 번째 명령은 현장 집계와 같은 계산·표시 코드를 빈 문서에서 실행해 두 결과표의 수치와 파일 내용까지 확인한다. 입력은 이 폴더에 있는 가상 명부와 가상 채점 기록만 사용한다.

```sh
node experiments/field-reason-time/build_fixture.cjs --check
node experiments/field-reason-time/render-reports.cjs --check
```

입력 파일과 결과표를 다시 생성하려면 두 명령에서 `--check`를 빼고 순서대로 실행한다.

## 빨라진 사람이 이유까지 맞힌 방식

[두 사례의 결과와 실제 모의 답안 열기](faster-reasons.html). 두 사례 모두 평소 도구에서 100초, 저널에서 20초였던 두 사람은 표와 판정을 맞혔다. 첫 사례에서 두 사람은 평소 도구로만 분모를 맞혔고 둘째 사례에서는 저널로만 맞혔다. 두 기사에 저널을 배정받은 빠른 편집자는 각각 한 명이다. 이전 버전 `725fc79`에서 같은 두 묶음으로 계산하면 전체 배정 결과가 같다. 실제 사람의 응답은 수집하지 않았다.

`node experiments/field-reason-time/faster-reasons.cjs --check`는 같은 과제·기준 설명에 해당하는 저장 풀이를 조합해 두 경우를 다시 채점하고 결과표의 내용까지 대조한다.


## 두 회신이 연결된 순서에서 시간·성공 수 읽기

[네 사람의 모의 순서 대조](observed-order.html)에서는 첫 회신 4건을 두 번째 측정과 연결했고, 한 사람은 권장 순서의 반대로 진행했다. 서로 다른 기사에 저널을 배정받은 사람이 순서별로 한 명씩 있어 네 조합 인원이 같다. 평소 도구가 먼저인 두 사람은 100초→20초, 저널이 먼저인 두 사람은 평소 도구 100초·저널 120초였다. 이는 관찰된 두 집단을 설명한 모의 계산이다. `node experiments/field-reason-time/observed-order.cjs --check`로 집계를 다시 계산한다.

# 새 통계표에서 연도와 지표를 함께 찾는 검사

처음 보는 한국 공공기관의 연도별 원표 한 개를 고른다. 기관과 표의 주제는 질문 작성자가 선택한다. 원표 발행처와 판본을 확인하고 머리글과 행의 값은 원문 순서대로 옮긴다. 질문 작성자는 검색기와 이전 테스트를 보거나 실제 검색을 실행하지 않는다.

기준판은 `1adb815`, 후보판은 `210ef5e`다. 두 판본을 고정한 뒤 새 표와 네 개의 수치 질문, 원표 셀로 답할 수 없는 두 질문을 받는다. 수치 질문 중 하나는 다른 행에 있는 숫자를 기사 주장에 사용한다. 답 없는 두 질문은 표에 빠진 연도와 분모 또는 모집단이 다른 지표를 각각 묻는다.

화면에 표시될 상위 세 행에서 첫 후보·상위 세 후보의 행 적중, 정확한 셀(행·열·값·표제·머리글 위치)의 안내, 잘못 안내한 셀이 있는 문항 수를 센다. 수치 안내가 없는 경우와 정확하지 않은 값을 표시한 경우를 나눠 기록한다. 자료가 부족한 질문에서는 수치를 표시한 문항 수를 따로 센다. 참가자 응답이나 편집 시간이 들어가지 않는 검색기 평가다.

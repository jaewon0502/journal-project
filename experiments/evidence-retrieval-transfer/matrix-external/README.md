# 다음 원표에서 행·열 찾기

질문을 받기 전에 기준판 `f0abc60`과 시험판 `3b301a0`을 지정했다. 새 원표는 한국에너지공단 표를 고치고 다시 푼 결과와 구분한다. 자료 작성자는 두 판본의 코드를 보지 않고 다른 기관·주제의 표에서 자연어 질문 여섯 개를 만든다. 붙여 넣을 때 표에 포함되는 머리글·단위는 그대로 남긴다. 두 판본에 같은 본문과 질문을 준다.

네 질문은 값을 특정할 수 있고, 그중 하나는 다른 칸의 숫자를 인용한다. 나머지 두 질문은 표에 없는 연도나 하위 집단을 묻는다. 다음을 각각 집계한다.

- 표시된 첫 후보, 앞의 세 후보에 정답 원문 행이 있는지
- 자동 안내가 실제 행 이름·연도 머리글·값·왼쪽부터의 열 번호·두 문단 위치와 일치하는지
- 잘못 연결한 셀이 있는 문항 수와, 답 없는 질문에 특정 수치를 안내한 건수
- 자동 안내를 보류한 문항에서 편집자가 행과 연도를 직접 선택하면 원문 위치를 열 수 있는지

원문 행의 숫자가 그대로 보이는 경우와 사람이 선택한 셀은 자동 셀 적중에 넣지 않는다. 실제 시간·기사 정확도·정치 편향은 이 검사에서 추정하지 않는다.

## 결과

문화체육관광부의 2024년 전국 공공도서관 통계조사 보도자료 11쪽 표 16을 사용했다. 표 제목과 단위 줄, 17개 시도와 전국 행, 2019~2023년 열을 보존했다. 질문·좌표는 `0bd898f`에 고정했다. [원표와 PDF 판본](source.md) · [질문 여섯 개](holdout.json)

| 판본 | 정답 행이 첫 후보 | 상위 세 후보에 정답 행 | 정확한 셀 자동 안내 | 잘못된 셀 안내 | 답 없는 질문에 셀 안내 | 직접 선택으로 확인한 정답 |
|---|---:|---:|---:|---:|---:|---:|
| [기준판](baseline.json) `f0abc60` | 4/4 | 4/4 | 0/4 | 0/4 | 0/2 | 0/4 |
| [최초 시험](first.json) `3b301a0` | 4/4 | 4/4 | 0/4 | 0/4 | 0/2 | 0/4 |
| [문항 공개 후 재시험](retest.json) `3578494` | 4/4 | 4/4 | 0/4 | 0/4 | 0/2 | 4/4 |

처음부터 네 행이 모두 첫 후보였다. 다만 표 제목이 머리글 앞에 있는 원문은 행·연도 선택기를 열 수 없어, 편집자가 여러 숫자 중 어느 열을 확인할지 직접 세어야 했다. 재시험에서는 인쇄된 표 제목과 단위를 곁에 두고 각 행의 연도 열을 열 수 있었다. 채점기가 화면에서 정답 좌표를 직접 선택해 원문 값과 발췌 위치를 검사했다.

| 직접 확인한 좌표 | 원문 값(명) |
|---|---:|
| 제주 · 2023 | 90,101 |
| 세종 · 2021 | 56,788 |
| 충북 · 2022 | 57,862 |
| 전국 · 2020 | 76,431 |

충북의 2022년 값이 77,092명이라는 문장에서 그 수치는 바로 아래 충남 행의 값이었다. 재시험판의 충북 후보에서 ‘2022년 열 직접 대조’를 누르면 57,862와 표 위치를 볼 수 있다. 초등학생 방문자 수와 2018년 값은 이 표에 없다. 제목에 들어 있는 ‘1관당’과 단위 ‘명’은 발행처가 제시한 원문이다. [문화체육관광부 보도자료](https://www.mcst.go.kr/site/s_notice/press/pressView.jsp?pSeq=21279)

저장소 루트에서 Node 24와 프로젝트의 jsdom 의존성을 사용한다.

```sh
work=$(mktemp -d)
trial=experiments/evidence-retrieval-transfer/matrix-external
for rev in f0abc60 3b301a0 3578494; do
  mkdir "$work/$rev"
  git archive "$rev" docs/reader | tar -x -C "$work/$rev"
  node "$trial/score.cjs" "$work/$rev/docs/reader" "$trial/holdout.json"
done
```

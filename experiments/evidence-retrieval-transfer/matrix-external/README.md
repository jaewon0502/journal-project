# 다음 원표에서 행·열 찾기

질문을 받기 전에 기준판 `f0abc60`과 시험판 `3b301a0`을 지정했다. 새 원표는 한국에너지공단 표를 고치고 다시 푼 결과와 구분한다. 자료 작성자는 두 판본의 코드를 보지 않고 다른 기관·주제의 표에서 자연어 질문 여섯 개를 만든다. 붙여 넣을 때 표에 포함되는 머리글·단위는 그대로 남긴다. 두 판본에 같은 본문과 질문을 준다.

네 질문은 값을 특정할 수 있고, 그중 하나는 다른 칸의 숫자를 인용한다. 나머지 두 질문은 표에 없는 연도나 하위 집단을 묻는다. 다음을 각각 집계한다.

- 표시된 첫 후보, 앞의 세 후보에 정답 원문 행이 있는지
- 자동 안내가 실제 행 이름·연도 머리글·값·왼쪽부터의 열 번호·두 문단 위치와 일치하는지
- 잘못 연결한 셀이 있는 문항 수와, 답 없는 질문에 특정 수치를 안내한 건수
- 자동 안내를 보류한 문항에서 편집자가 행과 연도를 직접 선택하면 원문 위치를 열 수 있는지

원문 행의 숫자가 그대로 보이는 경우와 사람이 선택한 셀은 자동 셀 적중에 넣지 않는다. 실제 시간·기사 정확도·정치 편향은 이 검사에서 추정하지 않는다.

# 2024년도 총지출의 정부안·확정예산·결산 검색 검사

2024년 중앙정부 총지출은 정부안 656.9조 원, 국회 확정예산 656.6조 원, 결산 638.0조 원이었다. 이 검사는 기사 속 금액이 다른 단계에서 나온 경우에도 검색기가 질문에 맞는 단계와 연도의 문단을 먼저 보여 주는지 확인한다. 질문과 검색용 본문은 아래 공개 자료에서 확인한 사실을 바탕으로 평가자가 새로 썼다. 실제 기사나 공식 문서의 인용문으로 사용할 수 없다.

| 확인한 사실 | 원자료와 위치 |
|---|---|
| 정부는 2023년 9월 1일 2024년도 예산안을 국회에 제출했다. 총지출 정부안은 656.9조 원이었다. | [국회예산정책처의 2024년 1월 12일 심의 결과 요약 첫 문단](https://korea.nabo.go.kr/En/report/findAnalysisAllInfo.do?bbsId=BMSR00154&boardId=3250&gubunCd=B154003&pageIndex=6) |
| 국회 본회의는 2023년 12월 21일 656.6조 원 규모로 의결했다. 수정안 표결에 찬성한 의원은 237명이었다. | [기획재정부의 2023년 12월 21일 의결 발표, 본문 첫 두 문단과 본회의 사진 설명](https://www.korea.kr/news/policyFocusView.do?newsId=148924053&pkgId=49500798) |
| 2024회계연도 중앙정부 총지출 결산액은 638.0조 원이었다. 같은 표의 전년도 결산액은 610.7조 원이었다. | [국회예산정책처의 2025년 7월 28일 결산 분석](https://nabo.go.kr/ko/report/analysisView.do?idx=8815&key=2509250001) · [보고서 인쇄본 4쪽 ‘2024회계연도 총지출 결산’의 총지출 행](https://www.nabo.go.kr/board/file/down.do?fid=33318702) |

결산에는 2025년에 발표된 자료를 쓴다. 국회 의결 당시의 문서만 제공하는 문항에는 결산액이 없다. 나란히 쓰인 금액은 모두 0.1조 원 단위이므로 여기서 정확한 조정액을 역산할 수 없다. 국회예산정책처는 심의 결과 실제 감액분을 2,332억 원으로 따로 밝혔다. [NABO Focus 제69호 표 2 각주](https://nabo.go.kr/board/file/down.do?fid=33317867)

## 문항과 채점

[평가 자료](fixture.json)는 검색 실행 전에 확정했다. 파일의 SHA-256은 `1b189cfd509a808a97b7e0571d66a1c93ab736492599cc578ef8c76f9cf1c5c5`다. 검색할 때는 지정된 문서의 줄을 줄바꿈 하나로 연결하고 질문만 전달한다. 정답과 원자료 설명은 검색 입력에서 제외한다. 문단 번호는 1부터 센다.

- 수치 질문 여섯 개는 연도와 단계가 모두 맞는 문단이 첫 후보와 상위 세 후보에 각각 드는지 센다. 이 중 두 문항에는 다른 단계의 금액을 잘못 쓴 원고가 나온다. 원고의 진위를 자동 판정하는 점수는 계산하지 않는다.
- 빠진 정보 두 개는 의결 당시 자료에 없는 결산액과, 제공한 자료에 없는 2022회계연도 결산액이다. 해당 정보가 없다는 경고가 나오는지와 경고가 나오면서 후보 목록도 비어 있는지를 각각 센다. 독자 화면은 경고가 있으면 일치어가 있는 주변 문단을 접어 두므로 두 결과를 구분한다.
- 일반 질문 한 개는 2024년도 예산안 표결에 찬성한 의원 수를 묻는다. 경고 없이 표결 문단이 첫 후보여야 한다.

## 같은 문항으로 비교한 결과

`1cec0285877f45917271f6f341471f0794b69631`의 `docs/reader`만 `git archive`로 추출하고 공개 함수 `evidence-search.search`에 아홉 문항을 실행했다. 각 후보의 본문이 해당 문단 원문과 일치하는지도 확인했다.

| 지표 | 기준판 | 수정 후 |
|---|---:|---:|
| 대상 연도·단계의 문단이 첫 후보 | 4/6 | 6/6 |
| 대상 연도·단계의 문단이 상위 세 후보에 포함 | 6/6 | 6/6 |
| 빠진 연도·단계에 대해 경고 | 0/2 | 2/2 |
| 빠진 연도·단계에 대해 경고하고 후보도 비움 | 0/2 | 0/2 |
| 일반 질문에서 경고 없이 첫 후보 적중 | 1/1 | 1/1 |

첫 후보가 달랐던 두 문항은 2024회계연도 실제 지출을 묻는 질문(2023년 결산 문단이 먼저 표시됨)과 656.9조 원을 국회 확정액으로 적은 원고(정부안 문단이 먼저 표시됨)였다. 두 문항 모두 정답 문단은 두 번째 후보였다. 이 소규모 검사는 합성 문장에서 검색 후보 순서와 누락 경고를 관찰한다. 편집 시간, 기사 정확도, 정치적 편향 변화는 별도 편집자 실험에서 측정해야 한다.

수정 후 누락 안내가 뜬 두 문항에서 주변 문단은 접혀 있었다. 편집자는 직접 펼쳐 같은 표현이 어느 문단에서 나왔는지 확인할 수 있었다. 오프라인 Chrome의 320픽셀과 1280픽셀 화면에서 각 문항을 확인했다. 검색만 실행한 뒤에는 판정·발췌문 입력란과 자료 선택란이 비어 있었다. 단계별 처리는 산문에 적용한다. 표와 별도 기사 문맥을 넣은 질문은 기존 검색으로 확인한다.

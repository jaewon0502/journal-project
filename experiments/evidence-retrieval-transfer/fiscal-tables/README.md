# 예산안·예산·결산을 나란히 실은 표에서 원문 셀 찾기

2024년 총지출은 정부 예산안에서 656.9조 원, 국회 확정예산에서 656.6조 원, 결산에서 638.0조 원이었다. 같은 행에 여러 금액이 나올 때 검색기가 질문의 연도와 단계에 해당하는 셀까지 짚는지 검사한다. 아래 두 표는 국회예산정책처가 공개한 PDF를 내려받아 머리글의 경계와 셀 표기를 페이지 이미지에서 확인했다. [예산안 심의 결과 PDF 2쪽 표 2](https://nabo.go.kr/board/file/down.do?fid=33317867#page=2) · [결산 분석 PDF 14쪽 아래 표](https://www.nabo.go.kr/board/file/down.do?fid=33318702#page=14)

## 원표를 검색 입력으로 옮긴 방법

| 원표와 단위 | 인쇄된 머리글 | 검색에 쓴 행 |
|---|---|---|
| 2024회계연도 총지출 결산, 조 원 | 2023년 묶음에는 결산(A)과 예산 대비, 2024년 묶음에는 예산(B)·결산(C)·예산 대비(C-B)가 있다. 마지막 열은 별도의 전년 대비(C-A)다. | 총지출, 일반회계, 특별회계, 기금 |
| 2024년도 예산의 총수입·총지출 및 재정수지·국가채무 증감, 발췌 행은 조 원 | 2023년 묶음에는 본예산(A), 2024년 묶음에는 예산안(B)과 확정예산(C), 증감 묶음에는 국회증감(C-B)과 전년대비(C-A)가 있다. | 총수입, 총지출, 통합재정수지, 관리재정수지 |

[평가 자료](fixture.json)의 각 표는 첫 줄이 머리글이고 열은 탭으로 나뉜다. 병합된 상단 머리글은 각 하위 열 앞에 되풀이해서 썼다. 결산표의 연도 표기에는 ‘년’을 붙였다. 글자 사이 공백과 줄바꿈은 정리했고 금액·소수 자릿수·△·+는 원표 표기대로 옮겼다. 결산표의 세출예산외 지출과 심의 결과 표의 국가채무·GDP 대비 비율은 발췌 범위에서 뺐다. 최초 발췌에는 단위가 빠져 있다. 원자료의 단위를 아는 평가자와 달리, 검색기는 화면에 붙여 넣은 텍스트에서만 단위를 확인할 수 있다.

결산표의 ‘예산(B)’는 결산과 비교할 예산액이다. 심의 결과 표의 ‘예산안(B)’는 국회 심의 전 정부안이다. 두 표에서 B가 가리키는 단계가 다르다. 심의 결과 표의 총지출 ‘국회증감’은 △0.3으로 인쇄돼 있고 원표 각주에서 반올림 전 감액분을 2,332억 원으로 밝힌다. ## 문항과 판정 기준

최초 실험의 질문과 원자료 정답 좌표를 검색 실행 전에 고정했다. `fixture.json`의 SHA-256은 `261697a6a0e10eb2a5419394e96084ceab665fee6c7099ac6e8f4c57b47bbdce`다. 문서에서 `lines`를 줄바꿈 하나로 이어 붙이고 `query`만 함께 검색기에 전달한다. 출처 설명과 정답은 입력에 넣지 않는다. 문단과 열은 1부터 세며 머리글은 1번 문단, 행 이름은 1번 열이다.

- 셀 문항 8개는 첫 후보와 상위 세 후보에 대상 행이 있는지, 원문에서 유일한 열과 표시값을 짚는지 따로 잰다. 원문 근거는 행 번호·열 번호·해당 머리글·원문 수치가 모두 맞아야 한다. 셀 진단이 다른 후보에도 잘못 붙었는지 함께 센다. 세 문항에는 같은 행의 다른 단계 금액이나 다른 회계의 금액을 일부러 넣었다.
- 누락 문항 3개는 의결 당시 표에 없는 결산, 결산표에 없는 정부 제출안, 결산표에 없는 2022년 결산을 묻는다. 필요한 정보가 빠졌다는 안내와 잘못 제시한 셀을 각각 확인한다.
- 모호한 문항 1개는 2024년 총지출만 묻는다. 예산안과 확정예산 중 어느 단계를 원하는지 확인해야 한다. 특정 셀을 표시했는지와 단계 선택을 안내했는지를 따로 본다.
- 일반 문항 1개는 정부 예산안의 국회 제출일을 묻는다. 심의 결과 표 1의 일정을 바탕으로 쓴 두 문장 중 제출일 문장이 첫 후보이고 불필요한 경고나 셀 표시가 없어야 한다.

## 단위가 보이는 조건에서의 추가 검사

최초 기준판을 실행한 뒤, 정답지의 조 원 단위가 검색기에 전달되지 않았음을 확인했다. 최초 입력과 성적은 그대로 남겼다. 이어 [단위 조건](variants.json)을 SHA-256 `763e8aa1ccfafd5e43017a59a8b96f7fd5752707bb5c57d51ee34b6fa49a01ba`로 고정한 뒤 기준판에 다시 실행했다. 같은 질문을 재사용하므로 아래 행들의 분모를 독립 문항 수로 합칠 수 없다.

| 입력에 실제로 보이는 단위 | 대상과 기대 동작 |
|---|---|
| 결산·심의 결과 두 표 모두 단위 없음 | 최초 8문항. 맞는 행을 안내하고 수치를 금액으로 특정하려면 원표 단위를 확인하라고 알린다. |
| 결산표 원문에 인쇄된 `(단위: 조원)` | 결산표 4문항. 행·열·금액 표기와 조 원 단위를 함께 특정한다. |
| 심의 결과 표 원문에 인쇄된 `(단위: 조원, %, %p)` | 심의 결과 표 4문항. 발췌 안에 행별 단위가 표시되지 않으므로 맞는 행과 단위 확인 안내를 보여 준다. |
| 금액 행만 추린 심의 결과 발췌에 평가자가 붙인 `(단위: 조원)` | 심의 결과 표 4문항. 행·열·금액 표기와 조 원 단위를 함께 특정한다. |

추가 조건은 표 앞에 단위 한 줄만 붙인다. 질문, 열의 순서, 수치가 같은 상태에서 머리글과 데이터 행의 번호만 하나씩 늘어난다. 참가자가 붙여 넣은 원문의 단위와 평가자가 알고 있는 단위를 섞지 않도록, 채점기는 `provenance`와 `expectedUnit`을 검색 입력에서 제외한다. 마지막 조건의 단위는 평가자가 발췌한 네 금액 행에 추가한 설명이다. 국회예산정책처는 같은 호 1쪽에서 총수입·총지출·통합재정수지·관리재정수지를 모두 조 원으로 설명하고, 2쪽 표에서는 GDP 대비 비율을 별도 행에 표시한다. [NABO Focus 제69호 1~2쪽](https://nabo.go.kr/board/file/down.do?fid=33317867)

## 같은 질문으로 비교한 결과

공개 함수 `evidence-search.search`로 기준판 `6e8aa6dc2c25906953fa61d80092c49bab991551`과 수정판에 같은 입력을 전달했다. 후보 문단과 주변 문맥을 원문의 해당 줄과 대조했다. 아래 표의 각 칸은 기준판 → 수정판 순서다.

| 수치 질문의 입력 조건 | 대상 행이 첫 후보 | 대상 행이 상위 세 후보 | 단위를 확인한 금액 셀 | 행·열 위치와 단위 확인 경고 |
|---|---:|---:|---:|---:|
| 최초 입력, 두 표의 단위 없음 | 0/8 → 8/8 | 8/8 → 8/8 | 0/8 → 0/8 | 0/8 → 8/8 |
| 결산표, 원표의 조 원 단위 | 3/4 → 4/4 | 4/4 → 4/4 | 0/4 → 4/4 | 0/4 → 0/4 |
| 심의 결과 표, 원표의 혼합 단위 | 1/4 → 4/4 | 4/4 → 4/4 | 0/4 → 0/4 | 0/4 → 4/4 |
| 심의 결과 표, 평가자가 금액 행에 붙인 조 원 단위 | 1/4 → 4/4 | 4/4 → 4/4 | 0/4 → 4/4 | 0/4 → 0/4 |

단위가 빠진 최초 입력에서 기준판은 매번 머리글과 대상 행을 차례로 보여 주었다. 수정판은 대상 행과 열을 찾고 단위를 확인하라고 안내했다. 기준판과 수정판 모두 이 입력에서 단위가 확인된 금액 셀은 0/8이었다. 네 조건 모두 예상 밖의 셀 진단은 없었다.

원표의 조 원 단위를 붙인 결산표에서 ‘2024년 특별회계 결산액이 344.5조 원이었나?’라고 물었을 때 기준판은 344.5가 있는 일반회계 행을 먼저, 대상인 특별회계 행을 두 번째로 보여 주었다. 수정판의 첫 후보는 특별회계였고, 그 행에서 `2024년 결산(C)` 열의 `78.6`을 표시했다.

| 누락·모호 질문과 일반 질문 | 기준판 | 수정판 |
|---|---:|---:|
| 요구한 단계나 연도가 없을 때 셀을 특정하기 어렵다고 경고 | 0/3 | 3/3 |
| 여러 단계가 가능한 질문에 경고 | 0/1 | 1/1 |
| 위 네 문항에서 특정 셀을 표시 | 0/4 | 0/4 |
| 일반 제출일 문항에서 경고 없이 첫 후보 적중 | 1/1 | 1/1 |

수정판은 해당 예산 단계의 열이 없는 두 문항에서 그 단계가 표시된 원표를 요청했다. 2022년 결산을 묻는 문항에서는 해당 연도를, 단계 없이 총지출만 묻는 문항에서는 필요한 예산 단계를 확인하도록 안내했다.

### PDF에서 추출한 여러 줄 머리글

[결산표 원문 추출](settlement-layout.txt) 1,390바이트와 [심의 결과 표 원문 추출](adoption-layout.txt) 946바이트는 각각 해당 PDF의 `pdftotext -layout` 결과에서 표 제목부터 네 번째 데이터 행까지 복사한 연속 구간이다. 내려받은 원자료와 바이트 단위로 대조했다. 앞의 단위 조건들과 달리 머리글이 여러 줄이고 정렬용 공백이 유지된다.

| 여러 줄 머리글에 같은 수치 질문을 입력 | 첫 후보가 대상 행 | 대상 행과 원표 확인 안내를 함께 표시 | 특정 셀을 표시 |
|---|---:|---:|---:|
| 결산표 | 2/4 → 4/4 | 0/4 → 4/4 | 0/4 → 0/4 |
| 심의 결과 표 | 2/4 → 4/4 | 0/4 → 4/4 | 0/4 → 0/4 |

여러 줄 머리글로는 수정판도 어느 열의 수치인지 표시하지 않았다. 두 자료의 8문항에서 편집자는 해당 행으로 이동한 뒤 원표 머리글과 단위를 대조해야 한다. 이 실험으로 다른 PDF 뷰어의 복사 순서나 다른 기관의 표, 편집자의 검증 시간, 기사 정확도는 평가하지 않았다.

# 처음 보는 양곡소비량 보도에서 근거 찾기

2026년 11월 25일, 기존 검색 시험에 없던 양곡소비량 보도를 기준판 `1df5945`로 처음 검토했다. 기사에서 고른 사실 두 가지 중 첫 후보에서 직접 근거를 찾은 것은 1/2건이었고, 세 번째 후보까지 보아도 1/2건이었다. 기사와 공식 자료의 업종 범위가 다른 경우를 놓쳤다. 검색기 실행 전에 문항·자료·기대 위치·채점 방법을 고정했다. [고정한 문항](first-pass.freeze.json) · [관찰 결과](observed.json)

| 검색한 내용 | 대조할 공식 근거 | 처음 표시된 결과 |
|---|---|---|
| 2024년 가구 1인당 연간 쌀 소비량과 전년 대비 변화. 보도에 근거해 풀어 쓴 문장 | PDF 7쪽 84행, 55.8kg·1.1% 감소 | 84행이 첫 후보 |

실제 뉴스핌 기사는 식료품 제조업이라고 적은 문장 바로 다음에 식료품과 음료 제조업 각각의 소비량을 제시한다. PDF 5쪽 첫 후보 주변에도 식료품 수치가 있지만 추출 과정에서 ‘58’과 ‘만 4,612톤’이 서로 다른 줄에 놓였다. 이 시험은 원문을 자동으로 판정하지 않는 검색기가 어느 근거로 편집자를 안내하는지 측정한다. 편집자의 소요 시간과 기사 전체 정확도는 측정하지 않았다. [2025년 1월 23일 뉴스핌 보도](https://ir.newspim.com/news/view/20250123000220)

통계청의 2024년 양곡년도 조사 기간은 2023년 11월 1일~2024년 10월 31일이다. 기준 자료는 통계청이 2025년 2월 5일 인쇄 7쪽의 단위를 ‘천톤’에서 ‘톤’으로 정정한 PDF 21쪽판이다. PDF 쪽은 표지부터 세고, 행 번호는 전체 파일에서 빈 줄을 제외해 센다. 기사는 같은 조사 결과를 인용하므로 통계를 독립적으로 측정한 자료로 취급하지 않았다. ## 재현

1. 고정 문항 파일의 SHA-256은 `85dabc74dd8d67837ce73e535e5c7be31d2acb412299038ebfa37bc99b480642`다. 위 PDF를 받으면 PDF 파일의 SHA-256과 `pdftotext -layout report.pdf report.txt` 출력 해시가 고정 문항에 적힌 값과 일치해야 한다. 사용한 Poppler 버전은 26.11.0이다.
2. `git archive 1df5945 docs/reader tools/prepare_pdf_source.py`를 별도 디렉터리에 풀고 그 안에서 `python3 tools/prepare_pdf_source.py /경로/report.pdf`를 실행한다.
3. 해당 판본의 `docs/reader/factcheck.html`에서 고정 문항의 `query` 한 개로 검토 목록을 만든다. 1번 문장에서 원자료 본문 검색을 열고 생성한 검색 파일과 원본 PDF를 연결한다. 추가 기사 문맥은 비워 둔다. 문항마다 새 탭에서 반복한다.
4. 첫 세 후보의 행과 PDF 쪽을 대조한다. 첫 후보에서 ‘이 문단을 발췌문으로 사용’을 눌러 실제 인용에 들어간 구절을 확인한다. 이때 펼쳐 볼 수 있는 주변 문단, 자동으로 제시한 셀, 편집자가 기록하는 문장 판정은 각각 따로 센다.

# 양곡소비량 근거 검색 재시험

이 재시험은 2026년 11월 25일 처음 관찰한 세 문항을 같은 공식 자료로 반복한다. 기사 전체의 사실성, 정치적 편향, 실제 편집자의 시간 절감률은 이 세 문항으로 측정할 수 없다. [처음 고정한 문항과 채점 규칙](../first-pass.freeze.json) · [최초 관찰](../observed.json)

## 기준판

동결 당시 판본 `1df5945`와 수정 직전 판본 `f2e9974`를 각각 `git archive`로 꺼내 확인했다. Chrome 158에서 너비 320px와 1280px로 새 오프라인 브라우저 세션을 열고 매번 기사 문장 하나만 입력했다. 두 판본의 후보 순서, PDF 물리 쪽, 첫 발췌의 SHA-256, 최종 판정란이 두 화면 모두 일치했다. 양성 2건 중 가구 전체 문장만 첫 후보와 상위 3개에서 직접 근거를 얻었다. 서울 1인 가구 문장에는 해당 집단의 자료가 없다는 경고가 없었다. 이때 제시된 전국 수치의 원문은 검색 후보였고, 판정란은 비어 있었다. [수정 직전 실제 화면 기록](baseline.json)

식료품 제조업 문장에서 첫 PDF 링크가 5쪽에서 11쪽으로 바뀌었다. 수정 직전에는 58행의 식료품·음료 제조업 합계가 발췌됐다. 수정 후에는 실제로 선택한 216행에 식료품 제조업 단독 소비량 584,612톤과 증가율 4.8%가 함께 들어 있었다. 가구 전체 문장은 두 판본 모두 7쪽 84행을 발췌했다. 서울 1인 가구 문장은 검색 즉시 해당 집단의 수치를 같은 구절에서 확인할 수 없다는 안내를 보였다. 전국 수치가 있는 세 후보는 처음에 접혀 있다. 편집자가 직접 펼치면 여전히 7쪽 84행을 선택할 수 있다. 세 문항은 최초 결과가 알려진 뒤 수정에 재사용했다. 위 변화는 같은 결함의 재현과 수정을 보여 준다. 새 기사에서의 성공률과 편집자 소요 시간은 별도 표본으로 측정해야 한다.

## 실행

Node.js, Chrome, Node에서 로드할 수 있는 Playwright가 필요하다. `report.pdf`는 최초 시험과 같은 정정판이어야 한다. 원본 검색 파일과 레이아웃 텍스트를 다시 만들려면 Poppler 26.11.0과 저장소의 준비 도구를 사용한다. 파일 이름도 `report.pdf`로 유지한다. PDF·레이아웃·검색 파일·문항·최초 관찰 파일 중 하나라도 SHA-256이 다르면 스크립트가 중단된다. [공식 자료와 준비 절차](../README.md#재현)

저장소 루트에서 실행한다. 아래 두 경로는 로컬 설치 위치로 바꾼다. Playwright를 이 스크립트로부터 로드할 수 있다면 `PLAYWRIGHT_MODULE` 설정은 생략할 수 있다.

```sh
source_dir="/path/to/grain-source"
export PLAYWRIGHT_MODULE="/path/to/node_modules/playwright"
suite="experiments/evidence-retrieval-transfer/grain-consumption"
baseline_dir="$(mktemp -d)"
git archive f2e997448c397996c6eecab37238070786f01914 docs/reader | tar -xf - -C "$baseline_dir"
node "$suite/retest/replay.cjs" "$baseline_dir/docs/reader" "$source_dir" "$suite/first-pass.freeze.json" > "$baseline_dir/observed.json"
node "$suite/retest/replay.cjs" docs/reader "$source_dir" "$suite/first-pass.freeze.json" > "$baseline_dir/current.json"
```

각 실행은 기사 입력 → 검토 문장 선택 → 추가 기사 문맥 없이 검색 파일·PDF 연결 → 첫 검색 → 첫 후보에서 발췌 순서로 진행한다. `initialCandidates`는 화면을 펼치기 전 각 후보의 가시 여부와 인용문이 실린 공식 자료 행·쪽을 기록한다. `firstSelection`에는 실제 발췌에 들어간 행과 해시를 남긴다. 접힌 어휘 후보는 필요할 때 따로 펼쳐 첫 항목을 눌러 본다. 처음부터 직접 근거가 표시된 경우와 구별할 수 있다. 첫 후보 PDF 링크가 가리키는 파일의 해시와 화면의 발췌 쪽 안내를 확인한다. PDF 뷰어의 페이지 그림을 육안으로 판독하는 과정은 포함하지 않는다. `visibleTypedCell`은 화면에 보이는 셀 안내 문구인 ‘원문 표기’ 또는 ‘원표 표기’의 유무다. 원문 인용에 숫자가 있다는 사실만으로는 셀 안내로 세지 않는다. 서로 다른 화면 너비에서 반복해도 고유 문항 수는 3건이다.

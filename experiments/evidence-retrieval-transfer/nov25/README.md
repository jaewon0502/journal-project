# 새 기관 통계표의 근거 행 찾기

## 최초 측정 규칙

원표를 고르고 질문과 정답 행을 정하는 담당자는 검색 코드·기존 테스트·검색 결과를 열지 않는다. 정답이 다른 네 문항 중 하나에는 실제 값과 다른 주장을 넣는다. 자료에 없는 정보를 묻는 다섯 번째 문항은 따로 본다. 측정 전 정답 파일과 채점기를 해시로 고정한다.

편집 화면과 같은 `JournalEvidenceSearch.search`에 원문과 질문만 입력한다. 원문 그대로인 후보의 문단 번호가 지정 행과 일치할 때만 적중으로 센다. 첫 후보와 상위 세 후보를 각각 4건 중 몇 건인지 보고한다. 다섯 번째 문항은 반환한 행과 자료 범위 안내를 그대로 남긴다. 후보 발견은 기사 주장의 사실 판정이나 편집자의 시간 절감률을 뜻하지 않는다.

기존 기본 브랜치 `ac127e2`와 새 검색 버전 `46f0825`를 비교한다. 최초 결과를 본 뒤의 변경은 같은 질문에 대한 재시험으로 기록한다.

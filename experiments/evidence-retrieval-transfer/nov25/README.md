# 새 기관 통계표의 근거 행 찾기

## 최초 측정 규칙

원표를 고르고 질문과 정답 행을 정하는 담당자는 검색 코드·기존 테스트·검색 결과를 열지 않는다. 정답이 다른 네 문항 중 하나에는 실제 값과 다른 주장을 넣는다. 자료에 없는 정보를 묻는 다섯 번째 문항은 따로 본다. 측정 전 정답 파일과 채점기를 해시로 고정한다.

편집 화면과 같은 `JournalEvidenceSearch.search`에 원문과 질문만 입력한다. 원문 그대로인 후보의 문단 번호가 지정 행과 일치할 때만 적중으로 센다. 첫 후보와 상위 세 후보를 각각 4건 중 몇 건인지 보고한다. 다섯 번째 문항은 반환한 행과 자료 범위 안내를 그대로 남긴다. 후보 발견은 기사 주장의 사실 판정이나 편집자의 시간 절감률을 뜻하지 않는다.

기존 기본 브랜치 `ac127e2`와 새 검색 버전 `46f0825`를 비교한다. 최초 결과를 본 뒤의 변경은 같은 질문에 대한 재시험으로 기록한다.

## 2026년 11월 25일 결과

한국도로교통공단의 2021~2025년 교통사고 원표를 사용했다. 원표와 질문은 `a5fdd66`에 동결했다. [자료 출처와 질문 작성 기록](source-note.md) · [원표와 질문](holdout.json)

| 판본 | 첫 후보에 정답 행 | 상위 세 후보에 정답 행 | 표에 없는 2020년 질문의 후보 수 |
|---|---:|---:|---:|
| 기존판과 첫 개선판 · 두 판본의 전체 출력 동일 | 2/4 | 4/4 | 0 |
| 연도·지표 표제를 고친 뒤 같은 문항으로 재시험 · `3f34ceb` | 4/4 | 4/4 | 0 |

‘2024년 교통사고 사망자가 2,551명이었나’에 최초 검색은 표 머리글, 2,551명이 적힌 2023년 행, 2,521명이 적힌 2024년 행 순으로 보여 줬다. 수정 후에는 2024년 행이 첫 후보였다. 2021년 부상신고자 수 질문도 머리글보다 2021년 행을 먼저 보여 줬다. 근거 행은 편집자가 수치와 단위를 확인한 뒤 최종 판정을 내리는 출발점이다. 이 재시험에서는 사람의 소요 시간을 측정하지 않았다. [최초 결과](first.json) · [동일 문항 재시험](retest.json)

기존 교통·선거, 산불, 독서, 추가 두 기관의 고정 문항도 전후에 같은 후보를 반환했다. 답이 있는 26문항은 모두 첫 후보에 정답 행이 있었고, 답이 없는 10문항 중 4문항에는 관련 표현이 있는 행이 후보로 남았다. 이 값은 후보 검색기의 결과이며 편집 화면의 단위·자료 범위 안내는 별도다.

### 같은 판본으로 재현하기

저장소 루트에서 실행한다. 채점기는 세 번 모두 이 폴더의 같은 원표와 질문을 읽는다.

```sh
root=$(mktemp -d)
for rev in ac127e2 46f0825 3f34ceb; do
  mkdir "$root/$rev"
  git archive "$rev" docs/reader | tar -x -C "$root/$rev"
  node experiments/evidence-retrieval-transfer/nov25/score.cjs "$root/$rev/docs/reader"
done
```

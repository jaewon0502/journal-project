# 성인 종합독서율 수치 대조

**기사에 쓸 수 있는 문장**은 “문화체육관광부의 2023년 국민독서실태조사에서 성인 연간 종합독서율은 43.0%로, 2021년 47.5%보다 4.5%포인트 낮았다”이다. 조사 대상은 만 19세 이상 성인 5,000명이다. 2022년 9월 1일부터 2023년 8월 31일까지 일반도서를 종이책·전자책·오디오북 중 어느 매체로든 한 권 이상 읽거나 들은 비율이다. [문체부 조사보고서 공표 페이지](https://www.mcst.go.kr/site/s_policy/dept/deptView.jsp?pDataCD=0417000000&pSeq=1851&pType=04)

| 확인 위치 | 확인한 값 |
|---|---|
| 조사보고서 인쇄 80쪽(파일 88쪽) 그림 2-7, 성인 계열 | 2021년 47.5%, 2023년 43.0%. 두 점의 차이는 −4.5%p. [보고서](https://clik.nanet.go.kr/clikr-collection/policyinfo/226/1074/2024/CLIKC1748527459366069_attach_1.pdf#page=88) |
| 같은 보고서 인쇄 81쪽(파일 89쪽) 표 2-17, 전체 행 | 사례 수 5,000명. 독서 경험 있음 43.0%, 없음 57.0%. [보고서](https://clik.nanet.go.kr/clikr-collection/policyinfo/226/1074/2024/CLIKC1748527459366069_attach_1.pdf#page=89) |
| 같은 조사 성인용 엑셀 통계표, ‘테이블’ 시트 Q7 ‘독서 경험’, C804:E804 | 전체 5,000명. D804에 저장된 비율 42.9946748…을 소수 첫째 자리로 반올림하면 43.0%. [공표 통계표](https://www.mcst.go.kr/site/s_policy/dept/deptView.jsp?pDataCD=0417000000&pSeq=1851&pType=04) |
| 2024년 4월 18일 보도자료 PDF 1쪽과 5쪽 | 본문 1쪽은 43.0%. 5쪽 성인 표의 ‘전체’ 행 ‘종합’ 묶음에는 2021년 47.5, 2023년 **47.5(-4.5)**가 인쇄됐다. 후자의 수준값은 같은 자료의 본문, 조사보고서와 공표 통계표에 모두 어긋난다. [보도자료](https://www.mcst.go.kr/site/s_notice/press/pressView.jsp?pSeq=21011) |

문체부가 공개한 두 PDF의 텍스트와 해당 표·그림의 페이지 이미지를 2026년 11월 24일에 대조했다. 국회도서관 보관 보고서는 문체부에서 내려받은 보고서와 파일 해시가 같다. 문체부 공표 페이지·보도자료와 정정·정오표 검색에서 5쪽 수치에 관한 별도 정정 공지는 확인하지 못했다. 해당 셀을 인용할 때는 표기 불일치를 밝혀야 한다. [문체부 원보고서 공지](https://www.mcst.go.kr/site/s_notice/notice/noticeView.jsp?pFlagJob=N&pSeq=18001)

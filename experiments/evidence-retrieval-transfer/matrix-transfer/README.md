# 연도가 가로로 놓인 원표의 기사 수치 대조

## 측정 규칙

개선 전 판본은 `f0abc60`이다. 질문 작성자는 검색 코드나 결과를 열지 않고 새 공공기관 원표를 고른다. 명시된 연도와 항목으로 답할 수 있는 네 질문과 표에 없는 연도·하위 집단을 묻는 두 질문을 만든다. 네 질문 중 하나에는 이웃한 행이나 열의 다른 값을 넣는다. 자료와 정답을 고른 사람, 검색을 고친 사람은 첫 채점 전에 서로의 작업을 보지 않는다.

검색에는 붙여 넣은 표와 질문만 전달한다. 정답 행이 첫 후보인지, 세 후보 안에 있는지, 화면이 정답 셀을 짚는지를 각각 센다. 셀 적중은 원문의 행 이름, 연도 머리글, 왼쪽부터 센 열 번호, 머리글과 자료의 문단 번호, 원문 값이 모두 맞아야 한다. 후보로 보인 원문 행 자체는 숫자 안내로 세지 않는다. 한 질문에서 잘못 짚은 셀이 하나라도 있으면 따로 센다. 표로 답할 수 없는 두 질문은 특정 셀을 제안한 건수를 별도로 보고한다. 시간 절감과 기사 판정의 정확성은 이 검사에서 측정하지 않는다.

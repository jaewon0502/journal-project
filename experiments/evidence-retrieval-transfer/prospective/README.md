# 두 기관 통계표 공동 전향 평가

2026년 11월 24일, 앞선 20문항에서 사용하지 않은 두 기관의 공식 통계표를 동시에 선정했다. 정답이 있는 질문은 기관별 3개씩, 표에 필요한 측정값이 없는 질문은 기관별 1개씩이다. 편집자가 주장에 적힌 수치를 확인할 때처럼, 정답값을 주지 않는 질문과 인접 연도·지표의 수치를 넣은 문장을 함께 사용했다.

기관, 원문 행, 질문, 정답 행, 통제 질문, 채점 규칙을 담은 `holdout.json`의 SHA-256은 `09b371de9a1371825fcfb84213d93c7fc2a81afd8063680069eaf6859861f4a3`이다. 이 값을 개발 담당자에게 전달할 때는 기관과 질문을 공개하지 않았다. 두 표 모두 같은 최종 후보 버전 한 개와 고정 기준선을 사용한다.

## 원문 확인

- 관세청의 2025년 1월 확정치 총괄표는 연도와 월이 두 층에 있고, 수출과 수입 각각의 금액 아래에 전년 동기 대비 증감률이 한 줄씩 있다. 재배포 PDF 1번째 면 왼쪽 인쇄 1쪽의 표를 직접 읽고, 관세청 보도자료 HTML에서 다섯 열의 수치를 모두 대조했다. PDF의 한 행을 한 줄로 옮기고 열 칸은 탭으로 구분했다. 월 및 누계가 함께 실린 구조, 반복된 증감률 행명, 띄어 쓴 수출·수입 행명을 유지했다. 원본의 2025년 묶음 안에 12월 열도 표시돼 있어 그 열의 연도는 채점에 사용하지 않았다. PDF SHA-256은 `2183f6c06191fc9ad163a59c4dd54f5b2affc37f40b1b1f09d36bc63d36e4de4`이다. [관세청 공식 발표](https://www.customs.go.kr/kcs/na/ntt/selectNttInfo.do?bbsId=1362&mi=2891&nttSn=10131214&nttSnUrl=0d6cf45ec0389ee7ade33c0e060bc107) · [같은 보도자료의 배포 PDF](https://www.kormia.co.kr/data/2025/03/7bf1d3b5c0d5fea6f0ea51485b8b6e8f.pdf)
- 한국소비자원의 소비자피해 구제 통계는 국가지표체계 표 F014701의 2016~2025년 머리글과 9개 수치 행 전체, 단위, 구제율 산식을 사용했다. 합쳐진 구제내용 셀은 처음 나타난 줄에만 두었다. 동적 표의 향후 갱신과 구별할 수 있도록 검색에 입력한 값을 동결 파일에 보관했다. [국가지표체계 원표](https://www.index.go.kr/unity/potal/eNara/sub/showStblGams3.do?freq=Y&idx_cd=F0147&period=N&stts_cd=F014701)

## 채점

정답 있는 6문항의 첫 후보와 상위 세 후보에서 지정 근거 행이 나온 횟수를 센다. 화면에 덧붙은 주변 문맥은 채점에서 제외한다. 같은 행에 여러 연도와 지표값이 있어 행을 찾은 뒤에도 열과 단위를 확인해야 한다. 미수록 2문항은 검색기가 후보를 내놓은 횟수와 빈 목록을 반환한 횟수를 따로 센다. 검색 결과만으로 화면의 유보 문구, 편집자의 소요 시간 또는 정치적 편향의 변화를 판단할 수 없다.

`score.cjs`는 기준선과 후보에 동일한 원문과 질문을 입력하고 추천 문단의 위치와 발췌가 원본과 일치하는지 함께 확인한다. 실행 전에 골드, 두 검색 모듈, 후보 모듈과 같은 폴더의 기간 판독 모듈 해시를 확인한다.

## 첫 비교 결과

| 원문 | 기준선 첫 후보 | 최종 첫 후보 | 기준선 상위 3개 | 최종 상위 3개 |
| --- | ---: | ---: | ---: | ---: |
| 관세청 수출입 통계 PDF | 1/3 | 1/3 | 1/3 | 1/3 |
| 한국소비자원 피해구제 통계 HTML | 2/3 | 3/3 | 3/3 | 3/3 |
| 전체 | 3/6 (50.0%) | 4/6 (66.7%) | 4/6 (66.7%) | 4/6 (66.7%) |

- 소비자원의 구제율 산식이 3위에서 1위로 올랐다. 정답이 상위 세 후보에 새로 들어온 질문은 0개였다.
- 관세청 표에서 잘못된 수출액을 제시한 질문에는 그 수치가 실제로 실린 수입 행이 첫 후보가 됐다. 수입 감소율을 물은 질문에는 연도와 월 머리글만 돌아왔다. 두 버전 모두 정답인 수출액 행과 수입 증감률 행을 놓쳤다.
- 표에 없는 수출 중량 및 환급액 합계를 물었을 때 두 버전 모두 후보를 2/2건 반환했고 빈 목록은 0/2건이었다. 이 실행은 화면에서 해당 후보를 어떻게 표시하는지 검사하지 않았다.
- 관세청은 인쇄물의 시각적 행 구조를 보존한 전사다. 자동 PDF 변환 과정 자체는 평가하지 않았다. 한국소비자원 HTML은 연도 10개와 수치 90칸 전체 및 구제율 산식을 원표와 대조했다. 기관당 3문항이므로 증감은 관찰된 문항 수와 함께 해석해야 한다.

질문별 순위는 `result.json`에 있다. SHA-256은 `cb6275a06af8997374624cdc4e28ea36aca767a8bd92a88c6aa3efabf532e6ec`이다. 이 결과가 공개된 뒤 같은 자료에서 얻은 성적은 재시험으로 기록한다.

프로젝트 루트에서 동일 입력으로 재현하는 명령은 다음과 같다.

```sh
node experiments/evidence-retrieval-transfer/prospective/score.cjs \
  experiments/evidence-retrieval-transfer/prospective/snapshot/evidence-finder.cjs \
  51467c1eb7ecdb9b482a36267b88e3a72d50df93d8300e2dbf287b03c9682160 \
  f0f05d007e9b377507105adcfeea8fec41074b7e4d94f43b8d23cd9fce29e64d
```

## 첫 화면의 판단 보류

같은 8문항을 Chrome 157.0.8103.79에서 직접 조회했다. 답이 없는 질문에서 기본 화면이 근거 부족을 명시하는지, 후보 원문이 접힌 상태인지 확인했다. 정답이 있는 질문에서는 잘못된 보류 메시지를 따로 셌다. 관측 기준은 기존 `../ui-rule.json`과 동일하다.

| 첫 화면 관측 | 문항 수 |
| --- | ---: |
| 미수록 질문에서 명시적 유보 | 1/2 |
| 미수록 질문에서 후보 원문 기본 노출 | 1/2 |
| 미수록 질문에서 후보 원문 기본 숨김 | 1/2 |
| 정답이 있는 질문에서 잘못된 유보 | 0/6 |

환급액 합계에는 원 단위를 찾지 못했다는 안내와 접힌 후보 두 개가 표시됐다. 수출 물량에는 겹치는 표현이 있는 문단이 두 개라는 안내만 나왔고 연도와 월 머리글이 기본 노출됐다. 두 경우 모두 검색기는 원후보를 반환했다. 정답이 있는 질문 중 검색기가 상위 3개에서 근거를 놓친 두 건도 일반 후보로 표시됐다.

`ui-initial.json`은 문항별 기본 노출 문단 번호, 전체 후보, 접힘 표시, 상태 문구 및 화면 구성 파일 7개의 SHA-256을 담고 있다. 결과 SHA-256은 `f0fd754e017ec0aba389e2687555f65c71c2a65e8f7c36d7159f8311cdbeda65`이다. 첫 화면과 원순위 결과는 이후 UI 재시험과 따로 보존한다.

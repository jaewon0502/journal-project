# v23: 검증 대상 문장 노출만 바꾸는 근거 답변 비교

v22의 부분 근거→전체 지지 오류를 보존한다. 원자화/표지 계약만으로 해결됐다고 하지 않는다. 과거 v12 H1과 v15 H-S에 원자료 선행 답변/목록이 있으므로 이 방법을 새 독립 접근으로 세지 않는다. 이번 검증 가능한 차이는 동일 원자료·중립 질문·답변 예산·두 단계 구조에서 제1 검토자의 대상 문장 접근 유무를 조작하는 것이다. 기존 v22를 그대로 반복하는 실험은 아니며, v22식 대상 명제 대조를 두 단계 대조군으로 맞춘 변형이다.

V: 검토자는 원자료+중립 질문+대상 문장을 읽는다. M: 같은 원자료+같은 질문을 읽지만 대상 문장·기존 판정 표지·기존 근거 선택은 보지 못한다. 양쪽 모두 표지를 보기 전에 근거에서 답을 만들며, 원문 주장의 값에 대한 노출만 다르다. 이후 각각 다른 새 문맥의 편집자가 같은 원자료·대상 문장·각 답 장부와 동일 편집 지시를 받는다. 자료량은 같고 문장 노출량은 의도적으로 다르므로 총 입력 토큰까지 같은 실험은 아니다. 답 장부를 gold로 쓰지 않는다.

고정 합성4쌍: 문장 간 대상 연결, 접속사로 결합한 다중 결과, 일부/전체 양화, 계획/실행 시제. 각 쌍은 오류형과 정상형이며 한 요소만 다르다. 전체8단위. 추가2단위는 v22 실제 생성 명제 C20/C37의 노출 근거 연결 회귀로 같은 사건의 두 표현이다. 실제 기사2건이나 새 미사용 실제 사건으로 세지 않는다. 실제 원자료는 v22 동결 전체 텍스트를 그대로 쓰며 새로운 자료를 추가하지 않는다.

각 조건의 10개 답변은 하나의 별도 문맥에 제시하고, 각 조건의 10개 편집도 하나의 새 문맥에서 실행한다. 반복·같은 사건·동일 문맥의 의존성을 기록한다. 순서 고정이며 순서효과를 분리하지 못한다. 정확한 배포 모델·seed·비용은 미통제. 같은 상속 runtime, 별도 override나 유료 API 없음.

사전 판정: 합성 오류4단위는 지지된 부분을 보존하면서 부당한 자료 귀속/범위/시제만 고쳐야 한다. 정상4단위는 그대로 유지하며 근거 없는 보류·배경 추가를 하지 않는다. 기존 명제2단위는 지지된 고유 양자 성질과 자료에서 미확인인 정의/비유를 구분하고, 일부 지지를 전체 지지로 확대하지 않는다. 미확인을 거짓이라 하거나 전체 보류만 하는 것도 개선이 아니다. 원문이 참일 수 있으면 절별 근거 주석을 사용하며 본문 삭제를 자동 요구하지 않는다.

각 축 별도 보고: 부분 지지 과대판정, 정상 과잉 보류/수정, 필수 국소 수정 실제 반영, 지지된 부분 손실, 근거 부족→거짓 오판, 정확한 패치 전달, 남은 미확인. 단일 성공점수로 합치지 않는다. 독립 평가자가 입력/사전기준과 익명 출력에 근거해 최종문까지 대조하며 AI 판단을 인간 정답으로 부르지 않는다. 신뢰/독자 이해/일반 편향 감소는 측정하지 않는다.

신규 접근 가족 +0. 결과가 같으면 개선 미관측으로 보고하고 반복 실행으로 실패 횟수를 늘리지 않는다. 실패시 구체적인 새 가설/실제 근거가 있을 때만 다음 개입을 설계한다.

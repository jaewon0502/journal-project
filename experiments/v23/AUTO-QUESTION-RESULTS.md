# 자동 질문 후속: 알려진 명제와 정상 대조

사람이 주제별 질문을 주지 않고 새 모델 문맥에 두 문장만 제공했다. 질문 생성자는 기존 명제 T701에서 각운동량·내재성·문자적 회전3질문, 정상 T812에서 내재성·양자 성질2질문을 만들었다. 예/아니오 형식의 질문으로, 대상 문장 자체를 숨겨도 질문에 주장 요소가 남는다는 한계가 있다.

별도 근거 답변 문맥은 원문을 보지 않고 질문과 같은 전체 원자료를 읽었다. 다시 다른 편집 문맥이 원문·원자료·답변을 대조했다. 독립 평가자는 출력 전에 자체 기준을 저장한 뒤 질문부터 최종 산출물까지 검사했다.

T701은 기존 주장 단어를 보존하면서 각운동량 정의와 회전 부정 뒤에 미확인 표시를 본문에 각각 삽입했고(국소 삽입 패치2개), T812는 수정·주석·보류 없이 유지했다. 독립 감사에서 질문의 필수 범위 누락, 근거 지지 확대, 미확인→거짓 오판, 문자 패치 불일치를 찾지 못했다. 이는 실제 생성 명제1개와 구성한 정상 대조문1개의 국소 회귀 결과다.

단계별 원출력은 질문2·근거답2·편집2 =6개이며 최종 편집문은2개다. 새로운 실제 기사2건이나 독립 접근6개가 아니다. 원자료를 추가하지 않았으므로 미확인 정의의 사실성 자체는 여전히 검증되지 않았다. 다른 기사에서 자동 질문이 모든 의미를 찾는지에 대한 보증도 아니다.

# 사람이 지정한 질문의 영향: 후속 범위 고정

본 실험의 합성 전달문 양쪽이 같다는 초기 결과를 본 뒤, 손으로 지정한 질문이 알려진 오류 위치를 지나치게 알려줬는지 검사한다. 본 비교의 입력/평가/정책은 바꾸지 않는다.

기존 v22 실제 생성 명제1개(T701, R662와 같은 문장)와 기관 자료가 지지하는 정상 대조문1개(T812)를 사용한다. 별도 새 문맥이 원문 문장만 읽고 중립 검증 질문을 만든다. 사람이 각운동량/회전이라는 질문을 따로 공급하지 않는다. 이후 원문을 보지 않는 별도 문맥이 같은 전체 자료로 질문에 답하고, 새 편집자가 같은 정책으로 원문·전체 자료·답 장부를 대조한다. 기존 명제를 다시 쓰므로 노출 회귀이며 정상문도 구성한 대조문이다. 신선한 실제 사건으로 세지 않는다.

사전 기대는 T701에서 부분 지지→전체 지지를 피하되 거짓/전체보류로 처리하지 않기, T812는 정확히 유지하기다. 질문의 명제 범위, 근거 답의 충실성, 최종 전달·주석을 각각 검사한다. 인간 질문 없이 성공하더라도 한 실제 사건의 두 문장에 대한 국소 타당성이고 일반 자동 추출의 완전성이 아니다. 독립 접근 가족 +0, 본 비교의 노출효과 추정에 합치지 않는다.

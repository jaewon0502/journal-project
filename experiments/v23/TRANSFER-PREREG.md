# 새 실제 기사 1건: 자동 질문 전이

합성 비교와 노출 명제 회귀가 두 조건 모두 통과했고 수동 질문이 오류 위치를 알려준 한계가 남았다. 자동 질문 노출 회귀의 작성 결과도 보존을 유지했지만 같은 사건 반복이다. 따라서 별도 수집자가 기존 주제와 다른 실제 과학 기사1건과 직접 연결된 원자료 전체를 수집한다. 오류가 있을 법해서 고르는 방식이 아니라 첫 접근 가능한 후보를 사용하고 후보·보류 이유를 기록한다. 원자료 접근이 막히면 최대 다른 후보2건을 확인하며, 실패하면 자료 blocker로 보고한다.

질문 생성자는 기사만 읽고 동일 자동 질문 정책으로 질문과 원문 대응구간을 만든다. 질문 목록을 원자료 답변 전에 동결한다. 같은 질문과 같은 원자료를 두 검토자에 주되 V는 기사도 읽고 M은 읽지 않는다. 이후 서로 다른 새 편집 문맥이 동일 원문·자료·각 답 장부를 받는다. 원자료량/단계는 같고 의도한 원문 노출량은 다르다. 본문 길이상 두 조건의 근거 답/감사 설명 예산을 각각 최대 목표1200단어(인용 제외)로 동일하게 확장한다. 기존 단위 실험과 분량이 다르므로 별도 전이로 보고한다.

별도 평가자는 질문/출력을 보기 전에 전체 기사·자료에서 필요한 사실·범위·조건·귀속 및 근거 미확인 항목을 자체 구성한다. 그 목록도 gold로 가정하지 않는다. 후속 출력 감사에서 질문 누락, 근거 답의 부분 지지 확대, 필수 수정 누락, 정상문장 과잉수정/보류, 지지된 내용 손실, 최종 정확한 전달을 구분한다. 완벽한 기사 검증이나 전체 분야 성능으로 일반화하지 않는다. 기존 동결 평가 기준은 변경하지 않고 발견한 새로운 문제는 별도 사후 기록으로 남긴다.

이번 전이는 실제 기사1건으로 제한한다. 실패를 숨기기 위해 사례를 바꾸지 않는다. 반복/버전/새 기사수는 독립 실패 접근 수가 아니며 이번도 기존 A03 계열 변형 +0이다. 전문과 원출력은 비공개 보존, 공개본은 짧은 구간·위치·링크·해시 중심이다.

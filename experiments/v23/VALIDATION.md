# 검증 기록

`python tools/run_checks.py` 전체 종료코드0. unittest 260개 / 20회 실행과 기존 저장 산출물 재생, v23 합성16편집+추가4편집의 정확 패치 재생을 포함한다. 이는 사실·의미 정답 검사 수가 아니다. 새 모델 호출0인 오프라인 재생이다.

비공개 구조 검사: 주요 답/편집48파일의 근거 인용371개가 지정 입력에 문자로 존재했다. 기사 자체를 출처ID로 쓴 메타데이터7개를 처음 검사기가 누락하여 오류로 반환했고, 입력ID 등록을 고친 기록을 따로 보존했다. 인용 존재는 논리적 지지/독립 근거 입증이 아니다. 최종 복원2본문은 독립 감사자가 원문+잔존패치로 재구성하고 해시·주석 보존을 확인했다.

정확한 모델 배포버전, seed, 토큰 비용은 얻지 못했다. 호출/파일 수로 비용이나 벽시계 작업시간을 추정하지 않았다. 생성 결과는 별도 네이티브 문맥의 실제 AI 출력이고, 파생 복원본은 native overlay의 기계적 적용이다.

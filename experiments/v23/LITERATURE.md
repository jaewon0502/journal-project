# 이번 개입의 1차 연구 근거와 차이

[Chain-of-Verification, arXiv v2, 2023-09-25](https://arxiv.org/html/2309.11495v2)의 3.3절은 검증 질문의 답변 단계에서 원래 응답을 숨기는 2-Step/Factored 방식을 구분한다. 원응답의 오류를 그대로 반복할 가능성을 낮추기 위한 문맥 분리이며, 질문별 독립 실행과 질문 묶음 실행도 구분한다. 이 논문은 해당 실험에서 외부 검색 도구를 사용하지 않았다. 이번에는 모델 기억의 지식 정확도보다 동결된 외부 근거에 대한 답변이 원문 주장 노출에 따라 바뀌는지를 검사한다. 질문마다 독립 호출하는 Factored 전체 재현은 아니며, 조건별 묶음 문맥의 의존성이 남는다.

[RARR, ACL 2023](https://aclanthology.org/2023.acl-long.910/)의 3.1–3.2절은 질문별 근거 수집, 원문과 근거가 암시하는 답 비교, 불일치시 해당 구간 편집을 구분한다. 따라서 ‘질문·근거·국소 수정’ 자체가 이번에 새로 발명된 것은 아니다. 논문의 검색·모델·평가 설정을 재현하지 않았으며 보고된 성능을 이 프로젝트의 성능으로 옮기지 않는다. 원문/근거 답을 비교하는 단계에서 근거 답을 원문과 독립해 먼저 생성한다는 노출 조작만 이번 비교의 가설이다.

두 원자료를 2026-10-03 UTC에 직접 열었고 원본 HTML/PDF와 해시를 비공개 보관했다. 검색 결과가 관련 없는 내용을 반환해 알려진 논문 식별자의 공식 원문을 직접 확인했다. CoVe 방법3.3 및 관련 실험 설명, RARR 초록·방법3.1–3.2를 읽었으며 모든 부록/실험을 재현하거나 전수 검증한 문헌 리뷰는 아니다.

프로젝트 내에는 v12 H1과 v15 H-S의 선행 구현이 이미 있다. 이번은 A03 계열의 통제된 노출 진단이며 신규 독립 접근 수 +0이다. 더 많은 호출을 했다는 이유만으로 다른 접근 또는 성공으로 세지 않는다.

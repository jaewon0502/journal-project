# 본 비교 결과: 문장 노출 유무의 추가 이득은 확인 못함

동일 원자료·중립 질문·답변/편집 지시를 사용하고 제1 검토자의 대상 문장 접근만 바꿨다. V는 문장을 읽고 M은 읽지 않았다. 두 조건 모두 기존 판정 라벨은 보지 않았다. 각 조건은 근거 답변10개와 최종 편집10개를 생성했다. 합계40개 단계별 원출력이며 최종 편집문은20개다. 실제 사건40개가 아니다.

| 축 | V: 문장 보임 | M: 문장 숨김 |
|---|---:|---:|
| 합성 오류의 필요한 수정 실제 전달 | 4/4 | 4/4 |
| 합성 정상문 정확 유지·전체보류 없음 | 4/4 | 4/4 |
| 기존 실제 생성 명제의 국소 근거 주석 | 2/2 | 2/2 |
| 독립 감사에서 확인한 지지 확대·새 의미 손실 | 0 | 0 |
| 전체 보류 | 0 | 0 |

두 독립 AI 평가자는 각자 사전 원문 기준을 저장한 뒤 익명 출력20개와 근거 답을 검사했고 위 실질 결과가 일치했다. 같은 자료의 정상/과장 문장 쌍에서도 잘못된 주장을 따라 근거 답이 바뀐 실질적 오염은 찾지 못했다. 행 수·설명 분량 차이는 성능으로 세지 않았다. 최종 본문은 모든10단위에서 조건 간 문자까지 같았다. 같은 모델 계열의 공통 오류를 배제하거나 사람 검증을 대신한 결과는 아니다.

## 실제 최소 수정

- 문장 간 대상: A팀 성인24명·4주 관찰 결과는 유지하고, B팀 영아에서도 결과가 나왔다는 절만 제안 단계·결과 없음으로 수정했다.
- 접속사 결합: 전력 감소·3일 시험은 살리고, 수명 연장과 안전성 향상을 확인했다는 부분만 미측정으로 고쳤다. 실제 수명이 늘지 않았다는 뜻으로 바꾸지 않았다.
- 양화: ‘12명 모두’를 ‘12명 중 적어도 일부’로 수정했다. ‘일부만’ 또는 ‘전원은 아니다’라는 반대 단정을 만들지 않았다.
- 시제: 승인된 예산30억원은 유지하고, 2025년9월 착공 완료형을 당시 계획형으로 고쳤다. 조사기준일2025년6월2일과 실제 현재를 혼합하지 않았다.

이 네 오류형과 정상형은 연구자가 만든 완전 합성 최소쌍이다. 실제 뉴스 성능으로 일반화하지 않는다. 두 조건의 오류 수정문은 대응 정상문과 일치했다.

## 기존 실제 실패의 처리

v22 실제 생성 명제2개는 같은 알터자성 사건의 다른 표현이다. 기관 자료는 전자 스핀의 내재적 양자 성질을 지지하지만 각운동량 정의와 문자 그대로의 회전 부정은 제공 자료에서 확인되지 않는다. 두 조건 모두 본문을 버리지 않고 해당 절에만 미확인 주석을 붙였다. 전체 지지로 과대평가하지 않았고 거짓으로 바꾸지도 않았다.

이는 근거 상태를 올바르게 전달한 국소 회귀 성공이며 정의 자체를 새 물리학 자료로 검증한 성공이 아니다. 주석을 떼어낸 본문만 검증 완료로 배포해서는 안 된다. 일부 감사행의 원문 앵커가 미확인 절까지 넓게 포함하는 주의점이 있었으나, 판정 대상 명제·별도 미확인 행·최종 주석을 함께 읽으면 전체 지지 주장이 아니었다. 앵커 문자열만 추출해 지지 표지를 붙이는 후속 표시 방식은 허용하지 않는다.

## 추가 이득과 한계

문장 숨기기의 추가 이득은 관측하지 못했다. 두 조건 모두 잘했으므로 숨기기가 필요하거나 더 좋다는 증거도, 모든 상황에서 무용하다는 증거도 아니다. v22보다 알려진 반례를 잘 처리했지만 이번에는 질문과 출력 범위·두 단계 구조가 달라져 어떤 변경이 원인인지는 분리할 수 없다.

질문은 실패 위치를 아는 연구자가 정했으며 전체 기사 자동 질문의 완전성을 검증하지 않았다. 같은 조건의10단위는 한 문맥에 들어갔고 정상/오류 쌍을 함께 볼 수 있어 독립 단위가 아니다. v22 실제 원자료 전체 텍스트를 재사용했지만 원기사 전체 편집을 다시 한 것이 아니라 생성 명제 두 개만 검사했다. 배포 모델·seed·토큰비용은 미통제다. 원출력과 기존 기준을 보존한다.

인용144개는 모두 제공 자료 안에 있음을 재생 검사했다. 인용 존재는 함의 검증이 아니며 의미 평가는 별도 AI 감사 결과다. 공개 합성16편집 출력은 replay.py로 정확한 패치 전달을 재생할 수 있다.

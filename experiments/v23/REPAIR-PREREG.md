# 새 전이 실패 후 국소 보완: 대상 동일성과 귀속 범위

신규 전이 원평가 후 두 실패를 확인했다. 양쪽이 패널 시스템20×20m와 재배 구획20㎡를 같은 측정 대상으로 보아 contradicted로 표시했다. V는 추가로 ‘발표문이 보고한다’는 수정을 콜론 뒤 처리별4.5배/2.8배 전체에 걸어, 일부 수치만 뒷받침하는 발표문을 전체 근거로 확장했다. 기존 출력·PRE·POST를 보존한다. 이 자료는 이제 노출 회귀다.

별도 문맥에서 원문/근거의 대상·속성·모집단·시점·단위와 동일 대상임을 입증하는 구간을 적게 한다. 두 문장이 동시에 참일 수 있는 구체적 가상 해석이 있으면 직접 반박을 유보한다. 가상 해석을 실제 사실로 쓰지 않는다. 귀속 패치는 새 출처 문구가 지배하는 모든 후속 절의 범위를 확인한다. 대상 일치 근거와 귀속 범위를 실제 표로 만들며 지시문만 반복해 성공으로 세지 않는다.

변경은 문제 패치와 해당 판정/주석에 한정한다. 필요하면 해당 패치를 롤백하고 원래 정보는 미확인 주석과 함께 남긴다. 다른 검증된 수정과 비판·수치·날짜는 보존한다. 독립 검토자가 전체 적용 결과를 재검사한다.

같은 원리의 새 합성4단위(다른 대상 정상/같은 대상 직접 충돌, 올바른 분리 귀속/부당한 전체 귀속)를 별도로 실행한다. 각 쌍은 대상 일치 또는 귀속 범위 한 요소만 바꾼다. 이는 실제 사건 일반화나 새 미사용 실제 기사 성공이 아니다. A03 반례·A08 경계·A09 선택복원 계열의 노출 실패 보완이며 신규 독립 가족 +0이다. 이번 전이1건의 추가 수정과 이 작은 검증까지만 수행하고 남은 문제를 보고한다.

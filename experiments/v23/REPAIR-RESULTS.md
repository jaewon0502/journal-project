# 후속 최소복원·독립 재검사

원래 신규 전이 출력/PRE/POST는 덮어쓰지 않았다. 노출된 같은 기사에 대한 회귀수리이며 새 미사용 평가가 아니다. 첫 native overlay 파일1개(두 조건 계획), 최종 overlay 파일1개(두 조건 계획)를 결정론적으로 적용했다. 파생 본문을 새로운 모델 생성본으로 세지 않는다.

| 문제 | 최소 처리 | 최종 독립 검사 |
|---|---|---|
| 재배구역과 패널 시스템을 동일 대상처럼 모순 판정 | 양쪽 P3 복원, 비교대상 결합을 미확인 처리 | 일치. 20㎡가 참임을 확인한 것은 아님 |
| 일반 효율 자료의 귀속이 처리별 수치 전체까지 번짐 | 노출 조건 P5만 복원; 수치/처리 연결과 원래 추론은 국소 미확인 | 새 귀속 오류 제거. 원래 추론 검증 아님 |
| 자료의 침묵을 세계의 미해결/미시험 상태로 표현 | 양쪽 P2를 ‘제공된 발표·전문가 반응으로는 미래의 해당 가능성을 확립하지 못한다’로 한정 | R1 해소. 세계에 연구가 없다는 뜻 아님 |
| 전문가 출처가 같은 패널 크기라는 미확인 절까지 지배 | 노출 P8의 새 출처 도입만 제거, 생산량의 추정 상태는 유지 | R2 해소. 동등 크기는 여전히 국소 미확인 |

첫 복원 감사에서 R1/R2가 발견돼 그대로 기록한 뒤 최종 수정했다. 마지막 독립 감사는 해당 결함 해소·나머지 패치/주석 보존·최종 문자/해시 일치를 확인했고 새 범위 확대를 찾지 못했다. 전체 기사 검증이나 모든 편집의 필요성 인증은 아니다. ‘유사 수확량→유사 크기’ 등의 편집 필요성은 해석 여지가 남는다. 본문만 떼어 배포하면 미확인 주석이 사라지므로 검증 완료본으로 취급하지 않는다.

## 별도 새 합성 대조

K731은 재배구역 P와 시스템 M을 구별하여 정상문 그대로. K842는 같은 시스템 M의 면적만20→400㎡로 정정. K953은 두 출처가 각 수치를 말한 정상문 그대로. K164는 두 번째 수치의 출처만 정정했다. 별도 감사자가 사전 판정 후 최종문을 확인했다. 정상2/2 정확 보존, 오류2/2 국소 정정, 불필요 전체보류0/4. 합성4건이며 이전 정책 직접 대조가 없어 개선 효과 추정치가 아니다.

원문에서 보호할 짧은 구간과 위치는 PROTECTION-EXAMPLES.md와 protection-examples.json. 재생 코드는 저장된 합성 패치의 문자 결과만 확인한다.

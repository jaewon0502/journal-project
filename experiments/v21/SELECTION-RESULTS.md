# 고정 후보 선택: 우위는 확인되지 않음

| 단계·원문/후보 관계 | 현행 정책 A | 분리 정책 B | 독립 AI 사전 판정 |
| --- | --- | --- | --- |
| 노출 기사: 피부라는 조직 명칭 → 점막 | 적용 | 적용 | 국소 사실 충돌 수정 |
| 노출 기사: 농산물 검사 수에 유통 경로 나열 추가 | 거절 | 거절 | 참인 선택 설명 |
| 합성: 승인 보류 → 거부 | 거절 | 거절 | 정상 원문을 바꾸는 오류 |
| 합성: 관측 감소 → 인과 입증 | 거절 | 거절 | 정상 원문에 근거 없는 인과 추가 |
| 새 자료: 임시 보상 제거 → 제거 안 함 | 거절 | 거절 | 정상 원문을 바꾸는 오류 |
| 새 자료 주입 오류: 3단계 → 2단계 | 적용 | 적용 | 국소 사실 충돌 수정 |
| 새 자료: 달콤한 보상 → 자당 보상 | 거절 | 거절 | 참인 선택 설명 |
| 새 자료 미확인 주장: 야생 60% → 40% | 보류 | 보류 | 원문·후보 모두 일치하는 야생 근거 없음 |

실제 선택 JSON 16개(각 정책8개). 각 단계에서 같은 후보·원문·전체 수집 근거를 사용했고 작성하지 않았다. 기계 적용문은 선택 결과를 고정 문자열 치환한 파생물이며 새 모델 작성문이 아니다. 두 독립 AI 감사는 각각 PRE를 먼저 저장한 뒤 정책 이름을 가린 출력8개씩을 검토했다. 16결정은 해당 PRE와 일치했다. 이는 16개 독립 사건 또는 사람이 검증한 정답이 아니다.

두 정책 모두 국소 충돌 2건을 적용, 선택 설명2건을 거절, 정상 원문 손상 후보3건을 거절, 미확인 원문1건을 보류했다. 각각의 분모를 합산 성공 점수로 바꾸지 않는다. 분리 정책이 현행보다 실패를 줄였다는 증거는 **없다**. 후보를 미리 제공하자 현행도 이전 조직 명칭 누락을 교정했으므로 관측된 변화에는 후보 제공/역할/새 문맥 효과가 섞여 있다. 이것을 새 정책의 개선율로 발표하지 않는다.

보류한 야생 비율 원문은 여전히 근거가 없다. 보류는 수정 성공이나 출판 가능한 전달문이 아니다. 해당 문장은 release 보류 상태로 남아야 하며, 코드가 그대로 보존한 문자열을 승인문으로 쓰면 안 된다. 필요한 자료는 해당 야생 집단·과제·관찰 기간·표본/분모를 실제 측정한 근거다. 숫자만 다른 후보는 해법이 아니다.

## 새 자료 범위

[Phys.org, 2024-03-06](https://phys.org/news/2024-03-bumblebees-scientists-advanced-social-skills.html)은 Queen Mary University of London 제공 글이다. 독립 기자 취재와 논문이라는 두 독립 증거로 세지 않는다. 전체 기사와 [Nature 원논문](https://www.nature.com/articles/s41586-024-07126-4), DOI 10.1038/s41586-024-07126-4를 확보했다. 기사 직접 HTTP는 400이었으나 브라우저 도구에서 전체 본문을 읽었고, 논문은 HTTP200 전체 텍스트다. 검색 요약으로 대체하지 않았다. 보충 PDF/영상은 미수집이다.

새 기사1건에서 두 변형에는 연구자 오류/미확인 주장을 주입했고, 나머지는 원문에 고정 후보만 제공했다. 원기사의 자연 오류4건 또는 새 실제 사건4건으로 세지 않는다. 문제의 국소 판단만 검증하며 기사 전체의 표현 모두를 정상으로 인증하지 않는다.

## 다음 검증으로 이동한 이유

선택 정책의 우위가 없으므로 기본 방법을 B로 교체하지 않는다. 남은 중요한 검증은 후보 없이 원문/근거를 읽을 때 차이를 기록하고 유지하는가다. 문단별 관측 목록을 실제 만들게 하는 방식과 현재 자율 기준 작성 방식을 비교하되, 더 긴 출력·더 많은 작업량과 구조 자체의 효과는 분리하지 못한다. 별도 모듈의 결과를 이 선택 결과에 섞지 않는다.

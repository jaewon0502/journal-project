# 후보 없이 관측 기록 유지 비교

동일 패치 선택 비교는 개발과 새 이식에서 모두 결정 차이가 없었다. 이를 새 정책 성공으로 채택하지 않고 후보 발견 단계로 이동한다. 원문/전체 자료만 주며 후보·정답·표적 질문은 주지 않는다.

A는 현재 중요 오류/누락 중심 자율 기준 작성, B는 문단별 확인 가능한 주장과 출처 대조를 먼저 기록하고 이후 필요성을 판정하는 전체 절차다. B에서는 필요성 no여도 이미 관측한 차이를 삭제하지 않는다. 단순 필드 추가가 아니라 관측 행 유지와 문단별 처리 흔적이 실행되는지 검사한다. 자료는 같지만 출력 분량/작업량은 다르다. 따라서 효과가 있더라도 분량·노력과 기록 순서의 효과를 분리했다고 하지 않는다.

개발은 기존 조직 명칭과 이번 벌 기사(모두 이미 연구자 노출) 2건×2조건이다. 독립 AI 원문 선행 PRE 이후 익명 출력을 판정한다. 표적만 주지 않고 전체 원문을 다시 검토한다. 누락 발견, 명시적 충돌의 근거 연결, 선택적 추가를 오류로 취급한 거짓 양성, 근거 부족을 오류로 취급한 경우, 인용 강도·귀속 손실을 따로 센다. 문단 체크 수를 의미 완전성으로 간주하지 않는다.

정책/출력 형식 동결 후 다른 실제 기사1건에서 같은 두 조건을 적용한다. 원자료 접근 범위와 계보를 기록한다. 한 차례 새 이식 뒤 일반 완전성이나 우위를 주장할 근거가 없으면 실패/불확실성으로 보고하며 같은 체크리스트의 재명명은 새 접근으로 세지 않는다. 확인 가능한 불일치와 독자 중요성 판단을 분리하고 기존 평가를 소급 수정하지 않는다.

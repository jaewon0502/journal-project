# 후보 없는 발견의 새 자료 이식

정책 변경 없이 새 DART 기사 원문과 연구자 변형을 각 정책·각 입력의 새 문맥4개에서 실행했다. 독립 AI 평가자는 전체 원문/원자료 PRE를 먼저 저장한 뒤 익명 출력4개를 확인했다. 두 정책 모두 변형의 성공 기준 83초와 NASA의 73초를 연결해 충돌로 판정했다. 같은 기준이 본문에서 두 번 등장하지만 원자 명제1건이다. 정상 원문2출력에서는 거짓 충돌이나 근거 없는 필수 수정이 발견되지 않았다.

| 입력 | 현행 A | 문단별 관측 B |
| --- | --- | --- |
| 실제 원문 | 관측7행; 근거 없는 필수 수정 없음 | 관측29행; 근거 없는 필수 수정 없음 |
| 기준 숫자만 바꾼 변형 | 관측9행; 기준 충돌 탐지 | 관측32행; 기준 충돌 탐지 |

관측 수 증가의 추가 탐지 이득은 이 사례에서 없다. 두 방식 모두 자료 범위 밖의 인용·직함·비용·거리 등을 곧바로 거짓으로 만들지 않았다. 원자료의 초기 측정 불확실성과 최초라는 표현의 범위는 별도 불확실성/선택 맥락으로 다뤘다. 분출물의 반동 설명은 네 출력 모두 명시적으로 목록화하지 않았고, 별도 평가자가 설명 범위의 누락으로 지적했다. 이를 정책들이 보존한 항목이라고 주장하지 않는다. 이는 원자료의 추가 설명 맥락이며 원문 의미 손실이나 확정된 필수 수정 실패로 세지 않는다. 기사에 이미 근사 표현이 있으므로 정확한 오차 수치 미기재를 자동 중대 오류로 세지 않았다.

이는 한 사건에서 만든 최소쌍이며 실제 원기사에 기준 오류가 있었다는 뜻이 아니다. 목표 기준을 제시하거나 후보 패치를 주지 않았다. 표적 외 모든 문장의 완전성을 입증하지도 않았다. 새 수정문은 생성하지 않아 실제 편집 성공·인용문 수정 안전을 주장하지 않는다. 발언 내용의 기준이 원자료와 다르다는 것과 해당 인물이 실제 어떤 말을 했는지는 구별해야 한다.

자료는 [Guardian 보도](https://www.theguardian.com/science/2022/oct/11/nasa-dart-spacecraft-asteroid-successful)와 [NASA 초기 결과 발표](https://www.nasa.gov/news-release/nasa-confirms-dart-mission-impact-changed-asteroids-motion-in-space/)다. 정확한 원자료 주소·발행/수집 날짜는 `new-source-metadata.json`에 기록했다. 두 문서 모두 직접 HTTP200으로 전체 본문을 확보했고 Guardian의 기존 정정문을 유지했다. NASA 문서는 당사자 공식 초기 발표이지 독립 측정이나 심사 논문이 아니다. 이후 정밀 결과를 당시 기사 기준으로 소급하지 않았다.

문단별 목록은 검토 가능성을 높이는 기록 형식으로 쓸 수 있지만 자율 탐지 우위나 의미 목록 완전성의 해결법으로 채택할 근거는 없다. 개발에서 나타난 제목의 필요성 유보 문제도 새 숫자 사례 통과로 해결됐다고 볼 수 없다.

# 실제 실패 감소 여부: 국소 수리는 가능하나 새 정책 우위는 없음

미실행이던 두 경로를 계속 실행했다. 첫째 작성·후보를 고정하고 선택 정책만 비교했다. 차이가 없자 둘째 후보 없이 원문에서 사실 차이를 기록하는 방식을 비교하고 별도 새 자료에서 검증했다. 실제 사례별 모델 출력24개를 보존했다. 이를 기사24건이나 독립 반복24회로 세지 않는다.

## 검증된 국소 결과

고정 후보 선택에서는 현행과 분리 정책이 같은 결정을 내렸다. 두 정책 각각 조직 명칭/단계 수의 지지된 국소 수정2건을 선택했고, 참인 선택 설명2건과 정상 문장을 해치는 후보3건은 거절했다. 근거 없는 원문 비율1건은 보류했다. 각 분모는 서로 다른 경계이므로 합산 정확도 점수로 제시하지 않는다. 새 정책이 과잉수정과 누락을 동시에 더 줄였다는 증거는 없었다. 조건별 반복 없는 소규모 비교이므로 두 정책의 통계적 동등성도 입증하지 않는다.

실제 고정 패치 예: 피부라는 명칭만 점막으로 바꾸면서 금속 용출·흡수 여부는 아직 모른다는 주변 문장을 유지했다. 농산물 검사 수에 긴 유통 경로를 덧붙이는 후보는 참이지만 필수는 아니어서 적용하지 않았다. 이는 실제 저장된 모델 선택을 기계적으로 적용한 결과이며 새 자유 재작성 결과가 아니다.

## 확인된 남은 문제

1. **한 행에 섞인 명제.** 현행 발견 출력은 피부 표현의 부정확성을 이유에 적었으나, 흡수 기전과 묶은 행의 전체 판정을 supported로 했다. 이 경우 표지만 읽는 다음 단계는 이미 기록된 차이를 놓칠 수 있다. 문단별 방식은 조직 명칭을 분리했지만 이것만으로 모든 항목을 빠짐없이 찾는다는 증거는 없다.
2. **근거 범위와 세계 사실의 혼동.** 문단별 방식은 논문에 귀속한 제목의 과도한 범위를 알아보고도 필요성을 unknown, 선택 설명을 yes로 남겼다. 논문이 그 주장을 지지하지 않는다는 것과 그 주장의 반대가 세계에서 참임을 입증하는 것은 다르다. 독립 감사도 이 차이를 지적했다. 탐지 누락으로 둔갑시키지 않고 필요성 판정 문제로 기록했다.
3. **자세한 목록의 한계.** 벌 기사에서는 양쪽 모두 주요 일반화2건을 찾았고, 새 DART 최소쌍에서는 양쪽 모두 동일한 기준 오류1건을 찾았다. 더 긴 목록의 추가 탐지 이득은 없었다. 분출물 반동이라는 설명 맥락은 DART 네 출력 모두 목록화하지 않았고 별도 감사에서 확인됐다. 이는 원자료의 추가 설명 맥락이며 원문 의미 손실이나 확정된 필수 수정 실패로 세지 않는다. 중요성 논쟁과 AI 판정 불확실성은 남는다.

기존 피부 사례의 모든 실패를 ‘못 봄’이라고 표현하면 안 된다. 인지했으나 편집 불필요라고 본 경우, 인지한 차이가 혼합 행의 지지 표시에 가려진 경우, 별도 충돌로 기록한 경우가 실제 출력에서 구분된다.

## 현재 사용할 절차와 중단 기준

원문에서 주장별 근거 위치·주체·조건·반론 대상·인용 강도·시간을 기록한다. 서로 판정이 다른 명제는 한 행으로 합치지 않고, 사실 차이와 수정 필요성을 따로 남긴다. ‘필요성 낮음’으로 원래 관측을 삭제하지 않는다. 독립 검토는 목록뿐 아니라 원문을 다시 본다.

수정할 근거가 확정되면 해당 절만 고정 패치로 만들고 주변 조건·인용·반론이 남는지 검사한다. 참인 상세 추가만으로는 적용하지 않는다. 판정과 이유가 어긋나거나, 원자료가 귀속된 결론을 실제로 지지하는지 모호하거나, 새 의미 손실이 생기면 자동 적용을 멈추고 해당 패치를 보류/롤백한다. 필요한 조건이 길이에 들어가지 않으면 길이 증가 필요로 반환한다. 보류 원문은 출판 승인문이 아니다.

이 절차는 검토 가능한 국소 작업 방식이다. 보존목록 완전성, 자동 필요성 판단, 한국 언론 전체의 편향 감소를 보장하지 않는다. 새 정책을 기본값으로 교체하지 않았고, 기존 기록의 성공률을 바꾸지 않았다. 두 실행 가설의 결과가 동일/혼합이었으므로 새 이름의 정책 반복을 개선 증거로 포장하지 않는다.

## 실행과 한계

- 선택16사례 출력은 별도 문맥4개, 발견8사례 출력은 별도 문맥6개에서 생성했다. 별도 AI 평가 문맥4개가 각각 원문 선행 PRE와 익명 출력 감사를 수행했다. 인간 참가자 없음.
- 새 실제 기사/원자료 맥락은 벌 사회학습과 DART 초기 결과2건이다. 주입 오류·미확인 주장, 순수 합성 경계, 기존 노출 사례는 구별했다.
- 정확한 배포 모델·seed·토큰/금액은 미통제다. 같은 상속 runtime을 사용했다. 관측 목록 방식은 더 긴 출력/작업량을 요구해 구조와 분량 효과를 분리하지 못했다. 측정하지 않은 시간·비용 절감은 주장하지 않는다.
- 실제 원문 전체를 읽되 확보한 판본/문서 범위를 넘는 보충자료·영상·인용 원녹취·독립 측정은 미확인이다. 공개 패키지에는 전문을 넣지 않았다. 원자료·원출력·PRE·감사는 비공개로 보존하고 해시와 재생 방법을 제공한다.

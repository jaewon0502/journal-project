# 후보 없는 발견: 관측과 필요성은 여전히 갈림

두 노출 기사 각각에 현행 A와 문단별 관측 B를 적용해 실제 JSON4개를 생성했다. A의 관측 행은 조직 기사7·벌 기사8, B는 각각19·17이었다. 더 많은 행을 완전성 개선으로 세지 않는다. 독립 AI가 원문 선행 PRE를 먼저 저장하고, 익명 출력과 원문을 다시 대조했다.

| 원문 쟁점 | 현행 A | 문단별 관측 B | 별도 감사 |
| --- | --- | --- | --- |
| 피부/점막 | 이유에 부정확성을 적었지만 흡수 기전과 묶어 supported·필요성 no | 별도 원자 주장으로 conflict·필요성 yes | 두 방식 모두 차이를 인지했다. B의 근거 연결과 분리가 더 명시적이다. 국소 사실 차이와 편집상 중요성은 분리해야 한다. |
| 제목의 모든 금속을 독성으로 묶는 표현 | 범위 확장을 지적하고 수정 필요 | 범위 확장을 지적하지만 insufficient·필요성 unknown·선택 설명 yes | B는 탐지 자체를 놓친 것이 아니다. 다만 연구에 귀속한 범위 확장 수정 필요성을 유보했다. 반대되는 세계 사실 입증과 해당 논문이 지지하는 범위는 다른 질문이다. |
| 관찰한 벌들이 쉽게 학습했다는 일반화 | 실제 성공5/15와 반복 훈련을 연결해 문제 지적 | 같은 문제 지적 | 추가 발견 이득 없음 |
| 혼자서는 불가능하다는 일반화 | 실험 실패와 평생 불가능을 구분 | 같은 문제 지적 | 추가 발견 이득 없음 |

‘피부 차이를 A가 못 봤다’라는 해석은 부정확하다. A의 reason에는 부정확한 일상 표현이라고 적혀 있다. 문제는 서로 다른 사실을 한 행으로 묶은 지지 판정과, 그 차이를 선택 설명으로 처리한 것이다. B의 제목 역시 전면 누락으로 계산하지 않는다. 알고도 필요성을 다르게 판정한 기록이다.

독립 감사는 일부 세부 쟁점—벌의 연속 동작과 두 기계 단계, 세대라는 문화 정의, 이미 가능성으로 표현된 문화 가설에 추가 단서를 넣을 필요—를 별도 중요성 이견으로 유지했다. 이를 모두 오류로 합산하거나 합의가 나올 때까지 정답을 바꾸지 않았다. 실제 수정문은 이 모듈에서 생성하지 않았으므로 새 편집 손실이 없다는 성능 주장도 하지 않는다.

## 개발 후 동결

개발 출력4개 확보 뒤 정책을 변경하지 않고 새 DART 이식 입력·정책을 동결했다. 당시 개발 POST 감사는 진행 중이었고, 이후 감사 결과를 새 이식 정책에 반영하지 않았다. 이 순서의 한계를 그대로 남긴다. 새 기사 원문과 성공 기준 숫자만 바꾼 변형을 각 조건의 별도 문맥에서 평가한다. 연구자 주입 오류는 원기사 오류가 아니다.

# 원문을 보존하며 필요한 부분만 고치는 짧은 절차

이번 시험에서 유망했던 절차이며, 의미 보존의 자동 보장은 아니다.

1. **질문과 범위를 먼저 고정한다.** 독자가 무엇을 판단해야 하는지, 기사·원자료의 수집일과 포함 구간, 분량을 적는다. 원문에 있던 의미의 보존, 질문에 필요한 추가 답, 선택적 맥락을 구분한다. 자료에 있다는 이유만으로 모두 필수화하지 않는다.
2. **원문을 보고 보호표를 만든다.** 주장마다 행위자·귀속·강도·조건·수치·시점·비교대상·반론을 근거 위치와 연결한다. 다른 검토자는 이 표를 보지 않고 원문부터 읽어 빠진 관계를 찾는다. 보호표를 정답표로 취급하지 않는다.
3. **고칠 절만 지정한다.** 변경 구간의 각 원래 주장을 보존 / 근거로 반박됨 / 미확인으로 나눈다. 미확인은 삭제 근거가 아니다. 필요한 경우 기사에서 보고한 내용이라는 귀속을 유지하고 원자료의 빠진 구간을 추가 확인한다.
4. **수정 전후를 양방향으로 검사한다.** 새 문장이 더 강한 주장·다른 비교·다른 시점을 만들지 않는지, 원문에서 필요한 조건·정당한 비판이 사라지지 않는지 본다. 질문에 답이 있다는 사실보다 답의 의미가 같은지가 중요하다. 변경하지 않은 인접 문장과의 관계도 검사한다. 감사 주석에만 적힌 답은 본문 회복으로 세지 말고 최종 기사에서 실제 위치를 확인한다.
5. **실패하면 적용을 멈춘다.** 중대한 의미 손실, 근거 없는 강화, 중요한 평가 불일치가 남으면 해당 수정은 자동 적용하지 않는다. 원문과 문제 설명을 남기고 더 좁은 수정 또는 추가 근거 검토로 넘긴다. 분량 안에 필수 의미를 담지 못하면 ‘압축 불가·분량 증가 필요’를 표시한다.

‘미확인 주장을 귀속해 남김’은 그 내용의 사실성을 검증했다는 뜻이 아니다. ‘원문 밖 문자를 바꾸지 않음’도 의미 보존과 같지 않다. 이번 재실행에서도 보존했다고 설명한 출력이 비교 관계를 명시적으로 빠뜨렸다.

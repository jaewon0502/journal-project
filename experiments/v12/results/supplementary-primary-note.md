# 고정 실험 밖의 원논문 보충 확인

이 확인에 사용한 Results·표·그림·통계분석 방법은 당초 고정된 과학 원문 발췌에 포함되지 않았다. 따라서 아래 내용은 작성자에게 제공된 근거로 간주하지 않으며, 작성자의 공과를 소급 판단하거나 본 실험 점수·성공률을 변경하지 않는다. 새 모델 실험도 수행하지 않았다.

전체 원논문의 정확한 구간은 비활동 ≤3,000보, 낮은 활동 3,001–5,000보, 중간 활동 5,001–7,500보, 높은 활동 ≥7,501보/일이다. 기사의 3,000–5,000보와 5,000–7,500보는 하한을 둥글린 표현으로, 정확한 분류 경계와는 다르다. 정확히 3,000보는 비활동군, 5,000보는 낮은 활동군에 속한다. 이 구간 정의는 추가 확인으로 해소됐다. 근거: [원논문 Results·표 3·Methods](https://www.nature.com/articles/s41591-025-03955-6), 보관 BioC passage 31·35·63(0부터 시작).

Results와 그림 3 설명은 기저 아밀로이드가 높은 사람에서 낮은 활동군도 비활동군보다 타우 축적·인지 저하가 완만했고, 중간 활동군에서는 더 완만한 양상을 보였다고 서술한다. 따라서 기사의 ‘낮은 활동에서는 상대적으로 덜 완화된다’는 **서술 방향**은 추가 원문으로 확인됐다. 그러나 표 3의 유의성 검정은 각 활동군 대 비활동군 비교이며, 낮은 활동군 대 중간 활동군의 직접 비교 검정은 확인되지 않았다. 두 군 간 차이가 통계적으로 유의하다거나 특정 비율만큼 타우 축적이 줄었다고 확대 해석하지 않는다. 낮은 활동군의 기능 저하(CDR-SOB)와 비활동군의 차이는 유의하지 않았다(P=0.11). 근거: [원논문 표 3·그림 3·Results](https://pmc.ncbi.nlm.nih.gov/articles/PMC12705434/), passage 31–36. 이는 관찰연구의 연관성이며 치료 효과의 입증은 아니다.

# Journal v12 — 누락 발견·최소편집·평가 불일치 검증

## 결론

세 문제 모두 **부분 해결**이다. 보호표를 원자료에서 먼저 만들고 별도 누락 검토를 붙이는 방법, 절별 수정 경계 검사, 조건 이름을 가린 평가를 실제로 실행했다. 그러나 보호표의 완전성뿐 아니라 **무엇을 필수로 남겨야 하는지의 타당성**도 보장하지 못했다. 수정자가 정보를 알고도 최종 본문에 반영하지 않는 문제는 알려진 두 누락에 목표를 명시한 국소 재검증에서는 복구됐지만, 새로운 누락을 스스로 찾아 복구하는 일반 해법은 입증하지 못했다. 평가자가 같은 텍스트를 다르게 채점하는 문제도 남았다.

구체적인 국소 수정은 확인했다. 과학 개발 사례의 재실행에서 삭제됐던 걸음 수 범위·타우 관련 정보를 되살렸다. 신규 육아휴직 사례에서는 고정 기준의 본문 누락 회복이 일반 절차 3/4, 개선 절차 4/4였다. 차이는 R13인 육아기 단축 기간의 기본 1년·최대 3년 계산 규칙 한 항목이다. 다만 별도 원문 검토자는 이 기준 중 일부를 선택적 정보로 보았다. 따라서 이 차이는 **고정된 잠정 기준에서의 결과**이며 객관적 품질 개선이나 일반 성능 우위로 확정하지 않는다.

신규 영국 금리 사례의 최초 평가에서는 두 절차 모두 중요한 것으로 사전 지정한 정보를 본문에 넣지 못했다. 이후 노출된 사례의 보충 검증은 별도 절에 보고하며 최초 평가 점수를 바꾸지 않는다. 합성 검사에서는 둘 다 잘 작동해 절차 간 우위가 없었다. 하나의 종합 점수나 한국 언론 전체의 정치적 편향 감소율로 합치지 않는다.

## 이번 회차의 범위와 실제 실행

이 보고서는 이전 v11·기존 A–D 실험과 분리한 새 회차다. 기존 Library v11 항목 `[private-library-reference-omitted]`은 변경하지 않았다. 실행 시작은 2026-10-02 00:30 UTC, 실험 중단 목표 03:10 UTC, 전달 목표 03:25 UTC로 고정했다. 새 계정·인증·유료 API·원격 저장소·기존 PR·외부 Page 변경은 수행하지 않았다.

- 처음 사용하는 실제 기사 4건: 한국어 2건·영어 2건, 개발 2건·평가 2건. ‘새 사례’는 이 연구에서 미사용이라는 뜻이며 최신 뉴스라는 뜻이 아니다.
- 실제 기사 출력 10개: 최초 개발 A/B 4개, B 개선 후 노출된 개발 재실행 2개, 신규 평가 A/B 4개. 생성만 하고 실행하지 않은 입력 6개는 실험 건수에서 제외했다.
- 실제 출력 10개 모두에 별도 초기 평가 2회씩, 총 20개 평가 결과. 모든 출력에 원문부터 질문을 만든 제3 감사도 수행했다: 총 10개 감사. 이상이 없어 보이는 출력도 제외하지 않았다.
- 합성 6개 기반 사례의 정상/단일변경 최소쌍 12문장에 두 절차를 적용한 24개 탐지 출력, 별도 24개 수정 검토. 24개를 독립 사건 24건으로 세지 않는다.
- 실제 출력의 정확한 위치 수정 56개는 모두 적용됐다. 수정 구간 밖 바이트 보존은 확인했지만 의미 보존은 별도의 판단이다.

독립 데이터 검산은 758개 무결성·개수·재계산 검사를 통과했다. 이는 연구 결과가 모두 옳다는 758개 의미 검증이 아니다. 20개 초기 평가에는 원자화 주장 판정 128개·보호항목 판정 382개·수정 판정 112개가 포함된다. 반복 판정은 독립 표본 수가 아니다.

추가로 원인을 분리하는 세 모듈을 사전 고정해 실행했다. 원자료 범위 비교는 같은 과학 기사에서 4개 작성 출력·8개 평가, 필수성 반례는 새 가상 기반 3개·6문항에서 12개 분류 출력, 본문 전이 비교는 이미 노출된 영국 금리 수정본에서 4개 작성 출력·8개 평가다. 실제 기사 기반 작성 출력은 본 실험 10개와 보충 8개를 합쳐 18개지만, 서로 다른 실제 기사는 여전히 4건이다. 보충 출력의 수정 22개와 8개도 모두 위치 적용됐으며 본 실험 56개와 구분한다. 세 모듈은 기존 평가의 점수·분모를 변경하지 않았다.

## 고정 입력과 조건

A는 같은 기사와 원자료로 일반 근거 감사·최소수정을 수행했다. B-v1은 여기에 원자료→기사 역방향 보존 검사와 행위자·귀속·강도·수치·조건·시점·범위 점검을 추가했다. 개발 후 B에만 한 번 절별 통과/축소/보류 판단을 추가해 B-v2로 동결했다. A는 바꾸지 않았다. 따라서 최종 비교는 **역방향 검사와 수정 경계 판단이 합쳐진 처리 효과**이며 각 구성요소의 독립 효과를 분리하지 못한다.

쌍별 기사·원자료·공통 질문·출력 형식·분량 조건은 같고, 입력 해시를 검산했다. 영어 설명 900단어, 한국어 3,500자 제한을 공통으로 요청했다. 정확한 원문 앵커 등 제외 항목을 명시한 관측 계산에서 실제 10개 출력 모두 제한 안이었다. API가 강제한 토큰 상한은 아니다.

공통 질문은 사건/조치의 상태, 원자료가 입증하는 것과 못 하는 것, 이해에 중요한 조건·비교·대상집단·반론·시간 관계다. 질문이 넓기 때문에 ‘중요함’의 판단 자체가 불안정할 수 있다. 결과를 보고 질문이나 원분모를 고쳐 실패를 지우지 않았다.

보호항목은 원자료 선행 작성 → 기사 대조 → 다른 검토자의 원문 선행 누락·중복·필수성 감사 → 출력 전 동결 순서로 만들었다. 작성자는 이 표나 기존 결함 목록을 받지 않았다. 표는 잠정 기준이지 gold 정답이 아니다.

모든 역할은 같은 기본 런타임의 별도 문맥으로 실행했다. 조건 이름·다른 출력·기존 평가를 숨겼으나 출력의 문체나 구조에서 절차를 추측할 가능성은 남는다. 파일 접근 제한은 역할 지시로 시행했으며 별도 보안 격리를 증명한 것은 아니다. 정확한 배포버전·시드·토큰·비용·내부 호출 횟수는 확보하지 못했다. 인간 검증이나 서로 다른 모델 계열의 합의라고 부르지 않는다.

## 개발 실패와 한 차례 개선

과학 개발 출력 A P6와 B-v1 P7은 인과 표현을 연관성으로 고치는 과정에서 낮은 활동군 수치와 타우·상대 비교 정보를 함께 지웠다. 두 작성자 모두 고정 원자료 발췌에 수치가 확인되지 않는다는 이유를 적었다. 발췌에서 확인하지 못했다는 점을 삭제 근거로 삼은 흔적은 확인되지만, 편집자의 내적 판단을 확정할 수는 없다. 제공 자료에서 반박되지 않은 정보를 없앴다는 점과 그 정보의 실제 중요성을 나누어 평가했다. 원문 수치가 진실이라고 확정하는 문제와, 반박 근거 없이 그 보고 내용을 제거하는 문제는 별개다.

B-v1 P8은 다른 한계 설명을 넣으면서 활동 추적기에 관한 저자 귀속 문장도 삭제했다. 삭제 자체는 확인되지만 그 정보의 중요성은 감사자 사이에 이견이 있었다. 일반화 가능성에 대한 가능 표현을 더 확정적으로 바꾼 흔적은 A/B 모두에서 발견됐다. 별도 근거 검토는 표현 강화는 인정하면서도, 제한된 직접 근거를 뜻하는 관용적 표현으로 읽힐 수 있어 실질적 위해의 크기는 확정하지 않았다.

B-v2는 각 수정 경계 안의 원래 주장을 보존/반박/미확인으로 구분하고, 새 주장과 인접 문장 관계가 근거에 맞지 않으면 축소하거나 보류하도록 했다. 재실행은 이미 노출된 개발 사례이므로 새 평가로 세지 않는다.

재실행에서 걸음 수 구간과 타우 관련 정보는 복원됐다. 그러나 원문의 짧은 비교 표현 **“albeit to a lesser extent”**가 명시적으로 남지는 않았다. 별도 검토는 plateau 설명으로 방향을 추론할 여지는 있으나 완전한 동치라고 확정하지 않았다. 수정자가 보존했다고 적은 자체 설명은 실제 보존의 증거가 아니었다. 한국어 재실행에서도 공식 변동성 경계는 정확히 추가했지만, 원문의 장애 완화 설명을 ‘반박됨’으로 처리한 근거는 과했다.

추가 수정으로 계속 조건을 늘리지 않고 이 지점에서 방법을 동결했다. 남은 사례는 보류·회귀 실패/불일치로 기록했다.

## 추가 원자료 확인으로 해소된 부분

고정 실험 종료 후, 같은 과학 논문의 **당초 입력 밖 Results·표·그림**을 보충 확인했다. 낮은 활동은 3,001–5,000보, 중간 활동은 5,001–7,500보이며, 더 높은 구간에서 더 완만한 변화라는 서술 방향도 확인됐다. 단, 낮은 활동군과 중간 활동군의 직접 유의성 검정을 확인한 것은 아니다. 이는 관찰연구이며 치료 효과의 입증으로 해석하지 않는다. [원논문](https://www.nature.com/articles/s41591-025-03955-6)

이 보충 확인은 **입력 범위를 늘려 특정 미확인을 해소한 리서치 결과**다. 작성자가 이 자료를 받았던 것으로 간주하거나 이전 점수·성공률을 바꾸지 않았다. 중요한 비교가 고정 발췌 밖에 있었다는 점은 보호표 생성뿐 아니라 자료 수집 범위도 실패 원인이 될 수 있음을 보여준다. 자세한 위치·한계는 `results/supplementary-primary-note.md`에 있다.

## 평가 기준·평가자 불일치

원점수와 출력은 수정하지 않았다. 특히 KO 평가의 원기사는 조건 간 완전히 같은데, A 출력 평가에서는 수정 전 기준이 9/14, B 출력 평가에서는 8/14였다. R09의 원문 충족 여부 판정이 달랐기 때문이다. 이는 기사 변화가 아닌 평가 변동이며, 이 차이를 처리 효과로 해석하지 않는다. 보호항목 5개 판정 필드에서 평가자 간 다른 값이 45개 발생했다. 이는 45개 독립 오류나 오류율이 아니다. 이미 있는 내용을 ‘작성자가 발견했다’고 볼지, QA에서만 언급한 것을 발견으로 인정할지, 조건이 암묵적으로 보존됐는지 등이 섞여 있다.

별도 원문 선행 민감도 검토에서는 KO 누락 4개 중 기간 계산·두 연차 관련 항목을 선택적 정보로, 고위험 임신 예외를 모호한 경계로 보았다. EN은 정책 기조·조건부 경로를 필수로 보면서 기대 변화·시나리오·영국 상대 영향을 필수인지 모호하다고 봤다. 이 판단도 정답으로 채택하지 않았다. **고정 기준 결과와 기준의 타당성 이견을 병기**한다. 실패를 지우기 위해 분모를 줄이지 않았다.

본 실험 실제 출력 10개의 제3 감사는 원문부터 자체 질문을 만들고 전체 입력 문단과 실제 선택한 문단 관계를 살폈다. 모든 가능한 문장 관계를 검사했다는 뜻은 아니다. 두 초기 평가자가 함께 놓친 확정적 중대 위해를 이번 표본에서 새로 확정하지는 못했다. 다만 일반화 표현 강화처럼 함께 통과시킨 의심 지점이 있었고, 추가 검토에서도 해석·중요성의 불확실성이 남았다. **공통 오류가 없다는 증거가 아니다.**

문자열 검사에서는 보호항목 평가의 source_anchor 382개가 입력의 부분 문자열과 일치했다. candidate_anchor는 337개가 일치했고 45개는 부재 표시·축약 등으로 문자 그대로 일치하지 않았다. 모든 인용 필드를 전수 확인한 것은 아니므로 모든 감사 인용이 정확하다고 주장하지 않는다.

## 사전 지정 지표의 추가 집계와 미해결 부분

20개 초기 판정의 원자화 주장 128개는 지지 109·미지지 1·부분 지지 18·미확인 0으로 기록됐다. 부분 지지를 제외한 분수만 보면 대부분 만점처럼 보이므로 제외 수를 반드시 나란히 표시한다. 평가자별 분수·명시적 중복 표지·미답 질문·동일 버전의 짝 차이는 `results/metric-limitations.md`와 `results/additional-metrics.json`에 있다. 독립적인 의미 중복 제거가 완료됐다는 뜻은 아니다.

의미 손실 8개 표지와 과잉수정 8개 표지는 같은 평가 행에 겹친다. 수정 ID로 합치면 5개 서로 다른 수정에 해당한다. 최초 과학 A의 P6와 B의 P7/P8은 두 초기 평가자가 모두 표시했고, 재실행 KO P2와 EN P2는 한 평가자만 표시했다. 이것을 16개 독립 오류로 세지 않는다. 원자료/추가 감사에 비추어 중요성이 미해결인 부분도 별도 유지한다.

새 주장 표지 107개 중 99개는 근거로 정당화됐다고 기록됐다. 나머지 8개는 전체 수정의 차이가 정당하지 않다는 필드와 손실 표지가 겹쳐, 그 값만으로 어느 추가 주장이 미지원인지 구별할 수 없다. 순수한 미지원 추가 수, 의미 중복을 제거한 발견 수, 전혀 수정할 이유가 없는 정상 문장을 고친 좁은 의미의 과잉수정 수는 **완전한 확정 집계가 미해결**이다. 미답 질문 목록도 평가자별 원자화가 달라 전체 완전성을 나타내는 공통 분모로 합치지 않았다.

출력 전 주석 전체와 대조한 별도 계보 감사에서는 ‘고정 기준에도, 사전 주석에도 없었던’ 자연 기사 추가 발견은 0건이었다. 개발 6출력·28개 finding 항목·36개 수정, 평가 4출력·22개 finding 항목을 살폈다. 이는 작성자에게 주지 않은 기존 누락을 스스로 찾지 못했다는 뜻이 아니다. 그 발견은 고정 누락 지표에 남아 있다. 배우자 휴가의 청구/사용 기한 구별도 유용한 수정이었지만 사전 주석에 이미 있었다. 추가 발견의 합집합이 비어 별도 확장 분모 점수는 적용하지 않았다. 미지 오류 전체의 회수율은 알 수 없다.

## 실험 후 보류·원문 복구 보조 코드

별도 전달 보조 코드가 기존 출력·평가·원문 해시를 연결하고, 불확실성이나 판정 차이가 남으면 수정안 대신 원문을 반환하도록 구현했다. 8개 자체 작성 기계 검사에서는 지원된 추가의 승인, 불일치·미지원·오래된 해시·평가 누락에 대한 보류가 작동했다.

실제 10출력 재생에서는 **10개 모두 보류**됐다. 비핵심 판정 차이까지 엄격하게 막는 규칙은 안전해 보이지만 실용적인 자동 편집 해법이라고 할 수 없다. 이 결과도 실패/한계로 남긴다. 원문 복구는 원문에 있던 오류나 누락을 해결하지 않는다. 이 10개 결정은 새 모델 출력도, 개선된 품질 점수도 아니다. `RELEASE-GATE.md`와 원장에 제안본·전달본 해시와 사유를 보존했다.

## 합성 최소쌍·정상 문장 대조

H0는 일반 근거 대조, H1은 후보를 보기 전에 별도 작성한 원문 질문·답을 추가하고 양방향 반례를 검사하는 절차다. H1에는 추가 입력·전처리가 있고 한국어 사례에도 영어 보조 QA가 들어가므로 같은 입력 길이에서 순수 지시 효과를 검증한 것은 아니다.

개발 3기반·평가 3기반으로 쌍을 분리했다. 각 절차는 개발 6문장과 평가 6문장을 각각 6/6 기대 판정으로 구분했다. 합계 조작 문장 12회는 별도 검토에서 모두 수정됐고, 정상 문장 12회는 모두 무수정이었다. 두 정상 사례에는 정당한 비판도 포함됐다. 새 오류·과잉수정은 이 작은 검사에서 확인되지 않았다.

두 절차 모두 같은 결과이므로 H1의 추가 가치는 입증하지 못했다. 일부 조작문은 내부 긴장이나 명백한 귀속 모순이 있어 쉬운 단서가 됐을 수 있다. 실제 기사의 미지 오류 탐지율·정치적 편향·독자 신뢰를 측정한 결과가 아니다.

루트 실행자가 합성 평가 라벨 일부를 동결 전에 실수로 보았지만 원문/후보는 보지 않았다. 이를 기록하고 합성 절차는 변경하지 않았다. 각 탐지 역할의 문맥에는 라벨이 제공되지 않았다. 루트까지 완전 맹검이었다고 주장하지 않는다.

### 자료 범위와 표현 손실은 같은 문제가 아니다

같은 과학 기사와 B-v2 절차에서 기존 원자료 19문단과 Results·통계 방법·일부 확장 그림 설명을 포함한 62문단을 비교했다. 각 조건은 별도 문맥에서 두 번 생성하고 두 명씩 평가했다. 기존 19문단은 확장 입력의 동일한 접두부이며 질문·기사·분량·절차는 같다. 다만 자료량과 주의 부담이 함께 늘어 자료 내용만의 효과로 분리할 수 없다.

확장 조건 2/2는 저활동 구간 하한을 3,000에서 **3,001걸음**으로 원논문에 맞게 바로잡았다. 기존 입력에서 이 경계를 확인하지 못한 것은 그 자료로 알 수 없었던 사항이며 새 근거를 소급해 이전 오류로 채점하지 않았다. 반면 저활동과 중활동의 정성적 비교는 기존 자료 조건도 2/2, 확장 조건도 2/2에서 보존됐다. 이전 손실을 자료 부족 하나로 설명할 수 없고 같은 절차의 실행 변동도 남는다.

확장했다고 모든 문제가 사라지지는 않았다. 인과적인 개입 효과를 암시하는 도입부가 확장 2/2와 기존 1/2에서 잔존한다는 검토가 있었고, 기존 조건 한 출력의 일반화 가능성 강도에는 평가자 이견이 있었다. 이런 잔존 표현과 새로 생긴 오류는 구분했다. 정성적 비교가 원문에 있다는 사실과 두 집단 간 직접 유의성 검정은 같지 않다. 여섯 평가 차원은 생성 전에 고정했지만 상세 평가 지시 파일의 잠금은 작성 시작 및 기존 조건 첫 출력 완료 뒤였다. 당시 출력을 열지 않았다는 실행 기록은 있으나 독립 인증은 아니다. 상세 판정은 `supplementary/scope/RESULTS.md`와 원장에 보존했다.

### 원문 의미 손실·필수 답 누락·선택 맥락을 분리한다

새 가상 반례 3쌍에서 자료와 후보를 그대로 두고 독자 질문만 바꾸거나, 원문에 있던 조건 하나만 삭제했다. 각 문항을 두 번 독립 분류했다. 12개 출력 모두 사전의 잠정 기대와 일치했으며, 인용 47개는 지정 입력의 정확한 부분 문자열이었다. 이는 명시적으로 제공한 구분을 작은 가상 문항에서 적용한 결과이지 일반 기사 성능이나 인간 정답 대비 정확도가 아니다. 실제 재작성은 생성하지 않았다.

예를 들어 가상 공동작업실 기사가 사업 시작과 예약 창구에 대한 참여자 비판을 모두 보존한다면, 사업 요지를 묻는 질문에는 신청 자격을 추가하지 않아도 된다. 질문이 신청 자격으로 바뀌면 같은 후보에 답을 추가해야 하지만 **원문 의미 손실**로 분류하지 않는다. 반대로 원문에 있던 ‘안전교육을 이수한 경우에만’을 삭제하면 사용 가능 대상을 넓힌 것이므로 실제 의미 손실이다. 상세 입력·분류·잠정 기대는 `supplementary/necessity/RESULTS.md`와 공개 합성 자료에 담았다.

### 발견한 사실을 최종 본문으로 옮기는 별도 회귀 검증

이미 노출된 영국 금리 B 수정본에, 빠졌던 두 사실을 같은 내용으로 명시했다. F는 일반 문장, T는 행위자·시점·지표·비교대상·양태 표 형식이며 각각 두 번 생성했다. 기사·원자료·질문·수정 요구·분량은 같고 표현 형식만 달랐다. 기존 출력과 달리 두 사실을 반드시 본문에 넣으라는 목표를 두 조건 모두 받았으므로, 이전 실패 대비 효과를 표 형식이나 일반적 발견 능력으로 돌릴 수 없다.

네 출력 모두 두 사실을 실제 본문에 넣었고, 각 출력을 별도 두 명이 평가한 8개 결과 모두 근거가 지지하는 2/2 회복으로 판정했다. 총 8개 수정은 정확히 적용됐다. 이 검토에서 새 본문 손상은 확인되지 않았지만 기존 본문에 남은 미검증 주장까지 참이라고 인증한 것은 아니다. 원자료의 세계 대비 비교는 앞 문맥과 연결해 해석해야 한다는 근거 해석상의 주의가 남았다. T의 한 출력에서는 본문 밖 Q3 답변의 시간 표현에 경미한 우려가 남았다. 본문과 감사 답변을 구분해 원판정을 보존했다.

수정 전에는 가계가 물가 상승을 우려할 수 있다는 전망만 있었고, 수정 후에는 **은행이 최근 가계 기대인플레이션 지표가 실제로 올랐다고 보고했다**는 관측을 별도 문장으로 넣었다. 또 세계 경기 둔화에 대한 재무장관 경고를 그대로 두고, **은행은 영국 성장과 물가에 미칠 부정적 영향이 세계적 영향보다 작을 가능성이 있다고 판단했다**는 비교·유보를 붙였다. 실제 원문에서는 관측/전망, 은행/장관, 영국/세계의 구분을 유지했다.

이는 알려진 두 누락에 대한 국소 복구다. F와 T가 모두 성공했으므로 구조화 표의 추가 효과는 입증되지 않았다. 새 사례·미지 오류 탐지·일반화 검증이 아니며 본 실험 평가 점수도 고치지 않는다. 상세 기록은 `supplementary/transfer/RESULTS.md`에 있다.

| 문제 | 이번에 확인한 것 | 아직 해결하지 못한 것 |
|---|---|---|
| 보호 정보 목록 | 원자료 선행 표와 독립 원문 검토로 중복·과도한 필수화·조건을 드러낼 수 있었다. 추가 원문 수집으로 특정 미확인을 해소했다 | 목록 완전성, 필수성, 수집 범위의 충분성을 보장하지 못함 |

| 평가 재현성 | 원판정·불일치·근거를 보존하고 발견/본문 회복을 분리해 잘못된 성공 집계를 막음 | 같은 계열 AI의 공통 오판, 필수성·암묵적 의미·강도 판단 불일치. 인간 검증 없음 |

바로 적용할 절차는 `USER-PROCEDURE.md`에 있다. 중대한 의미 손실·근거 없는 강화·중요한 불일치가 남으면 자동 적용을 중단하고 원문과 문제 설명을 남긴다. 필수 정보를 담을 분량이 부족하면 몰래 생략하지 않고 길이 증가 필요를 표시한다. 이것은 사용상의 중단 기준이며 이번 실험이 완전한 의미 보존을 보장했다는 뜻이 아니다.

## 연구 근거와 적용 한계

[QuestEval](https://aclanthology.org/2021.emnlp-main.529.pdf)에서 원문→요약의 회복 방향과 답이 있다는 것만으로 정답이 되는 것은 아니라는 문제를 참고했다. 훈련된 질문/응답 모델이나 원 논문의 지표를 재현하지 않았다.

[SummEdits](https://aclanthology.org/2023.emnlp-main.600.pdf)의 검증된 원문·작은 변경·경계 사례 구분을 참고해 합성 최소쌍을 만들었다. 원 벤치마크나 인간 라벨링을 재현한 것은 아니다. [FaithBench](https://aclanthology.org/2025.naacl-short.38.pdf)의 불일치 중심 어려운 표본과 일반 표본의 차이를 참고해 본 실험 실제 출력 10개에 제3 감사를 붙였다. 서로 다른 모델 계열의 합의 실험은 아니다.

[CommitmentBank](https://aclanthology.org/P19-1412/)와 [MoNLI](https://aclanthology.org/2020.blackboxnlp-1.16/)는 발언 강도와 작은 논리 변경에 대한 반례 점검의 참고다. 근거 있는 실제 오류 수정까지 원문과 동치여야 한다고 요구하지 않았다.

## 측정·실행 통제·남은 제약

자료 수집·생성·평가·보충 리서치는 서로 다른 단계다. 파일 수와 내용 해시는 확인했지만 실제 내부 모델 호출·재시도·지연·비용을 인증하는 로그는 아니다. 본 실험 작성자 10개 중 개별 시작/종료 기록은 하나만 남아 있어 조건별 시간·비용 효율을 비교하지 않는다. 보충 작성자 8개의 작업 시작·종료 시각은 별도로 남겼지만 API 지연·모델 연산 시간·비용이 아니며 겹친 실행 시간을 합쳐 전체 경과로 해석하지 않는다. 추정 비용을 측정값으로 제시하지 않았다.

처음 정한 사건·질문·기준을 바꾸는 대신 이견을 별도 기록했다. EN 개발/평가 주제 배정은 결과 전이지만 엄격한 확보 순서는 아니며, 평가 표시 순서도 완전 무작위가 아닌 고정된 교차 배정이었다. 정확한 배포버전·시드·런타임 변동을 통제하지 못한 한계는 작은 실험으로 사라지지 않는다.

서로 다른 해결법을 10개 시험한 것이 아니다. 본 실험 비교는 일반 감사와 역방향 검사, 한 번의 수정 경계 보완, 별도의 합성 H0/H1이다. 보충 모듈의 자료 범위·질문별 필요성·표현 형식 비교는 각각 구분한다. 반복 실행이나 사례 수를 ‘10가지 접근법 실패’로 바꾸지 않는다.

## 재실행·자료 보존

원기사·원자료·원출력·평가 원본은 `/historical-research/journal-v12-private`에 보존했다. 기존 출력이나 평가를 덮어쓰지 않았다. 공개 패키지는 원문 링크·해시·범위, 자체 프로토콜·코드·집계, 합성 원자료와 원출력, 짧은 실제 사례 분석을 담는다. 수집한 기사/논문 전문과 긴 발췌는 포함하지 않는다. 따라서 공개 패키지만으로 자연어 원문 실험 전체를 그대로 재현할 수 있다고 주장하지 않는다.

로컬 전체 자료가 있는 환경에서는 `code/validate_artifacts.py`, `code/summarize_reviews.py`, `code/output_lengths.py`로 무결성과 집계를 재계산한다. 이 스크립트는 저장된 응답을 검사할 뿐 새 모델 응답을 생성하지 않는다. 새 생성은 입력별 별도 문맥을 열어 고정 지시를 실행하고 원출력을 저장해야 한다. API 자동실험과 동일하지 않다. 재사용한 평가 사례는 이후부터 회귀 사례로 표시한다.

공개 패키지의 `code/verify_public_package.py`는 패키지 해시와 합성 수정 재생을 확인한다. 다른 환경에서는 원문을 정당한 접근 경로로 다시 확보하고 해시·범위를 확인해야 한다. 원문이 달라졌다면 새 입력 버전이며 같은 실험이라고 조용히 합치지 않는다.

후속 우선순위는 (1) 독자의 구체 질문으로 필수성과 선택 맥락을 먼저 구분하기, (2) 미확인 때문에 수정 결정을 못 하는 지점에서 필요한 원자료 구간을 추가 확보하기, (3) 발견→수정 계획→최종 본문의 연결 누락 점검, (4) 사람 또는 다른 모델 계열의 근거 감사다. 이번 회차에서는 이들을 검증된 일반 해법으로 보고하지 않는다.

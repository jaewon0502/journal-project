# Supplementary necessity distinction protocol

This separate supplementary module contains three independent, newly invented Korean bases with two minimal variants per base: six items. These are six synthetic items, not new real cases. All institutions, programs, policies, and factual details are hypothetical. No old real case or hidden fixture was recreated. The original frozen synthetic suite and existing experiments are unchanged.

The controlled factor in two pairs is only the fixed reader question: a broad news-gist question versus an explicit eligibility or duration question. Within each such pair the full source, original article, and candidate are byte-identical. The third pair holds source, original article, and reader question fixed, and only deletes one material condition from the candidate. The module includes a faithfully attributed critical statement as a normal control. Pair membership and provisional expectations stay private.

Each detector receives only an opaque item ID, a fiction notice, full source, original article, candidate, fixed reader question, and a constant classifier prompt and output schema. It receives no expected labels, pair mapping, rationale, or result-bearing filename. Detector inputs reside in the private workspace; only this protocol and content hashes are public. Public visibility of a hash does not publish its underlying content.

The fixed output fields separately assess `source_meaning_error`, `original_meaning_loss`, `required_answer_missing`, and `optional_context_absence`, plus `decision` (`accept`, `patch`, or `hold`), quoted `evidence`, and `reason`. Omission of a source-only fact can require a patch when that fact answers the fixed question without becoming original-meaning loss. Optional source context alone does not require a patch. Material condition removal can change source meaning as well as lose original meaning. Faithful attributed criticism is not an error simply because it is critical.

Two fresh independent classifications per item are planned, for 12 classification outputs. Each call will use a fresh context, the same frozen prompt/schema, and only that item's detector input. No classification outputs have been produced as part of creating this module. The independent validator must first record and commit its own answers from source/candidate/question and original article before receiving provisional author labels. Author labels are AI-authored hypotheses for comparison, not validated ground truth. Later disagreements must remain visible; do not silently replace the frozen author expectations.

This is a controlled supplementary counterexample module. It supports no method-performance, real-world prevalence, generalization, accuracy, or improvement claims. Six items and 12 planned outputs are distinct counts, and future model calls must not be presented as independent real cases.

The private manifest freezes SHA-256 digests of every input, source/task-only collection, author-label file, and this protocol. The manifest itself is frozen in `freeze.sha256`. A separate public `input-hashes.json` exposes only opaque input filenames and hashes. No detector or validation run should proceed on modified bytes under this freeze.

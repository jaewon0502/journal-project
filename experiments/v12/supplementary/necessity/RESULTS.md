# 보충 실험: 원문 보존과 질문에 필요한 답의 구별

이 모듈은 **새로 만든 가상 문항 6개, 독립 가상 기반 3개, 최소대조 쌍 3개, 분류 출력 12개**를 사용한 통제된 기제 점검이다. 새로운 실제 사례는 0개이며, 12개를 서로 독립적인 사례로 세지 않는다. 실제 재작성 결과물을 생성하거나 수정 성공을 평가하지 않았다. `patch`는 수정 필요 판정이다. 기존 본 실험의 자료·분모·성능 지표는 바꾸지 않았다.

네 불리언과 최종 결정의 전체 조합이 12개 출력 모두 사전의 잠정 기대와 일치했다. 그러나 이는 AI가 작성한 기대와 AI 분류의 일치이며, 인간 정답 대비 정확도나 방법의 성능 향상 근거가 아니다. 아래 반례는 “원문 의미를 보존했으므로 충분하다”와 “자료에 없는 내용은 모두 보완해야 한다”라는 두 판단을 구분하기 위한 것이다. 모든 기관·사업·조건은 이 실험을 위해 지어낸 설정으로, 실제 제도나 법적 요건을 설명하지 않는다.

## 판정 기준과 사전 고정

- `source_meaning_error`(S): 자료와 모순되거나 중요한 조건 삭제로 주장을 넓힘. 자료 일부의 단순 부재만으로는 해당하지 않는다.
- `original_meaning_loss`(O): 원문에 실제 있던 중요한 의미·조건·귀속을 잃음. 원문에도 없던 자료의 추가 정보 누락과 구분한다.
- `required_answer_missing`(R): 고정된 독자 질문에 필요한, 자료에 명시된 답이 후보에 없음.
- `optional_context_absence`(C): 후보에 없는 자료의 추가 사실 중 원문 보존과 해당 질문에 필요하지 않은 사실이 있음. 같은 빠진 사실을 필수와 선택으로 중복 계산하지 않는다.

S·O·R이 모두 거짓이면 `accept`이며 C만 참인 경우 수정하지 않는다. 세 오류 중 하나라도 참이고 자료로 수정 가능하면 `patch`, 자료만으로 핵심 판정이나 수정을 확정할 수 없으면 `hold`다. 충실하게 귀속된 비판은 부정적인 내용이라는 이유만으로 오류가 아니다. 이 정의는 분류 전 고정된 프롬프트에 명시되었으므로, 구분을 자발적으로 발견했는지 시험한 실험은 아니다.

매니페스트 자체의 SHA-256과 매니페스트에 포함된 10개 파일의 해시·바이트 수가 모두 일치했다. 여섯 입력의 프롬프트·스키마는 같고, 입력에는 기대 라벨·쌍 정보·해설이 없었다. 두 쌍은 자료·원문·후보가 바이트 단위로 같고 질문만 다르다. 나머지 한 쌍은 자료·원문·질문을 고정하고 후보의 안전교육 조건만 정확히 삭제했다. 사전 검증 기록에는 검증자가 기대 라벨을 받기 전에 자신의 판정을 저장하고 분류 출력을 보지 않았다고 기재되어 있다. 해당 기록의 여섯 판정은 잠정 기대와 일치하며 사전 모호성 표시는 0개다. 이 순서는 저장 기록에 근거하며 검사 코드가 실행 이력을 독립 인증하지는 않는다.

각 문항의 A/B 출력 두 개씩을 확인했다. 실행 담당자는 실제 `native independent-context invocation` 호출에서 `review-role-a1`~`a6`, `review-role-b1`~`b6`를 각각 `context_inheritance=none`으로 실행했다고 보고했다. 번호는 입력 파일명 정렬 순이며 별도 모델·추론 노력 재정의는 없었다. 이는 역할을 분리한 실행 기록이며 독립 인증은 아니다. 출력 JSON 자체로는 새 문맥 격리, 난수 시드 또는 정확한 모델 버전까지 증명할 수 없다.

## 같은 후보인데 질문에 따라 달라지는 반례

**쌍 1: 신청 대상과 귀속된 비판.** 전체 자료는 다음과 같다.

> 새봄시는 동네 작업실 공동이용 사업을 시작했다. 참여 단체들은 예약 창구가 하나뿐이라 이용이 불편하다고 비판했다. 신청 대상은 새봄시에 등록된 비영리 동아리다.

원문과 두 후보는 다음 문장으로 동일하다.

> 새봄시는 동네 작업실 공동이용 사업을 시작했다. 참여 단체들은 예약 창구가 하나뿐이라 이용이 불편하다고 비판했다.

질문 A는 “어떤 사업이 시작됐고 참여 단체들은 무엇을 비판했는가?”다. 후보가 답을 모두 담아 S=O=R=거짓, C=참, `accept`다. 질문 B는 “이 사업의 신청 대상은 누구인가?”다. 같은 후보에 필요한 답 “새봄시에 등록된 비영리 동아리”가 없어 R=참, C=거짓, `patch`로 바뀌지만 S와 O는 여전히 거짓이다. 원문에도 없던 사실이므로 원문 의미 손실이라고 부를 수 없다. 두 반복 모두 이 구분을 유지했다.

이 쌍은 정상 비판 통제도 겸한다. 후보의 “참여 단체들은 예약 창구가 하나뿐이라 이용이 불편하다고 비판했다.”는 자료의 주체·이유·귀속을 그대로 보존한다. 요지 질문에서는 두 반복 모두 `accept`였고, 신청 대상 질문의 `patch`도 비판의 삭제·완화 때문이 아니라 필요한 신청 대상의 누락 때문이다. 이것은 해당 통제에서 관찰된 구분이며, 일반적인 비판 보존 성능의 추정이 아니다.

**쌍 2: 대여 기간.** 전체 자료는 다음과 같다.

> 달여울문화관은 주민에게 휴대용 녹음기를 빌려주는 소리채집 사업을 시작했다. 문화관은 주민이 동네의 소리를 기록하도록 돕는 것이 목적이라고 밝혔다. 녹음기 대여 기간은 대여일부터 12일이다.

원문과 두 후보는 위 자료의 첫 두 문장으로 동일하다. 질문 A “문화관이 시작한 사업은 무엇이며 그 목적은 무엇인가?”에서는 C만 참이고 `accept`다. 질문 B “이 사업에서 녹음기를 며칠 동안 빌릴 수 있는가?”에서는 빠진 “대여일부터 12일”이 필수 답이 되어 R만 참이고 `patch`다. S와 O는 두 질문에서 모두 거짓이다. 두 반복 모두 같은 결과였다.

**쌍 3: 원문에 실제 존재한 조건의 삭제.** 자료·원문·정상 후보는 모두 다음과 같다.

> 별모래제작소는 등록 회원이 안전교육을 이수한 경우에만 공용 절단기를 사용할 수 있다고 안내했다.

질문은 “누가 어떤 조건을 충족해야 공용 절단기를 사용할 수 있는가?”로 고정했다. 대조 후보는 “별모래제작소는 등록 회원이 공용 절단기를 사용할 수 있다고 안내했다.”다. 정상 후보는 네 값 모두 거짓, `accept`다. 조건을 삭제한 후보는 S=O=R=참, C=거짓, `patch`다. 이 경우는 원문에 실제 있던 조건을 잃고 허용 대상을 넓히므로 앞선 자료 전용 사실의 누락과 다르다. 두 반복 모두 이 구분을 유지했다.

## 전체 결과와 인용 검사

각 행은 한 문항이며 A/B 열은 각각 한 번의 분류다. 0은 거짓, 1은 참이다. 튜플 순서는 S, O, R, C다.

| 문항 / 입력 ID | 사전 잠정 기대 | A | B |
|---|---|---|---|
| 1-A 요지 / `285cf1155fdc3469d7ee6681` | 0001 / accept | 0001 / accept | 0001 / accept |
| 1-B 신청 대상 / `696e705f4d8426a7a1e00fc3` | 0010 / patch | 0010 / patch | 0010 / patch |
| 2-A 요지 / `f09b014f3d4927e89ac2bb38` | 0001 / accept | 0001 / accept | 0001 / accept |
| 2-B 대여 기간 / `0ce5a7e0ec02731911b92d52` | 0010 / patch | 0010 / patch | 0010 / patch |
| 3-A 조건 보존 / `0e0d2a253a6004ba748256e3` | 0000 / accept | 0000 / accept | 0000 / accept |
| 3-B 조건 삭제 / `206a6e985b3915af8102500c` | 1110 / patch | 1110 / patch | 1110 / patch |

S·O·R·C·결정 각각 잠정 기대와 12/12 일치했고, 전체 다섯 필드 조합도 12/12 일치했다. A/B의 다섯 필드 조합은 6/6 문항에서 같았다. 관찰된 부분 불일치는 없으며, 특히 필수 답 누락과 선택 맥락 누락의 중복 표시도 없었다. 사전 기대를 결과에 맞춰 수정하지 않았다. 향후 기대가 논쟁적이면 모호성으로 남겨야 하며 기대를 바꿔 일치를 회복해서는 안 된다.

출력 12개 모두 고정 JSON 스키마에 적합했다. 근거 인용 47개 모두 자신이 지정한 `source`, `original_article`, `candidate`, `reader_question` 필드의 **비어 있지 않은 정확한 부분 문자열**이었다(47/47). 인용문 위치 일치는 의미적 정당성의 자동 증명이 아니다. 위 쌍별 대조와 설명은 어떤 사실이 원문에 있었는지, 어떤 질문에 필요한지, 실제 조건 삭제인지도 별도로 검토한 것이다.

## 재현과 해석의 범위

[results.json](results.json)은 문항별 네 불리언·결정·기대 대비 차이, 출력 해시, 47개 인용문의 필드와 정확성, 쌍별 변경 필드, 실행 이력의 한계를 포함한다. [검사 코드](../../code/check_necessity.py)는 Python 3 및 `jsonschema`가 필요하며 다음으로 실행한다.

```bash
python /historical-research/journal-v12/code/check_necessity.py
```

원본의 고정 파일 검증에는 비공개 입력·매니페스트·분류 출력에 대한 접근이 필요하다. 공개 보고서는 위 가상 텍스트와 결과만으로 논리적 대조를 검토할 수 있지만, 공개 산출물만으로 비공개 바이트 고정이나 실행 격리를 모두 재현할 수 있다고 주장하지 않는다.

이 관찰은 정의를 명시한 짧은 가상 입력에서 원문 보존·질문별 필요 정보·선택 맥락·귀속된 비판을 분리할 수 있었음을 보여준다. 적은 독립 기반, 쌍 내부 공유 문장, AI 기대·AI 검증, 명시적 지시 때문에 실제 기사 분포·일반화·정확도·편집 품질 개선·실제 수정의 성공으로 확장할 수 없다. 기존 본 실험의 수치와 결합하거나 그 성능 지표를 갱신하지 않는다.

# Source-scope 보조 실험 결과

확장 자료 조건의 두 실행은 저활동 구간 하한을 3,000에서 3,001걸음으로 근거 있게 교정했다. 그러나 저활동–중활동의 정성적 관계는 OLD에서도 2/2 보존됐다. 자료 확대가 이 관계 보존에 필수였다는 결과가 아니다. 인과적 도입부와 표현 강도의 잔존 문제는 별도로 남았다.

EN-DEV 한 기사에 고정 B-v2 절차를 적용한 노출된 회귀 진단이다. OLD·EXPANDED 각 두 독립 실행이며, 새로운 미지 사례 탐지 실험이 아니다. 기사·질문·공통/방법 지시·출력 스키마·900단어 한도는 일치하고, 기존 근거 19문단은 확장 근거 62문단의 동일한 접두부다. 의도한 변화는 허용 자료 범위와 그 출처 메타데이터다. 준비 잠금 9개 파일 및 평가 지시 해시가 일치했다. 평가 지시의 형식화 시점은 작성자 실행 시작 뒤였으며, 잠금 기록은 당시 보조 출력 미열람을 명시한다. 여섯 차원 자체는 생성 전 프로토콜에 있었다.

실행 시작 순서는 OLD-1 → EXPANDED-1 → EXPANDED-2 → OLD-2이고 실행 구간은 겹친다. 런타임·모델·추론 설정은 모두 상속이라고 기록됐으나 정확한 식별자/설정은 알 수 없어 완전한 동일성을 독립 검증할 수 없다. 본 v12의 입력·방법·출력·점수는 수정하지 않았다.

|---|---:|---:|---:|---:|---:|
| OLD-1 | 7 / 모두 적용 | 89초 | 688 | 5,163 | 13,291 |

경과 시간은 각 clock 메타의 UTC 종료−시작이며 API 지연이나 비용이 아니다. 동시 실행 시간을 합쳐 전체 실험 경과로 해석하면 안 된다. 네 출력 모두 동일한 `code/output_lengths.py` 필드 규칙으로 재계산했다. 설명·중요성·상태·한계, 패치의 대체문과 근거 설명, 질문 답변과 미해결 범위를 포함하고 원문 before·앵커·ID·JSON 키는 제외한다. 대체문은 복사된 부분도 센다. 모두 900단어 이내다. OLD-1 자체 메타의 652단어 대신 공통 규칙 재계산값 688을 사용했다. 나머지 자체 단어 수, API 비용·버전·시드는 미상이다.

**공통 보호 명제.** 네 실행 모두 저구간과 그에 연결된 tau·인지 결과, 저–중 정성적 순서, tracker의 저자 귀속과 가능성 표현을 보존했다. OLD-2의 저구간 결과/비교 연결은 앞 문단을 통한 암묵적 표현이라 덜 명시적이다. 양 조건 모두 기저 amyloid 조건을 2/2 추가하고 추적 중 amyloid 축적과 구분했다. 결과 간 효과량이나 유의성 전이는 양 조건 0/2이며, 평가자별 패치 부수손실 판정도 모두 없음이다. 기능 결과는 원 기사에서 따로 보고되지 않았으므로 새 자료에서 보인다고 반드시 추가할 의무가 생기지는 않는다.

**추가 근거로 가능해진 교정.** EXPANDED는 저구간 3,001–5,000의 정의와 비활동군 기준을 사용해 두 번 모두 수치 교정했다. OLD의 정확한 하한은 허용 자료에 없어 평가 불가이며, 기존 수치의 유지나 미교정을 실패 분모에 넣지 않았다. OLD-1은 기존 수치를 유지하고 OLD-2는 기사 보고임을 한정했다. 두 확장 실행의 허용 표 EN-DEV-S-P044는 저활동 대 비활동 비교에서 tau P=0.03, 인지 P=0.02, 기능 P=0.11을 구분한다. 이는 저–중 직접 쌍대 유의성 검정이 아니며, 기능의 비유의성은 무연관 입증도 아니다. 네 실행 어느 것도 직접 저–중 유의성이나 tau 백분율을 새로 만들어내지 않았다. EXPANDED-1은 Q3 답변에서 기능 비교의 비유의성을 구분했지만 기사에 기능 수치를 추가하지 않았다. 자료를 답변에서 이해한 것과 기사에 적용한 것을 구별했다.

**잔존 인과·범위 문제.** OLD-1은 도입부까지 수정했고 OLD-2는 도입부의 걷기 개입 함의를 남겼다. EXPANDED 두 실행은 본문을 고쳤지만 제목과 도입부의 질병 진행 억제·충분성·손쉬운 개입 함의를 남겼다. 분석상 잔존 도입부 문제는 OLD 1/2, EXPANDED 2/2다. 이 수치는 별도의 관찰 설명이지 새 성공 점수가 아니다. 특히 EXPANDED-1의 두 평가자는 이 문제를 설명하면서도 인과 차원을 정당변경으로 분류했고, EXPANDED-2는 모두 부분으로 분류했다. 원 판정과 잔존 설명을 동시에 보존했다. 두 OLD 작성자의 REFUTED 표현도 인과효과 미입증을 반증으로 과장한다는 평가를 별도 남겼다. 패치 이후 기사가 나아졌다고 작성자 판단의 과장이 사라지지는 않는다.

**불일치와 양태.** OLD-1 P7의 일반화 가능성 표현을 A는 지지되는 교정으로 봤지만 B는 가능성에서 단정으로 강해진 작은 문제를 지적해 부분 교정·근거 없는 강화로 기록했다. tracker 자체의 가능성·귀속 보존에는 둘 다 동의했다. 자료에 tracker 권고가 없다는 사실은 원 기사의 귀속된 가능성 주장을 거짓으로 만들지 않는다. 그 유지도 tracker 효능을 검증했다는 뜻은 아니다. 표의 보존/정당변경 및 근거 분류 차이, 패치 ID 차이, 세부 근거 역량 판정은 공개 JSON에 평가자별로 그대로 남겼다.

OLD 내 도입부 교정 차이와 EXPANDED 내 5개/3개 패치 차이는 동일 조건에서도 실행 변동이 있음을 보여준다. 정확한 저구간 교정은 자료 확대와 일관되게 동반됐지만, 전반적인 보존·인과 교정의 향상을 확정하지 않는다. 근거의 정보량과 입력 길이(30,632→64,713바이트)/주의 배분 효과는 이 설계로 분리되지 않는다. 한 노출 사례·조건당 두 번으로 유의성, 일반 성능 보장 또는 확정적 인과효과를 주장하지 않는다.

재현: `python /historical-research/journal-v12/code/analyze_scope.py`. [공개 원장](results.json)은 4×2×6 차원의 원 판정, 앵커/근거 ID, 패치별 평가, 조건별 평가자 분포, 시간과 길이를 담는다. 전체 평가 근거는 비공개 `journal-v12-private/supplementary/scope/analysis-evidence-summary.json`에 보존했다. 남은 한계는 정확한 실행 설정·API 계측의 부재, 단일 사례와 적은 반복, 자료 길이 교란이며 추가 작성·수정·재평가는 수행하지 않았다.

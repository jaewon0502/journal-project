# Journal v12 공개 실험패키지

REPORT.md는 한국어 종합 보고서, USER-PROCEDURE.md는 바로 적용할 짧은 절차다. 최초 동결 실험과 사용자 요청 후 보충 실험은 분리되어 있다. 원점수는 소급 변경하지 않았다.

포함: 자체 프로토콜·해시·수집범위·코드·평가 집계, 가상 최소쌍의 전체 입력/원출력/평가, 실제 사례의 짧은 자체 분석. 미포함: 수집한 자연 기사·논문 전문 및 긴 실제 원출력 인용. 이 원본은 작업 환경의 비공개 폴더에 보존했고, 파일명/해시만 공개한다.

압축을 푼 폴더에서 `python3 code/verify_public_package.py .`를 실행하면 패키지 해시와 저장된 합성 수정 24개를 재생한다. 모델을 호출하거나 의미의 참/거짓을 새로 판정하지 않는다.

다른 분석 스크립트는 실행 당시 `/historical-research/journal-v12`와 `/historical-research/journal-v12-private` 경로를 전제로 한다. 원문 포함 로컬 자료가 있는 환경에서 기존 집계 재검산에 사용한다. 경로가 공유됐다고 가정하지 않는다. 공개 ZIP만으로 자연 기사 실험의 완전 재현을 약속하지 않는다.

새 모델 실행은 정확한 입력·지시를 별도 문맥에 전달해 원응답을 저장해야 한다. 이 회차는 지원되는 하위 에이전트 기능을 사용했으며 API 자동실험이 아니다. 배포버전·시드·비용과 내부 호출 수를 통제하지 못했다. 재사용 사례는 이후 미사용 평가라고 부르지 않는다.

모든 평가자는 AI다. 원자료의 발언과 실제 사실, 원문 의미 보존과 질문에 필요한 추가 정보, 부분 지지와 미확인, 확인된 실패와 해석 이견을 구분한다. 합의가 정답을 보증하지 않는다.

## 남은 오류·평가 문제를 그대로 공개

**공동 승인 뒤 발견된 시간관계 문제.** REG_EN023 일반 최소편집은 원문의8월22일 기록 사건을 공식자료의8월24·25일 최고값으로 대체했다. 공식자료는 새 값/날짜를 지지하지만22일에도 앞선 기록이 있었는지 완전히 해결하지 않는다. 같은 시계열인지, 직전 기록 서술이 모든 중간 기록을 배제하는지, 동률인지가 남는다. 두 일반 평가자는 동일 출력에 성공을 부여했다. 별도 표적 근거 감사는 삭제가 입증된 정정이라고 볼 수 없다고 판단했다. 원판정은 고치지 않았으며 이의를 별도 이의 기록로 보존했다. 이는 동일 런타임 평가의 공동 승인 사례이지, 다른 모델들도 같은 오류를 냈다는 실험 결과나 외부 진실 기준 공동오답률이 아니다.

**검사 주석 전달의 새 문제.** 동일한 미해결 오류 주석을 두 복원 조건에 전달했는데, KO011 원복 출력의 주석에는 제안patch가 단위를 고친다는 문구가 남아 있었다. 평가자B는 이를 실제 전달본문도 수정됐다는 오해를 낳는 경미한 문제로 판정했고A는 그렇게 판정하지 않았다. 원출력/원판정은 보존했다. 수정 적용상태를 반영한 주석 생성이 다음 최소 보완이다. 이번에 결과를 본 뒤 주석을 다시 써 재채점하지 않았다.

**단일 성공값의 한계.** 두 평가자의 최종 task_resolution은18고유출력 모두 일치했지만,7세부축×18=126비교에서9개 판정은 달랐다. 예를 들어 원문 전체의 외부 사실 근거는 unknown인데 국소 수정은 success일 수 있고, 기존 시간 오류가 남아도 다른 단위 수정이 성공일 수 있다. 따라서 이 성공값을 완전 정확성이나 보존율로 합치지 않았다. 일치 자체를 정답으로 삼지 않았다.

## 다른 모델도 함께 놓칠 오류에 관한 리서치와 실행 경계

Correlated Errors in Large Language Models는 서로 다른 공급자·구조도 오류 독립성을 보장하지 않는다고 보고한다. 해당 연구의 벤치마크·채용 및 평가실험 결과를 우리 한국어/영어 기사 오류율로 옮기지 않는다. https://arxiv.org/html/2506.07962v1

FRANK는 사실성의 단일 이진값 대신 오류 유형별 분석의 필요성을 보여준다. 이번에 발언 기록 충실도·외부 근거·시간/조건·의존성·미해결 오류 공개를 나눈 것은 그 방향을 실제 실패에 적용한 설계 선택이다. https://aclanthology.org/2021.naacl-main.383/

DeepFact의 초록은 근거를 제출하고 감사한 뒤 버전 있는 기준을 갱신하는 방식을 설명한다. 우리는 원판정을 소급 덮어쓰지 않고 이의 기록을 분리했다. 논문의 전문가 성과를 우리의 인간 검증으로 부르지 않는다. https://aclanthology.org/2026.acl-long.1586/

위 원문/초록을 실제 열어 확인했으며 전체 문헌체계 검토는 아니다. 다른 모델의 추가효과를 보려면 동일 source/candidate/evidence/rubric을 실제 서로 다른 공급자/계열에 고정하고 model/provider/version/endpoint를 기록해야 한다. 별칭 변경·새 문맥·평가자 수 증가만으로 cross-family라고 부르지 않는다. 앞으로의 진단안은 KO6/EN6 고정 사례, 실제3계열×2독립판정이며 지금은 실행0건이다. 근거가 빠진 입력은 공동오답률 대신 공동승인·판정변동·추가발견만 보고해야 한다. 전원 승인 사례도 근거 감사 표본에 포함한다. 필요시4사례에서 핵심근거제거/무관근거제거를 구분하는 후속 실험을 제안하지만 이번에는 수행하지 않았다.

다른 공급자·모델 계열에 대한 실제 비교 실행은 0건이다. 접근 경로의 미확보와 개념적 난도는 구분한다.

## 바로 쓰는 절차와 중단 기준

발언 기록과 외부 사실을 별도 열로 적는다 → 같은 대상/지표/기간인지 대조한다 → 원 발언은 남기고 필요한 근거 주석만 붙인다 → 수정끼리 의존 관계를 표시한다 → 의존 묶음별 적용/보류 후 전체 원문과 양방향 대조한다 → 실제 적용된 수정과 남은 문제를 독자에게 분리해 표시한다.

근거로 원 발언을 반박할 수 없거나, 수정 관계를 판단할 수 없거나, 최종 출력과 검사 hash가 다르면 적용을 중단한다. 완전한 보존이 분량 안에 안 되면 길이 증가 필요를 표시한다. 아무것도 안 바꾼 결과를 오류 해결이라고 표시하지 않는다.

## 공개 자료·재실행 범위

원평가는 덮어쓰지 않았다. [summary.json](results/summary.json)은 실제 조건별 상태 판정과 출력 해시를 공개한 파생본이며, 사례와 출력 해시를 함께 써 중복을 제거하면 18고유출력·36판정·9개 세부축 불일치를 다시 계산할 수 있다. 실제 기사·전체 재작성·근거본문·평가자의 자연어 원판정·전체 인용 목록·비공개 식별자·내부 실행 지시문은 제외했다. [sources.json](results/sources.json)은 원문 URL, 날짜 및 확보된 해시를 보존한다. 확보되지 않은 값은 null이며 새로 추정하지 않았다.

[fixtures](fixtures/)에는 자체 작성 합성 8입력과 실제 생성/기계 산출된 해당 조건의 결과만 선별했다. 공개본은 원래 전체 파일과 바이트가 같은 기록이 아니며, 해시는 명시된 원문/출력 문자열의 UTF-8 바이트를 가리킨다. 합성 입력의 근거는 가상 자료이며 실제 세계의 증거가 아니다. 원 감사의 자연어 내용과 내부 역할 식별자를 제외했으므로 합성 결과도 의미적 재실행 전체 묶음은 아니다.

이 디렉터리에서 `python -m unittest discover -s tools -p 'test_*.py' -v`로 17기계검사와 공개 결과 무결성 검사 1개를 실행하고 `python tools/verify_results.py`로 공개 분모·판정·합성 해시를 검증한다. 코드만 실행해서 새 모델실험이 재현된다고 주장하지 않는다. 원문 전체와 원시 지시문을 제외했고 모델·seed·비용도 미확인이라 최초 모델 실행의 완전 재현은 불가능하다. 별도 라이선스를 추가하지 않았으며 저장소 NOTICE를 따른다.

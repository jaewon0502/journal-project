# v9 — 발언 보존·선택적 복원과 공동 누락 감사

2026-10-01 실행 결과의 공개용 파생본. [상세 보고서](report.md), [상태별 원평가 집계](results/summary.json), [출처·날짜·해시](results/sources.json), [후속 이의](results/followup-concern.json)를 제공한다.

12입력은 이미 노출된 회귀 2·새 실제자료 2·자체 합성 8이다. 한국어 6·영어 6이며, 실제 기사 12개가 아니다. 7입력×2조건에서 실제 AI 생성 14응답을 얻었고, 복원 5입력×2조건의 10산출물은 동일 수정안과 감사에 대한 결정적 규칙 결과다. 고유출력 18개를 별도 문맥 평가자 2명이 읽은 원판정은 36개다. 기계검사 17개, 다른 모델 계열 실행 0건이다. 인간 검증이나 일반 정확도 추정으로 해석하지 않는다.

발언 조건 BASE는 일반 최소편집, NOTE는 원 발언 보존과 별도 근거 주석이다. BASE도 주석을 선택할 수 있다. 복원 WHOLE은 전체복원, SELECTIVE는 의존 묶음별 복원이다. 정상·동등·시점 대조 4입력은 각 발언 조건에서 4/4 무변경이었다. 새 한국어 자료는 정부 정책뉴스이며 독립 언론사 일반화가 아니다. 영어 자료는 CBS 기사의 정식 재게시이며 동시기 조건부 계획을 비교했다. 두 신규 목표 문장은 직접 인물 인용이 아니다.

선택적 복원은 독립 승인 수정 3개를 보존했지만 전체 사실성을 보장하지 않는다. 최종 success는 국소 과제 해결과 전체 근거 충족을 구분하지 못할 수 있다. 두 평가자의 최종 판정은 18/18 일치했으나 세부축은 126비교 중 9개가 달랐다. KO011 전체복원 주석의 적용상태 오해 가능성은 평가자 B만 지적했다. EN023 BASE는 두 평가자가 성공으로 승인했으나 후속 감사가 원래 날짜의 사건을 삭제할 근거가 부족하다고 지적했다. 원판정을 소급 변경하지 않았다. 상세 보고서는 이 한계와 남은 난제 5개의 우선순위, 기존에 확인한 연구 링크를 보존한다.

## 공개·제외 범위

- `fixtures/`: 자체 합성 8입력과 해당 조건의 실제 생성/기계 산출 결과. 원시 지시문과 자연어 평가 원문은 제외했다.
- `results/summary.json`: 실제 조건별 상태 판정과 해시. 불투명 실행 식별자 대신 사례·조건으로 연결한다. 같은 사례의 같은 출력은 동일한 두 판정을 공유하므로 조건별 행을 단순 합산하면 중복된다.
- `tools/`: 이식 가능한 선택적 복원 코드, 합성 계약검사 17개와 공개 결과 검증기. 코드의 서로 다른 역할 ID는 독립적 사고나 실제 신원의 증명이 아니다.

실제 기사 전문·전체 재작성·실제 근거 전문·전체 인용 목록·자연어 원판정·개인 정보·비공개 서비스 식별자·내부 작업 지시문·실행환경 경로를 공개하지 않는다. 원문·출력 해시는 원자료를 공개했다는 뜻이 아니다. 이 패키지만으로 원 모델 실행이나 원문 전체 감사를 재현할 수 없다. 라이선스를 새로 부여하지 않으며 [NOTICE](../../NOTICE.md)를 따른다.

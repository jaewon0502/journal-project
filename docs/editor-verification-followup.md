# 편집자 검증 도구에서 확인한 결과와 남은 일

2026년 11월 25일 기준, **실제 편집자의 검증 시간 절감률, 실제 기사 편향 감소율, 여러 매체에 걸친 기사 정확성은 아직 미측정**이다. 다음 사람이 측정을 이어갈 때 재사용할 수 있는 사례와 기준을 정리했다.

## 확인한 범위

| 대상 | 관찰 결과 |
|---|---|
| 실제 정치 기사에서 근거 찾기 | 한국일보 예비비 기사에서 과거 지출을 언급한 문장을 선택했을 때, 기존 상위 세 후보에 없던 국회예산정책처의 용도별 결산표가 첫 후보로 나왔다. PDF 54쪽의 26,901억 원은 연간 지출 합계다. 수출 규제 대응액을 확인하려면 해당 사업의 세부 지출 자료가 더 필요하다. [검색 재현 기록](../experiments/cross-party-review/reserve-uses.md) |
| 편집 시간 집계 | 가상 편집자 4명의 평균이 똑같이 100초에서 70초로 줄어도, 빨라진 두 사람이 어느 방식에서 판단 이유까지 맞혔는지는 달랐다. 진행자는 제출한 근거 위치와 풀이를 함께 볼 수 있다. [가상 응답과 결과표](../experiments/field-reason-time/README.md) |
| 편향 판정 대조 | 가상 기사 두 편 모두 두 편집자가 표현의 왜곡이 줄었다고 평가했다. 같은 기사·원자료 구절을 대조한 경우는 한 편이었다. 같은 구절에 서로 다른 심각도를 매긴 경우도 각자의 판단 이유와 함께 열 수 있다. [인용 근거 대조](../experiments/bias-citation-audit/README.md) · [단계 차이 대조](../experiments/bias-score-review/README.md) |

## 남은 일과 판단 기준

| 남은 일 | 결과를 낼 때 필요한 증거 |
|---|---|
| 실제 편집자의 시간 절감 측정 | 서로 다른 두 기사를 평소 도구와 저널로 한 번씩 검증하도록 배정한다. 같은 편집자들의 평균 시간 절감률은 **(평소 평균 − 저널 평균) ÷ 평소 평균**으로 계산한다. 두 방식에서 근거 위치·판정·이유를 모두 맞힌 인원과 시간, 오답·중도 종료에 쓴 시간, 미회신 수도 함께 보고한다. [현장 측정 절차](field-review-protocol.md) |
| 실제 기사에서 편향이 얼마나 줄었는지 평가 | 두 편집자가 원본과 수정본을 독립 채점한다. 표현·발언 귀속, 제목·도입부, 맥락 누락, 당사자별 검증 기준을 각각 0~3점으로 기록한다. 공통 개선율은 두 사람 모두 원본에서 2~3점으로 평가한 뒤 **양쪽 판본에 숫자 점수를 모두 매긴 항목 중**, 수정본을 두 사람 모두 0~1점으로 매긴 비율이다. 원본에서 중요하게 본 전체 항목의 미평가·해당 없음, 개선 가능 범위, 근거가 달랐던 수도 병기한다. 정당 이름을 바꿨을 때의 사실 채택률 격차는 별도 실험으로 측정한다. [기사 평가 기준](article-rubric.md) · [정당 표기 실험](editor-study-protocol.md) |
| 새로운 기사에서 정확성과 검증 범위 확인 | 처음 보는 매체·주제의 기사를 선정하고, 핵심 주장별 정답·원자료·허용 위치를 독립적으로 먼저 정한다. 판정한 주장 중 지지율과 전체 대상 중 판정 완료율을 함께 내고, 핵심 오류·발언 속 사실과 충돌한 근거·미결 건수를 공개한다. 현재 고용·예비비 검색 결과는 특정 기사와 공식 자료에서 검증했다. [고용 기사 재현 예시](../experiments/labour-field-review/full-article-retrieval.md) · [사실 정확성 판정표](article-rubric.md) |
| 두 과제의 실제 진행 순서 확인 | 현 버전에서는 명부의 권장 순서와 각 회신의 활동 시간만 확인할 수 있다. 두 번째 측정을 시작할 때 첫 번째 완료 회신을 연결해 진행자가 대조하는 기능은 후속 개발 과제다. 그 전까지 배정표 행 순서나 응답 파일을 불러온 순서로 실제 진행 순서를 추정하지 않는다. [교차 배정과 해석 조건](field-review-protocol.md) |

참여자 명부·개별 답안은 진행자가 비공개로 보관하고 결과를 공유할 때는 표본 수와 집계값을 사용한다. 프런티어 API용 보조 도구는 별도 로컬 프로젝트에서 저장된 모델 응답으로 시험했다. 실제 모델 호출의 정확도·비용과 편집자 시간에 미치는 효과는 별도의 측정이 필요하다.

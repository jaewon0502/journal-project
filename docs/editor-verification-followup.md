# 편집자 검증 도구의 측정 결과와 현장 실측 현황

2026년 11월 26일까지 확인한 **실제 편집자의 시간 측정 회신은 0건, 원안·수정안에 대한 편집자의 독립 평가도 0건**이다. 시간 절감률과 정치적 편향 감소율은 아직 계산할 수 없다. 현장 배포 파일을 준비했다. 아래에는 공개된 사람의 판독 기록으로 재검 비용을 비교한 결과와 실제 기사에서 근거 검색을 시험한 결과를 함께 정리했다.

| 측정 대상 | 이번에 확인한 결과 | 해석 범위 |
|---|---|---|
| 편집자 시간 절감 | 서로 다른 기사 두 편을 검증하는 4명분 배포 파일을 준비했다. 평소 도구와 저널을 한 번씩 쓴다. | 실제 완료 회신 0건. 시간과 함께 근거 위치·판정·판단 이유를 모두 맞힌 건수를 보고한다. |
| 정치적 편향 감소 | 한국일보 예비비 기사의 한 문장과 AI가 작성한 수정 제안을 두 편집자가 독립 채점할 수 있게 준비했다. 두 사람이 받는 판본 순서는 서로 반대다. | 실제 평가 0건. 점수가 들어와도 우선 해당 구절에서 확인한 변화만 보고할 수 있다. |
| 새 매체·주제의 사실 검증 | K-공감의 한강 보도와 KEYT에 실린 CNN의 보이저 1호 보도에서 사전 선정한 6개 주장을 원자료와 대조했다. 지지 4건, 미결 2건, 충돌 0건이었다. | 두 기사에서 분할한 114개 구간 중 6개만 평가했다. 기사 전체나 매체의 정확도는 이 표본으로 추정할 수 없다. [주장별 판정과 근거](../experiments/editor-holdout-20261126/README.md) |
| 과제 진행 순서 | 두 번째 타이머를 시작할 때 첫 번째 완료 파일을 연결하고, 진행자가 회수한 두 파일을 대조할 수 있다. 모의 응답 네 쌍에서 계획 순서와 같은 3명과 반대로 진행한 1명을 구별했다. | 확인되는 것은 두 파일의 연결이다. 작성자·실제 작업 시각과 타이머 밖에서 미리 읽은 시간은 인증하지 않는다. [모의 결과표](../experiments/field-reason-time/observed-order.html) |

## 편집자가 덜 입력하고 필요한 판단에 집중하는 방법

| 방법 | 직접 확인한 변화 | 적용할 때 볼 점 |
|---|---|---|
| 원문을 유지하고 원자료 언어로 검색 | 한국어 기사 4편에서 선정한 20개 주장 중, 지정 자료가 완전히 지지한 10건을 비교했다. 세 후보 안에 필수 단락이 모두 나온 것은 한국어 원문만 사용하면 2/10, 미리 작성한 영어 표현을 기존 검색창에 넣으면 8/10, 새 보조 입력란을 쓰면 8/10이었다. | 검색어는 직접 작성한다. 합성 기사로 다른 행을 검토한 뒤 같은 근거로 돌아오는 구간은 클릭 5회에서 3회, 같은 영어 재입력은 1회에서 0회로 줄었다. 첫 검색은 두 방식 모두 클릭 2회와 영어 입력 1회였다. [기사별 적중·미적중](../experiments/editor-transfer-nov26/README.md) · [클릭 수 재현](../experiments/editor-source-phrase-nov26/README.md) |
| 날짜가 필요한 주장에 자료의 게시·수정 표시 전달 | NASA 발표에서 파일의 제목·주소·날짜를 한 번에 입력했다. 같은 문단을 발췌한 뒤 세 필드를 각각 입력하던 작업이 확인 버튼 1회로 줄었다. 날짜를 제공한 별도 블라인드 AI는 기존에 판정이 갈린 ‘6월 13일 기준’도 근거와 함께 맞혔다. | 최종판은 최초 날짜 시험에 쓴 6개 페이지 재검에서 5/6, 별도로 고른 정책 페이지 2개에서 1/2의 게시일을 제안했다. 나머지는 수동 확인 대상이다. [화면 검증·날짜별 결과](../experiments/editor-web-provenance-nov26/README.md) |
| 중요 왜곡 여부가 갈린 항목만 셋째에게 전달 | BABE 연구의 1,667문장에서 둘이 다를 때만 셋째에게 물으면 항상 세 명에게 물을 때보다 요청 수가 23.2% 줄고 세 사람의 이진 다수결과 같았다. 항상 두 명에게 묻는 방식과 비교하면 요청 수가 15.3% 늘었다. | 한국어 모의 기사에서는 원안·수정안 8개 항목 중 한 명은 0~1점, 다른 한 명은 2~3점을 준 항목 1개만 별도 파일로 만들었다. 기존 두 사람의 점수와 개선율 분모는 보존한다. [재검 방법별 비용·누락과 사용법](../experiments/editor-methods-nov26/README.md) |

6개 주장을 담은 안보리 기사에서 검색을 6회에서 16회로 쪼갠 결과도 읽을 문단 수에 따라 달랐다. 원자료가 지지한 네 주장 중 필수 근거를 모두 확보한 건수는 문항당 세 문단을 읽으면 2/4에서 1/4로 줄었고, 여섯 문단을 읽으면 2/4에서 3/4로 늘었다. 복수 검색은 검토량까지 정해 시험할 필요가 있다. [문항별 검색과 열람 예산](../experiments/editor-transfer-nov26/README.md)

## 처음 두 기사에서 확인한 범위

원자료가 지지한 4개 주장 중 검색 결과 상위 3개에 필수 단락이 모두 나온 것은 **2/4(50%)**였다. 한국어 기사를 영어 노벨상 자료에서 찾은 두 건은 0/2, 영어 기사를 영어 NASA 자료에서 찾은 두 건은 2/2였다. 영어의 두 주장은 같은 NASA 단락을 근거로 삼았다. 검색 결과가 표시됐어도 특정 시점의 서점 판매량과 보이저 기기의 재교정 여부는 지정한 자료만으로 확인할 수 없었다.

정답표와 검색 결과를 보지 않은 AI 한 명에게 선정 주장과 원자료 본문을 주자, **사전 판정과 5/6건이 일치**했다. 보이저 1호의 네 기기가 과학 자료 전송을 재개했다는 내용에는 양쪽이 동의했다. 차이는 ‘6월 13일 기준’이라는 조건이었다. 사전 판정은 날짜가 표시된 NASA 발표를 사용했고, 블라인드 판독에 제공한 본문 단락에는 발표일이 빠져 있었다. [블라인드 대조와 재현 방법](../experiments/editor-holdout-20261126/README.md)

## 실제 응답이 들어오면 계산할 지표

- **시간 절감률**은 같은 편집자들의 (평소 평균 활동 시간 − 저널 평균 활동 시간) ÷ 평소 평균 활동 시간 × 100이다. 전체 비교와 두 방식에서 근거 위치·판정·이유가 모두 맞은 사람의 시간을 함께 본다. 오답·중도 종료에 쓴 시간, 미회신 인원도 기록한다. 먼저 쓴 방식과 어느 기사에 저널을 썼는지에 따른 네 조합이 균형을 이룰 때만 순서별 시간과 정답 수를 비교한다. [현장 측정 절차](field-review-protocol.md)
- **편향 개선율**은 표현·발언 귀속, 제목·도입부, 맥락 누락, 당사자별 검증 기준을 각각 0~3점으로 매긴 뒤 계산한다. 분모는 두 편집자가 원안에 모두 2~3점을 주고 수정안까지 각각 채점한 항목 수다. 분자는 그중 수정안에 두 사람 모두 0~1점을 준 항목 수다. 악화·미평가·해당 없음과 두 사람이 대조한 기사·원자료 구절도 함께 확인한다. 정당 이름만 바꿨을 때 사실 채택률이 달라지는지는 별도 실험에서 측정한다. [기사 평가 기준](article-rubric.md) · [정당 표기 실험](editor-study-protocol.md)

## 함께 볼 수 있는 이전 검산

- 한국일보 예비비 기사에서는 국회예산정책처의 용도별 결산표가 첫 후보로 나왔다. PDF 54쪽의 26,901억 원은 연간 지출 합계다. 수출 규제 대응에 쓴 금액을 확인하려면 사업별 세부 지출 자료가 더 필요하다. [예비비 검색 기록](../experiments/cross-party-review/reserve-uses.md) · [고용 기사 사례](../experiments/labour-field-review/full-article-retrieval.md)
- 가상 편집자 4명의 평균이 100초에서 70초로 줄어든 두 사례에서도, 두 방식 모두 판단 이유까지 맞힌 사람들의 시간은 각각 80초 줄거나 20초 늘었다. [두 사례의 결과표](../experiments/field-reason-time/README.md)
- 가상 기사 두 편 모두 두 평가자가 표현의 왜곡이 줄었다고 봤다. 같은 기사·원자료 구절을 근거로 삼은 경우는 한 편이었다. [인용 근거 대조](../experiments/bias-citation-audit/README.md) · [단계 차이 대조](../experiments/bias-score-review/README.md)

실제 배정명부와 개별 답안은 진행자가 비공개로 보관한다. 공개 결과에는 표본 수와 집계값을 싣는다. 별도 로컬 프로젝트의 프런티어 API 보조 도구는 저장된 모델 응답으로 시험한 단계다. 실호출 비용과 품질, 실제 편집 시간은 별도 측정 대상이다.

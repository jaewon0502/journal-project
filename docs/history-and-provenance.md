# 연구 이력과 복원 범위

이 문서는 2026년 10월 1일 확인한 파일과 이력에 근거한다. 공개용으로 정리한 코드와 새 실험 결과를 과거 원본의 완전한 복원으로 부르지 않는다.

| 구간 | 확인한 자료 | 해석의 한계 |
|---|---|---|
| 최초 원격 이력 | README 하나를 담은 초기 커밋 | 연구 코드와 실험 기록은 당시 원격에 포함되지 않았다. |
| v1–v2 | 초기 검사·실행 도구, 버전별 테스트, 본실험·회귀 결과 파일 | 로컬 연구 산출물이며 원격에 누적된 커밋 이력은 아니다. |
| 74개 출력 | 본실험 48개, 개발 회귀 6개, 합성 18개, 전이 2개의 비어 있지 않은 본문 파일 | 파일은 존재한다. 정확한 모델 배포 버전·seed·비용·실행의 독립적 증명까지 복원된 것은 아니다. |
| v3 | 수정 실험 코드·합성 입력·출력·평가 기록 | 기존 사례와 별도 합성 사례를 구분해야 한다. |
| v4 | 국소 패치 엔진, 기계 검사, 결과·평가 기록 | 바이트 보존과 rollback 검사는 의미 보존·정치적 편향 감소의 증명이 아니다. |
| v5 | 이번 확인 범위에서 해당 이름의 원본 파일을 찾지 못했다. | 외부 세션이나 저장소에도 없다고 단정하지 않으며, 원본 복원이나 재실행을 주장하지 않는다. |

74개 출력은 모두 v4의 이전 자료 잠금 목록에 포함된다. 잠금 목록의 300개 파일을 현재 파일과 SHA-256으로 대조한 결과 불일치는 없었다. 이는 현재 파일과 저장된 잠금 기록의 일치를 뜻하며, 기록 자체의 외부 공증이나 실험 품질 검증을 뜻하지 않는다. 따라서 ‘74개 원본이 모두 없다’는 설명은 현재 확인 결과와 맞지 않는다.

초기 보고서는 실행 차단·미완료 상태를, 이후 보고서는 완료한 실행을 설명한다. 문서의 작성 시점과 대상 단계를 구분해야 하며, 준비 단계의 문구를 최종 실험 상태로 읽거나 후속 결과로 과거 상태를 덮어쓰지 않는다.

공개 범위는 출처를 확인한 코드, 합성 검사와 허구의 입력 예제, 한계를 명시한 설명부터 구성한다. 비공개 서비스의 식별자·전달 영수증·환경 기록·원문 캐시·내장 전체 패키지는 공개 대상에서 제외한다. 실제 기사와 관련된 원본 출력 및 평가 자료는 파일 존재 여부와 별도로 이용 권리·인용 범위·개인정보 검토가 필요하다.

원격 점검은 인증된 조회에서 광고된 모든 ref를 대상으로 했다. 해당 범위는 단일 main 브랜치, 커밋 하나, README blob 하나였으며 태그와 pull ref는 반환되지 않았다. 이 범위의 파일 본문에서 비밀키·비공개 서비스 식별자·기사 전문·내부 지침은 발견되지 않았다. 커밋 작성자의 GitHub 계정명과 noreply 주소는 일반 Git 메타데이터에 남아 있다. 광고되지 않는 내부 ref, 삭제된 객체, 이슈·첨부파일은 이 점검 범위가 아니다.

## 후속 회차 v8·v9

위 최초 복원·원격 점검 설명은 최초 공개 준비 당시의 범위다. 현재 main에 연구 산출물이 없다는 뜻이 아니다.

- v8: 한국어30·영어30 전체기사로 개발12/평가48을 분리한 AI 내부 비교다. 모델 생성128응답(개발32·평가96), 합성 생성16응답을 별도 기록한다. 원문 조건은 생성 응답이 아니며, 동일 출력을 공유하는 조건 관측과 고유 평가 수를 분리한다.
- v9: 기존 v8 노출 회귀2, 신규 실제자료2, 합성8의 한정 보강이다. 발언 실험14생성과 결정적 복원10조건을 구분한다. 원판정의 성공표시와 이후 근거 이의를 별도로 보존하고 소급 덮어쓰지 않는다.
- v8 이전 전체 과거 사건 목록을 완전히 확인하지 못했으므로 전역 미사용을 증명하지 않는다. v9 신규자료는 확인한 v8 사건 목록과 겹치지 않는 범위이며 한국어 정부 정책뉴스·영어 정식 재게시라는 한계가 있다.

원격 최초 공개와 후속 파일 공개는 연구 실행 시점과 다르다. 공개 커밋이 실험 당시 존재했던 것처럼 서술하지 않는다.

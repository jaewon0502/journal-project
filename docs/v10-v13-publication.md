# v10~v13 연구 결과의 Git 공개

이번 변경은 기존 연구 자료의 공개용 정리입니다. 새 모델 실험이나 재채점은 수행하지 않습니다. 기존 v1~v9 코드·원평가와 별도 승인 대기인 기존 버그 수정은 포함하지 않습니다.

## 보존한 것

각 회차의 종합 보고서, 원판정의 공개 투영값·집계, 실패 재현과 사후 수정 이력, 출처 URL·수집시점·자료 범위·해시, 자체 합성 입력 및 공개 가능한 합성 출력, 최소편집·영수증·선별 코드와 회귀 검사를 포함합니다. 연구 프로토콜은 실험 입력이지 내부 대화 전사본이 아닙니다. 합성 `private`/`hidden` 파일명은 당시 작성자 기대값의 가림 상태를 뜻하며 실제 개인정보나 비공개 실기사 자료가 아닙니다.

기사·논문 전문, 실제 기사 전체 수정본, 긴 인용이 든 비공개 원판정, 인증정보, 개인 연락처, 내부 대화, Library 식별자는 게시하지 않습니다. 원자료 해시는 내용을 공개하거나 독립 진실을 증명하지 않습니다. 비공개 원본 없이 실기사 의미 판정을 완전히 재감사할 수 없습니다.

## 공개 변환과 해시

원본 Library 패키지 자체는 변경하지 않았습니다. 각 회차 `PUBLIC-DERIVATION.json`은 원 패키지 파일 해시, 최초 경로 치환본 해시, 현재 공개 파일 해시를 구분합니다. `SHA256SUMS`와 v12/v13의 `PACKAGE-MANIFEST.json`은 현재 Git 파일을 검사합니다. 원 동결 기록의 해시는 과거 원본을 가리키므로 현재 파일과 같다는 주장으로 읽으면 안 됩니다.

역사적 실행 경로는 `/historical-research/` 등 비실행 표지로 치환했습니다. v11 portable receipt 후보도 해당 경로 문자열이 달라져 공개본 해시를 별도로 결박했습니다. v10 wrapper/vendor 의존성은 원 바이트와 같습니다. 이는 경로 비식별화와 명시적 이식성 조정이며 알고리즘 수정이나 재평가가 아닙니다. 보고서의 당시 외부 게시 미실행 설명은 연구 시점의 기록입니다.

실행 불가능한 역사적 분석·수집 스크립트도 provenance용으로 보존합니다. 그런 스크립트는 경로 수정과 허가된 원자료가 필요하며 전체 실행기로 제시하지 않습니다. v12/v13 중복 ZIP과 HTML, 전송용 메타데이터는 제외하고 읽을 수 있는 Markdown·JSON·코드를 게시합니다.

## 현재 실행하는 검사

저장소 루트에서:

```sh
python -m pip install -r requirements-research.txt
python tools/run_checks.py
```

기존 검사를 유지하면서 v10 수정본 15검사 및 거부 계약 정규화를 명시한 독립 적대4검사, 합성 calibration 판정 재집계, v11 합성 영수증10재생·손상6거부·독해60/정밀도8투영/보조표16판정 집계, v11 portable 스모크10변형, v12 gate8검사·저장합성24재생, v13 gate17검사·저장합성12행 재생을 실행합니다. 과거 실패한 frozen 버전은 그 실패 기록을 보존하며 현재 성공 테스트인 것처럼 일괄 실행하지 않습니다.

이 검사는 새 AI 생성·인간 검증·실기사 원문 재검증을 수행하지 않습니다. CI 통과도 보존정보 목록의 완전성이나 기사 전체 정확성 인증이 아닙니다. 자동 코드리뷰 서비스의 실행 여부는 CI와 별도로 확인하며 미실행을 완료로 표시하지 않습니다.

## 해석에서 반드시 분리할 것

- v13 8묶음의 27제안 = 연구자 합성10 + 노출 실제 사례의 이전 모델제안17. 두 처리 방식은 같은 자료·제안·새 AI 검토를 사용합니다. 채택13은 조건부 기계 선택 결과입니다.
- 추가 신규 Reuters/Bennu 사례1건은 별도입니다. NASA 후속 수정자료와 현재 문장을 대조했으므로 당시 기자의 오류를 확정하지 않습니다.
- ‘새 중대한 해 미검출’은 동일 계열 AI의 제한된 판정입니다. 가능성→단정 강화가 허용된 실패와 별도 사후 수정은 원집계를 바꾸지 않고 함께 남겼습니다.
- v12 자료범위 비교는 노출1사례·조건별2출력(총4작성/8평가)입니다. 원자료19→62문단 확대는 입력길이 효과와 분리되지 않으며 상세 평가도구의 늦은 동결도 공개합니다.
- 분량 상한이 있는 과거 실험은 연구 설계상의 조건이며 사용자 요구가 아닙니다. v13에는 임의 상한이 없습니다.
- 정확한 배포모델·seed·비용, 인간/교차모델 검증과 일반적인 정치적 편향 감소 효과는 확보되지 않았습니다.

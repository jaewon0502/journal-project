# 검증자료 읽기

[읽기 화면](reader/index.html)은 v28까지 Git에 공개된 연구 자료를 사용합니다. 원문·수정·근거를 항목별로 연결하고, 보류 이유와 확인하지 못한 내용을 함께 보여줍니다. 새 AI 실행이나 새로운 사실 판정은 하지 않습니다.

## 열기

저장소를 내려받은 뒤 `docs/reader/index.html`을 브라우저로 여세요. HTML 안에 화면 코드와 데이터가 들어 있어 서버나 추가 설치가 필요하지 않습니다. 원자료와 상세 연구 기록의 외부 링크를 열 때는 인터넷 연결이 필요합니다. GitHub의 HTML 파일 화면 자체는 미리보기를 제공하지 않습니다.

- **자료 읽기:** 쟁점을 고르고 기사 표현·수정 또는 평가 정정·원자료 연결·미확인을 확인합니다.
- **직접 평가하기:** 개인 판단을 적고 브라우저에 저장하거나 파일로 내보냅니다. AI 판단을 봤는지와 독립성의 한계가 함께 기록됩니다.
- **원자료:** 정확히 공개된 인용, 보고서의 요약, 공개되지 않은 구절을 구별합니다. PDF는 가능한 경우 해당 쪽으로 연결하며 PDF 뷰어에 따라 쪽 이동 지원이 다를 수 있습니다.
- **연구 기록:** 회차별 원보고서, 실행·정정 기록과 기존 평가 한계를 확인합니다.

## 반영 범위

연구 기준은 `research/integrate-v15-v28`의 공개 자료입니다. v28의 재감사 정정과 직접자료 확보, 그 이전 공개 연구 이력 및 원자료·AI 검토 후속 자료를 연결했습니다. 별도 검토 중인 v14 PR #7과 원격에 게시되지 않은 v28 이후 작업은 포함하지 않습니다.

기존 사람 1명의 중요도 응답 3개는 제한된 참고 응답입니다. 원문 독해·이유·동일 평가 조건 등이 확인되지 않았으며 인간 검증이나 일반 일치율의 근거로 바꾸지 않습니다. 이 화면의 개인 기록은 그 응답에 자동 합산되지 않습니다.

자료 전문과 PDF를 재배포하지 않는 [공개 원칙](../NOTICE.md)을 유지합니다. 공개 인용이 없는 항목은 해당 위치의 원자료로 이동해 확인해야 합니다. 요약문을 기사 원문이나 실제 수정문으로 표시하지 않습니다.

## 갱신

```sh
python tools/build_reader.py
python tools/run_checks.py
```

`docs/reader-data.json`에서 항목별 근거와 표시 종류를 관리하고, 생성기가 `docs/reader/index.html`을 만듭니다. 원기록을 바꾸는 작업과 읽기 화면 갱신을 구분하세요. 연구 결과를 새로 해석하거나 의미 판정을 바꾸려면 근거와 별도 검토가 필요합니다.

브라우저 저장은 기기·브라우저·파일 열기 방식에 따라 제한되거나 지워질 수 있습니다. 중요한 개인 기록은 파일로도 내려받아 보관하세요. 저장 실패 시 내보내기를 사용할 수 있습니다. 실제 사람의 사용성 평가는 이번 구현 검사와 별개입니다.

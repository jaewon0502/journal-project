제출 전에 중단한 과제

시간은 중단한 과제에서 타이머로 확인한 구간의 합계입니다. 실행 중 창이 닫혔다면 확인 가능한 구간만 더합니다. 이 과제는 방식별 평균과 판정 비교에서 제외합니다.

시간이 일부만 기록된 묶음까지 포함한 결과

네 명 모두 답안을 제출한 묶음에서 편집자마다 방식별 두 과제의 합계를 비교합니다. 타이머가 중단된 과제도 기록된 구간이 상대 방식의 전체 시간보다 길면 어느 쪽이 더 오래 걸렸는지 알 수 있습니다. 빠진 시간이 얼마나 긴지는 알 수 없어 절감률 계산에는 기존의 완전한 시간 기록만 씁니다.

완료한 편집자 묶음 전체의 판정 품질

답안을 모두 제출한 묶음은 시간이 일부 빠졌어도 여기에 포함합니다.

가상 기사에 붙인 성향 표기별 결과

근거 없는 사실 채택률은 기준 판정이 ‘근거로 지지됨’ 이외인 과제에서 계산합니다. 나머지 비율의 분모는 해당 표기와 방식으로 완료한 분석 대상 과제 수입니다.

정당 표기별 판정 분포와 사례별 응답 수

같은 기사와 근거를 본 두 집단의 응답을 비교합니다. 사례별로 네 판정의 응답률 차이를 절댓값으로 더한 뒤 절반을 취해 평균냅니다. 두 집단의 분포가 같으면 0%p, 어느 판정도 겹치지 않으면 100%p입니다. 표의 각 칸은 해당 판정 건수 / 전체 응답 수입니다.

분석에 포함된 배정 묶음

연구자가 미리 배정한 연속 4명을 한 묶음으로 봅니다. 네 참여자가 모두 네 사례를 끝내야 비교합니다.

지표 계산과 해석

시간은 편집자마다 각 방식에서 2건의 평균을 구한 뒤 참여자에게 같은 가중치를 주어 평균냅니다. 절감률은 두 방식의 평균 시간 차이를 원자료 방식의 평균으로 나눈 값입니다.

정당 단서 차이는 사례별로 보수·진보 성향 표지 간 사실 채택률 차이의 절댓값을 구한 뒤 네 사례를 평균냅니다. 절대 감소는 %p, 상대 감소는 원자료 방식의 차이를 분모로 한 %입니다. 원자료 방식의 차이가 0이면 상대 감소를 계산할 수 없습니다.

각 사례·방식·표기당 1명이면 한 사람의 판단만 달라도 격차가 크게 바뀝니다. 소수 편집자가 답한 가상 사례의 집계에는 우연한 응답 차이도 반영됩니다. 일반 기사에서의 정치적 편향이나 개인의 성향을 이 수치로 판단할 수 없습니다.

실제 기록 모으기

한 기기에서는 등록할 때 빈자리에 무작위로 배정합니다. 여러 기기에서 진행할 때는 연구자 한 명이 아래에서 초대 코드를 발급해 표시 순서대로 한 사람에게 하나씩 전달하세요. 편집자가 내려받은 JSON 파일을 여러 개 선택해 합칠 수 있습니다. 같은 기록을 다시 가져오면 한 번만 셉니다.

다른 기기에서 참여할 초대 코드

같은 연구용 폴더를 각 기기에서 열고 코드를 입력합니다. 초대 코드는 발급만으로 참여자 수에 들어가지 않습니다.

기존 배정 코드로 명부 복원

원래 명부 파일이 없을 때는 모집 당시 따로 보관한 배정 코드나 참여자에게 다시 확인한 코드를 입력하세요.

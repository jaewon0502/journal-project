편집자 참여

제출 전에 중단한 과제

시간은 중단한 과제에서 타이머로 확인한 구간의 합계입니다. 실행 중 창이 닫혔다면 확인 가능한 구간만 더합니다. 이 과제는 방식별 평균과 판정 비교에서 제외합니다.

네 과제를 마친 편집자의 검토 시간 변화

각 편집자가 원자료와 저널로 각각 두 건을 검토하는 데 쓴 시간을 비교했습니다. 시간이 일부 빠진 과제는 확인된 시간의 합을 하한으로 씁니다. 어느 쪽이 더 오래 걸렸는지 알 수 없으면 미확정으로 표시합니다. 기사의 난이도와 표기 배정은 네 명이 모두 마친 묶음에서 균형을 이룹니다.

같은 참여자 자료를 사용한 묶음의 결과

제출한 과제에 기록된 실제 사용 판본을 기준으로 합니다.

검증 성공 1건당 시간에는 실패한 과제에 쓴 시간도 포함합니다. 판정과 대표 근거가 모두 일치하면 성공입니다.

배정 묶음별 판본 확인

사전에 배정한 판본으로 마친 묶음

예정 판본에서 확인하지 못한 답이 정당 표기 격차를 얼마나 바꿀 수 있나

처음부터 같은 판본을 배정한 네 명의 답을 대상으로 합니다. 지정한 판본에서 받은 답을 고정하고, 미제출·다른 판본·판본 미확인 회차에서 사실을 채택하거나 채택하지 않을 때 가능한 격차 감소폭을 계산합니다. 양수는 격차 감소, 음수는 증가입니다.

배정 번호별 판본과 제출 회차 확인

미제출 답에 따른 정당 표기 격차의 변화 범위

제출한 판정은 그대로 두고, 남은 각 과제에서 사실을 채택하거나 채택하지 않았을 때 가능한 격차 감소폭의 양 끝을 계산합니다. 원자료 방식의 격차에서 저널 방식의 격차를 뺀 값입니다. 이 범위는 해당 배정에 가능한 답을 비교한 것으로, 모집단의 신뢰구간은 별도 분석이 필요합니다.

시간이 일부만 기록된 묶음까지 포함한 결과

네 명 모두 답안을 제출한 묶음에서 편집자마다 방식별 두 과제의 합계를 비교합니다. 타이머가 중단된 과제도 기록된 구간이 상대 방식의 전체 시간보다 길면 어느 쪽이 더 오래 걸렸는지 알 수 있습니다. 빠진 시간이 얼마나 긴지는 알 수 없어 절감률 계산에는 기존의 완전한 시간 기록만 씁니다.

검증 결과별 시간과 성공 1건당 총투입 시간

이 편집자들의 사실 채택과 원자료 일치율을 확인할 수 있습니다.

결과별 평균은 해당 방식에서 성공하거나 실패한 제출 과제 한 건씩에 같은 비중을 줍니다. 방식에 따라 각 결과에 포함된 기사와 편집자가 다를 수 있습니다.

기사별 검토 시간과 검증 성공

제공된 원자료 검토 시간

편집자별 단계 시간

원자료를 처음 찾아 확보하는 시간은 실제 기사 검토에서 따로 잽니다.

완료한 편집자 묶음 전체의 판정 품질

답안을 모두 제출한 묶음은 시간이 일부 빠졌어도 여기에 포함합니다.

사실 채택과 원자료 일치율

첫 두 행은 편집자가 사실로 채택한 응답을 분모로 씁니다. 아래 두 행은 기준 판정이 각각 ‘반박’인 과제와 ‘근거 불충분’인 과제에서 사실로 채택한 비율입니다.

가상 기사에 붙인 성향 표기별 결과

근거 없는 사실 채택률은 기준 판정이 ‘근거로 지지됨’ 이외인 과제에서 계산합니다. 나머지 비율의 분모는 해당 표기와 방식으로 완료한 분석 대상 과제 수입니다.

기사별 정당 표기 격차와 검증 정확도

각 모의 기사의 두 표기를 서로 다른 편집자에게 배정합니다. 기사를 펼치면 실제로 고른 판정과 실험의 기준 자료를 대조할 수 있습니다. 각 칸의 분모는 해당 방식과 표기로 기사를 검토한 응답 수입니다.

정당 표기별 판정 분포와 사례별 응답 수

같은 기사와 근거를 본 두 집단의 응답을 비교합니다. 사례별로 네 판정의 응답률 차이를 절댓값으로 더한 뒤 절반을 취해 평균냅니다. 두 집단의 분포가 같으면 0%p, 어느 판정도 겹치지 않으면 100%p입니다. 표의 각 칸은 해당 판정 건수 / 전체 응답 수입니다.

분석에 포함된 배정 묶음

연구자가 미리 배정한 연속 4명을 한 묶음으로 봅니다. 네 참여자가 모두 네 사례를 끝내야 비교합니다.

지표 계산과 해석

시간은 편집자마다 각 방식에서 2건의 평균을 구한 뒤 참여자에게 같은 가중치를 주어 평균냅니다. 절감률은 두 방식의 평균 시간 차이를 원자료 방식의 평균으로 나눈 값입니다.

정당 단서 차이는 사례별로 보수·진보 성향 표지 간 사실 채택률 차이의 절댓값을 구한 뒤 네 사례를 평균냅니다. 절대 감소는 %p, 상대 감소는 원자료 방식의 차이를 분모로 한 %입니다. 원자료 방식의 차이가 0이면 상대 감소를 계산할 수 없습니다.

각 사례·방식·표기당 1명이면 한 사람의 판단만 달라도 격차가 크게 바뀝니다. 소수 편집자가 답한 가상 사례의 집계에는 우연한 응답 차이도 반영됩니다. 일반 기사에서의 정치적 편향이나 개인의 성향을 이 수치로 판단할 수 없습니다.

실제 기록 모으기

한 기기에서는 등록할 때 빈자리에 무작위로 배정합니다. 여러 기기에서 진행할 때는 연구자 한 명이 아래에서 초대 코드를 발급해 표시 순서대로 한 사람에게 하나씩 전달하세요. 편집자가 내려받은 JSON 파일을 여러 개 선택해 합칠 수 있습니다. 같은 기록을 다시 가져오면 한 번만 셉니다.

다른 기기에서 참여할 초대 코드

코드를 발급한 뒤 각 행에서 ‘코드 복사’를 누르고 실험에 사용할 참여자 ZIP과 함께 한 사람에게 전달하세요. 초대만 받은 사람은 등록 인원에 포함되지 않습니다.

기존 배정 코드로 명부 복원

원래 명부 파일이 없을 때는 모집 당시 따로 보관한 배정 코드나 참여자에게 다시 확인한 코드를 입력하세요.

참여 화면

공유용 JSON에는 인원·과제 수와 전체·판본별 결과만 담습니다. ‘모은 기록 내려받기’는 명부·초대 코드와 개인별 답변을 포함한 진행자용 백업입니다. 완성된 묶음이 없으면 효과 지표는 미측정으로 남습니다.

편집자 검토 과제

가상 기사 4건을 검토합니다. 각 기사의 판단과 대표 근거 하나를 기록하세요.

참여 등록

공용 기기에서는 등록하면 자동 배정됩니다. 다른 기기로 참여하는 경우 연구자에게 받은 초대 코드를 입력하세요. 이름과 연락처는 수집하지 않습니다. 결과는 이 브라우저에 저장되며 JSON으로 내려받아 직접 전달할 수 있습니다.

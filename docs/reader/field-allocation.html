저장소에서 배포본을 만들려면 Python 3.11과 Node.js가 있는 컴퓨터에서 저장소 폴더를 열고 python3 tools/build_facilitator_pack.py를 실행하세요. 결과는 다운로드 폴더의 Journal-편집자-파일럿/진행자용/집계도구.zip에 저장됩니다.

참여자 ZIP의 blind-tasks.json 또는 진행자 폴더의 ‘참여 과제’에서 고르세요.

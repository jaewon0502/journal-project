# 공개 검토 범위

최초 공개 준비 당시 원격 저장소의 이력은 초기 README를 가진 main 커밋 하나였으며, 다른 원격 branch·tag·PR·release는 확인되지 않았습니다. 공개를 위해 기존 이력을 삭제하거나 다시 쓰지 않았습니다.

이번 변경은 별도 작업 트리에서 필요한 자료만 선별했습니다. 원문 전문 HTML·PDF·본문 packet, 비공개 서비스 식별자·링크, 인증정보, 실행환경 절대경로, 내부 대화와 작업 지시문은 복사하지 않습니다. 문서의 연구 절차와 공개용 코드 사용법은 내부 시스템 지시문과 구분합니다.

공개 데이터는 원래 출력·평가에서 선별·정리한 파생본입니다. 원평가를 새로운 성공 기준으로 덮어쓰지 않으며, 미확인·실패·부적격 대조와 사후 정정 이유를 유지합니다. 원본의 해시가 제공되더라도 원본 내용 자체를 공개한 것은 아닙니다.

검증은 공개 파일의 민감 패턴 검사, 회차별 산술 집계/무결성/회귀 검사, 작성과 분리한 최종 내용 검토를 포함합니다. 자동 패턴 검사는 모든 개인정보·저작물·비밀을 탐지하는 보장이 아닙니다. 원문 파일을 제외했으므로 모델 실행의 완전 재현과 최초 원자료 전체 감사는 공개 검사의 범위 밖입니다.

최초 공개에는 기존 74출력 및 후속 수정 기록 중 그때 실제 복구한 자료만 포함했습니다. 당시 v5 전체 보고서는 확보하지 못했으며, 다른 회차로 대체하거나 복구했다고 주장하지 않았습니다. v6·v7은 별도 회차입니다. 이번 후속 공개도 v5 원본 복구를 추가 주장하지 않습니다.

## v8·v9 후속 공개

v8·v9는 최초 공개 이후 추가한 회차다. v8의 언어별 결과·출처/hash와 v9의 한정된 보강·같은 출력의 별도 AI 판정·남은 실패를 공개용으로 선별했다. 원문 전문과 전체 재작성, 자연 기사 원판정의 긴 인용, 입력 packet, 실제 실행의 작업 지시문과 내부 식별자는 제외한다. 합성 입력과 허구의 결과, 기계적 검사, 공개용 집계는 실제 기사 성능과 구분한다.

공개용 경로/식별자 정리는 원평가의 의미 판정이나 분모 변경이 아니다. 새 문맥에 지시하는 원래 모델 실행은 공개 코드가 자동 재현하지 않는다. 기계검사·공개 집계 재검증과 모델실험 재실행을 혼동하지 않는다. 전체기사 본문을 확보하지 못하는 환경에서는 원문 수준의 의미 감사를 완전히 재현할 수 없다.

이번 변경은 기존 patch_engine.py와 score_T.py의 별도 리뷰 수정은 포함하지 않는다. v8·v9는 자체 명시된 검사 경로를 사용했다. 라이선스 선택이나 저장소 설정 변경도 포함하지 않는다.

## 원자료·AI 평가 후속 공개

[후속 패키지](../experiments/source-evidence-ai-review/)는 2026-10-03 실행의 선별 파생본이다. 법원 3사건의 자료 확보·후속 작업답안과, 재사용 한국은행 발표문의 AI 검토를 분리한다. 원문 전문·추출·직접 인용 필드·원문 우선 선정의 전체 본문·인간 원응답·내부 작업 메시지는 제외한다. 인간 피드백은 비식별 부분 응답의 사후 참고 대조만 제공한다.

공개 CI는 저장 판정 집계와 수정 문구의 후속 입력 연결을 검사한다. 해시26·근거55 및 해시35·인용172의 로컬 원자료 검사는 보관값으로 구분한다. 원보관 번들이 있을 때만 별도 원자료 검사기를 실행할 수 있다. 공개 준비에서는 변경 ID 집합만 보던 누락과 집계 오류 시 정상 종료하던 누락을 새 검사기에 보완했으며, 과거 실험 점수는 변경하지 않는다.

## v14 후속 보완

[새 패키지](../experiments/v14-followup/)는 제공된 v14 HTML의 보완 요구를 구현한 별도 작업이다. 원본 v14 실행 자료가 없어 과거 점수·실행의 복구를 주장하지 않는다. 새 가상 원자료·기사 통제 입력은 공개하며, 두 AI의 실제 판정과 동일 사례의 적응적 연결 시연을 기록한다. 기존 문맥 재사용·동일 모델 계열·작은 합성 표본이라는 한계도 공개한다.

재확보한 기사 전문·PDF·추출본, 내부 대화·실행환경 경로는 제외했다. 원문 P3 비교의 전체 입력은 비공개이며 공개본에는 최소 문구 변경·해시·범위와 저장된 AI 의견만 있다. 원본 HTML을 그대로 복제하지 않고 공개된 P3 제안·짧은 인용을 이용한 새 평가 양식을 제공한다. 브라우저 검사 입력은 합성 UI 자료이며 사람 연구 응답이 아니다. 공개 CI는 Python 회귀·저장 기록 재집계만 실행한다.
